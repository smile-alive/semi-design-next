**Props**

| 属性        | 说明                                                        | 类型             | 默认值      |
| ----------- | ----------------------------------------------------------- | ---------------- | ----------- |
| link        | 头部的 href 链接，传入时头部内容包裹在 a 标签中。           | `string`         | `undefined` |
| linkOptions | 透传给 a 标签的属性。                                       | `NavLinkOptions` | `undefined` |
| text        | Logo 文案；收起后文案隐藏，此时它作为头部链接的可访问名称。 | `string`         | `undefined` |

**Events**

| 事件 | 说明 | 回调参数 |
| ---- | ---- | -------- |
| 无   |      |          |

**Slots**

| 插槽    | 说明             | 作用域参数 |
| ------- | ---------------- | ---------- |
| default | 头部的其他内容。 | `any`      |
| logo    | Logo。           | `any`      |
| text    | 替换 Logo 文案。 | `any`      |

**Exposes**

| 名称 | 说明 | 类型 |
| ---- | ---- | ---- |
