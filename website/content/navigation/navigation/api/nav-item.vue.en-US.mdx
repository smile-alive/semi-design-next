**Props**

| Property         | Description                                                                                 | Type                | Default     |
| ---------------- | ------------------------------------------------------------------------------------------- | ------------------- | ----------- |
| disabled         | Whether the item is disabled.                                                               | `boolean`           | `undefined` |
| indent           | Whether to keep the icon's space when there is no icon. Applies to the first level only.    | `number \| boolean` | `undefined` |
| isCollapsed      | Whether the item is collapsed, combined with the collapsed state of the Nav.                | `boolean`           | `undefined` |
| itemKey          | Unique key of the item.                                                                     | `ItemKey`           | `undefined` |
| level            | Nesting level of the item. Determines the indentation when limitIndent is false.            | `number`            | `undefined` |
| link             | href of the item. When given the item renders as an a element.                              | `string`            | `undefined` |
| linkOptions      | Attributes passed to the a element.                                                         | `NavLinkOptions`    | `undefined` |
| text             | Text of the item and part of the click payload. The #text slot replaces what is shown.      | `string \| number`  | `undefined` |
| tooltipHideDelay | Delay in milliseconds before this item's Tooltip hides. Wins over the same prop of the Nav. | `number`            | `undefined` |
| tooltipShowDelay | Delay in milliseconds before this item's Tooltip shows. Wins over the same prop of the Nav. | `number`            | `undefined` |

**Events**

| Event | Description                                                                                      | Callback parameters    |
| ----- | ------------------------------------------------------------------------------------------------ | ---------------------- |
| click | Emitted when the item is clicked. The payload holds itemKey, text and the native event domEvent. | `[data: SelectedData]` |

**Slots**

| Slot       | Description                                                          | Scope parameters |
| ---------- | -------------------------------------------------------------------- | ---------------- |
| icon       | Icon of the item.                                                    | `any`            |
| text       | Replaces the text shown for the item.                                | `any`            |
| toggleIcon | Icon at the toggle position, which Nav's toggleIconPosition decides. | `any`            |
