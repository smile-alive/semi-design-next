**Props**

| Property         | Description                                                                                                                                                                              | Type                                                                                          | Default |
| ---------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------- | ------- |
| children         | Children of the sub navigation, such as `Nav.Item`, rendered in the expanded list.                                                                                                       | `ReactNode`                                                                                   | -       |
| className        | Has no effect; the class name of the outer element is fixed by the component.                                                                                                            | `string`                                                                                      | -       |
| classNames       | Class names of the inner parts, keyed by `dropdown` (the popup content `.semi-dropdown`); merged with the built-in classes.                                                              | <ApiType detail={"Partial\u003cRecord\u003cSubNavPart, string>>"}>Type</ApiType>              | -       |
| disabled         | Whether the sub navigation is disabled. Defaults to `false`.                                                                                                                             | `boolean`                                                                                     | -       |
| dropdownProps    | Props of the popup Dropdown, used in horizontal mode and when collapsed. Takes precedence over `subDropdownProps`.                                                                       | `DropdownProps`                                                                               | -       |
| expandIcon       | Expand arrow icon. The default arrow is used when it is not set.                                                                                                                         | `React.ReactNode`                                                                             | -       |
| icon             | Icon of the sub navigation.                                                                                                                                                              | `React.ReactNode`                                                                             | -       |
| indent           | Whether to keep the icon's space when there is no icon. Applies to the first level only. Defaults to `false`.                                                                            | `boolean`                                                                                     | -       |
| itemKey          | Unique key of the sub navigation. `openKeys` and `selectedKeys` match it.                                                                                                                | `string \| number`                                                                            | -       |
| level            | Nesting depth of the item, which sets the indentation when `limitIndent` is `false`. Items from `items` set it automatically; a `Nav.Sub` written by hand must pass it. Defaults to `0`. | `number`                                                                                      | -       |
| onMouseEnter     | Called when the pointer enters the sub navigation. The event is on the `li`.                                                                                                             | <ApiType detail={"React.MouseEventHandler\u003cHTMLLIElement>"}>Type</ApiType>                | -       |
| onMouseLeave     | Called when the pointer leaves the sub navigation. The event is on the `li`.                                                                                                             | <ApiType detail={"React.MouseEventHandler\u003cHTMLLIElement>"}>Type</ApiType>                | -       |
| ref              | Reference to the outer `li` element of the sub navigation.                                                                                                                               | <ApiType detail={"React.Ref\u003cHTMLLIElement>"}>Type</ApiType>                              | -       |
| style            | Style of the outermost `li` of the sub navigation.                                                                                                                                       | `CSSProperties`                                                                               | -       |
| styles           | Inline styles of the inner parts, keyed like `classNames`; `dropdown` takes precedence over the `style` in `dropdownProps`.                                                              | <ApiType detail={"Partial\u003cRecord\u003cSubNavPart, React.CSSProperties>>"}>Type</ApiType> | -       |
| subDropdownProps | Props of the popup Dropdown, used when `dropdownProps` is not given.                                                                                                                     | `DropdownProps`                                                                               | -       |
| text             | Title text of the sub navigation, a string or a node.                                                                                                                                    | `React.ReactNode`                                                                             | -       |
