import ApiType from '#/components/ApiType.astro';

**Props**

| Property         | Description                                                                                                                                                           | Type                                                                                                      | Default |
| ---------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------- | ------- |
| classNames       | Class names of the inner parts, keyed by `dropdown` (the popup content `.semi-dropdown`); merged with the built-in classes.                                           | <ApiType detail={"Partial\u003cRecord\u003cSubNavPart, string>>"}>Type</ApiType>                          | -       |
| disabled         | Whether the sub navigation is disabled.                                                                                                                               | `boolean`                                                                                                 | -       |
| dropdownProps    | Props of the popup Dropdown, used in horizontal mode and when collapsed. Takes precedence over `subDropdownProps`.                                                    | `DropdownProps`                                                                                           | -       |
| expandIcon       | Expand arrow icon.                                                                                                                                                    | `JSX.Element`                                                                                             | -       |
| icon             | Icon of the sub navigation.                                                                                                                                           | `JSX.Element`                                                                                             | -       |
| indent           | Whether to keep the icon's space when there is no icon. Applies to the first level only.                                                                              | `boolean`                                                                                                 | -       |
| itemKey          | Unique key of the sub navigation. `openKeys` and `selectedKeys` match it.                                                                                             | `ItemKey`                                                                                                 | -       |
| level            | Nesting depth of the item, which sets the indentation when `limitIndent` is `false`. Items from `items` set it automatically; a Nav.Sub written by hand must pass it. | `number`                                                                                                  | -       |
| styles           | Inline styles of the inner parts, keyed like `classNames`, as style objects or strings; `dropdown` takes precedence over the `style` in `dropdownProps`.              | <ApiType detail={"Partial\u003cRecord\u003cSubNavPart, JSX.CSSProperties \u007c string>>"}>Type</ApiType> | -       |
| subDropdownProps | Props of the popup Dropdown, used when `dropdownProps` is not given.                                                                                                  | `DropdownProps`                                                                                           | -       |
| text             | Title text of the sub navigation, a string or JSX.                                                                                                                    | `JSX.Element`                                                                                             | -       |
