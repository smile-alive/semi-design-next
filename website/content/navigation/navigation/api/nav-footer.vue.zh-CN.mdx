**Props**

| 属性           | 说明                                                                                 | 类型      | 默认值  |
| -------------- | ------------------------------------------------------------------------------------ | --------- | ------- |
| collapseButton | 是否展示底部的收起侧边栏按钮，仅 mode 为 vertical 且 Footer 没有默认插槽内容时有效。 | `boolean` | `false` |

**Events**

| 事件 | 说明 | 回调参数 |
| ---- | ---- | -------- |
| 无   |      |          |

**Slots**

| 插槽           | 说明                                                                           | 作用域参数                 |
| -------------- | ------------------------------------------------------------------------------ | -------------------------- |
| default        | 底部内容；有内容时不显示收起按钮。                                             | `any`                      |
| collapseButton | 替换内置的收起按钮；提供时无需设置 collapseButton 属性，显示条件与该属性相同。 | `any`                      |
| collapseText   | 内置收起按钮的文案，接收 collapsed；只含文本时也作为图标按钮的可访问名称。     | `NavCollapseTextSlotProps` |
