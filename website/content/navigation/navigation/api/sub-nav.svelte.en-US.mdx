import ApiType from '#/components/ApiType.astro';

**Props**

| Property         | Description                                                                                                                         | Type                                                                                 | Default |
| ---------------- | ----------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------ | ------- |
| children         | The `NavItem` and `SubNav` entries of the sub navigation.                                                                           | `Snippet`                                                                            | -       |
| classNames       | Class names of the inner parts, keyed by `dropdown` (the popup content `.semi-dropdown`); merged with the built-in classes.         | <ApiType detail={"Partial\u003cRecord\u003cSubNavPart, ClassValue>>"}>Type</ApiType> | -       |
| disabled         | Whether the sub navigation is disabled.                                                                                             | `boolean`                                                                            | -       |
| dropdownProps    | Props of the popup Dropdown, used in horizontal mode and when collapsed.                                                            | `SubDropdownProps`                                                                   | -       |
| expandIcon       | Expand arrow icon. The parameter holds size and the class to put on the icon element.                                               | <ApiType detail={"Snippet\u003c[NavExpandIconArgs]>"}>Type</ApiType>                 | -       |
| icon             | Icon of the sub navigation. The parameter holds size.                                                                               | <ApiType detail={"Snippet\u003c[NavIconArgs]>"}>Type</ApiType>                       | -       |
| indent           | Whether to keep the icon's space when there is no icon. Applies to the first level only.                                            | `boolean`                                                                            | -       |
| itemKey          | Unique key of the sub navigation.                                                                                                   | `ItemKey`                                                                            | -       |
| label            | Replaces the title text shown. Named `label` because `text` is already a prop.                                                      | `Snippet`                                                                            | -       |
| level            | Nesting level of the item. Determines the indentation when limitIndent is false. The SubNav above gives it, so this only overrides. | `number`                                                                             | -       |
| styles           | Inline style strings of the inner parts, keyed like `classNames`; `dropdown` wins over the style in dropdownProps.                  | <ApiType detail={"Partial\u003cRecord\u003cSubNavPart, string>>"}>Type</ApiType>     | -       |
| subDropdownProps | Props of the popup Dropdown, used when dropdownProps is not given.                                                                  | `SubDropdownProps`                                                                   | -       |
| text             | Title text of the sub navigation. The `label` snippet replaces what is shown.                                                       | `string \| number`                                                                   | -       |
