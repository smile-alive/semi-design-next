**Props**

| Property         | Description                                                                                                                 | Type                                                                                   | Default     |
| ---------------- | --------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------- | ----------- |
| classNames       | Class names of the inner parts, keyed by `dropdown` (the popup content `.semi-dropdown`); merged with the built-in classes. | <ApiType detail={"Partial\u003cRecord\u003c\"dropdown\", ClassValue>>"}>Type</ApiType> | `undefined` |
| disabled         | Whether the sub navigation is disabled.                                                                                     | `boolean`                                                                              | `undefined` |
| dropdownProps    | Props of the popup Dropdown, used in horizontal mode and when collapsed.                                                    | `SubDropdownProps`                                                                     | `undefined` |
| indent           | Whether to keep the icon's space when there is no icon. Applies to the first level only.                                    | `boolean`                                                                              | `undefined` |
| itemKey          | Unique key of the sub navigation.                                                                                           | `ItemKey`                                                                              | `undefined` |
| level            | Nesting level of the item. Determines the indentation when limitIndent is false.                                            | `number`                                                                               | `undefined` |
| styles           | Inline styles of the inner parts, keyed like `classNames`; `dropdown` wins over the style in dropdownProps.                 | <ApiType detail={"Partial\u003cRecord\u003c\"dropdown\", StyleValue>>"}>Type</ApiType> | `undefined` |
| subDropdownProps | Props of the popup Dropdown, used when dropdownProps is not given.                                                          | `SubDropdownProps`                                                                     | `undefined` |
| text             | Title text of the sub navigation. The #text slot replaces what is shown.                                                    | `string \| number`                                                                     | `undefined` |
