**Props**

| 属性             | 说明                                                                                   | 类型                                                                                   | 默认值      |
| ---------------- | -------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------- | ----------- |
| classNames       | 内部各部位的类名，键为 `dropdown`（弹层内容 `.semi-dropdown`），与组件自带的类名合并。 | <ApiType detail={"Partial\u003cRecord\u003c\"dropdown\", ClassValue>>"}>Type</ApiType> | `undefined` |
| disabled         | 是否禁用。                                                                             | `boolean`                                                                              | `undefined` |
| dropdownProps    | 弹层 Dropdown 的参数，水平模式与收起状态下使用。                                       | `SubDropdownProps`                                                                     | `undefined` |
| indent           | 没有图标时是否保留其占位，仅对一级导航生效。                                           | `boolean`                                                                              | `undefined` |
| itemKey          | 子导航的唯一标识。                                                                     | `ItemKey`                                                                              | `undefined` |
| level            | 当前项所在的嵌套层级，limitIndent 为 false 时用于确定缩进。                            | `number`                                                                               | `undefined` |
| styles           | 内部各部位的内联样式，键同 `classNames`；`dropdown` 优先于 dropdownProps 中的 style。  | <ApiType detail={"Partial\u003cRecord\u003c\"dropdown\", StyleValue>>"}>Type</ApiType> | `undefined` |
| subDropdownProps | 弹层 Dropdown 的参数，未传 dropdownProps 时生效。                                      | `SubDropdownProps`                                                                     | `undefined` |
| text             | 子导航标题文案；显示的内容可用 #text 插槽替换。                                        | `string \| number`                                                                     | `undefined` |
