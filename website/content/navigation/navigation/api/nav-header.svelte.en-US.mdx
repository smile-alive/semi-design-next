**Props**

| Property    | Description                                                                 | Type               | Default |
| ----------- | --------------------------------------------------------------------------- | ------------------ | ------- |
| children    | Other content of the header.                                                | `Snippet`          | -       |
| link        | href of the header. When given the header content sits inside an a element. | `string`           | -       |
| linkOptions | Attributes passed to the a element.                                         | `NavLinkOptions`   | -       |
| logo        | Logo.                                                                       | `Snippet`          | -       |
| text        | Logo text. It is hidden when collapsed, and then names the header link.     | `string \| number` | -       |
