import ApiType from '#/components/ApiType.astro';

**Props**

| Property         | Description                                                                                                                         | Type                                                            | Default |
| ---------------- | ----------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------- | ------- |
| disabled         | Whether the item is disabled.                                                                                                       | `boolean`                                                       | -       |
| icon             | Icon of the item. The parameter holds size.                                                                                         | <ApiType detail={"Snippet\u003c[NavIconArgs]>"}>Type</ApiType>  | -       |
| indent           | Whether to keep the icon's space when there is no icon. Applies to the first level only.                                            | `boolean \| number`                                             | -       |
| isCollapsed      | Whether the item is collapsed, combined with the collapsed state of the Nav.                                                        | `boolean`                                                       | -       |
| itemKey          | Unique key of the item.                                                                                                             | `ItemKey`                                                       | -       |
| label            | Replaces the text shown for the item. Named `label` because `text` is already a prop.                                               | `Snippet`                                                       | -       |
| level            | Nesting level of the item. Determines the indentation when limitIndent is false. The SubNav above gives it, so this only overrides. | `number`                                                        | -       |
| link             | href of the item. When given the item renders as an a element.                                                                      | `string`                                                        | -       |
| linkOptions      | Attributes passed to the a element.                                                                                                 | `NavLinkOptions`                                                | -       |
| onClick          | Called when the item is clicked, with itemKey, text and the native event domEvent. The native `onclick` still reaches the li.       | <ApiType detail={"(data: SelectedData) => void"}>Type</ApiType> | -       |
| text             | Text of the item and part of the click payload. The `label` snippet replaces what is shown.                                         | `string \| number`                                              | -       |
| toggleIcon       | Icon at the toggle position, which Nav's toggleIconPosition decides. The parameter holds size.                                      | <ApiType detail={"Snippet\u003c[NavIconArgs]>"}>Type</ApiType>  | -       |
| tooltipHideDelay | Delay in milliseconds before this item's Tooltip hides. Wins over the same prop of the Nav.                                         | `number`                                                        | -       |
| tooltipShowDelay | Delay in milliseconds before this item's Tooltip shows. Wins over the same prop of the Nav.                                         | `number`                                                        | -       |
