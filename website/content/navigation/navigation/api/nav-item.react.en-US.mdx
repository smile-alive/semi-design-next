import ApiType from '#/components/ApiType.astro';

**Props**

| Property         | Description                                                                                                                                                              | Type                                                                                  | Default |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------- | ------- |
| className        | Custom class name of the item. It replaces the default `semi-navigation-item-normal`.                                                                                    | `string`                                                                              | -       |
| disabled         | Whether the item is disabled. A disabled item can still take focus, but activating it has no effect. Defaults to `false`.                                                | `boolean`                                                                             | -       |
| forwardRef       | Receives the `li` element of the item. It runs together with `ref`.                                                                                                      | <ApiType detail={"(ele: HTMLLIElement) => void"}>Type</ApiType>                       | -       |
| icon             | Icon of the item. A Semi icon without a size of its own is shown at the size of the item.                                                                                | `React.ReactNode`                                                                     | -       |
| indent           | Whether to keep the icon's space when there is no icon. Applies to the first level only. Defaults to `false`.                                                            | `boolean \| number`                                                                   | -       |
| isCollapsed      | When `true`, the item is shown as collapsed and its text is given by a Tooltip. It is combined with the collapsed state of the navigation by OR.                         | `boolean`                                                                             | -       |
| isSubNav         | Whether the item is the title of a sub navigation. `Nav.Sub` sets it internally; a hand-written `Nav.Item` does not need it.                                             | `boolean`                                                                             | -       |
| itemKey          | Unique key of the item.                                                                                                                                                  | `ItemKey`                                                                             | -       |
| level            | Nesting depth of the item, which sets the indentation when `limitIndent` is `false`. Items from `items` set it automatically; a `Nav.Item` written by hand must pass it. | `number`                                                                              | -       |
| link             | `href` of the item. When given, the item renders as a link.                                                                                                              | `string`                                                                              | -       |
| linkOptions      | Attributes passed to the link, such as `target`, `rel` and `onClick`.                                                                                                    | <ApiType detail={"React.AnchorHTMLAttributes\u003cHTMLAnchorElement>"}>Type</ApiType> | -       |
| onClick          | Called when the item is clicked. The data holds `itemKey` and `text`; `domEvent` is the native event.                                                                    | <ApiType detail={"(clickItems: SelectedData) => void"}>Type</ApiType>                 | -       |
| onMouseEnter     | Called when the pointer enters the item. The event is on the `li`.                                                                                                       | <ApiType detail={"React.MouseEventHandler\u003cHTMLLIElement>"}>Type</ApiType>        | -       |
| onMouseLeave     | Called when the pointer leaves the item. The event is on the `li`.                                                                                                       | <ApiType detail={"React.MouseEventHandler\u003cHTMLLIElement>"}>Type</ApiType>        | -       |
| ref              | Reference to the `li` element of the item; inside a collapsed or horizontal popup, to the `li` of the `Dropdown.Item`.                                                   | <ApiType detail={"React.Ref\u003cHTMLLIElement>"}>Type</ApiType>                      | -       |
| style            | Style of the item's `li` element.                                                                                                                                        | `CSSProperties`                                                                       | -       |
| tabIndex         | `tabindex` of the link or button that takes focus.                                                                                                                       | `number`                                                                              | -       |
| text             | Text of the item, a string or a node.                                                                                                                                    | `React.ReactNode`                                                                     | -       |
| toggleIcon       | Icon at the toggle position, which the `toggleIconPosition` of `Nav` decides.                                                                                            | `React.ReactNode`                                                                     | -       |
| tooltipHideDelay | Delay in milliseconds before this item's Tooltip hides. Wins over the same prop of `Nav`. Applies when collapsed.                                                        | `number`                                                                              | -       |
| tooltipShowDelay | Delay in milliseconds before this item's Tooltip shows. Wins over the same prop of `Nav`. Applies when collapsed.                                                        | `number`                                                                              | -       |
