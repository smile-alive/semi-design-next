**Props**

| 属性             | 说明                                                             | 类型                | 默认值      |
| ---------------- | ---------------------------------------------------------------- | ------------------- | ----------- |
| disabled         | 是否禁用。                                                       | `boolean`           | `undefined` |
| indent           | 没有图标时是否保留其占位，仅对一级导航生效。                     | `number \| boolean` | `undefined` |
| isCollapsed      | 是否收起，与 Nav 的收起状态取并集。                              | `boolean`           | `undefined` |
| itemKey          | 导航项的唯一标识。                                               | `ItemKey`           | `undefined` |
| level            | 当前项所在的嵌套层级，limitIndent 为 false 时用于确定缩进。      | `number`            | `undefined` |
| link             | 导航项的 href 链接，传入时导航项渲染为 a 标签。                  | `string`            | `undefined` |
| linkOptions      | 透传给 a 标签的属性。                                            | `NavLinkOptions`    | `undefined` |
| text             | 导航项文案，也是点击事件的载荷；显示的内容可用 #text 插槽替换。  | `string \| number`  | `undefined` |
| tooltipHideDelay | 此导航项 Tooltip 隐藏的延迟，优先于 Nav 的同名属性，单位为毫秒。 | `number`            | `undefined` |
| tooltipShowDelay | 此导航项 Tooltip 显示的延迟，优先于 Nav 的同名属性，单位为毫秒。 | `number`            | `undefined` |

**Events**

| 事件  | 说明                                                         | 回调参数               |
| ----- | ------------------------------------------------------------ | ---------------------- |
| click | 点击导航项时触发，载荷含 itemKey、text 与原生事件 domEvent。 | `[data: SelectedData]` |

**Slots**

| 插槽       | 说明                                                              | 作用域参数 |
| ---------- | ----------------------------------------------------------------- | ---------- |
| icon       | 导航项图标。                                                      | `any`      |
| text       | 替换导航项显示的文案。                                            | `any`      |
| toggleIcon | 展开收起图标位置上的图标，位置由 Nav 的 toggleIconPosition 决定。 | `any`      |
