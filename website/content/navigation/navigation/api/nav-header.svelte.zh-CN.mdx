**Props**

| 属性        | 说明                                                        | 类型               | 默认值 |
| ----------- | ----------------------------------------------------------- | ------------------ | ------ |
| children    | 头部的其他内容。                                            | `Snippet`          | -      |
| link        | 头部的 href 链接，传入时头部内容包裹在 a 标签中。           | `string`           | -      |
| linkOptions | 透传给 a 标签的属性。                                       | `NavLinkOptions`   | -      |
| logo        | Logo。                                                      | `Snippet`          | -      |
| text        | Logo 文案；收起后文案隐藏，此时它作为头部链接的可访问名称。 | `string \| number` | -      |
