**Props**

| 属性        | 说明                                                                                                      | 类型                                                                                    | 默认值 |
| ----------- | --------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------- | ------ |
| children    | 头部的其他内容。                                                                                          | `Snippet`                                                                               | -      |
| classNames  | 内部各部位的类名，键为 `logo`、`text`、`link`（设置 `link` 后包住头部内容的链接），与组件自带的类名合并。 | <ApiType detail={"Partial\u003cRecord\u003cNavHeaderPart, ClassValue>>"}>Type</ApiType> | -      |

| linkOptions | 透传给 a 标签的属性。                                                                                     | `NavLinkOptions`                                                                        | -      |
| logo        | Logo。                                                                                                    | `Snippet`                                                                               | -      |
| styles      | 内部各部位的内联样式字符串，键同 `classNames`。                                                           | <ApiType detail={"Partial\u003cRecord\u003cNavHeaderPart, string>>"}>Type</ApiType>     | -      |
| text        | Logo 文案；收起后文案隐藏，此时它作为头部链接的可访问名称。                                               | `string \| number`                                                                      | -      |
