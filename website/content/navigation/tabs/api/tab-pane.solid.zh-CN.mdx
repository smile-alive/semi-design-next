**Props**

| 属性     | 说明                                                  | 类型          | 默认值 |
| -------- | ----------------------------------------------------- | ------------- | ------ |
| children | 面板内容。                                            | `JSX.Element` | -      |
| closable | 是否允许关闭该标签页，关闭时触发 Tabs 的 onTabClose。 | `boolean`     | -      |
| disabled | 是否禁用该标签页。                                    | `boolean`     | -      |
| icon     | 标签栏中该标签的图标，由 Tabs 渲染。                  | `JSX.Element` | -      |
| itemKey  | 标签页的唯一标识，对应 activeKey。                    | `string`      | -      |
| tab      | 标签栏中的标签内容，由 Tabs 渲染。                    | `JSX.Element` | -      |
