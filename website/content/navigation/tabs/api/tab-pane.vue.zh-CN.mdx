**Props**

| 属性     | 说明                                                     | 类型      | 默认值      |
| -------- | -------------------------------------------------------- | --------- | ----------- |
| itemKey  | 标签页的唯一标识，对应 activeKey。                       | `string`  | `undefined` |
| disabled | 是否禁用该标签页。                                       | `boolean` | `undefined` |
| closable | 是否允许关闭该标签页，关闭时触发 Tabs 的 tabClose 事件。 | `boolean` | `undefined` |

**Events**

| 事件 | 说明 | 回调参数 |
| ---- | ---- | -------- |
| 无   |      |          |

**Slots**

| 插槽    | 说明                                                                                                    | 作用域参数 |
| ------- | ------------------------------------------------------------------------------------------------------- | ---------- |
| default | 面板内容。                                                                                              | `any`      |
| tab     | 标签栏中的标签内容，由 Tabs 渲染。纯文本时才会出现在 tabBar 插槽参数 tabBarProps.list 项的 tab 字段中。 | `any`      |
| icon    | 标签栏中该标签的图标，由 Tabs 渲染。                                                                    | `any`      |

**Exposes**

| 名称 | 说明 | 类型 |
| ---- | ---- | ---- |
| 无   |      |      |
