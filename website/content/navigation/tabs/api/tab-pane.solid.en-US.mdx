**Props**

| Property | Description                                                          | Type          | Default |
| -------- | -------------------------------------------------------------------- | ------------- | ------- |
| children | Panel content.                                                       | `JSX.Element` | -       |
| closable | Whether the tab can be closed; closing calls onTabClose of the Tabs. | `boolean`     | -       |
| disabled | Whether the tab is disabled.                                         | `boolean`     | -       |
| icon     | The icon of the tab in the bar, rendered by the Tabs.                | `JSX.Element` | -       |
| itemKey  | Unique key of the tab, matched against activeKey.                    | `string`      | -       |
| tab      | The tab content in the bar, rendered by the Tabs.                    | `JSX.Element` | -       |
