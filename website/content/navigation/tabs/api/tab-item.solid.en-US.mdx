**Props**

| Property      | Description                                                                                                                                                                          | Type                                                                            | Default |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------- | ------- |
| closable      | Whether to show the close button.                                                                                                                                                    | `boolean`                                                                       | -       |
| deleteTabItem | Handler for the close button, with the itemKey and the event. Inside a Tabs it defaults to the Tabs' own, which calls onTabClose.                                                    | `TabBarProps['deleteTabItem']`                                                  | -       |
| disabled      | Whether the tab is disabled; clicks and the close button have no effect, while the close button still shows.                                                                         | `boolean`                                                                       | -       |
| handleKeyDown | Keyboard handler, with the event, the itemKey and closable. Inside a Tabs it defaults to the Tabs' own, which handles the arrow keys, Home, End, Enter, Space and Delete.            | `TabBarProps['handleKeyDown']`                                                  | -       |
| icon          | Tab icon; without content no icon is rendered.                                                                                                                                       | `JSX.Element`                                                                   | -       |
| itemKey       | Unique key of the tab.                                                                                                                                                               | `string`                                                                        | -       |
| onClick       | Called when the tab is clicked, with the itemKey and the event; not called while disabled. TabItem does not select the tab itself: update the activeKey of the Tabs in the callback. | <ApiType detail={"(itemKey: string, event: MouseEvent) => void"}>Type</ApiType> | -       |
| selected      | Whether the tab is selected.                                                                                                                                                         | `boolean`                                                                       | -       |
| size          | Size; small and medium add the matching class name.                                                                                                                                  | `TabSize`                                                                       | -       |
| tab           | Tab content.                                                                                                                                                                         | `JSX.Element`                                                                   | -       |
| tabPosition   | Position; defaults to the tabPosition of the enclosing Tabs.                                                                                                                         | `TabPosition`                                                                   | -       |
| type          | Style; defaults to the type of the enclosing Tabs.                                                                                                                                   | `TabType`                                                                       | -       |
