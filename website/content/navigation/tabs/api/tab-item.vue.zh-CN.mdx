**Props**

| 属性        | 说明                                                                                            | 类型          | 默认值      |
| ----------- | ----------------------------------------------------------------------------------------------- | ------------- | ----------- |
| itemKey     | 标签的唯一标识。                                                                                | `string`      | `""`        |
| selected    | 是否为选中状态。                                                                                | `boolean`     | `false`     |
| disabled    | 是否禁用；禁用时点击、关闭按钮与 Enter、Space、Delete、Backspace 键均不生效，关闭按钮仍会显示。 | `boolean`     | `false`     |
| closable    | 是否显示关闭按钮。                                                                              | `boolean`     | `false`     |
| size        | 尺寸，默认取所在 Tabs 的 size。                                                                 | `TabSize`     | `undefined` |
| type        | 样式，默认取所在 Tabs 的 type，在 Tabs 之外为 line。                                            | `TabType`     | `undefined` |
| tabPosition | 位置，默认取所在 Tabs 的 tabPosition，在 Tabs 之外为 top。                                      | `TabPosition` | `undefined` |

**Events**

| 事件  | 说明                                                                                          | 回调参数                               |
| ----- | --------------------------------------------------------------------------------------------- | -------------------------------------- |
| click | 点击标签时触发，参数为 itemKey 与事件；禁用时不触发。在 Tabs 之内，点击本身已会选中该标签页。 | `[itemKey: string, event: MouseEvent]` |

**Slots**

| 插槽 | 说明                               | 作用域参数 |
| ---- | ---------------------------------- | ---------- |
| tab  | 标签内容。                         | `any`      |
| icon | 标签图标；返回空内容则不渲染图标。 | `any`      |

**Exposes**

| 名称 | 说明 | 类型 |
| ---- | ---- | ---- |
| 无   |      |      |
