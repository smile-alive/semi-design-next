**Props**

| Property    | Description                                                                                                                                               | Type          | Default     |
| ----------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------- | ----------- |
| itemKey     | Unique key of the tab.                                                                                                                                    | `string`      | `""`        |
| selected    | Whether the tab is selected.                                                                                                                              | `boolean`     | `false`     |
| disabled    | Whether the tab is disabled; clicks, the close button and the Enter, Space, Delete and Backspace keys have no effect, while the close button still shows. | `boolean`     | `false`     |
| closable    | Whether to show the close button.                                                                                                                         | `boolean`     | `false`     |
| size        | Size; defaults to the size of the enclosing Tabs.                                                                                                         | `TabSize`     | `undefined` |
| type        | Style; defaults to the type of the enclosing Tabs, else line.                                                                                             | `TabType`     | `undefined` |
| tabPosition | Position; defaults to the tabPosition of the enclosing Tabs, else top.                                                                                    | `TabPosition` | `undefined` |

**Events**

| Event | Description                                                                                                                                   | Callback parameters                    |
| ----- | --------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------- |
| click | Emitted when the tab is clicked, with the itemKey and the event; not emitted while disabled. Inside a Tabs the click already selects the tab. | `[itemKey: string, event: MouseEvent]` |

**Slots**

| Slot | Description                                | Scope parameters |
| ---- | ------------------------------------------ | ---------------- |
| tab  | Tab content.                               | `any`            |
| icon | Tab icon; an empty result renders no icon. | `any`            |
