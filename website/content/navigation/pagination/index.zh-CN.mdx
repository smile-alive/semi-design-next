## API 参考

<Framework only="react">

<PaginationReactApi />

</Framework>

<Framework only="vue">

<PaginationVueApi />

`class`、`style` 与原生属性（`id`、`aria-*`、`data-*`、事件监听）经 attrs 落在根元素 `ul` 上，default 与 small 两种尺寸一致；`change` 已声明为组件事件，`@change` 只收到页码与每页条数，不会收到快速跳转输入框冒泡的原生 change 事件。`ref` 取到的是组件实例，根元素为实例的 `$el`。

</Framework>

## Accessibility

Pagination 按 [WAI-ARIA 分页导航](https://www.w3.org/WAI/ARIA/apg/patterns/landmarks/examples/navigation.html) 的常见做法实现。

### ARIA

- 根元素是 `ul`，每一项（总数、上一页、页码、下一页、每页条数、快速跳转）都是其中的 `li`
- 上一页、下一页、页码和「…」都是原生 `button`。页码的名称为「第 N 页」，「…」为「更多」，上一页、下一页按钮默认以语言包文案命名；传入 `prevText`、`nextText`（Vue 中为同名插槽）且内容是纯文本时以该文字命名，图标、元素等其他内容仍使用语言包文案
- 当前页的按钮带 `aria-current="page"`；禁用的按钮使用原生 `disabled`
- 快速跳转输入框以「跳至」命名，总页数小于 2 时禁用
- 组件本身不是导航地标。页面上的分页是主要导航手段时，建议包在 `<nav aria-label="...">` 里，并用名称区分页面上的多个分页

### 键盘和焦点

- 上一页、下一页、页码和「…」都可以用 `Tab` 聚焦，`Enter` 或 `Space` 翻页；
- 键盘聚焦「…」或 small 模式下开启 `hoverShowPageSelect` 的页码文字时，会打开被省略的页码列表：
    - `下箭头` 聚焦列表中的第一页，`上箭头` 聚焦最后一页；
    - 在列表中用 `Tab`、`Shift + Tab` 移动，`Enter` 或 `Space` 跳到该页；
    - `Esc` 关闭列表，焦点回到触发按钮。
