**Props**

| Property    | Description                                                                                           | Type          | Default |
| ----------- | ----------------------------------------------------------------------------------------------------- | ------------- | ------- |
| description | Description; not rendered by the nav type.                                                            | `JSX.Element` | -       |
| icon        | Custom icon that replaces the status icon; empty content shows no icon. Not rendered by the nav type. | `JSX.Element` | -       |
| status      | Own status of the step; when omitted it follows current and status of Steps.                          | `Status`      | -       |
| title       | Title.                                                                                                | `JSX.Element` | -       |
