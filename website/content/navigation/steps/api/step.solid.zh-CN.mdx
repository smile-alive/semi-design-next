**Props**

| 属性        | 说明                                                                   | 类型          | 默认值 |
| ----------- | ---------------------------------------------------------------------- | ------------- | ------ |
| description | 详情描述；nav 类型不渲染。                                             | `JSX.Element` | -      |
| icon        | 自定义图标，提供后替换状态图标，内容为空则不显示图标；nav 类型不渲染。 | `JSX.Element` | -      |
| status      | 该步骤自己的状态；缺省时随 Steps 的 current 与 status 自动决定。       | `Status`      | -      |
| title       | 标题。                                                                 | `JSX.Element` | -      |
