**Props**

| Property         | Description                                                                                                                                                                                                            | Type                                                           | Default        |
| ---------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------- | -------------- |
| current          | Current step, counting from 0; a child Step can override the state with status.                                                                                                                                        | `number`                                                       | `0`            |
| direction        | Direction: horizontal or vertical.                                                                                                                                                                                     | `StepsDirection`                                               | `"horizontal"` |
| hasLine          | Whether the basic type shows connecting lines.                                                                                                                                                                         | `boolean`                                                      | `true`         |
| initial          | Starting index, counting from 0.                                                                                                                                                                                       | `number`                                                       | `0`            |
| onChange         | Called when a step is selected by click or keyboard, with its number (initial plus index); not called for the current step. It is a function prop, bound with @change as usual; passing it makes every Step clickable. | <ApiType detail={"((current: number) => void)"}>Type</ApiType> | `undefined`    |
| onUpdate:current | Update function bound by v-model:current, behaving like onChange.                                                                                                                                                      | <ApiType detail={"((current: number) => void)"}>Type</ApiType> | `undefined`    |
| size             | Size of the basic and nav types: default or small.                                                                                                                                                                     | `StepsSize`                                                    | `"default"`    |
| status           | State of the current step: wait, process, finish, error or warning.                                                                                                                                                    | `StepStatus`                                                   | `"process"`    |
| type             | Steps type: fill, basic or nav.                                                                                                                                                                                        | `StepsType`                                                    | `"fill"`       |
