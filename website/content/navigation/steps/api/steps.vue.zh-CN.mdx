**Props**

| 属性             | 说明                                                                                                                                              | 类型                                                           | 默认值                                                   |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------- | -------------------------------------------------------- |
| type             | 步骤条类型，可选 fill、basic、nav。                                                                                                               | `StepsType`                                                    | `semiDefault("Steps", "type", "fill")`                   |
| current          | 当前步骤，从 0 开始计数；子 Step 可用 status 覆盖状态。                                                                                           | `number`                                                       | `semiDefault("Steps", "current", 0)`                     |
| initial          | 起始序号，从 0 开始计数。                                                                                                                         | `number`                                                       | `semiDefault("Steps", "initial", 0)`                     |
| direction        | 步骤条方向，可选 horizontal、vertical。                                                                                                           | `StepsDirection`                                               | `semiDefault("Steps", "direction", "horizontal")`        |
| status           | 当前步骤的状态，可选 wait、process、finish、error、warning。                                                                                      | `StepStatus`                                                   | `semiDefault("Steps", "status", "process")`              |
| size             | basic 与 nav 类型的尺寸，可选 default、small。                                                                                                    | `StepsSize`                                                    | `semiDefault("Steps", "size", "default")`                |
| hasLine          | basic 类型是否显示连接线。                                                                                                                        | `boolean`                                                      | `semiDefault("Steps", "hasLine", true)`                  |
| prefixCls        | 根元素的类名前缀。                                                                                                                                | `string`                                                       | `semiDefault("Steps", "prefixCls", stepsClasses.PREFIX)` |
| onChange         | 点击或键盘选择步骤时调用，参数为该步骤序号（initial 加索引）；点击当前步骤不调用。是函数 prop，使用方照常写 @change；传入后所有 Step 变为可点击。 | <ApiType detail={"((current: number) => void)"}>Type</ApiType> | `undefined`                                              |
| onUpdate:current | v-model:current 绑定的更新函数，行为与 onChange 一致。                                                                                            | <ApiType detail={"((current: number) => void)"}>Type</ApiType> | `undefined`                                              |
