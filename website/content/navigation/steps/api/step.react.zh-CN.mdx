| className | 步骤项（根元素）的类名。 | `string` | - |

| onClick | 点击步骤项时调用，包括点击其中的控件时。传入后步骤可点击，`role` 默认为 `button`；先于 Steps 的 `onChange` 调用。 | <ApiType detail={"React.MouseEventHandler\u003cHTMLDivElement>"}>Type</ApiType> | - |

| style | 步骤项（根元素）的样式。 | `React.CSSProperties` | - |

| title | 步骤标题。 | `React.ReactNode` | - |
