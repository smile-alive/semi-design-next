**Props**

| Property | Description | Type | Default |
| --- | --- | --- | --- |
| classNames | Class names of the inner parts, keyed by item, itemIcon, itemContent, itemTitle and itemDescription; merged with the built-in classes. Keys apply to every step: item is the step's root element, itemIcon is the leading status icon or number in the basic type and the trailing arrow in the nav type, and itemDescription is rendered by the basic type only. | <ApiType detail={"Partial\u003cRecord\u003cStepsPart, string>>"}>Type</ApiType> | - |
| current | Current step, counting from 0; a child Step can override the state with status. | `number` | `0` |
| direction | Direction of the steps, horizontal or vertical; applies to the basic type. | `Direction` | `"horizontal"` |
| hasLine | Whether to show the line between steps; basic type only. | `boolean` | `true` |
| initial | Starting index, counting from 0. | `number` | `0` |
| onChange | Called when a step is selected by click or by Enter or Space, with its number (initial plus index); not called for the current step. Passing it makes every Step clickable. | <ApiType detail={"(current: number) => void"}>Type</ApiType> | - |
| size | Size, small or default; applies to the basic and nav types. | `Size` | `"default"` |
| status | Status of the current step: wait, process, finish, error or warning; applies to the basic type. | `Status` | `"process"` |
| styles | Inline styles of the inner parts, keyed like classNames; style objects use kebab-case CSS property names, and style strings work too. | <ApiType detail={"Partial\u003cRecord\u003cStepsPart, JSX.CSSProperties \u007c string>>"}>Type</ApiType> | - |
| type | Steps type: basic or nav, defaults to basic. | `'basic' \| 'nav'` | `"basic"` |
