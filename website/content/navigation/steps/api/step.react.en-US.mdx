import ApiType from '#/components/ApiType.astro';

**Props**

| Property    | Description                                                                                                                                                                                   | Type                                                                            | Default |
| ----------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------- | ------- |
| className   | Class name of the step item (root element).                                                                                                                                                   | `string`                                                                        | -       |
| description | Description of the step. Not rendered by the `nav` type.                                                                                                                                      | `React.ReactNode`                                                               | -       |
| icon        | Custom icon that replaces the status icon; an empty value shows no icon. Not rendered by the `nav` type.                                                                                      | `React.ReactNode`                                                               | -       |
| onClick     | Called when the step item is clicked, including clicks on controls inside it. Passing it makes the step clickable with `role` defaulting to `button`; it runs before the `onChange` of Steps. | <ApiType detail={"React.MouseEventHandler\u003cHTMLDivElement>"}>Type</ApiType> | -       |
| ref         | Reference to the step item (root element, `div`).                                                                                                                                             | <ApiType detail={"React.Ref\u003cHTMLDivElement>"}>Type</ApiType>               | -       |
| status      | Own status of the step: `wait`, `process`, `finish`, `error` or `warning`. When omitted it follows `current` and `status` of Steps. Not applied by the `nav` type.                            | `Status`                                                                        | -       |
| style       | Style of the step item (root element).                                                                                                                                                        | `React.CSSProperties`                                                           | -       |
| title       | Step title.                                                                                                                                                                                   | `React.ReactNode`                                                               | -       |
