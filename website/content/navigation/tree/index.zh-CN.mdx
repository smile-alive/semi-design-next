### 自定义节点内容

<Framework only="react">

### 默认展开

`defaultExpandAll` 和 `expandAll` 均可以设置 `Tree` 的默认展开/收起状态。二者的区别是，`defaultExpandAll` 只在初始化时生效，而 `expandAll` 不仅会在初始化时生效，当数据(`treeData`/`treeDataSimpleJson`)发生动态更新时，`expandAll` 也仍然生效。

其中，`expandAll` 是从 1.30.0 开始支持的。

### 虚拟化

列表虚拟化，用于大量树节点的情况。开启后，动画效果将被关闭。

`virtualize` 是一个包含下列值的对象：

- height: 高度值，如果为 string 必须有计算高度才能被渲染出来，即其父节点有 offsetHeight
- width: 宽度值，默认 100%
- itemSize: 每行的treeNode的高度，必传

如果带搜索框，建议开启 `showFilteredOnly` 减少多余节点的渲染。

<Framework only="react">

拖拽事件的回调入参如下：

```
- onDragEnd: function({ event, node: DragTreeNode })
- onDragEnter:function({ event, node: DragTreeNode, expandedKeys: string[] })
- onDragLeave:function({ event, node: DragTreeNode })
- onDragOver:function({ event, node: DragTreeNode })
- onDragStart: function({ event, node: DragTreeNode })
- onDrop:function({ event, node: DragTreeNode, dragNode: DragTreeNode, dragNodesKeys: string[], dropPosition: number, dropToGap: Boolean })
```

数据类型 DragTreeNode，除了包含 TreeNodeData 所有属性外，还包含 expanded 和 pos 属性，

```
DragTreeNode {
    expanded: Boolean,
    pos: string
    value?: string | number;
    label?: React.ReactNode;
    disabled?: boolean;
    isLeaf?: boolean;
    [key: string]: any;
}
```

</Framework>

<Framework only="vue">

```
- @dragEnd: { event, node: TreeDragNode }

- @dragLeave: { event, node: TreeDragNode }
- @dragOver: { event, node: TreeDragNode }
- @dragStart: { event, node: TreeDragNode }
- @drop: { event, node: TreeDragNode, dragNode: TreeDragNode, dragNodesKeys: string[], dropPosition: number, dropToGap: boolean }
```

数据类型 TreeDragNode，除了包含 TreeNodeData 所有属性外，还包含 expanded 和 pos 属性，

```
TreeDragNode {
    expanded: boolean,
    pos: string
    value?: string | number;
    label?: string | number;
    disabled?: boolean;
    isLeaf?: boolean;
    [key: string]: any;
}
```

</Framework>

<Framework only="solid">

拖拽事件的回调参数是对象，参数如下：

```
- onDragEnd: ({ event, node: TreeDragNode }) => void
- onDragEnter: ({ event, node: TreeDragNode, expandedKeys?: string[] }) => void
- onDragLeave: ({ event, node: TreeDragNode }) => void
- onDragOver: ({ event, node: TreeDragNode }) => void
- onDragStart: ({ event, node: TreeDragNode }) => void
- onDrop: ({ event, node: TreeDragNode, dragNode: TreeDragNode, dragNodesKeys: string[], dropPosition: number, dropToGap: boolean }) => void
```

数据类型 TreeDragNode，除了包含 `TreeNodeData` 所有属性外，还包含 `expanded` 和 `pos` 属性：

```ts
interface TreeDragNode extends TreeNodeData {
    expanded: boolean;
    pos: string;
}
```

</Framework>

- `pos` 指的是当前节点在整个 treeData 中的位置关系，如第0层第1个节点的第2个节点的第0个节点：'0-1-2-0'
- `dropPosition` 指的是被拖拽节点在当前层级中被 drop 的位置，如插入在同级的第0个节点前则为 -1，在第0个节点后则为 1，落在其上则为 0，以此类推。配合 dropToGap 可以得到更完整的判断。
- `dropToGap` 指的是被拖拽节点是否被 drop 在节点之间的位置，如果为 false 则是 drop 在某个节点上方

### 高级定制

**版本 v>=1.7.0**

<Framework only="react">

Tree 组件的 api 支持了大部分的渲染需求，但是如果有非常特殊的定制要求的话，可以使用 `renderFullLabel` 来接管整行 option 的渲染效果。

renderFullLabel 参数类型如下：

```ts
type RenderFullLabelProps = {
    /* 节点数据 */
    data: BasicTreeNodeData;
    /* 层级 */
    level: number;
    /* 虚拟化情况下，该 style 必须给到 DOM 节点上*/
    style: any;
    /* 样式类名，包括内置样式，如缩进、展开按钮、过滤器、禁用、选择等。 */
    className: string;
    /* 展开按钮 */
    expandIcon: any;
    /* 选中状态 */
    checkStatus: {
        /* 是否选中 */
        checked: boolean;
        /* 是否半选 */
        halfChecked: boolean;
    };
    /* 展开状态 */
    expandStatus: {
        /* 是否展开 */
        expanded: boolean;
        /* 是否加载中 */
        loading: boolean;
    };
    /* 该节点是否符合筛选条件 */
    filtered: boolean | undefined;
    /* 当前搜索框输入值 */
    searchWord: string | undefined;
    /* 点击回调 */
    onClick: (e: MouseEvent) => void;
    /* 多选点击回调 */
    onCheck: (e: MouseEvent) => void;
    /* 右键点击回调 */
    onContextMenu: (e: MouseEvent) => void;
    /* 二次点击回调 */
    onDoubleClick: (e: MouseEvent) => void;
    /* 展开回调 */
    onExpand: (e: MouseEvent) => void;
};
```

<Notice type="primary" title="注意事项">
    <div>如果开启了虚拟化，需要将 style （虚拟化相关样式）赋予给渲染的 DOM 节点</div>
</Notice>

</Framework>

<Framework only="vue">

Tree 组件的 api 支持了大部分的渲染需求，但是如果有非常特殊的定制要求的话，可以使用 `#fullLabel` 插槽来接管整行的内容。

带有 `id`、`role="treeitem"` 和行状态的行元素（`li`）由 Tree 自己提供，虚拟化时的定位样式也在这个元素上，插槽只写行内的内容。把插槽参数中的 `class` 绑到内容元素上，该元素就获得与内置行相同的缩进、选中、焦点等样式和行内边距。

插槽参数类型如下：

```ts
type TreeFullLabelSlotProps = {
    /* 节点数据 */
    data: TreeNodeData;
    /* 层级 */
    level: number;
    /* 样式类名，包括内置样式，如缩进、选中、焦点、拖拽状态等 */
    class: string;
    /* 内置的展开按钮 */
    expandIcon: VNode;
    /* 选中状态 */
    checkStatus: {
        /* 是否选中 */
        checked: boolean;
        /* 是否半选 */
        halfChecked: boolean;
    };
    /* 展开状态 */
    expandStatus: {
        /* 是否展开 */
        expanded: boolean;
        /* 是否加载中 */
        loading: boolean;
    };
    /* 该节点是否符合筛选条件 */
    filtered: boolean;
    /* 当前搜索框输入值 */
    searchWord: string;
    /* 点击回调：单选时选中，多选时勾选 */
    onClick: (event: MouseEvent) => void;
    /* 多选点击回调 */
    onCheck: (event: MouseEvent) => void;
    /* 展开回调 */
    onExpand: (event: MouseEvent) => void;
    /* 右键点击回调 */
    onContextmenu: (event: MouseEvent) => void;
    /* 二次点击回调 */
    onDblclick: (event: MouseEvent) => void;
};
```

    checkStatus: {
        /* 是否选中 */
        checked: boolean;
        /* 是否半选 */
        halfChecked: boolean;
    };
    /* 展开状态 */
    expandStatus: {
        /* 是否展开 */
        expanded: boolean;
        /* 是否加载中 */

    /* 当前搜索框输入值 */
    searchWord: string;
    /* 点击整行的回调：单选时选中，多选时勾选 */
    onClick: (e: MouseEvent) => void;

## Accessibility

### ARIA

- Tree 支持传入 `aria-label`、`aria-labelledby`、`aria-describedby` 来命名和描述该 Tree，它们都设置在 `role="tree"` 的元素上;
- Tree 会自动为每个节点设置 `aria-level`、`aria-setsize`、`aria-posinset`、`aria-disabled`，可展开的节点设置 `aria-expanded`；单选时用 `aria-selected` 表示选中，多选时用 `aria-checked` 表示勾选（半选为 `mixed`）;
- Tree 会自动为对应部分分别设置 `role` 为 `tree`、`treeitem`。

<Framework only="react">

- `renderFullLabel` 返回的元素同样会被设置 `role="treeitem"` 和上述状态；返回文本、数组、Fragment 等不能承载这些属性的内容时，由带这些属性的 `li` 包住。

</Framework>

<Framework only="vue">

- `#fullLabel` 的内容由 Tree 自己的 `li` 包住，这个 `li` 带有 `id`、`role="treeitem"` 和上述状态。

</Framework>

<Framework only="solid">

- `renderFullLabel` 返回的内容由 Tree 自己的 `li` 包住，这个 `li` 带有 `id`、`role="treeitem"` 和上述状态。

### 键盘交互

Tree 按 [WAI-ARIA Tree View](https://www.w3.org/WAI/ARIA/apg/patterns/treeview/) 处理键盘：整棵树是一个 Tab 停靠点，焦点停在树上，`aria-activedescendant` 指向当前节点，当前节点显示焦点环。

- `ArrowDown`、`ArrowUp`：移到下一个、上一个可见节点；`Home`、`End`：移到第一个、最后一个可见节点
- `ArrowRight`：展开收起的节点；节点已展开时移到它的第一个子节点（RTL 下与 `ArrowLeft` 互换）
- `ArrowLeft`：收起展开的节点；否则移到父节点
- `Enter`、`Space`：选中当前节点，多选时勾选或取消勾选；禁用节点不响应
- 输入字符：移到文本以输入内容开头的下一个节点

用鼠标选中、勾选、展开、右键或双击的节点，同时成为键盘的当前节点，之后的方向键从它开始移动。

键盘不触发 `expandAction`，展开、收起只用方向键。

<Framework only="react">

节点内容里的按钮、链接（如 `renderLabel` 返回的控件）可以用 Tab 到达，焦点在它们上面时，按键由控件自己处理，树不响应。

示例:

```typescript
    <Tree
        /* 其他属性 */
        aria-label='example tree'
    />
```

</Framework>

<Framework only="vue">

节点内容里的按钮、链接（如 `#label` 插槽中的控件）可以用 Tab 到达，焦点在它们上面时，按键由控件自己处理，树不响应。

示例:

```vue
<Tree aria-label="example tree" :treeData="treeData" />
```

</Framework>

<Framework only="solid">

节点内容里的按钮、链接（如 `renderLabel` 或 `renderFullLabel` 中的控件）可以用 Tab 到达，焦点在它们上面时，按键由控件自己处理，树不响应。
