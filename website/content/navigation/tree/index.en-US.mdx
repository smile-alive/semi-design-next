### Searchable

Use `filterTreeNode` to support search input. By default it searches the `label` property of the data. You can use `treeNodeFilterProp` to set another property to search or pass in a function to `filterTreeNode` to customize search behavior.

You could also use `showFilteredOnly` if you prefer to display filtered results only.

<Demo id="searchable" />

<Framework only="react">

After setting the `filterTreeNode` property to enable search, you can customize the rendering method of the search box by setting `searchRender`. When set to `false`, the search box can be hidden.

</Framework>

<Framework only="vue">

After setting the `filterTreeNode` property to enable search, you can customize the search box with the `#search` slot, whose parameters are `class`, `modelValue`, `placeholder`, `showClear` and `onChange`. An empty slot (`<template #search />`) hides the search box.

</Framework>

<Framework only="svelte">

After setting the `filterTreeNode` property to enable search, you can customize the search box with the `search` snippet, whose arguments are `class`, `value`, `placeholder`, `showClear` and `onChange`. `search={false}` hides the search box.

</Framework>

<Framework only="solid">

After setting the `filterTreeNode` property to enable search, you can customize the rendering method of the search box by setting `searchRender`. When set to `false`, the search box can be hidden. The parameter of `searchRender` is a live object, read it in the returned JSX and do not destructure it.

</Framework>

### Default Expand All

Both `defaultExpandAll` and `expandAll` can set the default expanded/collapsed state of `Tree`. The difference between the two is that `defaultExpandAll` only takes effect at initialization, while `expandAll` will not only take effect at initialization, but also when the data (`treeData`/`treeDataSimpleJson`) is dynamically updated, `expandAll` will still take effect.

Among them, `expandAll` is supported starting from 1.30.0.

In the demo below, after clicking the button to update `TreeData`, `defaultExpandAll` becomes invalid, and `expandAll` still takes effect.

### Virtualized Tree

If you need to render large sets of tree structured data, you could use virtualized tree. In virtualized mode, animation / motion is disabled for better performance.

The property `virtualize` is an object consisting of the following values:

- height: Height of the tree, If passed in as a string, computed height should not be zero for render purpose, in other words, parent node should have offsetHeight
- width: Width of the tree.
- itemSize: Height for each line of treeNode, required

If tree is searchable, you could also turn on `showFilteredOnly` to reduce time of rendering for results.

<Notice title="Notice">Drag and drop is available since v 1.8.0. Simultaneous use with virtualization is currently not supported</Notice>

<Framework only="react">

The callback input parameters of the drag event are as follows:

```
- onDragEnd: function({ event, node: DragTreeNode })
- onDragEnter:function({ event, node: DragTreeNode, expandedKeys: string[] })
- onDragLeave:function({ event, node: DragTreeNode })
- onDragOver:function({ event, node: DragTreeNode })
- onDragStart: function({ event, node: DragTreeNode })
- onDrop:function({ event, node: DragTreeNode, dragNode: DragTreeNode, dragNodesKeys: string[], dropPosition: number, dropToGap: Boolean })
```

The data type DragTreeNode, in addition to all the attributes of TreeNodeData, also includes expanded and pos attributes,

```
DragTreeNode {
    expanded: Boolean,
    pos: string
    value?: string | number;
    label?: React.ReactNode;
    disabled?: boolean;
    isLeaf?: boolean;
    [key: string]: any;
}
```

</Framework>

<Framework only="vue">

The payload of each drag event is one object with the following fields:

```
- @dragEnd: { event, node: TreeDragNode }
- @dragEnter: { event, node: TreeDragNode, expandedKeys?: string[] }
- @dragLeave: { event, node: TreeDragNode }
- @dragOver: { event, node: TreeDragNode }
- @dragStart: { event, node: TreeDragNode }
- @drop: { event, node: TreeDragNode, dragNode: TreeDragNode, dragNodesKeys: string[], dropPosition: number, dropToGap: boolean }
```

The data type TreeDragNode, in addition to all the attributes of TreeNodeData, also includes expanded and pos attributes,

```
TreeDragNode {
    expanded: boolean,
    pos: string
    value?: string | number;
    label?: string | number;
    disabled?: boolean;
    isLeaf?: boolean;
    [key: string]: any;
}
```

</Framework>

<Framework only="svelte">

The argument of each drag callback is one object with the following fields:

```
- onDragEnd: { event, node: TreeDragNode }
- onDragEnter: { event, node: TreeDragNode, expandedKeys?: string[] }
- onDragLeave: { event, node: TreeDragNode }
- onDragOver: { event, node: TreeDragNode }
- onDragStart: { event, node: TreeDragNode }
- onDrop: { event, node: TreeDragNode, dragNode: TreeDragNode, dragNodesKeys: string[], dropPosition: number, dropToGap: boolean }
```

The data type TreeDragNode, in addition to all the attributes of TreeNodeData, also includes expanded and pos attributes,

```
TreeDragNode {
    expanded: boolean,
    pos: string
    value?: string | number;
    label?: string | number;
    disabled?: boolean;
    isLeaf?: boolean;
    [key: string]: any;
}
```

</Framework>

<Framework only="solid">

The callback arguments of the drag events are objects with the following fields:

```
- onDragEnd: ({ event, node: TreeDragNode }) => void
- onDragEnter: ({ event, node: TreeDragNode, expandedKeys?: string[] }) => void
- onDragLeave: ({ event, node: TreeDragNode }) => void
- onDragOver: ({ event, node: TreeDragNode }) => void
- onDragStart: ({ event, node: TreeDragNode }) => void
- onDrop: ({ event, node: TreeDragNode, dragNode: TreeDragNode, dragNodesKeys: string[], dropPosition: number, dropToGap: boolean }) => void
```

The data type TreeDragNode, in addition to all the attributes of `TreeNodeData`, also includes `expanded` and `pos` attributes:

```ts
interface TreeDragNode extends TreeNodeData {
    expanded: boolean;
    pos: string;
}
```

</Framework>

- `pos` refers to the positional relationship of the current node in the entire treeData, such as the 0th node of the 2nd node of the 1st node of the 0th layer: '0-1-2-0'
- `dropPosition` refers to the position where the dragged node is dropped in the current hierarchy. If it is inserted before the 0th node of the same level, it will be -1, and after the 0th node, it will be 1, and it will fall on it. is 0, and so on. With dropToGap, a more complete judgment can be obtained.
- `dropToGap` refers to whether the dragged node is dropped between nodes, if false, it is dropped above a node

```ts
    /* The level of the line can be used to customize the indentation value */
    level: number;
    /* Class name, including built-in styles such as indentation, selection, focus and drag state */
    class: string;
    /* Creates the built-in expand button; every call creates a new element, so call it where the button goes */
    expandIcon: () => JSX.Element;
    /* Selected state */
    checkStatus: {
        /* Whether to select in the multi-select state */
        checked: boolean;
        /* Whether to half-select in the multi-select state */
        halfChecked: boolean;
    };
    /* Expand status */
    expandStatus: {
        /* Has it been expanded */
        expanded: boolean;
        /* Is it unfolding */
        loading: boolean;
    };
    /* Whether the node meets the search conditions */
    filtered: boolean;
    /* Current search box input */
    searchWord: string;
    /* Click the callback of the entire row: selects it, or checks it in a multiple tree */
    onClick: (e: MouseEvent) => void;
    /* Multi-select click callback */
    onCheck: (e: MouseEvent) => void;
    /* Expand callback */
    onExpand: (e: MouseEvent) => void;
    /* Right-click the callback for the entire row */
    onContextMenu: (e: MouseEvent) => void;
    /* Double-click the entire row callback */
    onDoubleClick: (e: MouseEvent) => void;
};
```

Tree provides the row element (`li`) carrying the `id`, `role="treeitem"` and the row state, and the content is placed inside it; the positioning style of a virtualized tree is on that element too. Bind the `class` parameter to the content element and it gets the same indentation, selection and focus styles and the same inline padding as a built-in row.

```tsx
<Tree treeData={treeData} renderFullLabel={(row) => <div class={row.class}>{row.data.label}</div>} />
```

</Framework>

## Accessibility

### ARIA

- Tree supports passing in `aria-label`, `aria-labelledby` and `aria-describedby` to name and describe the Tree; they are all set on the `role="tree"` element;
- Tree sets `aria-level`, `aria-setsize`, `aria-posinset` and `aria-disabled` on each node, and `aria-expanded` on nodes that can expand; a single-choice tree marks the selected node with `aria-selected`, a multi-choice tree marks checked nodes with `aria-checked` (`mixed` when half checked);
- Tree will set `role` to `tree` and `treeitem` for corresponding parts.

### Keyboard Interaction

Tree follows the [WAI-ARIA Tree View](https://www.w3.org/WAI/ARIA/apg/patterns/treeview/) pattern: the whole tree is one Tab stop, focus stays on the tree, `aria-activedescendant` points at the current node, and the current node shows the focus ring.

- `ArrowDown`, `ArrowUp`: move to the next or previous visible node; `Home`, `End`: move to the first or last visible node
- `ArrowRight`: expand a collapsed node; on an expanded node, move to its first child (swapped with `ArrowLeft` in RTL)
- `ArrowLeft`: collapse an expanded node; otherwise move to the parent
- `Enter`, `Space`: select the current node, or check and uncheck it in a multi-choice tree; disabled nodes do not respond
- Typing characters: move to the next node whose text starts with them

A node that is selected, checked, expanded, right-clicked or double-clicked with the pointer becomes the current node of the keyboard, and the arrow keys continue from it.

The keyboard does not trigger `expandAction`; the arrow keys expand and collapse.

<Framework only="react">
