**Props**

| 属性         | 说明                                                                                                                                                                     | 类型                                                                         | 默认值                               |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------- | ------------------------------------ |
| activeIndex  | 受控使用，当前项的序号（从 0 起）；缺省时最后一项为当前项。                                                                                                              | `number`                                                                     | -                                    |
| autoCollapse | 超出 maxItemCount 后是否自动折叠。                                                                                                                                       | `boolean`                                                                    | `true`                               |
| compact      | 是否使用紧凑尺寸。                                                                                                                                                       | `boolean`                                                                    | `true`                               |
| icon         | 每一项的图标，参数为该项的路由、序号、size 与 class，需要把后两者传给图标；渲染为空时该项无图标。                                                                        | <ApiType detail={"Snippet\u003c[BreadcrumbIconContext]>"}>Type</ApiType>     | -                                    |
| item         | 自定义每一项的标题，参数为该项的路由与序号；内容按内联渲染，不走截断。                                                                                                   | <ApiType detail={"Snippet\u003c[BreadcrumbRouteContext]>"}>Type</ApiType>    | -                                    |
| maxItemCount | 超出多少个级别后自动折叠。                                                                                                                                               | `number`                                                                     | `4`                                  |
| more         | 自定义省略号区域，参数 restItems 是被折叠的项（`{ route, index }`）。                                                                                                    | <ApiType detail={"Snippet\u003c[BreadcrumbMoreContext]>"}>Type</ApiType>     | -                                    |
| moreType     | 内置省略号区域的渲染类型，可选 default、popover；提供 more snippet 时以 snippet 为准。                                                                                   | `BreadcrumbMoreType`                                                         | `"default"`                          |
| onClick      | 点击时调用，收到该项的路由（字符串路由为 `{ name }`）与原生 MouseEvent。是函数 prop，不是 nav 的原生点击监听；传入后没有 href 的项也可以用 Enter 操作。                  | `BreadcrumbClick`                                                            | -                                    |
| routes       | 路由信息，由路由对象或字符串组成的数组。                                                                                                                                 | <ApiType detail={"Array\u003cBreadcrumbRoute \u007c string>"}>Type</ApiType> | `[]`                                 |
| separator    | 分隔符，可以是文字或 snippet。                                                                                                                                           | `string \| Snippet`                                                          | `"/"`                                |
| showTooltip  | 是否在标题溢出时展示 Tooltip 及相关配置：width 为溢出宽度，ellipsisPos 为截断方式（从末尾或中间），opts 为传给 Tooltip 的属性，不含 content，class 与 style 落在弹层上。 | `boolean \| BreadcrumbShowTooltip`                                           | `{ width: 150, ellipsisPos: 'end' }` |
