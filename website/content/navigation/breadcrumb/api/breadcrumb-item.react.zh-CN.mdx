**Props**

| 属性                  | 说明                                                                                                                                               | 类型                                                                                                         | 默认值 |
| --------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------ | ------ |
| active                | 是否为当前项，由 `Breadcrumb` 设置，使用方不应传入。                                                                                               | `boolean`                                                                                                    | -      |
| children              | 标题内容。数字与字符串会被截断并展示 Tooltip，其他节点原样渲染。                                                                                   | `ReactNode`                                                                                                  | -      |
| className             | 包裹该项的外层 span 的类名。                                                                                                                       | `string`                                                                                                     | -      |
| href                  | 链接的目的地，挂载在 a 标签上；当前项不渲染为链接。                                                                                                | `string`                                                                                                     | -      |
| icon                  | 标题前的图标。Semi 图标未设置 `size` 时，按 `Breadcrumb` 的 `compact` 取 `small` 或 `default`。                                                    | `React.ReactNode`                                                                                            | -      |
| noLink                | 移除 hover 和 active 样式；没有 `href` 的项也不再可以用键盘操作。                                                                                  | `boolean`                                                                                                    | -      |
| onClick               | 单击时调用，参数同 `Breadcrumb` 的 `onClick`：`routes` 写法收到该项的路由对象，`children` 写法收到 `{ name, href }`；第二个参数为原生 MouseEvent。 | <ApiType detail={"(item: BreadcrumbItemInfo \u007c RouteProps, e: React.MouseEvent) => void"}>Type</ApiType> | -      |
| ref                   | 包裹该项的外层 span 的引用。                                                                                                                       | <ApiType detail={"React.Ref\u003cHTMLSpanElement>"}>Type</ApiType>                                           | -      |
| route                 | `Breadcrumb` 按 `routes` 渲染时传入的该项路由对象，作为 `onClick` 的参数；使用方不应传入。                                                         | `RouteProps`                                                                                                 | -      |
| separator             | 该项之后的分隔符，覆盖 `Breadcrumb` 的 `separator`，可以是文字或 React 节点。                                                                      | `React.ReactNode`                                                                                            | -      |
| shouldRenderSeparator | 是否渲染该项之后的分隔符，由 `Breadcrumb` 按位置与折叠状态设置，使用方不应传入；缺省为 true。                                                      | `boolean`                                                                                                    | -      |
| style                 | 包裹该项的外层 span 的内联样式。                                                                                                                   | `CSSProperties`                                                                                              | -      |
