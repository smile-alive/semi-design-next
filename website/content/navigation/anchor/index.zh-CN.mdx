### 综合使用

你可以搭配 `getContainer`，`targetOffset`，`style`，`offsetTop` 完成一个拆箱即用的超链接导航栏。

- 滚动容器：你可以通过 `getContainer` 设置滚动内容的容器，默认值为 `window` 。

- 距离顶部的距离：可以通过设置 `targetOffset` 设置文档滚动结束时，锚点距离容器顶部的距离。

- 自定义定位方式：Anchor 自身不设置定位，你可以通过 `style` 对象为它指定定位方式，例如 `position: fixed`。

- 偏移距离：`offsetTop` 可以在滚动内容距离容器顶部达到指定偏移量时触发当前 Link 切换。

<Framework only="react">

```jsx
import React from 'react';
import { Anchor } from '@fibrae/semi-ui-react';

() => {
    const getContainer = () => {
        return document.querySelector('window');
    };
    return (
        <div>
            <span>请看右侧固定的 Anchor </span>
            <Anchor getContainer={getContainer} offsetTop={100} targetOffset={100} style={{ position: 'fixed', right: '20px', top: '100px', width: '200px', zIndex: 3 }}>
```

### 自定义滚动位置

通过 `scrollIntoViewOptions` 可以调整点击锚点后目标元素在容器中的位置，类型为 [scroll-into-view-if-needed](https://github.com/scroll-into-view/scroll-into-view-if-needed) 的 `Options`，支持 `block`、`inline`、`scrollMode`、`boundary`、`skipOverflowHiddenElements`。不传时 `block` 为 `start`，即目标元素滚动到容器顶部。

- `scrollMotion` 决定滚动是否带动画（`behavior`），`targetOffset` 在 `block` 计算出的位置上再向上偏移，两者与 `scrollIntoViewOptions` 同时传入时依然生效。
- 只会滚动离目标最近的、可纵向滚动的容器；仅当传入 `inline` 时才同时调整横向位置。

## API 参考

### Anchor

<Framework only="react">

<AnchorReactApi />

`id`、`data-*` 等其他原生属性落在根导航元素（`role="navigation"`）上；`onChange` 与 `onClick` 是锚点的回调，不绑定到根元素。

</Framework>

<Framework only="vue">

<AnchorVueApi />

`class`、`style` 与原生属性经 attrs 落在根元素上；`style` 中的 `max-width`、`max-height` 优先于 `maxWidth`、`maxHeight` 属性。`click` 声明为组件事件后，`@click` 不再作为根元素的原生点击监听。

</Framework>

<Framework only="solid">

<AnchorSolidApi />

`class`、`style`、`ref` 与原生属性（如 `data-*`、`aria-*`）落在根元素（`role="navigation"`）上；`onClick` 是组件回调，不是根元素的原生点击监听。`maxWidth`、`maxHeight` 覆盖 `style` 中同名的 `max-width`、`max-height`。

</Framework>

<Framework only="svelte">

<AnchorSvelteApi />

`class`、`style`（字符串）与原生属性（如 `data-*`、`aria-*`）落在根元素（`role="navigation"`）上；`style` 中的 `max-width`、`max-height` 优先于 `maxWidth`、`maxHeight`。`onClick` 与 `onChange` 是组件回调，`onClick` 只在激活链接时触发。服务端首帧带全部链接，`autoCollapse` 的折叠首帧即正确；没有子链接的项不输出空的 `role="list"`。

</Framework>

### Anchor.Link

<Framework only="react">

<AnchorLinkReactApi />

`id`、`data-*` 等其他原生属性落在链接最外层的 div（`role="listitem"`）上。

</Framework>

<Framework only="vue">

<AnchorLinkVueApi />

`class`、`style` 与原生属性经 attrs 落在链接最外层的 `div`（`role="listitem"`）上。`Anchor.Link` 必须放在 `Anchor` 内，否则抛出错误。

</Framework>

<Framework only="solid">

<AnchorLinkSolidApi />

`class`、`style`、`ref` 与原生属性（如 `data-*`）落在链接最外层的 `div`（`role="listitem"`）上。

</Framework>

<Framework only="svelte">

Svelte 没有独立的 `Anchor.Link` 组件，每个链接是 `links` 数据中的一项，字段见上方 `links` 的说明。

</Framework>

## FAQ

1. **为何我的 Link 没有高亮和滑动跟随？**  
   检查下点击锚点是否可以滚动到指定位置：
    - 不可以，说明 href 有问题，检查文档中是否存在该 id；
    - 可以，可能是滚动容器设置不正确，确保文档内容被包裹在滚动容器内。滚动容器默认为 window，如果你的容器是 .my-container 的 div，则应该将滚动容器设置为该 div。

<Framework only="react">

```text
import React from 'react';
import { Anchor } from '@fibrae/semi-ui-react';

function() {
    // 此容器不是 Anchor 组件的容器，是文档内容的容器，因为要根据文档容器去计算当前是哪个 id 在容器上方
    const getContainer = () => {
        return document.querySelector('.my-container');
    }
    return (
        <Anchor
            /* 其他属性 */
            getContainer={getContainer}
            >
            /* Links */
        </Anchor>
    )
}
```

</Framework>

<Framework only="vue">

```text
<script setup lang="ts">
```
