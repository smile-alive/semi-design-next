### Basic Usage

Use `Link` to create an anchor, click it to jump to the hash tag location.

<Framework only="svelte">

Write the links as a `links` array of `{ href, title, disabled, children }`, where `children` nests the next level; use the `title` snippet, with the parameter `{ item, level }`, for custom titles.

</Framework>

### Integrated Usage

You can use `getContainer`, `targetOffset`, `offsetTop`, and `style` to create a out of the box hyperAnchor.Link navigation bar.

- getContainer：you can set the container of scroll content with `getContainer` property. Its default value is `window`.

- targetOffset: you can set the distance between the anchor point and the top of the container by setting `targetOffset`.

- style：Anchor does not position itself. Position it yourself with the `style` object, for example `position: fixed`.

- offsetTop：`offsetTop` can trigger the current Link switch when the scrolling content reaches a specified offset from the top of the container.

<Framework only="react">

```jsx
import React from 'react';
import { Anchor } from '@fibrae/semi-ui-react';

    const getContainer = () => {
        return document.querySelector('window');
```

### Custom Scroll Position

`scrollIntoViewOptions` adjusts where the target ends up in the container after a link is clicked. Its type is the `Options` of [scroll-into-view-if-needed](https://github.com/scroll-into-view/scroll-into-view-if-needed): `block`, `inline`, `scrollMode`, `boundary` and `skipOverflowHiddenElements`. Without it `block` is `start`, which scrolls the target to the top of the container.

- `scrollMotion` still decides whether the scroll is animated (`behavior`), and `targetOffset` still shifts the position `block` produces, when passed together with `scrollIntoViewOptions`.
- Only the innermost vertically scrollable container is scrolled; the horizontal position is adjusted only when `inline` is passed.

## API Reference

### Anchor

<Framework only="react">

<AnchorReactApi />

`id`, `data-*` and other native attributes are placed on the root navigation element (`role="navigation"`). `onChange` and `onClick` are the anchor callbacks and are not bound to the root element.

</Framework>

<Framework only="vue">

<AnchorVueApi />

`class`, `style` and native attributes land on the root element through attrs. A `max-width` or `max-height` in `style` takes precedence over the `maxWidth` and `maxHeight` props. As a component event, `@click` no longer listens for native clicks on the root element.

</Framework>

<Framework only="solid">

<AnchorSolidApi />

`class`, `style`, `ref` and native attributes (such as `data-*` and `aria-*`) land on the root element (`role="navigation"`). `onClick` is a component callback, not a native click listener on the root element. `maxWidth` and `maxHeight` override the `max-width` and `max-height` in `style`.

</Framework>

<Framework only="svelte">

<AnchorSvelteApi />

`class`, `style` (a string) and native attributes (such as `data-*` and `aria-*`) land on the root element (`role="navigation"`); the `max-width` and `max-height` in `style` win over `maxWidth` and `maxHeight`. `onClick` and `onChange` are component callbacks, and `onClick` is only called when a link is activated. The first server-rendered frame carries all links, and the `autoCollapse` folding is correct from the first frame; an item without child links renders no empty `role="list"`.

</Framework>

### Anchor.Link

<Framework only="react">

<AnchorLinkReactApi />

`id`, `data-*` and other native attributes are placed on the outermost div of the link (`role="listitem"`).

</Framework>

<Framework only="vue">

<AnchorLinkVueApi />

`class`, `style` and native attributes land on the outermost `div` (`role="listitem"`) of the link through attrs. `Anchor.Link` must be used inside `Anchor`, otherwise an error is thrown.

</Framework>

<Framework only="solid">

<AnchorLinkSolidApi />

`class`, `style`, `ref` and native attributes (such as `data-*`) land on the outermost `div` (`role="listitem"`) of the link.

</Framework>

<Framework only="svelte">

Svelte has no separate `Anchor.Link` component; each link is an item of the `links` data, with the fields described for `links` above.

</Framework>

## FAQ

1. **Why didn't my link highlight and slide to follow?**  
   Check whether you can scroll to the specified position by clicking the anchor:
    - No, it means there is a problem with the id. check whether the id exists in the document;
    - Yes, it may be that the scrolling container is not set correctly to ensure that the content of the document is wrapped in the scrolling container. The default scrolling container is window. If your container is a div of .my-container, you should set the scrolling container to this div.

<Framework only="react">

```text
import React from 'react';
import { Anchor } from '@fibrae/semi-ui-react';

function App() {
    const getContainer = () => {
        return document.querySelector('.my-container');
    };
    return (
        <Anchor
            /* Other props */
            getContainer={getContainer}
        >
            /* Links */
        </Anchor>
    )
}
```

</Framework>

<Framework only="vue">

```text
<script setup lang="ts">
import { Anchor } from '@fibrae/semi-ui-vue';

// This is the container of the document content, not of Anchor: the current id is computed against it
```
