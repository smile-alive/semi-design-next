**Props**

| Property | Description                                                                                                                          | Type          | Default |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------ | ------------- | ------- |
| disabled | Whether the link is disabled and ignores clicks.                                                                                     | `boolean`     | -       |
| href     | Target of the link. A value starting with # is looked up by element id, anything else as a CSS selector. Defaults to `#` when unset. | `string`      | -       |
| title    | Text of the link, which can be a node. When showTooltip is off and the value is a non-empty string, it is also the native title.     | `JSX.Element` | -       |
