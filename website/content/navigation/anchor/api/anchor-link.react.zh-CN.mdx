**Props**

| 属性      | 说明                                                                                | 类型                                                              | 默认值  |
| --------- | ----------------------------------------------------------------------------------- | ----------------------------------------------------------------- | ------- |
| children  | 下一级的 `Anchor.Link`，仅在链接展开时渲染。                                        | `React.ReactNode`                                                 | -       |
| className | 链接项的类名，落在最外层的 div 上。                                                 | `string`                                                          | -       |
| disabled  | 是否禁用，禁用后不响应点击跳转。                                                    | `boolean`                                                         | `false` |
| href      | 跳转的目标，以 # 开头时按元素 id 查找，其余按 CSS 选择器查找。                      | `string`                                                          | `"#"`   |
| ref       | 链接项（`role="listitem"`）最外层 div 的引用。                                      | <ApiType detail={"React.Ref\u003cHTMLDivElement>"}>Type</ApiType> | -       |
| style     | 链接项的样式，落在最外层的 div 上。                                                 | `React.CSSProperties`                                             | -       |
| title     | 链接的文字内容，可以是节点；未开启 showTooltip 且为非空字符串时同时作为原生 title。 | `React.ReactNode`                                                 | `""`    |
