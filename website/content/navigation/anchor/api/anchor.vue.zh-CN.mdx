**Props**

| 属性 | 说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| autoCollapse | 是否在滚动时动态展示下一级锚点。 | `boolean` | `semiDefault("Anchor", "autoCollapse", false)` |
| defaultAnchor | 默认高亮的锚点。 | `string` | `semiDefault("Anchor", "defaultAnchor", "")` |
| getContainer | 指定滚动的容器，缺省为 window；返回模板 ref 的值时容器出现或替换后自动换绑。 | <ApiType detail={"(() => HTMLElement \u007c Window \u007c null)"}>Type</ApiType> | `undefined` |
| maxHeight | 组件的 max-height，超出时显示滚动条；style 中的 max-height 优先。 | `string \| number` | `semiDefault("Anchor", "maxHeight", strings.MAX_HEIGHT)` |
| maxWidth | 组件的 max-width，超出时显示省略；style 中的 max-width 优先。 | `string \| number` | `semiDefault("Anchor", "maxWidth", strings.MAX_WIDTH)` |
| offsetTop | 滚动内容距离容器顶部达到指定偏移量时触发当前链接切换。 | `number` | `semiDefault("Anchor", "offsetTop", 0)` |

| scrollMotion | 点击锚点滚动时是否带动画。 | `boolean` | `semiDefault("Anchor", "scrollMotion", false)` |
| scrollIntoViewOptions | 点击锚点滚动时传给 scroll-into-view-if-needed 的选项，与 scrollMotion、targetOffset 合并使用。 | `Options` | `semiGlobalDefault("Anchor", "scrollIntoViewOptions")` |
| showTooltip | 文字缩略时是否显示 Tooltip 及相关配置：type 为浮层组件，支持 tooltip（默认）和 popover，opts 为传给浮层组件的属性。 | `boolean \| ShowTooltip` | `semiDefault("Anchor", "showTooltip", false)` |

| ------ | --------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------ |

| click  | 点击锚点或在锚点上按 Enter 时触发，参数为原生 MouseEvent 或 KeyboardEvent 与当前锚点；声明为组件事件后，@click 不再作为根元素的原生点击监听。 | `[event: AnchorClickEvent, currentLink: string]` |
