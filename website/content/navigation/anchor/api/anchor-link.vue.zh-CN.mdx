**Props**

| 属性     | 说明                                                                               | 类型      | 默认值      |
| -------- | ---------------------------------------------------------------------------------- | --------- | ----------- |
| disabled | 是否禁用，禁用后不响应点击跳转。                                                   | `boolean` | `false`     |
| href     | 跳转的目标，以 # 开头时按元素 id 查找，其余按 CSS 选择器查找。                     | `string`  | `"#"`       |
| title    | 纯文本标题；未开启 showTooltip 时同时作为原生 title，提供 title 插槽时以插槽为准。 | `string`  | `undefined` |

**Events**

| 事件 | 说明 | 回调参数 |
| ---- | ---- | -------- |
| 无   |      |          |

**Slots**

| 插槽    | 说明                                | 作用域参数 |
| ------- | ----------------------------------- | ---------- |
| default | 嵌套的下一级 Anchor.Link。          | `any`      |
| title   | 节点形式的标题，优先于 title 属性。 | `any`      |

| 名称 | 说明 | 类型 |
| ---- | ---- | ---- |
| 无   |      |      |
