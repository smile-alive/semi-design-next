**Props**

| 属性     | 说明                                                                                | 类型          | 默认值 |
| -------- | ----------------------------------------------------------------------------------- | ------------- | ------ |
| disabled | 是否禁用，禁用后不响应点击跳转。                                                    | `boolean`     | -      |
| href     | 跳转的目标，以 # 开头时按元素 id 查找，其余按 CSS 选择器查找；未设置时为 `#`。      | `string`      | -      |
| title    | 链接的文字内容，可以是节点；未开启 showTooltip 且为非空字符串时同时作为原生 title。 | `JSX.Element` | -      |
