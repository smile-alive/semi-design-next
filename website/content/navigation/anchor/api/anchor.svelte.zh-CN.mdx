**Props**

| 属性 | 说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| autoCollapse | 是否在滚动时动态展示下一级锚点。 | `boolean` | `false` |
| defaultAnchor | 默认高亮的锚点。 | `string` | `""` |
| getContainer | 指定滚动的容器，缺省为 window。 | <ApiType detail={"() => HTMLElement \u007c Window \u007c null"}>Type</ApiType> | - |
| links | 锚点数据，元素为 `{ href, title, disabled, children }`，`children` 嵌套下一级。`href` 以 # 开头时按元素 id 查找，其余按 CSS 选择器查找；`title` 为纯文本标题，未开启 showTooltip 时同时作为原生 title；`disabled` 禁用后不响应点击跳转。 | `AnchorLinkItem[]` | `[]` |
| maxHeight | 组件的 max-height，超出时显示滚动条；style 中的 max-height 优先。 | `string \| number` | `"750px"` |
| maxWidth | 组件的 max-width，超出时显示省略；style 中的 max-width 优先。 | `string \| number` | `"200px"` |
| offsetTop | 滚动内容距离容器顶部达到指定偏移量时触发当前链接切换。 | `number` | `0` |
| onChange | 高亮的锚点改变时的回调，参数为当前锚点与上一个锚点。 | <ApiType detail={"(currentLink: string, previousLink: string) => void"}>Type</ApiType> | - |
| onClick | 点击锚点或在锚点上按 Enter 时的回调，参数为原生 MouseEvent 或 KeyboardEvent 与当前锚点；只在激活链接时触发，点击根元素的其他位置不触发。 | <ApiType detail={"(event: AnchorClickEvent, currentLink: string) => void"}>Type</ApiType> | - |
| position | showTooltip 开启时 Tooltip 的显示位置，可选值同 Tooltip 的 position。 | `Position` | - |
| railTheme | 滑轨主题，可选 primary、tertiary、muted。 | `'primary' \| 'tertiary' \| 'muted'` | `"primary"` |
| scrollIntoViewOptions | 点击锚点滚动时传给 scroll-into-view-if-needed 的选项，与 scrollMotion、targetOffset 合并使用。 | `ScrollIntoViewOptions` | - |
| scrollMotion | 点击锚点滚动时是否带动画。 | `boolean` | `false` |
| showTooltip | 文字缩略时是否显示 Tooltip 及相关配置：type 为浮层组件，支持 tooltip（默认）和 popover，opts 为传给浮层组件的属性。 | `boolean \| ShowTooltip` | `false` |
| size | 锚点尺寸，可选 small、default。 | `'small' \| 'default'` | `"default"` |
| targetOffset | 锚点滚动结束时，目标距离容器顶部的偏移量。 | `number` | `0` |
| title | 渲染每个链接标题的 snippet，参数为 `{ item, level }`，`level` 为嵌套层级，顶层为 1；优先于 `links` 中的 `title`。 | <ApiType detail={"Snippet\u003c[AnchorTitleContext]>"}>Type</ApiType> | - |
