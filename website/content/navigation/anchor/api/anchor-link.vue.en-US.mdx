**Props**

| Property   | Description                                                                                                                                 | Type                                                                                | Default     |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------- | ----------- |
| classNames | Class names of the inner parts of the link, keyed by `title`; merged with the built-in classes, after the `itemTitle` class name of Anchor. | <ApiType detail={"Partial\u003cRecord\u003c\"title\", ClassValue>>"}>Type</ApiType> | `undefined` |
| disabled   | Whether the link is disabled and ignores clicks.                                                                                            | `boolean`                                                                           | `false`     |
| href       | Target of the link. A value starting with # is looked up by element id, anything else as a CSS selector.                                    | `string`                                                                            | `"#"`       |
| styles     | Inline styles of the inner parts of the link, keyed like `classNames`, after `styles` of Anchor.                                            | <ApiType detail={"Partial\u003cRecord\u003c\"title\", StyleValue>>"}>Type</ApiType> | `undefined` |
| title      | Plain-text title, also the native title when showTooltip is off. The title slot wins when it is provided.                                   | `string`                                                                            | `undefined` |
