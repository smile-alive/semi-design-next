**Props**

| 属性             | 说明                                                                                                                                                              | 类型                                                                             | 默认值                                            |
| ---------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------- | ------------------------------------------------- |
| duration         | 滚动到顶部所需的毫秒数；点击事件按此间隔节流。                                                                                                                    | `number`                                                                         | `semiDefault("BackTop", "duration", 450)`         |
| target           | 返回被监听滚动的元素的函数，未设置时为 window；返回 null 表示节点尚不可用。挂载时调用，函数本身变化时重新调用；模板 ref 在父组件 mounted 之前已赋值，可直接读取。 | <ApiType detail={"(() => Window \u007c HTMLElement \u007c null)"}>Type</ApiType> | `undefined`                                       |
| visibilityHeight | 出现 BackTop 需要达到的滚动高度。                                                                                                                                 | `number`                                                                         | `semiDefault("BackTop", "visibilityHeight", 400)` |
| badge            | 徽章参数，同 FloatButton。                                                                                                                                        | `FloatButtonBadge`                                                               | `semiGlobalDefault("BackTop", "badge")`           |
| colorful         | 多彩按钮，同 FloatButton；未设置时取 FloatButton 的默认值。                                                                                                       | `boolean`                                                                        | `semiGlobalDefault("BackTop", "colorful")`        |
| shape            | 形状，可选 round、square；未设置时取 FloatButton 的默认值。                                                                                                       | `"square" \| "round"`                                                            | `semiGlobalDefault("BackTop", "shape")`           |
| size             | 尺寸，可选 default、small、large；未设置时取 FloatButton 的默认值。                                                                                               | `"small" \| "default" \| "large"`                                                | `semiGlobalDefault("BackTop", "size")`            |

**Events**

| 事件  | 说明                                                                    | 回调参数              |
| ----- | ----------------------------------------------------------------------- | --------------------- |
| click | 点击时触发，载荷为原生 click 事件；按 duration 节流，发出时滚动已开始。 | `[event: MouseEvent]` |

**Slots**

| 插槽       | 说明                                                 | 作用域参数 |
| ---------- | ---------------------------------------------------- | ---------- |
| default    | 按钮内的静态内容，代替图标显示；不能包含可交互元素。 | `any`      |
| badgeCount | 自定义徽章内容，代替 badge.count。                   | `any`      |
| icon       | 按钮图标，默认 IconBackTop。                         | `any`      |
