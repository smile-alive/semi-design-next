### Basic Usage

BackTop is a [FloatButton](/en-US/react/basic/float-button) that appears once `target` scrolls past `visibilityHeight` and scrolls it back to the top when clicked. It shows a back-to-top icon by default, and its accessible name comes from the locale by default ('Back to top' in English), which `aria-label` can override.

## API Reference

<Framework only="react">

<BackTopReactApi />

Other native props (such as `data-*` and `aria-*`) are spread through `...rest` into FloatButton and land on the `<button>`.

</Framework>

<Framework only="vue">

<BackTopVueApi />

`class`, `style` and native attributes (such as `data-*` and `aria-*`) are passed through attrs and land on the button. `click` is a declared event, so it shadows a native click listener on the root and is throttled by `duration`. When `target` reads a template ref, the ref is already assigned before the parent's mounted hook; a stable `target` function that returns the element only after mount is not rebound, so remount BackTop. The `$el` of the component ref is the `<button>` while visible and a placeholder comment node otherwise.

</Framework>

<Framework only="solid">

<BackTopSolidApi />

`class`, `style`, `ref` and native attributes (such as `data-*` and `aria-*`) land on the button, and `onClick` is throttled by `duration`.

`target` is called once after mount, when the ref of a parent container is already readable; a stable `target` function that returns the element only after mount needs BackTop remounted.

</Framework>

<Framework only="svelte">

<BackTopSvelteApi />

`class`, `style` (a string) and native attributes (such as `data-*` and `aria-*`) land on the button. The click callback is the native `onclick`, throttled by `duration`, and `overrideDefaultProps.BackTop` cannot set it. `children`, `icon` and `badgeCount` are snippets.

`target` is called once after mount, when the element reference of a parent container is already readable; a stable `target` function that returns the element only after mount needs BackTop remounted.

</Framework>

## Accessibility

### ARIA

- BackTop renders a single native `<button type="button">`, which screen readers announce as a button
- The accessible name comes from `aria-label`; without it, it comes from the button content when content is passed, and otherwise from the locale's default name ('Back to top' in English)
- `children` (the default slot in Vue, a snippet in Svelte) is static content of the button and becomes part of its name; the button must not contain interactive elements

### Keyboard and focus

- Once visible, the button is reached with Tab and Shift + Tab, and Enter or Space scrolls to the top
- A focus outline is shown on keyboard focus
