**Events**

| 事件          | 说明                                                                             | 回调参数            |
| ------------- | -------------------------------------------------------------------------------- | ------------------- |
| play          | 开始播放时触发。                                                                 | `[]`                |
| pause         | 暂停时触发。                                                                     | `[]`                |
| qualityChange | 切换清晰度时触发，参数为所选清晰度的值。                                         | `[quality: string]` |
| rateChange    | 切换倍速时触发，参数为所选倍率。                                                 | `[rate: number]`    |
| routeChange   | 切换线路时触发，参数为所选线路的值。                                             | `[route: string]`   |
| volumeChange  | 用户拖动音量滑块或切换静音时触发，参数为变化后的音量，静音时为 0；初始化不触发。 | `[volume: number]`  |
