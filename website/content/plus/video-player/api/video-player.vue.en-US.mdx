**Events**

| Event         | Description                                                                                                                       | Callback parameters |
| ------------- | --------------------------------------------------------------------------------------------------------------------------------- | ------------------- |
| play          | Emitted when playback starts.                                                                                                     | `[]`                |
| pause         | Emitted when playback pauses.                                                                                                     | `[]`                |
| qualityChange | Emitted when the quality changes, with the selected quality value.                                                                | `[quality: string]` |
| rateChange    | Emitted when the playback rate changes, with the selected rate.                                                                   | `[rate: number]`    |
| routeChange   | Emitted when the route changes, with the selected route value.                                                                    | `[route: string]`   |
| volumeChange  | Emitted when the user drags the volume slider or toggles mute, with the new volume (0 when muted); not emitted on initialization. | `[volume: number]`  |
