### Set controls list

Set the display items of the menu bar through `controlsList`. The accepted value is an array. The default value is `['play', 'next', 'time', 'volume', 'playbackRate', 'quality', 'route', 'mirror', 'fullscreen', 'pictureInPicture']`

A control shows when `controlsList` allows it and the prop it depends on is provided: `next` needs `onNext`, `quality` needs a non-empty `qualityList`, and `route` needs a non-empty `routeList`; the other controls depend only on `controlsList`.

<Framework only="vue">

`onNext` is a function prop; write `@next` or `:onNext` in the template. Whether it is passed decides whether the Next button shows.

</Framework>

<Framework only="solid">

`onNext` is a function prop. Passing it, with `next` in `controlsList`, shows the Next button, and clicking the button calls it.

</Framework>

<Framework only="svelte">

`onNext` is a function prop. Passing it, with `next` in `controlsList`, shows the Next button, and clicking the button calls it.

</Framework>

### Using ref for control

<Framework only="react">

Get the native video element via `ref` for more flexible control, such as synchronized playback/pause of multiple videos

</Framework>

<Framework only="vue">

Get the component instance through a template ref (`useTemplateRef`); its `video` property is the native video element, for more flexible control such as synchronized playback/pause of multiple videos. It is `null` before mount

</Framework>

<Framework only="solid">

Pass a callback to `ref`; it is called with the native video element, for more flexible control such as synchronized playback/pause of multiple videos

</Framework>

<Framework only="svelte">

Bind the component with `bind:this` and call its `getVideo()` method, which returns the native video element, for more flexible control such as synchronized playback/pause of multiple videos. It returns `undefined` before mount

</Framework>

### Keyboard and focus

- While focus is inside the player, Space toggles play and pause, except on a button or an input control, which keeps the key; the left and right arrow keys rewind and fast forward by `seekTime`, except inside an input control, the progress bar or a menu, which keep the keys. Combinations with Alt, Ctrl or Meta are ignored.
- The progress bar is a slider (`role="slider"`): the arrow keys move it by `seekTime`, PageUp and PageDown by a tenth of the duration, and Home and End jump to either end. Screen readers announce "current time / total time".
- The playback rate, quality and route buttons open their menu when focused with Tab; the down and up arrow keys move focus to the first and last item. In the menu, the up and down arrow keys, Home and End move focus, Enter or Space selects, and Esc closes the menu and returns to the button.
- The volume popover opens when the volume button receives focus, and Enter or Space toggles mute; the down arrow key moves focus into the popover, where the volume slider takes the arrow keys.
- When the pointer leaves the player during playback, the control bar stays visible while it holds keyboard focus.

### API

<Framework only="react">

<VideoPlayerReactApi />

Other native attributes (such as `id`, `aria-*`, `onClick`) fall through to the root `div`. When the root has `aria-label` or `aria-labelledby` it gets `role="group"`, and a `role` you pass takes precedence. Media events (`onTimeUpdate` and so on) do not bubble to the root, so listening to them on the component is not supported; get the native element through `ref` and listen on it instead.

</Framework>

<Framework only="vue">

<VideoPlayerVueApi />

`class`, `style` and native attributes fall through to the root `div` as attrs, and a width or height in `style` overrides the `width` and `height` props. When the root has `aria-label` or `aria-labelledby` it gets `role="group"`, and a `role` you pass takes precedence. Media events (`timeupdate`, `ended` and so on) do not bubble to the root, so listening to them on the component is not supported; get the native element through `video` and listen on it instead.

</Framework>

<Framework only="solid">

<VideoPlayerSolidApi />

`class`, `style`, native attributes and events (such as `id`, `aria-*`, `onClick`, `onMouseEnter`) fall through to the root `div`, and a width or height in `style` overrides the `width` and `height` props. When the root has `aria-label` or `aria-labelledby` it gets `role="group"`, and a `role` you pass takes precedence. `ref` points at the video element, not the root. Media events (`timeupdate`, `ended` and so on) do not bubble to the root, so listening to them on the component is not supported; get the native element through `ref` and listen on it instead.

</Framework>

<Framework only="svelte">

<VideoPlayerSvelteApi />

`class` (a string, array or object) and native attributes fall through to the root `div`, `style` is a string, and a width or height in `style` overrides the `width` and `height` props. When the root has `aria-label` or `aria-labelledby` it gets `role="group"`, and a `role` you pass takes precedence. Media events (`ontimeupdate`, `onended` and so on) do not bubble to the root, so listening to them on the component is not supported; get the native element through `getVideo()` and listen on it instead.

</Framework>
