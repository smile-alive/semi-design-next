### 设置菜单栏功能

通过 `controlsList` 设置菜单栏的展示项，该项接受值为数组，默认值为`['play', 'next', 'time', 'volume', 'playbackRate', 'quality', 'route', 'mirror', 'fullscreen', 'pictureInPicture']`

控件在 `controlsList` 允许、并且它所依赖的属性已提供时才显示：`next` 需要 `onNext`，`quality` 需要非空的 `qualityList`，`route` 需要非空的 `routeList`；其余控件只看 `controlsList`。

<Framework only="vue">

`onNext` 是函数 prop，模板里写 `@next` 或 `:onNext` 都可以；传与不传决定「下一个」按钮是否显示。

</Framework>

<Framework only="solid">

`onNext` 是函数 prop，传入它且 `controlsList` 包含 `next` 时才显示「下一个」按钮，点击时调用该函数。

</Framework>

### 键盘和焦点

- 焦点在播放器内时，空格键切换播放与暂停，焦点在按钮或输入控件上时空格键交给该控件；左右方向键按 `seekTime` 快退、快进，焦点在输入控件、进度条或菜单内时方向键交给它们。带 Alt、Ctrl、Meta 的组合键不处理。
- 进度条是滑块（`role="slider"`），用方向键按 `seekTime` 增减，PageUp、PageDown 按总时长的十分之一增减，Home、End 跳到两端。读屏读出的是「当前时长 / 总时长」。
- 倍速、清晰度、线路按钮用 Tab 聚焦即展开菜单，下、上方向键把焦点移到菜单的第一项、最后一项；菜单内用上下方向键与 Home、End 移动，Enter 或空格确认，Esc 关闭并回到按钮。
- 音量按钮获得焦点时展开音量弹层，Enter 或空格切换静音；下方向键把焦点移进弹层，音量滑块用方向键调节。
- 播放中指针离开播放器后，控制栏内有键盘焦点时控制栏保持显示。

### API

<Framework only="react">

<VideoPlayerReactApi />

其他原生属性（如 `id`、`aria-*`、`onClick`）落在根元素 `div` 上。根元素带 `aria-label` 或 `aria-labelledby` 时自动加 `role="group"`，自己传 `role` 则以传入的为准。媒体事件（`onTimeUpdate` 等）不会冒泡到根元素，因此不支持在组件上监听，需要时通过 `ref` 取得原生元素后自行监听。

</Framework>

<Framework only="vue">

<VideoPlayerVueApi />

`class`、`style` 与原生属性经 attrs 落在根元素 `div` 上，`style` 中的 width、height 覆盖 `width`、`height` 属性；根元素带 `aria-label` 或 `aria-labelledby` 时自动加 `role="group"`，自己传 `role` 则以传入的为准。媒体事件（`timeupdate`、`ended` 等）不会冒泡到根元素，因此不支持在组件上监听，需要时通过 `video` 取得原生元素后自行监听。

</Framework>

<Framework only="solid">

<VideoPlayerSolidApi />

`class`、`style` 与原生属性和事件（如 `id`、`aria-*`、`onClick`、`onMouseEnter`）落在根元素 `div` 上，`style` 中的 width、height 覆盖 `width`、`height` 属性；根元素带 `aria-label` 或 `aria-labelledby` 时自动加 `role="group"`，自己传 `role` 则以传入的为准。`ref` 指向的是 video 元素而不是根元素。媒体事件（`timeupdate`、`ended` 等）不会冒泡到根元素，因此不支持在组件上监听，需要时通过 `ref` 取得原生元素后自行监听。

#### VideoPlayerOption

`playbackRateList`、`qualityList`、`routeList` 的选项类型，`value` 的类型随列表而定（倍速为 `number`，清晰度与线路为 `string`）。

| 属性  | 说明                 | 类型             | 默认值 |
| ----- | -------------------- | ---------------- | ------ |
| label | 菜单中显示的名称     | string           | -      |
| value | 选项值，事件参数取此 | number \| string | -      |

</Framework>

<Framework only="solid">

#### VideoPlayerOption

| value | 选项值，回调参数取此 | `T`      | -      |

</Framework>
