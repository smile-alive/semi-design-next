import ApiType from '#/components/ApiType.astro';

**Props**

| 属性 | 说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| modelValue | 编辑器的文本，配合 v-model 使用；变为与编辑器当前内容不同的值时重建编辑器，与当前内容相同的回写不会丢失光标；未传时按空文本创建。 | `string` | `undefined` |
| width | 宽度，数字按 px 处理，字符串原样使用。 | `string \| number` | `semiDefault("JsonViewer", "width", 400)` |
| height | 高度，数字按 px 处理，字符串原样使用。 | `string \| number` | `semiDefault("JsonViewer", "height", 400)` |
| showSearch | 是否显示搜索按钮。 | `boolean` | `semiDefault("JsonViewer", "showSearch", true)` |
| options | 编辑器配置，字段见 JsonViewerOptions。ariaLabel、readOnly、autoWrap 的默认值按键合并，只传部分字段时其余仍取默认值。内容按深比较变化时重建编辑器；就地修改 formatOptions、customRenderRule 等嵌套对象不会被察觉，需替换为新对象。 | `JsonViewerOptions` | `semiGlobalDefault("JsonViewer", "options")` |
| limitSearchButtonBounds | 是否限制搜索按钮的拖动范围在组件容器内。 | `boolean` | `semiDefault("JsonViewer", "limitSearchButtonBounds", false)` |

**Events**

| 事件              | 说明                                                                                                          | 回调参数          |
| ----------------- | ------------------------------------------------------------------------------------------------------------- | ----------------- |
| update:modelValue | 编辑内容变化时触发，供 v-model 回写，参数为编辑器当前文本。                                                   | `[value: string]` |
| change            | 编辑内容变化时触发，参数为编辑器当前文本。它是组件事件，`@change` 不会收到搜索栏输入框冒泡上来的原生 change。 | `[value: string]` |

**Slots**

| 插槽         | 说明                                                                                                                                                                 | 作用域参数                        |
| ------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------- |
| customRender | 替换被 options.customRenderRule 命中的 token 的内容，作用域参数为命中的规则 item、规则序号 index 与 token 原文 content；不提供或为空时保留原文。仅在只读模式下生效。 | `JsonViewerCustomRenderSlotProps` |
| searchButton | 整体替换默认搜索按钮；defaultButton 是默认按钮的 VNode，用 `<component :is>` 渲染，其余参数用于自建搜索界面。showSearch 为 false 时不渲染。                          | `JsonViewerSearchButtonSlotProps` |

**Exposes**

| 名称             | 说明                                                                 | 类型                                                                                                                                                                              |
| ---------------- | -------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| getValue         | 获取编辑器当前文本。                                                 | <ApiType detail={"() => string"}>Type</ApiType>                                                                                                                                   |
| format           | 按 formatOptions 格式化当前内容。                                    | <ApiType detail={"() => void"}>Type</ApiType>                                                                                                                                     |
| search           | 搜索文本，可选参数控制大小写敏感、全词匹配和正则表达式。             | <ApiType detail={"(searchText: string, caseSensitive?: boolean \u007c undefined, wholeWord?: boolean \u007c undefined, regex?: boolean \u007c undefined) => void"}>Type</ApiType> |
| getSearchResults | 获取当前搜索结果。                                                   | <ApiType detail={"() => FindMatch[] \u007c null \u007c undefined"}>Type</ApiType>                                                                                                 |
| prevSearch       | 跳转到上一个搜索结果，可选步长。                                     | <ApiType detail={"(step?: number \u007c undefined) => void"}>Type</ApiType>                                                                                                       |
| nextSearch       | 跳转到下一个搜索结果，可选步长。                                     | <ApiType detail={"(step?: number \u007c undefined) => void"}>Type</ApiType>                                                                                                       |
| replace          | 替换当前搜索匹配项；替换文本为空串时删除匹配，没有匹配时不做任何事。 | <ApiType detail={"(replaceText: string) => void"}>Type</ApiType>                                                                                                                  |
| replaceAll       | 替换所有搜索匹配项；替换文本为空串时删除全部匹配。                   | <ApiType detail={"(replaceText: string) => void"}>Type</ApiType>                                                                                                                  |
| getStyle         | 返回当前的 width 与 height。                                         | <ApiType detail={"() => { width: string \u007c number; height: string \u007c number; }"}>Type</ApiType>                                                                           |
