**Props**

| Property   | Description                                                                                                                                                                                                        | Type                  | Default                                            |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------- | -------------------------------------------------- |
| code       | Plain text of the code, treated as an empty string when omitted. After code changes the new text shows first and is replaced once highlighting finishes.                                                           | `string`              | `semiGlobalDefault("CodeHighlight", "code")`       |
| language   | Language, which must be registered or passed through languages.                                                                                                                                                    | `string`              | `undefined`                                        |
| lineNumber | Whether to show line numbers.                                                                                                                                                                                      | `boolean`             | `semiDefault("CodeHighlight", "lineNumber", true)` |
| languages  | Extra Shiki grammars for this block; once loaded, other blocks can use them too. Declare it at the top level of script setup, not as an inline array in the template, which would highlight again on every render. | `LanguageInput[]`     | `semiGlobalDefault("CodeHighlight", "languages")`  |
| themes     | Replaces the Shiki themes of this block for light and dark mode.                                                                                                                                                   | `CodeHighlightThemes` | `semiGlobalDefault("CodeHighlight", "themes")`     |
