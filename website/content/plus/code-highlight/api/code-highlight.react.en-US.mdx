**Props**

| Property   | Description                                                                                                                                                                              | Type                                                              | Default |
| ---------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------- | ------- |
| className  | Class name of the root element.                                                                                                                                                          | `string`                                                          | -       |
| code       | Plain text of the code, treated as an empty string when omitted. After `code` changes the new text shows right away and is replaced once highlighting finishes.                          | `string`                                                          | -       |
| language   | Language, which must be registered or passed through `languages`.                                                                                                                        | `string`                                                          | -       |
| languages  | Extra Shiki grammars for this block; once loaded, other blocks can use them too. Assigning a new array reference highlights the block again.                                             | `LanguageInput[]`                                                 | -       |
| lineNumber | Whether to show line numbers.                                                                                                                                                            | `boolean`                                                         | `true`  |
| ref        | Reference to the root `div` element.                                                                                                                                                     | <ApiType detail={"React.Ref\u003cHTMLDivElement>"}>Type</ApiType> | -       |
| style      | Style of the root element.                                                                                                                                                               | `React.CSSProperties`                                             | -       |
| themes     | Replaces the Shiki themes of this block for light and dark mode. Without it, the themes registered by `CodeHighlight.register` apply, which default to `github-light` and `github-dark`. | `CodeHighlightThemes`                                             | -       |
