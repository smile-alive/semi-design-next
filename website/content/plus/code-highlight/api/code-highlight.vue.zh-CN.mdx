**Props**

| 属性       | 说明                                                                                                                                    | 类型                  | 默认值                                             |
| ---------- | --------------------------------------------------------------------------------------------------------------------------------------- | --------------------- | -------------------------------------------------- |
| code       | 代码纯文本，未传时按空字符串处理。code 变化后先显示新文本，高亮完成后再替换。                                                           | `string`              | `semiGlobalDefault("CodeHighlight", "code")`       |
| language   | 语言类型，需已注册或经 languages 传入。                                                                                                 | `string`              | `undefined`                                        |
| lineNumber | 是否开启行数显示。                                                                                                                      | `boolean`             | `semiDefault("CodeHighlight", "lineNumber", true)` |
| languages  | 该代码块额外使用的 Shiki 语法，加载后其他代码块也可使用。请在 script setup 顶层声明，不要在模板里写内联数组，否则每次渲染都会重新高亮。 | `LanguageInput[]`     | `semiGlobalDefault("CodeHighlight", "languages")`  |
| themes     | 替换该代码块亮色、暗色模式下的 Shiki 主题。                                                                                             | `CodeHighlightThemes` | `semiGlobalDefault("CodeHighlight", "themes")`     |
