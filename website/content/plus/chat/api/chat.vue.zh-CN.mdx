import ApiType from '#/components/ApiType.astro';

**Props**

| 属性                     | 说明                                                                                                                                    | 类型                                                                    | 默认值                                                  |
| ------------------------ | --------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------- | ------------------------------------------------------- |
| chats                    | 对话列表，配合 v-model:chats 使用。只有整体替换数组才视为变化，就地 push 不会触发跟随滚动。                                             | `Message[]`                                                             | `semiGlobalDefault("Chat", "chats")`                    |
| align                    | 对话布局方式，可选 leftRight（左右分布）或 leftAlign（左对齐）。                                                                        | `ChatAlign`                                                             | `semiDefault("Chat", "align", "leftRight")`             |
| mode                     | 对话模式，可选 bubble、noBubble 或 userBubble。                                                                                         | `ChatMode`                                                              | `semiDefault("Chat", "mode", "bubble")`                 |
| roleConfig               | 角色信息，键为消息的 role。avatar 只接受图片 URL，节点头像使用 roleAvatar 插槽；color 传给 Avatar。                                     | `ChatRoleConfig`                                                        | `semiGlobalDefault("Chat", "roleConfig")`               |
| hints                    | 提示信息列表。点击某项后触发 hintClick，并将该项作为新的用户消息。                                                                      | `string[]`                                                              | `semiGlobalDefault("Chat", "hints")`                    |
| sendHotKey               | 发送快捷键，可选 enter 或 shift+enter。enter 时单独按 Enter 发送，Shift+Enter 换行；shift+enter 相反。                                  | `SendHotKey`                                                            | `semiDefault("Chat", "sendHotKey", "enter")`            |
| placeholder              | 输入框占位符。                                                                                                                          | `string`                                                                | `semiGlobalDefault("Chat", "placeholder")`              |
| showStopGenerate         | 是否在最后一条消息生成中时显示停止生成按钮。生成中发送按钮不可用，点击停止按钮触发 stopGenerator。                                      | `boolean`                                                               | `semiDefault("Chat", "showStopGenerate", false)`        |
| showClearContext         | 是否在输入框中显示清除上下文按钮。                                                                                                      | `boolean`                                                               | `semiDefault("Chat", "showClearContext", false)`        |
| enableUpload             | 是否启用上传。布尔值同时控制粘贴、点击和拖拽上传；传对象时分别设置 pasteUpload、clickUpload、dragUpload，未设置的项为 true。            | `boolean \| EnableUploadProps`                                          | `semiDefault("Chat", "enableUpload", true)`             |
| canSend                  | 发送按钮是否可用。通常由内部逻辑决定，设置后以此值为准。                                                                                | `boolean`                                                               | `semiGlobalDefault("Chat", "canSend")`                  |
| escapeHtml               | 是否转义用户消息中的 HTML 标签，防止被 Markdown 解析器当作 HTML 处理导致内容丢失。                                                      | `boolean`                                                               | `semiDefault("Chat", "escapeHtml", true)`               |
| uploadProps              | 传给 Upload 的属性，fileList 与 defaultFileList 由 Chat 管理，Upload 的事件以 onXxx 形式传入。添加或移除附件时 Chat 自己处理 onChange。 | `ChatUploadProps`                                                       | `semiGlobalDefault("Chat", "uploadProps")`              |
| uploadTipProps           | 上传按钮提示 Tooltip 的属性，不含 content；提示文字使用 uploadTip 插槽。                                                                | <ApiType detail={"Omit\u003cTooltipProps, \"content\">"}>Type</ApiType> | `semiGlobalDefault("Chat", "uploadTipProps")`           |
| markdownRenderProps      | 传给消息内容所用 MarkdownRender 的属性，默认 format 为 md。raw 与 components 不可设置，自定义渲染组件使用 customMarkDownComponents。    | `ChatMarkdownRenderProps`                                               | `semiGlobalDefault("Chat", "markdownRenderProps")`      |
| customMarkDownComponents | 自定义 Markdown 渲染组件，键为元素名，传给消息内容的 MarkdownRender。                                                                   | `MarkdownRenderComponents`                                              | `semiGlobalDefault("Chat", "customMarkDownComponents")` |
| inputBoxCls              | 输入框的类名。                                                                                                                          | `string`                                                                | `semiGlobalDefault("Chat", "inputBoxCls")`              |
| inputBoxStyle            | 输入框的样式。                                                                                                                          | `StyleValue`                                                            | `semiGlobalDefault("Chat", "inputBoxStyle")`            |
| hintCls                  | 提示区最外层的类名。                                                                                                                    | `string`                                                                | `semiGlobalDefault("Chat", "hintCls")`                  |
| hintStyle                | 提示区最外层的样式。                                                                                                                    | `StyleValue`                                                            | `semiGlobalDefault("Chat", "hintStyle")`                |

**Events**

| 事件                | 说明                                                            | 回调参数                                                  |
| ------------------- | --------------------------------------------------------------- | --------------------------------------------------------- |
| update:chats        | 对话列表变化时触发，供 v-model:chats 回写；先于 chatsChange。   | `[chats: Message[]]`                                      |
| chatsChange         | 对话列表变化时触发。                                            | `[chats: Message[]]`                                      |
| messageSend         | 发送消息时触发，参数为文本内容和附件。                          | `[content: string, attachment?: FileItem[] \| undefined]` |
| messageCopy         | 复制消息时触发。                                                | `[message: Message]`                                      |
| messageGoodFeedback | 消息正向反馈时触发。                                            | `[message: Message]`                                      |
| messageBadFeedback  | 消息负向反馈时触发。                                            | `[message: Message]`                                      |
| messageReset        | 重置消息时触发；由 resetMessage 方法触发时参数为 null。         | `[message: Message \| null]`                              |
| messageDelete       | 删除消息时触发。                                                | `[message: Message]`                                      |
| clear               | 清除上下文时触发。                                              | `[]`                                                      |
| hintClick           | 点击提示信息时触发。                                            | `[hint: string]`                                          |
| inputChange         | 输入内容或附件变化时触发，参数为 `{ inputValue, attachment }`。 | `[props: ChatInputChangeProps]`                           |
| stopGenerator       | 点击停止生成按钮时触发。                                        | `[event: MouseEvent]`                                     |

**Slots**

| 插槽         | 说明                                                                                                                                             | 作用域参数                 |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------- |
| topSlot      | 对话区域顶部的内容。                                                                                                                             | `any`                      |
| bottomSlot   | 输入框下方的内容。                                                                                                                               | `any`                      |
| title        | 自定义消息标题，参数为 message、role 和默认标题 defaultTitle。提供但内容为空时不显示标题。                                                       | `ChatTitleSlotProps`       |
| avatar       | 自定义消息头像，参数为 message、role 和默认头像 defaultAvatar。提供但内容为空时不显示头像。                                                      | `ChatAvatarSlotProps`      |
| roleAvatar   | 没有图片 URL 的角色的头像内容，参数为 message 和 role。                                                                                          | `ChatRoleAvatarSlotProps`  |
| content      | 自定义消息内容区域，参数为 message、role、默认内容 defaultContent 和类名 class。                                                                 | `ChatContentSlotProps`     |
| action       | 自定义消息操作栏，参数为 message、默认按钮数组 defaultActions、按名称索引的 defaultActionsObj 和类名 class。                                     | `ChatActionSlotProps`      |
| fullChatBox  | 完全自定义整个消息框，参数为 message、role、各部分默认节点 defaultNodes 和类名 class。                                                           | `ChatFullChatBoxSlotProps` |
| inputArea    | 自定义输入区域，参数为 defaultNode、各部分节点（clearContextNode、uploadNode、inputNode、sendNode）以及需要自行调用的 onSend、onClear、onClick。 | `ChatInputAreaSlotProps`   |
| hintBox      | 自定义提示项，参数为 content、index 和点击处理函数 onHintClick。                                                                                 | `ChatHintBoxSlotProps`     |
| divider      | 自定义清除上下文后的分割线，参数为 message。                                                                                                     | `ChatDividerSlotProps`     |
| uploadButton | 替换上传按钮。                                                                                                                                   | `any`                      |
| uploadTip    | 上传按钮的提示文字。                                                                                                                             | `any`                      |

**Exposes**

| 名称           | 说明                                                                        | 类型                                                                                                   |
| -------------- | --------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| resetMessage   | 将最后一条消息重置为空内容的 loading 状态并触发 messageReset，参数为 null。 | <ApiType detail={"() => void"}>Type</ApiType>                                                          |
| clearContext   | 在对话末尾追加分割线以清除上下文并触发 clear；末尾已是分割线时无效果。      | <ApiType detail={"() => void"}>Type</ApiType>                                                          |
| scrollToBottom | 滚动到最底部，animation 为 true 时平滑滚动，否则直接跳转。                  | <ApiType detail={"(animation?: boolean \u007c undefined) => void"}>Type</ApiType>                      |
| sendMessage    | 发送消息，不传 attachment 时消息的 content 为字符串。                       | <ApiType detail={"(content: string, attachment?: FileItem[] \u007c undefined) => void"}>Type</ApiType> |
