## 使用场景

Chat 组件可用于普通会话，AI 会话等场景。

<Framework only="react">

对话内容渲染基于 [MarkdownRender](/zh-CN/react/plus/markdown-render) 组件，支持 Markdown 和 MDX (注：Chat 中的 MarkdownRender 的默认 format 模式是 md，如果需要使用 MDX 格式，可通过 markdownRenderProps API 设置)，可实现图片，表格，链接，加粗，代码区等常用富文本功能。也可通过 JSX 实现更加复杂定制化的文档撰写与展示需求。代码区的高亮语言需先通过 [CodeHighlight](/zh-CN/react/plus/code-highlight) 的 `CodeHighlight.register` 注册。

</Framework>

### 基本用法

<Framework only="react">

通过设置 `chats` 和 `onChatsChange`，`onMessageSend` 实现基础对话显示和交互。

</Framework>

<Framework only="vue">

通过 `v-model:chats` 绑定对话列表，`@messageSend` 监听发送实现基础对话显示和交互。`v-model:chats` 在列表变化时先触发 `update:chats`，再触发 `chatsChange`；只用单向的 `:chats` 而不回写时，列表保持不变。

</Framework>

<Framework only="solid">

通过设置 `chats`、`onChatsChange` 和 `onMessageSend` 实现基础对话显示和交互。`chats` 是受控属性，只有在 `onChatsChange` 中写回新的列表，对话列表才会变化。

</Framework>

附件支持通过点击上传按钮，输入框粘贴，拖拽文件至 Chat 区域上传。通过 `uploadProps` 设置上传参数，详情参考 [Upload](/zh-CN/react/input/upload#API%20%E5%8F%82%E8%80%83)。

<Framework only="react">

上传按钮的提示文案可通过 `uploadTipProps` 设置，详情参考 [Tooltip](/zh-CN/react/show/tooltip#API%20%E5%8F%82%E8%80%83)。

</Framework>

<Framework only="vue">

上传按钮的提示文案通过 `#uploadTip` 插槽设置，Tooltip 的其他属性通过 `uploadTipProps` 设置（不含 `content`），详情参考 [Tooltip](/zh-CN/react/show/tooltip#API%20%E5%8F%82%E8%80%83)。

</Framework>

<Framework only="solid">

上传按钮的提示文案可通过 `uploadTipProps` 设置，`content` 为提示文字，详情参考 [Tooltip](/zh-CN/react/show/tooltip#API%20%E5%8F%82%E8%80%83)。

</Framework>

对话是多方参与，多轮交互的场景。可通过 `roleConfig` 传入角色信息（包括名称，头像等），具体参数细节 [RoleConfig](#roleConfig)。

使用 `align` 属性可以设置对话的布局，支持左右分布（`leftRight`， 默认）和左对齐（`leftAlign`）。

<Framework only="solid">

通过 `chatBoxRenderConfig` 传入自定义渲染配置, chatBoxRenderConfig 类型如下

```ts
export interface RenderTitleProps {
    readonly message?: Message;
    readonly role?: Metadata;
    /* 创建默认标题，在插入处调用 */
    readonly defaultTitle?: () => JSX.Element;
}

export interface RenderAvatarProps {
    readonly message?: Message;
    readonly role?: Metadata;
    /* 创建默认头像，在插入处调用 */
    readonly defaultAvatar?: () => JSX.Element;
}

export interface RenderRoleAvatarProps {
    readonly message?: Message;
    readonly role?: Metadata;
}

export interface RenderContentProps {
    readonly message?: Message;
    readonly role?: Metadata;
    /* 创建默认内容，在插入处调用 */
    readonly defaultContent?: () => JSX.Element;
    readonly class?: string;
}

/* 与默认操作栏显示的按钮一致，按钮不显示时（如消息未完成）对应的键不存在；值是按钮的渲染函数 */
export interface DefaultActionNodeObj {
    readonly copyNode?: () => JSX.Element;
    readonly likeNode?: () => JSX.Element;
    readonly dislikeNode?: () => JSX.Element;
    readonly resetNode?: () => JSX.Element;
    readonly deleteNode?: () => JSX.Element;
}

export interface RenderActionProps {
    readonly message?: Message;
    /* 默认按钮的渲染函数，按显示顺序排列；在插入处调用 */
    readonly defaultActions?: (() => JSX.Element)[];
    readonly class: string;
    defaultActionsObj?: DefaultActionNodeObj;
}

export interface FullChatBoxNodes {
    readonly avatar?: JSX.Element;
    readonly title?: JSX.Element;
    readonly content?: JSX.Element;
    readonly action?: JSX.Element;
}

export interface RenderFullChatBoxProps {
    readonly message?: Message;
    readonly role?: Metadata;
    defaultNodes?: FullChatBoxNodes;
    readonly class: string;
}

export interface ChatBoxRenderConfig {
    /* 自定义渲染标题 */
    renderChatBoxTitle?: (props: RenderTitleProps) => JSX.Element;
    /* 自定义渲染头像 */
    renderChatBoxAvatar?: (props: RenderAvatarProps) => JSX.Element;
    /* 渲染内置头像里的内容，用于 avatar 图片地址之外的头像 */
    renderRoleAvatar?: (props: RenderRoleAvatarProps) => JSX.Element;
    /* 自定义渲染内容区域 */
    renderChatBoxContent?: (props: RenderContentProps) => JSX.Element;
    /* 自定义渲染消息操作栏 */
    renderChatBoxAction?: (props: RenderActionProps) => JSX.Element;
    /* 完全自定义渲染整个聊天框 */
    renderFullChatBox?: (props: RenderFullChatBoxProps) => JSX.Element;
}
```

每个渲染函数对每条消息调用一次，替换函数时重新调用。参数的字段是 getter，返回的 JSX 会随消息流式更新。默认节点是渲染函数（`defaultTitle`、`defaultAvatar`、`defaultContent`、`defaultNodes` 的各项、操作栏按钮 `defaultActions` 的各项与 `defaultActionsObj` 的各值），每次调用都会新建节点，只在插入处调用，没有调用的节点不会创建，例如 `{props.defaultTitle?.()}`、`<For each={props.defaultActions}>{(action) => action()}</For>`。

</Framework>

### 自定义渲染输入框

<Framework only="react">

可通过 `renderInputArea` 自定义渲染输入框，参数如下

```ts
export interface RenderInputAreaProps {
    /* 默认节点 */
    defaultNode?: ReactNode;
    /* 如果自定义输入框，发送消息时需调用 */
    onSend?: (content?: string, attachment?: FileItem[]) => void;
    /* 如果自定义清除上下文按钮，点击清除上下文时需调用 */
    onClear?: (e?: any) => void;
    detailProps: {
        /* 清除上下文按钮 */
        clearContextNode?: ReactNode;
        /* 上传按钮 */
        uploadNode?: ReactNode;
        /* 文本输入框 */
        inputNode?: ReactNode;
        /* 发送按钮 */
        sendNode?: ReactNode;
        /* 点击触发聚焦文本输入框的处理函数*/
        onClick?: () => void; // 聚焦输入框
    };
}
```

`detailProps` 的使用示例如下

```jsx
function CustomInputRender(props) {
    const { detailProps } = props;
    const { clearContextNode, uploadNode, inputNode, sendNode, onClick } = detailProps;

    return (
        <div
            style={{
                margin: '8px 16px',
                display: 'flex',
                flexDirection: 'row',
                alignItems: 'flex-end',
                borderRadius: 16,
                padding: 10,
                border: '1px solid var(--semi-color-border)',
            }}
            onClick={onClick}
        >
            {uploadNode}
            {inputNode}
            {sendNode}
        </div>
    );
}
```

</Framework>

## API 参考

<Framework only="react">

<ChatReactApi />

其他未声明的原生属性（如 `data-*`、`id`）落在根元素 `div` 上；根元素带有 `aria-label` 或 `aria-labelledby` 且没有传 `role` 时，自动加上 `role="group"`。`onDragOver`、`onDragStart`、`onDragEnd` 监听同样落在根元素上，Chat 自己的拖拽上传处理先于使用方的监听执行。

#### RoleConfig

| 属性      | 说明     | 类型     | 默认值 |
| --------- | -------- | -------- | ------ |
| user      | 用户信息 | Metadata | -      |
| assistant | 助手信息 | Metadata | -      |
| system    | 系统信息 | Metadata | -      |

#### Metadata

| 属性   | 说明                                                                                                                                                                                                                | 类型                | 默认值 |
| ------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------- | ------ |

## Accessibility

### 键盘和焦点

- 输入框中按 `Enter` 或 `Shift` + `Enter` 发送消息，由 `sendHotKey` 决定：`enter` 时 `Enter` 发送、`Shift` + `Enter` 换行，`shift+enter` 相反。
- 在输入框按 `Shift` + `Tab` 回到上传按钮。默认的上传按钮是原生按钮，`Enter` 或 `Space` 打开文件选择；设置了上传提示时，提示文字是该按钮的描述，按钮获得焦点时显示。
- 停止生成按钮仅在生成中出现。生成结束、按钮卸载时，如果焦点在它上面，焦点回到输入框，不会落到页面开头。
- 除最后一条已完成的消息外，消息操作栏平时隐藏，仍在 `Tab` 顺序中，焦点进入其中的按钮时显示。删除按钮打开的确认框按 `Esc` 关闭，焦点回到删除按钮；在 Modal 中只关闭确认框，Modal 保持打开。
- 消息列表是带名称的 `role="log"` 区域，最后一条消息生成中时带 `aria-busy="true"`，读屏在回复完成后再播报，不逐段朗读。
