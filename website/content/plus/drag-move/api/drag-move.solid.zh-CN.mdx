import ApiType from '#/components/ApiType.astro';

**Props**

| 属性             | 说明                                                                                                          | 类型                                                                                         | 默认值       |
| ---------------- | ------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------- | ------------ |
| allowInputDrag   | 在原生 input、textarea 上按下时是否允许拖动。                                                                 | `boolean`                                                                                    | `false`      |
| allowMove        | 按下时判断是否允许拖动的函数，返回 false 则不拖动。                                                           | <ApiType detail={"(e: PointerEvent, element: HTMLElement) => boolean"}>Type</ApiType>        | -            |
| children         | 被拖动的内容。每个顶层 DOM 元素各自可拖动，文本节点无法拖动。                                                 | `JSX.Element`                                                                                | -            |
| constrainer      | 限制拖动范围的元素：`'parent'` 表示父级元素，或返回该元素的函数；该元素需要为 relative 定位。                 | <ApiType detail={"'parent' \u007c (() => HTMLElement \u007c null)"}>Type</ApiType>           | -            |
| customMove       | 自定义拖动后的位置处理；设置后组件只在 requestAnimationFrame 中回传计算出的位置，不再改写元素的 top 与 left。 | <ApiType detail={"(element: HTMLElement, top: number, left: number) => void"}>Type</ApiType> | -            |
| handler          | 返回触发拖动的元素，返回 null 时回退为被拖动元素本身。                                                        | <ApiType detail={"() => HTMLElement \u007c null"}>Type</ApiType>                             | -            |
| onMouseDown      | 鼠标或触控笔按下时触发。                                                                                      | <ApiType detail={"(e: PointerEvent) => void"}>Type</ApiType>                                 | -            |
| onMouseMove      | 鼠标或触控笔移动时触发。                                                                                      | <ApiType detail={"(e: PointerEvent) => void"}>Type</ApiType>                                 | -            |
| onMouseUp        | 鼠标或触控笔抬起时触发。                                                                                      | <ApiType detail={"(e: PointerEvent) => void"}>Type</ApiType>                                 | -            |
| onTouchCancel    | 指针被系统取消（pointercancel）时触发。                                                                       | <ApiType detail={"(e: PointerEvent) => void"}>Type</ApiType>                                 | -            |
| onTouchEnd       | 触摸结束时触发。                                                                                              | <ApiType detail={"(e: PointerEvent) => void"}>Type</ApiType>                                 | -            |
| onTouchMove      | 触摸移动时触发。                                                                                              | <ApiType detail={"(e: PointerEvent) => void"}>Type</ApiType>                                 | -            |
| onTouchStart     | 触摸开始时触发。                                                                                              | <ApiType detail={"(e: PointerEvent) => void"}>Type</ApiType>                                 | -            |
| positionStrategy | 定位策略，relative 保留元素原有的布局位置。                                                                   | `'absolute' \| 'relative'`                                                                   | `"absolute"` |
