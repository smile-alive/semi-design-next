## 使用场景

Lottie 组件能够便捷简单地渲染 Lottie 动画，同时提供方式获取到全局 Lottie 和 动画实例满足更广泛的配置需求。内部基于 `lottie-web` 渲染 Lottie 动画。  
相较于直接使用 `lottie-web`，使用 Semi Lottie 组件的优势在于

- 无需关心动画容器的创建与销毁
- 无需关心动画本身的生命周期

### 基本用法

**当 Lottie 动画资源 JSON 在 CDN 上时**

向 `params` props 里传入 path= 你的 lottie json 的 URL 即可

<Demo id="path" />

**当 Lottie 动画资源 JSON 需要被打包到网站代码中时**

向 `params` props 里传入 animationData= 你的 lottie json 对象即可 (下方 Demo 请求 JSON 是仅作为演示，实际项目中 json 应当被手动 import，而不是通过网络请求获取，这样 JSON 动画资源才会被打包进网站代码)

<Demo id="animation-data" />

### Params 其他常用参数

`params` 会被组件传入 `lottie-web` 的 `lottie.loadAnimation` 中，可以参考 `lottie-web` [文档](https://github.com/airbnb/lottie-web?tab=readme-ov-file#usage)

常用参数

```json
//params
{
    container: element, // 渲染容器，不传则由 Semi Lottie 组件自动配置并生成
    renderer: 'svg', // 渲染方式， 默认 SVG
    loop: true, // 是否开启循环，默认 true
    autoplay: true, // 是否自动播放，默认 true，设置为 false 时需要通过动画实例上的 play 方法手动播放
    path: 'data.json' // 动画 JSON 文件的 URL 路径 （与 animationData 互斥）
    animationData: {/*...*/} // 动画的 JSON 对象 （与 animationData 互斥）
    /*...*/
}
```

### 获取全局 Lottie

<Framework only="react">

使用 `getLottie` Props 获取全局 lottie，也可以使用 Semi Lottie 组件上的静态方法 `Lottie.getLottie` 来获取全局 lottie

`lottie-web` 体积较大，Semi 在需要创建动画时才按需加载它：`getLottie` Props 在加载完成、动画创建后调用，静态方法 `Lottie.getLottie()` 是异步的，返回解析为 lottie 的 `Promise`（需要使用 `await` 或 `.then`）。加载完成前组件不渲染动画；卸载时若尚未加载完成，则不会再创建动画。

</Framework>

### API

<Framework only="react">

<LottieReactApi />

其他原生属性（如 `data-*`、`onClick`、`aria-*`）落在容器 `div` 上。`params.container` 存在时组件不渲染任何内容，这些属性不会落地。

</Framework>

<Framework only="vue">

<LottieVueApi />

`class`、`style` 与原生属性经 attrs 落在容器元素上。`params` 按引用变化加深比较决定是否重新加载：父级每次渲染传新的字面量不会重载，整体替换为不同内容才会重载，原地修改 `params` 不会重载。较大的动画数据用 `shallowRef` 或 `markRaw` 持有，组件传给 `lottie-web` 的是原始对象。`params.container` 存在时组件只渲染一个注释节点，`$el` 是该注释，attrs 被丢弃。

</Framework>

<Framework only="solid">

<LottieSolidApi />

`class`、`style`、`ref` 与原生属性（如 `data-*`、`aria-*`）落在容器 `div` 上。`params.container` 存在时组件不渲染任何内容，这些属性不会落地。

</Framework>

## Accessibility

- 传入 `aria-label` 或 `aria-labelledby` 的动画是带名称的图像，容器带 `role="img"`；没有名称的动画是装饰，容器带 `aria-hidden="true"`。使用方传入的 `role` 与 `aria-*` 优先
- 系统开启 `prefers-reduced-motion: reduce` 时动画不自动播放，运行中系统设置变化时会随之暂停或播放；`params.autoplay` 显式设置时以它为准
