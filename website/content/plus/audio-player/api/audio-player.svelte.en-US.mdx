**Props**

| Property     | Description                                                                                                            | Type               | Default  |
| ------------ | ---------------------------------------------------------------------------------------------------------------------- | ------------------ | -------- |
| audioUrl     | Audio address: a string, an AudioInfo object, or an array of them. An array shows the previous and next track buttons. | `AudioUrl`         | -        |
| autoPlay     | Whether to play automatically.                                                                                         | `boolean`          | `false`  |
| showToolbar  | Whether to display the toolbar.                                                                                        | `boolean`          | `true`   |
| skipDuration | Seconds skipped by each backward or forward button press.                                                              | `number`           | `10`     |
| theme        | Player theme: dark or light.                                                                                           | `AudioPlayerTheme` | `"dark"` |
