**Props**

| 属性     | 说明                                          | 类型         | 默认值                                     |
| -------- | --------------------------------------------- | ------------ | ------------------------------------------ |
| bordered | 是否展示边框，仅在非全屏模式下有效。          | `boolean`    | `semiDefault("Banner", "bordered", false)` |
| fullMode | 是否为全屏模式。                              | `boolean`    | `semiDefault("Banner", "fullMode", true)`  |
| title    | 纯文本标题；同时传入 title 插槽时以插槽为准。 | `string`     | `undefined`                                |
| type     | 类型，可选 info、success、danger、warning。   | `BannerType` | `semiDefault("Banner", "type", "info")`    |

**Events**

| 事件  | 说明                                                                    | 回调参数              |
| ----- | ----------------------------------------------------------------------- | --------------------- |
| close | 点击关闭按钮时触发，载荷为按钮的原生 click 事件；监听器返回后横幅隐藏。 | `[event: MouseEvent]` |

**Slots**

| 插槽        | 说明                                               | 作用域参数 |
| ----------- | -------------------------------------------------- | ---------- |
| default     | 消息下方的自定义内容。                             | `any`      |
| description | 描述内容。                                         | `any`      |
| icon        | 替换类型图标；传入空插槽则不显示图标。             | `any`      |
| closeIcon   | 替换关闭按钮内的图标；传入空插槽则不显示关闭按钮。 | `any`      |
| title       | 标题内容。                                         | `any`      |

**Exposes**

| 名称 | 说明 | 类型 |
| ---- | ---- | ---- |
| 无   |      |      |
