import ApiType from '#/components/ApiType.astro';

**Props**

| 属性       | 说明                                                                                                                              | 类型                                                                                 | 默认值                                      |
| ---------- | --------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------ | ------------------------------------------- |
| bordered   | 是否展示边框，仅在非全屏模式下有效。                                                                                              | `boolean`                                                                            | `false`                                     |
| classNames | 内部各部位的类名，键为 `icon`、`title`、`description`、`close`、`extra`，与组件自带的类名合并；`extra` 是默认插槽所在的附加区域。 | <ApiType detail={"Partial\u003cRecord\u003cBannerPart, ClassValue>>"}>Type</ApiType> | `semiGlobalDefault("Banner", "classNames")` |
| fullMode   | 是否为全屏模式。                                                                                                                  | `boolean`                                                                            | `true`                                      |
| styles     | 内部各部位的内联样式，键同 `classNames`。                                                                                         | <ApiType detail={"Partial\u003cRecord\u003cBannerPart, StyleValue>>"}>Type</ApiType> | `semiGlobalDefault("Banner", "styles")`     |
| title      | 纯文本标题；同时传入 title 插槽时以插槽为准。                                                                                     | `string`                                                                             | `undefined`                                 |
| type       | 类型，可选 info、success、danger、warning。                                                                                       | `BannerType`                                                                         | `"info"`                                    |

**Events**

| 事件  | 说明                                                                    | 回调参数              |
| ----- | ----------------------------------------------------------------------- | --------------------- |
| close | 点击关闭按钮时触发，载荷为按钮的原生 click 事件；监听器返回后横幅隐藏。 | `[event: MouseEvent]` |

**Slots**

| 插槽        | 说明                                               | 作用域参数 |
| ----------- | -------------------------------------------------- | ---------- |
| closeIcon   | 替换关闭按钮内的图标；传入空插槽则不显示关闭按钮。 | `any`      |
| default     | 消息下方的自定义内容。                             | `any`      |
| description | 描述内容。                                         | `any`      |
| icon        | 替换类型图标；传入空插槽则不显示图标。             | `any`      |
| title       | 标题内容。                                         | `any`      |

**Exposes**

| 名称 | 说明 | 类型 |
| ---- | ---- | ---- |
| 无   |      |      |
