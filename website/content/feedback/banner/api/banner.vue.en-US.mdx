**Props**

| Property | Description                                                   | Type         | Default     |
| -------- | ------------------------------------------------------------- | ------------ | ----------- |
| bordered | Whether to show a border. Only takes effect in non-full mode. | `boolean`    | `false`     |
| fullMode | Whether the banner is in full mode.                           | `boolean`    | `true`      |
| title    | Plain-text title. The title slot wins when both are given.    | `string`     | `undefined` |
| type     | Type: info, success, danger or warning.                       | `BannerType` | `"info"`    |

**Events**

| Event | Description                                                                                                        | Callback parameters   |
| ----- | ------------------------------------------------------------------------------------------------------------------ | --------------------- |
| close | Emitted when the close button is clicked, with its native click event. The banner hides once the listeners return. | `[event: MouseEvent]` |

**Slots**

| Slot        | Description                                                              | Scope parameters |
| ----------- | ------------------------------------------------------------------------ | ---------------- |
| closeIcon   | Replaces the icon in the close button. An empty slot removes the button. | `any`            |
| default     | Custom content below the message.                                        | `any`            |
| description | Description content.                                                     | `any`            |
| icon        | Replaces the icon of the type. An empty slot hides the icon.             | `any`            |
| title       | Title content.                                                           | `any`            |

**Exposes**

| Name | Description | Type |
| ---- | ----------- | ---- |
| None |             |      |
