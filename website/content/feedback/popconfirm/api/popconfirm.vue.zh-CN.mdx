**Events**

| 事件           | 说明                                                                                                                        | 回调参数                 |
| -------------- | --------------------------------------------------------------------------------------------------------------------------- | ------------------------ |
| open           | 确认框显示、进场动画开始时触发，每次打开一次，早于 afterOpen，受控与非受控相同；悬停打开后指针已离开而撤回的打开不触发。    | `[]`                     |
| update:visible | 需要显示或隐藏时触发，供 v-model:visible 回写。                                                                             | `[visible: boolean]`     |
| visibleChange  | 显示状态变化时触发；用户点击触发器后早于确认框出现。visible 受控时只报告用户交互发起的请求，父组件自己改变 visible 不触发。 | `[visible: boolean]`     |
| clickOutSide   | 确认框打开时在触发元素与确认框以外的区域按下鼠标时触发，仅 trigger 为 click、contextMenu 或 custom 时有效。                 | `[event: MouseEvent]`    |
| escKeyDown     | closeOnEsc 为 true（缺省）时，确认框打开期间按 Esc 触发。                                                                   | `[event: KeyboardEvent]` |
| afterOpen      | 确认框打开且进场动画结束后触发；没有进场动画时打开后即触发，受控与非受控相同；进场结束前被关闭的打开不触发。                | `[]`                     |
| afterClose     | 确认框关闭且离场动画结束后触发。                                                                                            | `[]`                     |
