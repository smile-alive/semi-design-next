| onClickOutSide | Called with the native `MouseEvent` when the popup is shown and the mouse is pressed outside the trigger and the popup. | `TooltipProps['onClickOutSide']` | - |

| onEscKeyDown | Called with the native `KeyboardEvent` when Esc is pressed while the popup is open. | `TooltipProps['onEscKeyDown']` | - |
| onOpen | Called once per opening when the card is shown, as its enter animation starts, before `afterOpen`, controlled or not. A hover open withdrawn because the pointer already left does not call it. | `TooltipProps['onOpen']` | - |

| Method       | Description                                                                                                                                                                                                  | Type                                          |

| focusTrigger | Moves focus to the trigger element. It only takes effect when `returnFocusOnClose` is `true` and `trigger` is not `custom`. When `disabled`, there is no trigger element to focus and the call does nothing. | <ApiType detail={"() => void"}>Type</ApiType> |
