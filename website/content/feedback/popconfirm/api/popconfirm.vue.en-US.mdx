**Events**

| Event          | Description                                                                                                                                                                                                                 | Callback parameters      |
| -------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------ |
| open           | Emitted once per opening when the card is shown, as its enter animation starts, before afterOpen, controlled or not; not emitted for a hover open withdrawn because the pointer already left.                               | `[]`                     |
| update:visible | Emitted when it should show or hide, for v-model:visible to write back.                                                                                                                                                     | `[visible: boolean]`     |
| visibleChange  | Emitted when the visibility changes. After a click on the trigger it fires before the card appears. With a controlled visible it reports only requests from user interaction, not changes the parent makes to visible.      | `[visible: boolean]`     |
| clickOutSide   | Emitted when the mouse is pressed outside of the trigger and the open card. Only for trigger click, contextMenu or custom.                                                                                                  | `[event: MouseEvent]`    |
| escKeyDown     | Emitted when Esc is pressed while the card is open and closeOnEsc is true (the default).                                                                                                                                    | `[event: KeyboardEvent]` |
| afterOpen      | Emitted after the card has opened and its enter animation has finished, or right after opening when there is no enter animation, controlled or not; not emitted for an open that is closed before the enter animation ends. | `[]`                     |
| afterClose     | Emitted after the card has closed and its leave animation has finished.                                                                                                                                                     | `[]`                     |
