## API Reference

The static methods provided are as follows: Display: You can pass in `options` object or string directly. Methods return the value of `toastId`: `const toastId = Toast.info({ /*...options*/ })`

**The global configuration is set before any method call, and takes effect only once**

- `Toast.config(config)`
- `Toast.resetConfig()` restores the global configuration to its defaults; only toasts shown afterwards are affected. An instance created by `ToastFactory.create(config)` is restored to the `config` it was created with

**Show Toast Directly**

- `Toast.info(options || string)`
- `Toast.error(options || string)`
- `Toast.warning(options || string)`
- `Toast.success(options || string)`

**`info` `error` `warning` `success` return the `toastId`, can be used for manually closing**

- `Toast.close(toastId)` Close Manually

## Accessibility

### ARIA

- The role of Toast depends on its type: `alert` for `warning` and `error`, `status` for `info`, `success` and a Toast without `type`
- `status` Toasts are read by a persistent `aria-live="polite"` region owned by the list; the Toast itself is `aria-live="off"`, and only the text of `content` is announced. `warning` and `error` still announce themselves as `alert`

### Keyboard and Focus

- The close button is a native `button`: focus it with `Tab`, and activate it with `Enter` or `Space`
- A Toast does not take focus when it appears
- When the pointer or keyboard focus enters a Toast, its auto-close timer pauses and a stack expands; both resume when it leaves

- Keep it simple
- Do not use periods at the end of sentences
- Explain using the noun + verb format

| ✅ Recommended usage   | ❌ Deprecated usage                      |
| ---------------------- | ---------------------------------------- |
| Language added         | New language has been added successfully |
| Ticket transfer failed | Can't transfer ticket                    |

- Provide prompt message for action
    - only provide one action
    - Don't use actions like "read" like OK, Got it, Dismiss, Cancel
