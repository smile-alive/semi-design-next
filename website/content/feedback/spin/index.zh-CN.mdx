</Framework>

<SpinVueApi />

</Framework>

<Framework only="solid">

<SpinSolidApi />

`class`、`style`、`ref` 与原生属性和事件落在根元素 `div` 上。

</Framework>

<Framework only="svelte">

<SpinSvelteApi />

`class`、`style` 与原生属性和事件落在根元素 `div` 上。

</Framework>

Spin 作为包裹元素且处于加载中时，被包裹的内容带 `inert`，不能聚焦和操作，根元素带 `aria-busy`。焦点原在被包裹内容里时会先移到 Spin 根元素，加载结束后回到原来的元素。

## 文案规范

- 准确地说明加载状态，使用比如“Loading”, “Submitting”, “Processing”等词
- 使用尽量少的词汇去描述状态

## FAQ

- **怎么修改 icon 的颜色？**

    可以通过给 .semi-spin-wrapper 类添加 color 属性覆盖原有的颜色（推荐以更高权重覆盖）

    ```
    .custom .semi-spin-wrapper {
      color: red;
    }
    ```
