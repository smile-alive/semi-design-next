## API Reference

<Framework only="react">

<SpinReactApi />

Other native attributes (such as `id`, `aria-*` and `onClick`) land on the root `div` element.

</Framework>

<Framework only="vue">

<SpinVueApi />

`class`, `style` and native attributes passed as attrs land on the root element.

</Framework>

<Framework only="solid">

<SpinSolidApi />

`class`, `style`, `ref` and native attributes and events land on the root `div` element.

</Framework>

<Framework only="svelte">

<SpinSvelteApi />

`class`, `style` and native attributes and events land on the root `div` element.

</Framework>

While a Spin that wraps content is loading, the wrapped content is `inert`: it cannot be focused or operated, and the root carries `aria-busy`. If focus was inside the wrapped content, it moves to the Spin root first and returns to the original element when loading ends.

## Content Guidelines

- Precisely state the loading status, using words such as "Loading", "Submitting", "Processing", etc.
- Use as few words as possible to describe the state

## FAQ

- **How to modify the color of the spin icon?**

    You can override the original color by adding the color property to the .semi-spin-wrapper class (it is recommended to override with a higher weight).

    ```
    .custom .semi-spin-wrapper {
      color: red;
    }
    ```
