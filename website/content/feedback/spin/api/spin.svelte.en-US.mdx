**Props**

| Property         | Description                                                                                                                                         | Type       | Default    |
| ---------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- | ---------- | ---------- |
| children         | Wrapped content. With content, Spin acts as a wrapper and carries `aria-busy` while loading, and the content cannot be focused or operated (inert). | `Snippet`  | -          |
| childStyle       | Style string of the inner children element.                                                                                                         | `string`   | -          |
| delay            | Delay in milliseconds before the loading effect is shown.                                                                                           | `number`   | `0`        |
| indicator        | Snippet for a custom loading indicator.                                                                                                             | `Snippet`  | -          |
| size             | Component size.                                                                                                                                     | `SpinSize` | `"middle"` |
| spinning         | Whether it is loading.                                                                                                                              | `boolean`  | `true`     |
| tip              | Snippet for the description text, used when Spin acts as a wrapper.                                                                                 | `Snippet`  | -          |
| wrapperClassName | Class name of the wrapper element.                                                                                                                  | `string`   | -          |
