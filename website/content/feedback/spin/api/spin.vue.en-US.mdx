**Props**

| Property | Description | Type | Default |
| --- | --- | --- | --- |
| classNames | Class names of the inner parts, keyed by child (the element wrapping the children), indicator (the loading indicator, or the element wrapping the indicator slot) and tip (the tip text), appended after the built-in class names. | <ApiType detail={"Partial\u003cRecord\u003cSpinPart, ClassValue>>"}>Type</ApiType> | `semiGlobalDefault("Spin", "classNames")` |
| delay | Delay in milliseconds before the loading effect is shown. | `number` | `0` |
| minDuration | Minimum time in milliseconds the loading effect stays once shown, so a load that ends right after it appears does not flash. | `number` | `0` |
| size | Component size. | `SpinSize` | `"middle"` |
| spinning | Whether it is loading. | `boolean` | `true` |
| styles | Styles of the inner parts, keyed like classNames; values take any style binding. | <ApiType detail={"Partial\u003cRecord\u003cSpinPart, StyleValue>>"}>Type</ApiType> | `semiGlobalDefault("Spin", "styles")` |

| --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------- |

| tip       | Description text, used when Spin acts as a wrapper.                                                                                                     | `any`            |
