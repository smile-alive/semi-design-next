**Props**

| Property         | Description                                               | Type            | Default                                         |
| ---------------- | --------------------------------------------------------- | --------------- | ----------------------------------------------- |
| size             | Component size.                                           | `SpinSize`      | `semiDefault("Spin", "size", "middle")`         |
| spinning         | Whether it is loading.                                    | `boolean`       | `semiDefault("Spin", "spinning", true)`         |
| delay            | Delay in milliseconds before the loading effect is shown. | `number`        | `semiDefault("Spin", "delay", 0)`               |
| wrapperClassName | Class name of the wrapper element.                        | `string`        | `semiGlobalDefault("Spin", "wrapperClassName")` |
| childStyle       | Style of the inner children element.                      | `CSSProperties` | `semiGlobalDefault("Spin", "childStyle")`       |

**Events**

| Event | Description | Callback parameters |
| ----- | ----------- | ------------------- |
| None  |             |                     |

**Slots**

| Slot      | Description                                                                                                                                             | Scope parameters |
| --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------- |
| default   | Wrapped content; with a default slot Spin acts as a wrapper and carries aria-busy while loading, and the content cannot be focused or operated (inert). | `any`            |
| indicator | Custom loading indicator.                                                                                                                               | `any`            |
| tip       | Description text, used when Spin acts as a wrapper.                                                                                                     | `any`            |
