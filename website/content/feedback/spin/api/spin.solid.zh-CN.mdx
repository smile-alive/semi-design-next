**Props**

| 属性        | 说明                                                                                                                                                    | 类型                                                                                                    | 默认值     |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- | ---------- |
| classNames  | 内部各部位的类名，键为 child（包裹 children 的元素）、indicator（加载指示器，传入 indicator 时为其外层包裹元素）、tip（提示文字），追加在自带类名之后。 | <ApiType detail={"Partial\u003cRecord\u003cSpinPart, string>>"}>Type</ApiType>                          | -          |
| delay       | 延迟显示加载效果的时间，单位毫秒。                                                                                                                      | `number`                                                                                                | `0`        |
| indicator   | 自定义加载指示符，传入 JSX 元素。                                                                                                                       | `JSX.Element`                                                                                           | -          |
| minDuration | 加载效果显示后至少保持的时间，单位毫秒，避免加载刚显示就结束时闪烁。                                                                                    | `number`                                                                                                | `0`        |
| size        | 组件大小。                                                                                                                                              | `SpinSize`                                                                                              | `"middle"` |
| spinning    | 是否处于加载中的状态。                                                                                                                                  | `boolean`                                                                                               | `true`     |
| styles      | 内部各部位的样式，键同 classNames，值可以是对象（键使用 kebab-case）或字符串。                                                                          | <ApiType detail={"Partial\u003cRecord\u003cSpinPart, JSX.CSSProperties \u007c string>>"}>Type</ApiType> | -          |
| tip         | 当 Spin 作为包裹元素时，自定义描述文字，传入 JSX 元素。                                                                                                 | `JSX.Element`                                                                                           | -          |
