**Props**

| 属性             | 说明                                                        | 类型                          | 默认值     |
| ---------------- | ----------------------------------------------------------- | ----------------------------- | ---------- |
| childStyle       | 内部子元素的样式，可以是对象（键使用 kebab-case）或字符串。 | `JSX.CSSProperties \| string` | -          |
| delay            | 延迟显示加载效果的时间，单位毫秒。                          | `number`                      | `0`        |
| indicator        | 自定义加载指示符，传入 JSX 元素。                           | `JSX.Element`                 | -          |
| size             | 组件大小。                                                  | `SpinSize`                    | `"middle"` |
| spinning         | 是否处于加载中的状态。                                      | `boolean`                     | `true`     |
| tip              | 当 Spin 作为包裹元素时，自定义描述文字，传入 JSX 元素。     | `JSX.Element`                 | -          |
| wrapperClassName | 包裹元素的类名。                                            | `string`                      | -          |
