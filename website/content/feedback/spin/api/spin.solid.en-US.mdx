**Props**

| Property         | Description                                                                   | Type                          | Default    |
| ---------------- | ----------------------------------------------------------------------------- | ----------------------------- | ---------- |
| childStyle       | Style of the inner children element, an object (kebab-case keys) or a string. | `JSX.CSSProperties \| string` | -          |
| delay            | Delay in milliseconds before the loading effect is shown.                     | `number`                      | `0`        |
| indicator        | Custom loading indicator, passed as a JSX element.                            | `JSX.Element`                 | -          |
| size             | Component size.                                                               | `SpinSize`                    | `"middle"` |
| spinning         | Whether it is loading.                                                        | `boolean`                     | `true`     |
| tip              | Description text when Spin acts as a wrapper, passed as a JSX element.        | `JSX.Element`                 | -          |
| wrapperClassName | Class name of the wrapper element.                                            | `string`                      | -          |
