**Props**

| Property | Description | Type | Default |
| --- | --- | --- | --- |
| classNames | Class names of the inner parts, keyed by rail (the full-length groove), track (the completed part) and text (the percentage text); values take any class binding and merge with the built-in classes. rail and track here are the reverse of the built-in class semi-progress-track, which is the groove. | <ApiType detail={"Partial\u003cRecord\u003cProgressPart, ClassValue>>"}>Type</ApiType> | `semiGlobalDefault("Progress", "classNames")` |
| direction | Direction of the line progress bar: horizontal or vertical. | `ProgressDirection` | `"horizontal"` |
| indeterminate | Whether the progress is indeterminate. When on, percent no longer controls the length, the text is hidden and aria-valuenow is omitted. | `boolean` | `false` |
| motion | Whether the shown number animates to the new percent. When off it jumps to the target. | `boolean` | `true` |
| orbitStroke | Fill color of the track. | `string` | `semiGlobalDefault("Progress", "orbitStroke")` |
| percent | Progress percentage. Passing NaN throws an error. | `number` | `0` |
| showInfo | Whether to show the text: in the center of a circle, or on the right of a bar. | `boolean` | `false` |
| size | Size: default, small (circle only) or large (line only). | `Size` | `"default"` |
| stroke | Fill color. An array is a list of `{ percent, color }` intervals, where color is any CSS color or a Semi palette name. | `string \| StrokeArr` | `semiGlobalDefault("Progress", "stroke")` |
| strokeGradient | Whether to generate gradient colors between intervals. Requires at least one interval in stroke. | `boolean` | `false` |
| strokeLinecap | Line cap of the circle progress bar: round or square. | `"round" \| "square"` | `"round"` |
| strokeWidth | Stroke width of the circle progress bar. | `number` | `4` |
| styles | Inline styles of the inner parts, keyed like classNames; values take any style binding. In a circle, rail and track are SVG circles, so use SVG properties such as stroke. | <ApiType detail={"Partial\u003cRecord\u003cProgressPart, StyleValue>>"}>Type</ApiType> | `semiGlobalDefault("Progress", "styles")` |
| type | Type: line or circle. | `ProgressType` | `"line"` |
| width | Diameter of the circle progress bar. Defaults to 24 when size is small and 72 otherwise. | `number` | `semiGlobalDefault("Progress", "width")` |
