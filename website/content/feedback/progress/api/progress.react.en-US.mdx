**Props**

| Property | Description | Type | Default |
| --- | --- | --- | --- |
| className | Class name of the root element. | `string` | `""` |
| direction | Direction of the line progress bar: `horizontal` or `vertical`. | `'horizontal' \| 'vertical'` | `"horizontal"` |
| format | Formatting function. It receives the shown percentage, clamped to 0-100 and animated during transitions, and its return value is rendered in the center of a circle or on the right of a line. It runs on every render, even when `showInfo` is `false`. | <ApiType detail={"(percent: number) => React.ReactNode"}>Type</ApiType> | <ApiType detail={"(percent: number) => `${percent}%`"}>Type</ApiType> |
| indeterminate | Whether the progress is indeterminate. When on, `percent` no longer controls the length, the text is hidden and `aria-valuenow` is omitted. | `boolean` | `false` |
| motion | Whether the number in the text animates to the new `percent`. When off, it jumps to the target. | `Motion` | `true` |
| orbitStroke | Fill color of the track. When not set, the stylesheet decides it. | `string` | - |
| percent | Progress percentage. Values outside 0-100 are clamped. | `number` | `0` |
| ref | Reference to the root element (`role="progressbar"`). | <ApiType detail={"React.Ref\u003cHTMLDivElement>"}>Type</ApiType> | - |
| showInfo | Whether to show the text: in the center of a circle, or on the right of a line. A circle with `size` `small` never shows the text. | `boolean` | `false` |
| size | Size: `default`, `small` (circle only) or `large` (line only). | `Size` | `"default"` |
| stroke | Fill color. An array is a list of `{ percent, color }` intervals, where `color` is any CSS color or a Semi palette name such as `blue` or `orange-9` (shade 5 when no shade is given). | `string \| StrokeArr` | - |
| strokeGradient | Whether to generate gradient colors between the intervals. Takes effect only when `stroke` is an array of intervals. | `boolean` | `false` |
| strokeLinecap | Line cap of the circle progress bar: `round` or `square`. Has no effect on a line progress bar. | `'round' \| 'square'` | `"round"` |
| strokeWidth | Stroke width of the circle progress bar. | `number` | `4` |
| style | Style of the root element. | `React.CSSProperties` | `{}` |
| type | Type: `line` or `circle`. | `'line' \| 'circle'` | `"line"` |
| width | Diameter of the circle progress bar, effective only when `type` is `circle`. When not set, it is 24 for size `small` and 72 otherwise. | `number` | - |
