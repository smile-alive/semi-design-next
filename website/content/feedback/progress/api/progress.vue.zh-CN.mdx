**Props**

| 属性           | 说明                                                                                        | 类型                  | 默认值                                               |
| -------------- | ------------------------------------------------------------------------------------------- | --------------------- | ---------------------------------------------------- |
| direction      | 条状进度条的方向，可选 horizontal、vertical。                                               | `ProgressDirection`   | `semiDefault("Progress", "direction", "horizontal")` |
| indeterminate  | 是否为不确定状态。开启后 percent 不再控制进度长度，且不展示文字，aria-valuenow 省略。       | `boolean`             | `semiDefault("Progress", "indeterminate", false)`    |
| motion         | 文字数字是否以动画过渡到新的 percent；关闭后直接跳到目标值。                                | `boolean`             | `semiDefault("Progress", "motion", true)`            |
| orbitStroke    | 进度条轨道的填充色。                                                                        | `string`              | `semiGlobalDefault("Progress", "orbitStroke")`       |
| percent        | 进度百分比；传入 NaN 会抛出错误。                                                           | `number`              | `semiDefault("Progress", "percent", 0)`              |
| showInfo       | 是否显示文字：环形显示在中间，条状显示在右侧。                                              | `boolean`             | `semiDefault("Progress", "showInfo", false)`         |
| size           | 尺寸，可选 default、small（仅 type 为 circle 时生效）、large（仅 type 为 line 时生效）。    | `Size`                | `semiDefault("Progress", "size", "default")`         |
| stroke         | 填充色。数组形式为 `{ percent, color }` 的区间列表，color 可为任意 CSS 颜色或 Semi 色板名。 | `string \| StrokeArr` | `semiGlobalDefault("Progress", "stroke")`            |
| strokeGradient | 是否自动生成渐变色补齐区间颜色，需要 stroke 至少设置一个颜色区间。                          | `boolean`             | `semiDefault("Progress", "strokeGradient", false)`   |
| strokeLinecap  | 环形进度条端点形状，可选 round、square。                                                    | `"round" \| "square"` | `semiDefault("Progress", "strokeLinecap", "round")`  |
| strokeWidth    | 环形进度条的线宽。                                                                          | `number`              | `semiDefault("Progress", "strokeWidth", 4)`          |
| type           | 类型，可选 line、circle。                                                                   | `ProgressType`        | `semiDefault("Progress", "type", "line")`            |
| width          | 环形进度条的直径；缺省时 size 为 small 时为 24，其他为 72。                                 | `number`              | `semiGlobalDefault("Progress", "width")`             |
