## Overview

- `Avatar`: Avatar placeholder, by default uses Avatar medium sizing: `width: 48px`, `height: 48px`. Supports the `size` and `shape` properties; see the API reference for their values.
- `Image`: Image placeholder, default size: `width: 100%`, `height: 100%`.
- `Title`: Title placeholder, default size: `width: 100%`, `height: 24px`.
- `Paragraph`: Content part placeholder, default size: `width: 100%`, `height: 16px`, `margin-bottom: 10px`.
- `Button`: Button placeholder, default size: `width: 115px`, `height: 32px`.

## API reference

### Skeleton

<Framework only="react">

<SkeletonReactApi />

Other native attributes (such as `id`, `aria-*` and events) fall through onto the placeholder root `div`. When `loading` is `false` the component renders only the children and has no root element, so these are dropped together with the placeholder. The root's `aria-busy="true"` cannot be switched off.

</Framework>

<Framework only="vue">

<SkeletonVueApi />

`class`, `style` and native attributes fall through attrs onto the placeholder root element. When `loading` is `false` the component renders only the default slot and has no root element, so attrs are dropped together with the placeholder. The root's `aria-busy="true"` cannot be switched off through attrs.

</Framework>

<Framework only="solid">

<SkeletonSolidApi />

`class`, `style`, `ref` and native attributes and events fall through onto the placeholder root element. When `loading` is `false` the component renders only the children and has no root element, so these are dropped together with the placeholder. The root's `aria-busy="true"` cannot be switched off.

</Framework>

## Accessibility

- While loading, the outer element of Skeleton carries `aria-busy="true"`, and the placeholder blocks and paragraph carry `aria-hidden="true"`, so screen readers only know that content is loading. An `aria-hidden` passed by the caller takes precedence on a placeholder block; `aria-busy` cannot be switched off.
- Once loading ends, the children are rendered directly and Skeleton adds no outer element.

## Content Guidelines

- Unchanged fixed content directly displays fixed content, and variable content is displayed using skeleton screen
