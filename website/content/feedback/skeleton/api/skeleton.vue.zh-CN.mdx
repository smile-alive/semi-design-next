**Props**

| 属性    | 说明                                                | 类型      | 默认值                                     |
| ------- | --------------------------------------------------- | --------- | ------------------------------------------ |
| active  | 是否展示动画效果。                                  | `boolean` | `semiGlobalDefault("Skeleton", "active")`  |
| loading | 为 true 时显示 placeholder 插槽，反之显示默认插槽。 | `boolean` | `semiDefault("Skeleton", "loading", true)` |

**Events**

| 事件 | 说明 | 回调参数 |
| ---- | ---- | -------- |
| 无   |      |          |

**Slots**

| 插槽        | 说明                   | 作用域参数 |
| ----------- | ---------------------- | ---------- |
| default     | 加载结束后显示的内容。 | `any`      |
| placeholder | 加载等待时的占位元素。 | `any`      |

**Exposes**

| 名称 | 说明 | 类型 |
| ---- | ---- | ---- |
| 无   |      |      |
