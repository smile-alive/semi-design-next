**Props**

| 属性        | 说明                                           | 类型          | 默认值 |
| ----------- | ---------------------------------------------- | ------------- | ------ |
| active      | 是否展示动画效果。                             | `boolean`     | -      |
| loading     | 为 true 时显示 `placeholder`，反之显示子内容。 | `boolean`     | `true` |
| placeholder | 加载等待时的占位元素。                         | `JSX.Element` | -      |
