**Props**

| Property    | Description                                                          | Type          | Default |
| ----------- | -------------------------------------------------------------------- | ------------- | ------- |
| active      | Whether to show the animated loading effect.                         | `boolean`     | -       |
| loading     | When true, `placeholder` is shown. Otherwise the children are shown. | `boolean`     | `true`  |
| placeholder | Elements shown while loading.                                        | `JSX.Element` | -       |
