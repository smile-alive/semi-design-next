**Props**

| 属性        | 说明                                            | 类型      | 默认值 |
| ----------- | ----------------------------------------------- | --------- | ------ |
| active      | 是否展示动画效果。                              | `boolean` | -      |
| children    | 加载结束后显示的内容。                          | `Snippet` | -      |
| loading     | 为 true 时显示 placeholder，反之显示 children。 | `boolean` | `true` |
| placeholder | 加载等待时的占位元素。                          | `Snippet` | -      |
