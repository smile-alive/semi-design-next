**Props**

| Property    | Description                                                            | Type      | Default |
| ----------- | ---------------------------------------------------------------------- | --------- | ------- |
| active      | Whether to show the animated loading effect.                           | `boolean` | -       |
| children    | Content shown once loading ends.                                       | `Snippet` | -       |
| loading     | When true, the placeholder is shown. Otherwise the children are shown. | `boolean` | `true`  |
| placeholder | Elements shown while loading.                                          | `Snippet` | -       |
