**Props**

| Property | Description | Type | Default |
| --- | --- | --- | --- |
| direction | Text direction: ltr or rtl. Inherited from the outer ConfigProvider when omitted, and ltr at the outermost level. | `"ltr" \| "rtl"` | `undefined` |
| timeZone | Time zone for time components: a number (hour offset from UTC), a GMT±HH:MM string or an IANA identifier. Numbers and GMT strings are fixed offsets all year. Inherited from the outer ConfigProvider when omitted. | `string \| number` | `undefined` |
| locale | Locale configuration, which takes precedence over LocaleProvider. Inherited from the outer ConfigProvider when omitted; when no ConfigProvider sets it, LocaleProvider decides, and zh_CN is used without either. Pass null to clear the outer locale. | `Locale \| null` | `undefined` |
| getPopupContainer | Function returning the popup container. It only affects Modal, SideSheet and ImagePreview, which still render through a Portal; the container needs position: relative. Inherited from the outer ConfigProvider when omitted, and document.body at the outermost level. | <ApiType detail={"(() => HTMLElement)"}>Type</ApiType> | `undefined` |
| responsiveObserve | Whether to observe responsive breakpoints. When off, no matchMedia listener is registered; when on, listeners are registered on the first subscription and removed when none remain. Inherited from the outer ConfigProvider when omitted, and false at the outermost level. | `boolean` | `undefined` |
| responsiveMap | Custom responsive breakpoints: keys are xs, sm, md, lg, xl and xxl, values are media query strings. Compared by content, so an inline object does not re-register listeners. Inherited from the outer ConfigProvider when omitted, and defaultResponsiveMap at the outermost level. | `ResponsiveMap` | `undefined` |
