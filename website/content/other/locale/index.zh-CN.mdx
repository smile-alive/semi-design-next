## 使用

<Framework only="react">

LocaleProvider 使用了 React 的 context 上下文特性，你只需要在应用外围包裹一次即可全局生效  
当需要切换语言时，直接切换 props 传入的 locale 即可

```jsx hideInDSM

import zh_CN from '@fibrae/semi-foundation/locale/source/zh_CN';
import en_GB from '@fibrae/semi-foundation/locale/source/en_GB';
import en_US from '@fibrae/semi-foundation/locale/source/en_US';
import ko_KR from '@fibrae/semi-foundation/locale/source/ko_KR';
import ja_JP from '@fibrae/semi-foundation/locale/source/ja_JP';
import vi_VN from '@fibrae/semi-foundation/locale/source/vi_VN';
import ru_RU from '@fibrae/semi-foundation/locale/source/ru_RU';
import id_ID from '@fibrae/semi-foundation/locale/source/id_ID';
import ms_MY from '@fibrae/semi-foundation/locale/source/ms_MY';
import th_TH from '@fibrae/semi-foundation/locale/source/th_TH';
import tr_TR from '@fibrae/semi-foundation/locale/source/tr_TR';
import pt_BR from '@fibrae/semi-foundation/locale/source/pt_BR';
import zh_TW from '@fibrae/semi-foundation/locale/source/zh_TW';
import sv_SE from '@fibrae/semi-foundation/locale/source/sv_SE';
import pl_PL from '@fibrae/semi-foundation/locale/source/pl_PL';
```

</Framework>

<Framework only="vue">

LocaleProvider 通过 provide/inject 向后代传递语言包，你只需要在应用外围包裹一次即可全局生效  
当需要切换语言时，直接切换 `locale` 属性的值即可

```vue
<script setup lang="ts">
    import en_GB from '@fibrae/semi-foundation/locale/source/en_GB';
    import { LocaleProvider } from '@fibrae/semi-ui-vue';
</script>

<template>
    <LocaleProvider :locale="en_GB">
        <App />
    </LocaleProvider>
</template>
```

</Framework>

<Framework only="solid">

`LocaleProvider` 使用 context 向后代传递语言包，你只需要在应用外围包裹一次即可全局生效  
当需要切换语言时，把 `locale` 绑定到随之变化的值上即可，子树会自动更新。

```jsx
import en_GB from '@fibrae/semi-foundation/locale/source/en_GB';
import { LocaleProvider } from '@fibrae/semi-ui-solid';

() => (
    <LocaleProvider locale={en_GB}>
        <App />
    </LocaleProvider>
);
```

</Framework>

不传 `locale` 时 LocaleProvider 继承外层 LocaleProvider 的语言，最外层都没有时回退 `zh_CN`；ConfigProvider 的 `locale` 优先于 LocaleProvider。

## API 参考

---

### LocaleProvider

<LocaleProviderVueApi />

LocaleProvider 不接受未声明的属性，`class`、`style` 等 attrs 不会落到 DOM 上。

### LocaleConsumer

<LocaleConsumerVueApi />

LocaleConsumer 不渲染自己的元素，也不接受未声明的属性。

### useLocale

`useLocale(componentName)` 返回 `ComputedRef<LocaleResult>`，`componentName` 可以是字符串，也可以是 ref 或 getter。

| 字段          | 说明                                                   | 类型                 |
| ------------- | ------------------------------------------------------ | -------------------- |
| locale        | `componentName` 对应的文案片段                         | `Locale[K]`          |
| localeCode    | 语言代码                                               | string               |
| dateFnsLocale | date-fns 的语言对象，缺失时由 date-fns 使用默认的 enUS | `Locale`（date-fns） |
| currency      | 语言所在地区的 ISO 4217 货币码                         | string               |

</Framework>

## API 参考

---

### LocaleProvider

<LocaleProviderSolidApi />

LocaleProvider 不渲染 DOM 元素，`class`、`style`、`ref` 与原生属性和事件都不会落到页面上。

### LocaleConsumer

<LocaleConsumerSolidApi />

LocaleConsumer 不渲染自己的元素，`class`、`style`、`ref` 与原生属性和事件都不会落到页面上。

### useLocale

`useLocale(componentName)` 返回 `Accessor<LocaleResult>`，调用访问器读取结果。`componentName` 可以是字符串，也可以是返回字符串的访问器。

| 字段          | 说明                                                   | 类型                 |
| ------------- | ------------------------------------------------------ | -------------------- |
| locale        | `componentName` 对应的文案片段                         | `Locale[K]`          |
| localeCode    | 语言代码                                               | string               |
| dateFnsLocale | date-fns 的语言对象，缺失时由 date-fns 使用默认的 enUS | `Locale`（date-fns） |
| currency      | 语言所在地区的 ISO 4217 货币码                         | string               |

</Framework>
