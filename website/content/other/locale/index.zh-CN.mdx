## 内置语言

| 语言         | 导出名  |
| ------------ | ------- |
| 简体中文     | `zh_CN` |
| 英语（美国） | `en_US` |

两个语言包都从 UI 包的 `/locale` 入口导入，例如 `import { en_US } from '@fibrae/semi-ui-react/locale'`。其他语言需要自己编写语言包，见[自定义语言包](#自定义语言包)。

## 已支持组件

目前有以下组件存在内置默认文本，均已实现国际化多语言适配  
Calendar、Cascader、Chat、DatePicker、Form、Image、List、Modal、Navigation、Nav、Pagination、Popconfirm、Select、Table、TimePicker、Transfer、Tree、TreeSelect、Typography、Upload

## 使用

<Framework only="react">

LocaleProvider 使用了 React 的 context 上下文特性，你只需要在应用外围包裹一次即可全局生效  
当需要切换语言时，直接切换 props 传入的 locale 即可

```jsx
import { LocaleProvider } from '@fibrae/semi-ui-react';
import { en_US } from '@fibrae/semi-ui-react/locale';

// 在locale中传入相应的语言包即可
() => {
    return (
        <LocaleProvider locale={en_US}>
            {/* eslint-disable-next-line react/jsx-no-undef */}
            <App />
        </LocaleProvider>
    );
};
```

</Framework>

<Framework only="vue">

LocaleProvider 通过 provide/inject 向后代传递语言包，你只需要在应用外围包裹一次即可全局生效  
当需要切换语言时，直接切换 `locale` 属性的值即可

```vue
<script setup lang="ts">
    import { LocaleProvider } from '@fibrae/semi-ui-vue';
    import { en_US } from '@fibrae/semi-ui-vue/locale';
</script>

<template>
    <LocaleProvider :locale="en_US">
        <App />
    </LocaleProvider>
</template>
```

</Framework>

<Framework only="solid">

`LocaleProvider` 使用 context 向后代传递语言包，你只需要在应用外围包裹一次即可全局生效  
当需要切换语言时，把 `locale` 绑定到随之变化的值上即可，子树会自动更新。

```jsx
import { LocaleProvider } from '@fibrae/semi-ui-solid';
import { en_US } from '@fibrae/semi-ui-solid/locale';

() => (
    <LocaleProvider locale={en_US}>
        <App />
    </LocaleProvider>
);
```

</Framework>

<Framework only="svelte">

`LocaleProvider` 使用 context 向后代传递语言包，你只需要在应用外围包裹一次即可全局生效  
当需要切换语言时，把 `locale` 绑定到随之变化的状态上即可，子树会自动更新。

```svelte
<script lang="ts">
    import { LocaleProvider } from '@fibrae/semi-ui-svelte';
    import { en_US } from '@fibrae/semi-ui-svelte/locale';
</script>

<LocaleProvider locale={en_US}>
    <App />
</LocaleProvider>
```

</Framework>

不传 `locale` 时 LocaleProvider 继承外层 LocaleProvider 的语言，最外层都没有时回退 `zh_CN`；ConfigProvider 的 `locale` 优先于 LocaleProvider。

### 日期组件的 date-fns 语言

DatePicker、TimePicker、Calendar 用 date-fns 格式化和解析日期。语言包只含文案，不含 date-fns 的语言数据：这些组件按当前语言的 `code` 取内置的 zh-CN 或 en-US，其他语言使用 enUS。使用其他语言时，从 `date-fns/locale` 导入对应语言，传给 ConfigProvider 的 `dateFnsLocale`，例如日语语言包搭配 `date-fns/locale/ja` 导出的 `ja`。只有导入的语言会进入打包结果，服务端渲染与客户端首帧使用同一个语言对象。

### 自定义语言包

内置语言之外的语言，参照 `Locale` 类型自己写一个语言包，传给 ConfigProvider 或 LocaleProvider 的 `locale`。`locale` 的类型是 `LocaleInput`，和 `Locale` 一起从 UI 包导出：只有 `code` 必填，其余只写要翻译的组件和键，没写的文案和 `currency` 回退到 `en_US`。

- `code` 决定日期组件取哪个内置 date-fns 语言，也是 LocaleConsumer 与 `useLocale` 读到的 `localeCode`。
- 日期组件的 date-fns 语言另经 ConfigProvider 的 `dateFnsLocale` 传入，见上一节。
- 语言包对象只创建一次，放在模块顶层或做 memo。组件按对象缓存补齐后的文案，原地修改不会生效，要改就换一个新对象。

示例只翻译了 Pagination 的翻页按钮与跳页文字、DatePicker 的占位文本，总页数、每页条数和日期面板里的文案回退为英文。

### 自定义国际化组件

<Framework only="react">

</Framework>

<Framework only="vue">

当你的自定义组件，也希望消费 Semi LocaleProvider 中的 localeCode 或者读取具体某个组件的 i18n 文本时，你可以使用 LocaleConsumer 的默认作用域插槽获取 `locale`、`localeCode` 与 `currency`；在 `<script setup>` 中可以调用 `useLocale(componentName)`，它返回包含同样三项的 computed。语言的优先级为 ConfigProvider、LocaleProvider、`zh_CN`。自定义命名空间（示例中的 `ComponentA`）通过 declaration merging 扩展 `Locale` 类型。

</Framework>

<Framework only="solid">

当你的自定义组件，也希望消费 Semi LocaleProvider 中的 localeCode 或者读取具体某个组件的 i18n 文本时，你可以使用 LocaleConsumer 获取：它的子节点是函数，参数依次为组件文案片段（locale）、localeCode 与 currency。在组件体中也可以调用 `useLocale(componentName)`，它返回一个访问器，调用它即可读到同样三项。语言的优先级为 ConfigProvider、LocaleProvider、`zh_CN`。自定义命名空间（示例中的 `ComponentA`）通过 declaration merging 扩展 `Locale` 类型。

</Framework>

<Framework only="svelte">

## API 参考

---

### LocaleProvider

<LocaleProviderVueApi />

LocaleProvider 不接受未声明的属性，`class`、`style` 等 attrs 不会落到 DOM 上。

### LocaleConsumer

<LocaleConsumerVueApi />

LocaleConsumer 不渲染自己的元素，也不接受未声明的属性。

### useLocale

`useLocale(componentName)` 返回 `ComputedRef<LocaleResult>`，`componentName` 可以是字符串，也可以是 ref 或 getter。

| 字段       | 说明                           | 类型        |
| ---------- | ------------------------------ | ----------- |
| locale     | `componentName` 对应的文案片段 | `Locale[K]` |
| localeCode | 语言代码                       | string      |
| currency   | 语言所在地区的 ISO 4217 货币码 | string      |

</Framework>
