### Basic Usage

The scrolling list provides a scrolling selection mode similar to the iOS operating system, while supporting scrolling to the specified window location selection and click selection.

<Framework only="vue">

Bind the selected item with `v-model:selectedIndex`; there is no uncontrolled mode. `header` and `footer` are string props; use the slots of the same name for custom content.

</Framework>

<Framework only="solid">

Bind the selected item with `selectedIndex` and `onSelect`; there is no uncontrolled mode. `header` and `footer` are JSX elements passed directly.

</Framework>

<Framework only="svelte">

Bind the selected item with `bind:selectedIndex`, which writes the new index back on selection; the callback is `onSelect`. Write a column as `ScrollList.Item` or the named export `ScrollItem`, which are the same component. `header` and `footer` accept a string or a snippet and render whenever given: define one with `{#snippet footer()}...{/snippet}` and pass it as a prop, or write it inside the ScrollList tag.

</Framework>

## Accessibility

### ARIA

- When `aria-label` or `aria-labelledby` is passed, the root element of `ScrollList` gets `role="group"`
- `ScrollItem` is a `role="listbox"` and supports `aria-label`, which indicates the label of the current column.
- `ScrollItem` uses `aria-disabled` to indicate whether the item is disabled
- `ScrollItem` uses `aria-selected` to indicate whether the item is selected
- The copies that fill the wheel of a `cycled` column carry `aria-hidden="true"`, so screen readers only read the real options

### Keyboard and Focus

- Each column is a `listbox`: focus it with `Tab`. Focus stays on the list and the selected item is exposed through `aria-activedescendant`; selection follows focus, and each selection fires the select callback
- `ArrowUp` selects the previous item and `ArrowDown` the next one, skipping disabled items; `Home` selects the first item and `End` the last one
- With `cycled`, the arrow keys wrap around at both ends in either mode; without it they stop at the ends
- Typing characters selects the item whose text starts with them; typing the same character repeatedly moves on to the next match
