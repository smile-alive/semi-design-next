**Props**

| 属性       | 说明                                                  | 类型               | 默认值 |
| ---------- | ----------------------------------------------------- | ------------------ | ------ |
| bodyHeight | 列表主体的高度，数字单位为 px；未设置时由样式表决定。 | `number \| string` | -      |
| children   | 列表中的 ScrollItem。                                 | `JSX.Element`      | -      |
| footer     | 底部内容，可传任意 JSX 元素。                         | `JSX.Element`      | -      |
| header     | 头部内容，可传任意 JSX 元素。                         | `JSX.Element`      | -      |
| prefixCls  | 样式类名前缀，默认为 `semi-scrolllist`。              | `string`           | -      |
