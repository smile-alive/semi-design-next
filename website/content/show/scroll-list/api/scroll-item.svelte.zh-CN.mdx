import ApiType from '#/components/ApiType.astro';

**Props**

| 属性          | 说明                                                                                                                       | 类型                                                                            | 默认值    |
| ------------- | -------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------- | --------- |
| cycled        | 是否无限循环。wheel 模式下列表首尾相接地无限滚动；两种模式下方向键都在首尾循环。                                           | `boolean`                                                                       | `false`   |
| list          | 列表内容。                                                                                                                 | `T[]`                                                                           | -         |
| mode          | 模式，可选 normal 或 wheel。                                                                                               | `'normal' \| 'wheel'`                                                           | `"wheel"` |
| motion        | 是否开启滚动动画。                                                                                                         | `boolean`                                                                       | `true`    |
| onSelect      | 选中某项时的回调，参数是该项数据加上列的 type 和该项在 list 中的 index。                                                   | <ApiType detail={"(data: ScrollItemSelectData\u003cT>) => void"}>Type</ApiType> | -         |
| selectedIndex | 选中项的索引，可用 `bind:selectedIndex` 绑定；选中时写回新索引。                                                           | `number`                                                                        | -         |
| transform     | 对选中项文案的变换，没有 text 的项参数为 undefined；未传时显示 text，没有 text 时显示 value。数据项自带的 transform 优先。 | <ApiType detail={"(value: T['value'], text?: string) => string"}>Type</ApiType> | -         |
| type          | 标识该列，供 TimePicker、DatePicker 等组件使用，不面向使用方。                                                             | `string \| number`                                                              | -         |

**Methods**

| 方法          | 说明                                                                                                                          | 类型                                                                                     |
| ------------- | ----------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| scrollToIndex | 将列表滚动到当前选中项。`selectedIndex` 暂不生效，目标始终是最近一次选中的项；`duration` 为滚动动画时长，单位毫秒，默认 120。 | <ApiType detail={"(\_selectedIndex?: number, duration?: number) => void"}>Type</ApiType> |
