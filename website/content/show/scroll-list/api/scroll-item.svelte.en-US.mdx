import ApiType from '#/components/ApiType.astro';

**Props**

| Property      | Description                                                                                                                                                                                  | Type                                                                            | Default   |
| ------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------- | --------- |
| cycled        | Whether the column cycles. In wheel mode the list scrolls without end; in both modes the arrow keys wrap around.                                                                             | `boolean`                                                                       | `false`   |
| list          | Items of the column.                                                                                                                                                                         | `T[]`                                                                           | -         |
| mode          | Mode: normal or wheel.                                                                                                                                                                       | `'normal' \| 'wheel'`                                                           | `"wheel"` |
| motion        | Whether to animate scrolling.                                                                                                                                                                | `boolean`                                                                       | `true`    |
| onSelect      | Called when an item is selected, with the item's data plus the column's type and the item's index in list.                                                                                   | <ApiType detail={"(data: ScrollItemSelectData\u003cT>) => void"}>Type</ApiType> | -         |
| selectedIndex | Index of the selected item; bind it with `bind:selectedIndex`. A selection writes the new index back.                                                                                        | `number`                                                                        | -         |
| transform     | Formats the text of the selected item; the text is undefined for an item without one. When omitted, text is shown, or value when there is no text. An item's own transform takes precedence. | <ApiType detail={"(value: T['value'], text?: string) => string"}>Type</ApiType> | -         |
| type          | Identifies the column to components such as TimePicker and DatePicker, not meant for end users.                                                                                              | `string \| number`                                                              | -         |

**Methods**

| Method        | Description                                                                                                                                                                              | Type                                                                                     |
| ------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| scrollToIndex | Scrolls the list to the selected item. `selectedIndex` has no effect yet, the target is always the item last selected; `duration` is the animation time in milliseconds, 120 by default. | <ApiType detail={"(\_selectedIndex?: number, duration?: number) => void"}>Type</ApiType> |
