**Props**

| 属性       | 说明                                     | 类型                | 默认值 |
| ---------- | ---------------------------------------- | ------------------- | ------ |
| bodyHeight | 列表主体的高度。                         | `number \| string`  | -      |
| children   | 列表中的 ScrollItem，写在标签内。        | `Snippet`           | -      |
| footer     | 底部内容，字符串或 snippet；传了就渲染。 | `Snippet \| string` | -      |
| header     | 头部内容，字符串或 snippet；传了就渲染。 | `Snippet \| string` | -      |
