**Props**

| Property   | Description                                                                | Type               | Default |
| ---------- | -------------------------------------------------------------------------- | ------------------ | ------- |
| bodyHeight | Height of the list body; a number is in px. Unset, the stylesheet decides. | `number \| string` | -       |
| children   | The ScrollItem columns.                                                    | `JSX.Element`      | -       |
| footer     | Footer content; any JSX element.                                           | `JSX.Element`      | -       |
| header     | Header content; any JSX element.                                           | `JSX.Element`      | -       |
| prefixCls  | Class name prefix, `semi-scrolllist` by default.                           | `string`           | -       |
