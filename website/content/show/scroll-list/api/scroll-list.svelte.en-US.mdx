**Props**

| Property   | Description                                                     | Type                | Default |
| ---------- | --------------------------------------------------------------- | ------------------- | ------- |
| bodyHeight | Height of the list body.                                        | `number \| string`  | -       |
| children   | The ScrollItem columns, written inside the tag.                 | `Snippet`           | -       |
| footer     | Footer content, a string or a snippet; rendered whenever given. | `Snippet \| string` | -       |
| header     | Header content, a string or a snippet; rendered whenever given. | `Snippet \| string` | -       |
