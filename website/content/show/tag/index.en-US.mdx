### Basic usage

To use this tag, just wrap the content with the `<Tag>` tag.  
It can be turned into a closable label by adding the `closable` property.

<Framework only="react">

At this time, clicking x to close will trigger the onClose event, and blocking the default event in onClose can make it still show and not hide after clicking

</Framework>

<Framework only="vue">

At this time, clicking x to close will emit the `close` event, and calling `preventDefault` on the event in the `@close` handler keeps the tag shown after clicking

</Framework>

<Framework only="solid">

At this time, clicking x to close will trigger the `onClose` event, and calling `preventDefault` on the event in `onClose` keeps the tag shown after clicking

</Framework>

<Framework only="svelte">

At this time, clicking x to close will call `onClose(event, tagKey)`, and calling `preventDefault` on the event in `onClose` keeps the tag shown after clicking. The tag content goes inside the Tag tag, as the `children` snippet.

</Framework>

### TagGroup

You can pass in configs for tags through `tagList` to create a TagGroup. The `maxTagCount` can be used to cap the number of list and will be displayed as `+N` when the limit is exceeded.  
Set the `showPopover` property to control whether the remaining content is displayed by Popover when hover to + N Tag

<Demo id="tag-group" />

<Framework only="react">

If the tags in the TagGroup can be deleted, the user needs to process the `tagList` passed to the TagGroup in `onTagClose`. Provide a `tagKey` for every item when tags are removed from the list; otherwise removing the earlier of two tags with the same text shifts the later one onto its instance.

</Framework>

<Framework only="vue">

If the tags in the TagGroup can be deleted, the user needs to process the `tagList` passed to the TagGroup in the `@tagClose` handler. Provide a `tagKey` for every item when tags are removed from the list; otherwise removing the earlier of two tags with the same text shifts the later one onto its instance. Items of `tagList` take `string | number` as `children`; use the `#tag="{ tag, index }"` slot to render a fully custom node for each tag.

</Framework>

<Framework only="solid">

If the tags in the TagGroup can be deleted, the user needs to update the `tagList` passed to the TagGroup in `onTagClose`. Provide a `tagKey` for every item when tags are removed from the list; otherwise removing the earlier of two tags with the same text shifts the later one onto its instance. Items of `tagList` take `string | number` as `children`; use `renderTag={(tag, index) => ...}` to render a fully custom node for each tag.

</Framework>

<Framework only="svelte">

If the tags in the TagGroup can be deleted, the user needs to update the `tagList` passed to the TagGroup in `onTagClose`. Provide a `tagKey` for every item when tags are removed from the list; otherwise removing the earlier of two tags with the same text shifts the later one onto its instance. Items of `tagList` take `string | number` as `children`; use the `tag` snippet, whose parameter is `{ tag, index }`, to render a fully custom node for each tag. Both the item's own `onClose` in `tagList` and the group's `onTagClose` are called.

</Framework>

## API Reference

### Tag

<Framework only="react">

<TagReactApi />

`aria-label`, `onClick` and other native attributes are spread onto the root element (`div`). Declaring `onClick` or `closable` turns the root element into a focusable button (`role="button"`).

</Framework>

<Framework only="vue">

<TagVueApi />

`class`, `style` and native attributes passed as attrs land on the root element. A `@click` listener makes the tag interactive.

</Framework>

<Framework only="solid">

<TagSolidApi />

`class`, `style`, `ref` and native attributes are spread onto the root element (`div`). An `onClick` listener makes the tag interactive.

</Framework>

<Framework only="svelte">

<TagSvelteApi />

`class`, `style` and native attributes are spread onto the root element (`div`); native events use lowercase names (`onclick`, `onmouseenter`). An `onclick` listener or `closable` makes the tag interactive.

</Framework>

## Accessibility

### ARIA

- `aria-label` is used to indicate the role of `Tag`, for deletable or clickable `Tag`, we recommend using this attribute

### Keyboard and Focus

- If the current `Tag` is interactive, then this `Tag` can be focused. Such as:
    - When the `onClick` attribute (`@click` in Vue, `onclick` in Svelte) is used, the keyboard user can activate this `Tag` with the `Enter` or `Space` key
    - When the `closable` property is `true`, keyboard users can delete this `Tag` by pressing the `Delete` or `Backspace` key, and focus moves to the adjacent focusable `Tag`
