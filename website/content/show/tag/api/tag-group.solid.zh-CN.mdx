import ApiType from '#/components/ApiType.astro';

**Props**

| 属性              | 说明                                                                                                                                                        | 类型                                                                                                                       | 默认值      |
| ----------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- | ----------- |
| avatarShape       | 组内头像标签的头像形状，可选 `square` 和 `circle`。                                                                                                         | `AvatarShape`                                                                                                              | `"square"`  |
| maxTagCount       | 最多显示的标签数，超出的部分显示为 +N。                                                                                                                     | `number`                                                                                                                   | -           |
| onPlusNMouseEnter | 指针移入 +N 标签时的回调。                                                                                                                                  | <ApiType detail={"() => void"}>Type</ApiType>                                                                              | -           |
| onTagClose        | 组内标签被关闭时的回调，参数为标签内容、关闭事件与该标签的 `tagKey`；需在回调中更新 `tagList`。                                                             | <ApiType detail={"(tagChildren: JSX.Element, event: TagCloseEvent, tagKey?: string \u007c number) => void"}>Type</ApiType> | -           |
| popoverProps      | 传给 Popover 的属性，可设置 `position`、`trigger` 等。                                                                                                      | `PopoverProps`                                                                                                             | -           |
| renderTag         | 自定义每个标签的渲染，参数为标签配置与它在 `tagList` 中的序号，返回值取代默认的 Tag。只为显示的标签调用，超出 `maxTagCount` 的标签在 Popover 打开时才渲染。 | <ApiType detail={"(tag: TagGroupItem, index: number) => JSX.Element"}>Type</ApiType>                                       | -           |
| restCount         | +N 中显示的数量，缺省为超出 `maxTagCount` 的标签数。                                                                                                        | `number`                                                                                                                   | -           |
| showPopover       | 悬停在 +N 上时，是否通过 Popover 显示剩余标签。                                                                                                             | `boolean`                                                                                                                  | -           |
| size              | 组内标签的尺寸，可选 `default`、`small` 或 `large`。                                                                                                        | `TagSize`                                                                                                                  | `"default"` |
| tagList           | 标签配置数组，每项为 Tag 的属性，`children` 为 string 或 number 的标签文字，不含 `prefixIcon`、`suffixIcon`；其他内容用 `renderTag` 渲染。                  | `TagGroupItem[]`                                                                                                           | -           |
