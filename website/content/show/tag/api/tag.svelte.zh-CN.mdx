**Props**

| 属性        | 说明                                                                                                                                                           | 类型                                                                                             | 默认值      |
| ----------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------ | ----------- |
| avatarShape | 头像标签中头像的形状，可选 square 或 circle。                                                                                                                  | `AvatarShape`                                                                                    | `"square"`  |
| avatarSrc   | 头像资源地址，设置后生成头像标签。                                                                                                                             | `string`                                                                                         | -           |
| children    | 标签内容的 snippet。                                                                                                                                           | `Snippet`                                                                                        | -           |
| closable    | 标签是否可以关闭。                                                                                                                                             | `boolean`                                                                                        | `false`     |
| color       | 标签颜色，可选色板中的 16 种颜色和 white。                                                                                                                     | `TagColor`                                                                                       | `"grey"`    |
| colorful    | 是否为多彩标签。                                                                                                                                               | `boolean`                                                                                        | `false`     |
| gradient    | 多彩标签是否为渐变色，需 colorful 为 true。                                                                                                                    | `boolean`                                                                                        | `false`     |
| onClose     | 关闭标签时调用，参数为关闭事件与 tagKey；点击关闭图标时为 click 事件，按 Backspace 或 Delete 关闭时为 keydown 事件。对事件调用 preventDefault 可保持标签显示。 | <ApiType detail={"(event: TagCloseEvent, tagKey?: string \u007c number) => void"}>Type</ApiType> | -           |
| onkeydown   | 标签上按下按键时调用。                                                                                                                                         | <ApiType detail={"KeyboardEventHandler\u003cT> \u007c null"}>Type</ApiType>                      | -           |
| prefixIcon  | 内容前的图标的 snippet。                                                                                                                                       | `Snippet`                                                                                        | -           |
| shape       | 标签形状，可选 square 或 circle。                                                                                                                              | `TagShape`                                                                                       | `"square"`  |
| size        | 标签尺寸，可选 small、default 或 large。                                                                                                                       | `TagSize`                                                                                        | `"default"` |
| suffixIcon  | 内容后的图标的 snippet。                                                                                                                                       | `Snippet`                                                                                        | -           |
| tabindex    | 标签的 tabindex；可交互的标签缺省为 0。                                                                                                                        | `number \| null`                                                                                 | -           |
| tagKey      | 标签的唯一标识，作为 onClose 的第二个参数。                                                                                                                    | `string \| number`                                                                               | -           |
| type        | 样式类型，可选 light、ghost 或 solid。                                                                                                                         | `TagType`                                                                                        | `"light"`   |
| visible     | 标签是否可见，可用 `bind:visible` 绑定；函数绑定的 setter 可以拒绝关闭。不传时标签自行关闭，之前一直显示。                                                     | `boolean`                                                                                        | -           |
