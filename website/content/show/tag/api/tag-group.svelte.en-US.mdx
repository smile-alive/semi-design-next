**Props**

| Property          | Description                                                                                                                                                             | Type                                                                                             | Default     |
| ----------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------ | ----------- |
| avatarShape       | Avatar shape of the avatar tags in the group.                                                                                                                           | `AvatarShape`                                                                                    | `"square"`  |
| maxTagCount       | Maximum number of visible tags. The rest is shown as +N.                                                                                                                | `number`                                                                                         | -           |
| onPlusNMouseEnter | Called when the pointer enters the +N tag.                                                                                                                              | <ApiType detail={"(event: MouseEvent) => void"}>Type</ApiType>                                   | -           |
| onTagClose        | Called when a tag in the group is closed, with the close event and the tagKey of the tag; the item's own onClose is called too. Update tagList in the callback.         | <ApiType detail={"(event: TagCloseEvent, tagKey?: string \u007c number) => void"}>Type</ApiType> | -           |
| popoverProps      | Props passed to the Popover, such as position and trigger; `child` and `content` are fixed by TagGroup.                                                                 | `PopoverProps`                                                                                   | -           |
| restCount         | The number shown in +N. Defaults to the number of tags beyond maxTagCount.                                                                                              | `number`                                                                                         | -           |
| showPopover       | Whether hovering +N shows the remaining tags in a Popover.                                                                                                              | `boolean`                                                                                        | -           |
| size              | Size of the tags in the group.                                                                                                                                          | `TagSize`                                                                                        | `"default"` |
| tag               | Snippet for custom rendering of each tag, with the parameter `{ tag, index }`: the tag configuration and its index, counted across the visible tags and the +N popover. | <ApiType detail={"Snippet\u003c[scope: { tag: TagGroupItem; index: number }]>"}>Type</ApiType>   | -           |
| tagList           | Tag configurations. Each item holds the props of a Tag, with children as the string or number label.                                                                    | `TagGroupItem[]`                                                                                 | -           |
