import ApiType from '#/components/ApiType.astro';

**Props**

| Property | Description | Type | Default |
| --- | --- | --- | --- |
| afterClose | Called after the popup has closed and its leave animation has finished. | <ApiType detail={"() => void"}>Type</ApiType> | - |
| afterOpen | Called after the popup has opened and its enter animation has finished, or right after opening when there is no enter animation; not called for an open that is closed before the enter animation ends. | <ApiType detail={"() => void"}>Type</ApiType> | - |
| aria-label | `aria-label` of the popup when its `role` is `dialog`; ignored for other roles. | `string` | - |
| aria-labelledby | `aria-labelledby` of the popup when its `role` is `dialog`; ignored for other roles. | `string` | - |
| arrowPointAtCenter | Whether the arrow points at the center of the trigger. Requires `showArrow`. | `boolean` | `true` |
| autoAdjustOverflow | Whether the popup flips automatically when it would be clipped. | `boolean` | `true` |
| children | The trigger. Use a DOM element, or a function component that forwards its props and `ref` to its root DOM node. Text and other content is wrapped in a span that serves as the trigger. | `React.ReactNode` | - |
| className | Class name of the popup. | `string` | - |
| clickToHide | Whether a click on the popup or anything inside it closes the popup. | `boolean` | - |
| clickTriggerToHide | Whether a click on the trigger closes an open popup. | `boolean` | - |
| closeOnEsc | Whether Esc closes the open popup. With `trigger` set to `custom`, only `onEscKeyDown` is called and the caller decides whether to close. | `boolean` | `true` |
| condition | Whether the popup may be triggered. Only an explicit `false` disables the `hover`, `click` and `focus` triggers; with `trigger` set to `custom`, `visible` still shows the popup. Changing it from `true` to `false` closes an open popup at once; with a controlled `visible` it only calls `onVisibleChange(false)`, and the popup closes once the caller writes back. | `boolean` | `true` |
| content | Popup content: a node, or a function returning one. The function receives `initialFocusRef`; attach its `ref` to the element that takes focus once the popup opens. | `React.ReactNode \| RenderContent` | - |
| disableArrowKeyDown | Whether the arrow keys on the trigger are prevented from moving focus into the popup. | `boolean` | `false` |
| disableFocusListener | When `trigger` is `hover`, whether keyboard focus is ignored instead of opening the popup. | `boolean` | `false` |
| guardFocus | Whether Tab cycles inside the popup while focus is in it. | `boolean` | `false` |
| keepDOM | Whether the popup content stays mounted while closed. | `boolean` | `false` |
| motion | Whether the popup is animated. | `boolean` | `true` |
| mouseEnterDelay | Milliseconds before the popup shows after the pointer enters. Applies to the `hover` and `focus` triggers. | `number` | `50` |
| mouseLeaveDelay | Milliseconds before the popup hides after the pointer leaves. Applies to the `hover` and `focus` triggers; not less than `mouseEnterDelay`. | `number` | `50` |
| onClickOutSide | Called with the native `MouseEvent` when the mouse is pressed outside of the trigger and the open popup. Only for `trigger` `click`, `contextMenu` or `custom`, or with `clickTriggerToHide`. | <ApiType detail={"(e: MouseEvent) => void"}>Type</ApiType> | - |
| onEscKeyDown | Called with the native `KeyboardEvent` when Esc is pressed while the popup is open and `closeOnEsc` is `true`. | <ApiType detail={"(e: KeyboardEvent) => void"}>Type</ApiType> | - |
| onOpen | Called once per opening when the popup is shown, as its enter animation starts, before `afterOpen`, controlled or not; not called for a hover open withdrawn because the pointer already left. | <ApiType detail={"() => void"}>Type</ApiType> | - |
| onVisibleChange | Called with whether the popup is shown when its visibility changes. With a controlled `visible` it reports only requests from user interaction, not changes the caller makes to `visible`. | <ApiType detail={"(visible: boolean) => void"}>Type</ApiType> | - |
| position | Position of the popup relative to the trigger: `top`, `topLeft`, `topRight`, `left`, `leftTop`, `leftBottom`, `right`, `rightTop`, `rightBottom`, `bottom`, `bottomLeft` or `bottomRight`. | `Position` | `"top"` |
| prefixCls | Class name prefix of the popup wrapper. A custom value drops the Tooltip styles. | `string` | `"semi-tooltip"` |
| preventScroll | Whether focusing the element that `initialFocusRef` points at, when the popup opens, avoids scrolling it into view. | `boolean` | - |
| ref | Handle of the component; its methods are listed under Methods below. | <ApiType detail={"React.Ref\u003cTooltipHandle>"}>Type</ApiType> | - |
| returnFocusOnClose | Whether focus returns to the trigger after the popup closes. Has no effect with `trigger` set to `custom`. | `boolean` | `false` |
| role | ARIA role of the popup. | `string` | `"tooltip"` |
| showArrow | Whether the arrow is shown. A node renders as a custom arrow. | `boolean \| React.ReactNode` | `true` |
| spacing | Distance in pixels between the popup and the trigger. An object sets the horizontal and vertical distances. | `number \| { x: number; y: number }` | `8` |
| stopPropagation | Whether click, mousedown and focus in/out events on the popup stop propagating. | `boolean` | - |
| style | Inline style of the popup. The arrow color reads `background-color` of an object style only. | `React.CSSProperties` | - |
| trigger | When the popup shows: `hover`, `focus`, `click`, `contextMenu` or `custom`. With `custom`, `visible` alone decides. | `Trigger` | `"hover"` |
| visible | Whether the popup is shown (controlled). When given, the trigger, outside clicks and Esc only request a change through `onVisibleChange`, which takes effect once the caller writes it back. | `boolean` | - |
| wrapperClassName | Class name of the span that wraps the trigger when a wrapper is needed. | `string` | - |
| wrapperId | id of the popup element, referenced by the trigger's ARIA attributes. Generated when omitted. | `string` | - |
| wrapWhenSpecial | Whether a disabled or loading trigger is wrapped in a span so that it still triggers the popup. | `boolean` | `true` |

**Methods**

| Method | Description | Type |
| --- | --- | --- |
| focusTrigger | Focuses the trigger. Only works when `returnFocusOnClose` is `true` and `trigger` is not `custom`. | <ApiType detail={"() => void"}>Type</ApiType> |
| getPopupId | Returns the id of the popup. | <ApiType detail={"() => string"}>Type</ApiType> |
| hide | Closes the popup at once without moving focus and calls `onVisibleChange(false)`. With a controlled `visible` it only calls `onVisibleChange(false)`, and the popup closes once the caller writes back. | <ApiType detail={"() => void"}>Type</ApiType> |
| rePosition | Recomputes the popup position from the trigger's current position at once. The popup already follows scrolling, window resizing, trigger moves and size changes of the trigger or popup, so this is rarely needed; following a trigger move lands a frame late, so call this to align within the same frame. | <ApiType detail={"() => void"}>Type</ApiType> |
