**Events**

| Event                  | Description                                                                                                                                  | Callback parameters                                                                                                |
| ---------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| scroll                 | Emitted when the vertical offset of a virtualized body changes. A horizontal scroll does not emit it.                                        | `[args: VirtualListScrollArgs]`                                                                                    |
| change                 | Emitted when the page, the sorting or the filters change. The argument holds pagination, filters, sorter and extra.changeType.               | <ApiType detail={"[changeInfo: TableChangeInfo\u003cR>]"}>Type</ApiType>                                           |
| expand                 | Emitted when an expand button is clicked, with the expanded state, the record (an object with groupKey for a group row) and the mouse event. | <ApiType detail={"[expanded: boolean, record: TableIncludeGroupRecord\u003cR>, event: MouseEvent]"}>Type</ApiType> |
| expandedRowsChange     | Emitted when the expanded rows change, with the array of expanded records.                                                                   | <ApiType detail={"[expandedRows: TableIncludeGroupRecord\u003cR>[]]"}>Type</ApiType>                               |
| update:expandedRowKeys | Emitted when the expanded rows change, with the array of expanded keys, group keys included. Backs v-model:expandedRowKeys.                  | `[expandedRowKeys: (string \| number)[]]`                                                                          |
| rowMouseEnter          | Emitted when the pointer enters a data row, before the onMouseenter returned by onRow.                                                       | `[record: R, event: MouseEvent]`                                                                                   |
| rowMouseLeave          | Emitted when the pointer leaves a data row, before the onMouseleave returned by onRow.                                                       | `[record: R, event: MouseEvent]`                                                                                   |
