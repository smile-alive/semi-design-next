**Events**

| 事件                   | 说明                                                                                              | 回调参数                                                                                                           |
| ---------------------- | ------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| scroll                 | 虚拟化表体的纵向偏移变化时触发，横向滚动不触发。                                                  | `[args: VirtualListScrollArgs]`                                                                                    |
| change                 | 分页、排序、筛选变化时触发，参数含 pagination、filters、sorter 与 extra.changeType。              | <ApiType detail={"[changeInfo: TableChangeInfo\u003cR>]"}>Type</ApiType>                                           |
| expand                 | 点击展开按钮时触发，参数为展开状态、行数据（分组行为 groupKey 对象）和鼠标事件。                  | <ApiType detail={"[expanded: boolean, record: TableIncludeGroupRecord\u003cR>, event: MouseEvent]"}>Type</ApiType> |
| expandedRowsChange     | 展开的行变化时触发，参数为展开的行数据数组。                                                      | <ApiType detail={"[expandedRows: TableIncludeGroupRecord\u003cR>[]]"}>Type</ApiType>                               |
| update:expandedRowKeys | 展开的行变化时触发，参数为展开的行 key 数组，包含已展开的分组 key，用于 v-model:expandedRowKeys。 | `[expandedRowKeys: (string \| number)[]]`                                                                          |
| rowMouseEnter          | 鼠标进入数据行时触发，先于 onRow 返回的 onMouseenter 调用。                                       | `[record: R, event: MouseEvent]`                                                                                   |
| rowMouseLeave          | 鼠标离开数据行时触发，先于 onRow 返回的 onMouseleave 调用。                                       | `[record: R, event: MouseEvent]`                                                                                   |
| rowDoubleClick         | 双击数据行时触发，先于 onRow 返回的 onDblclick 调用。                                             | `[record: R, event: MouseEvent]`                                                                                   |
| rowContextMenu         | 数据行触发右键菜单时触发，先于 onRow 返回的 onContextmenu 调用。                                  | `[record: R, event: MouseEvent]`                                                                                   |

| expandIcon         | 展开按钮的图标，参数 expanded；输出为空时显示默认图标。自定义图标不带旋转动画。                                                         | `TableExpandIconSlotProps`                                                  |
| pagination         | 替换分页信息与分页器，参数 pagination 可直接 v-bind 给 Pagination；输出为空时显示默认分页。                                             | `TablePaginationSlotProps`                                                  |
