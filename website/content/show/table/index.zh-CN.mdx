## 如何使用

往 Table 传入表头 `columns` 和数据 `dataSource` 进行渲染。

<Notice title='注意事项'>

请为 `dataSource` 中的每个数据项提供一个与其他数据项值不同的 `key`，或者使用 `rowKey` 参数指定一个作为主键的属性名，表格的行选择、展开等绝大多数行操作功能都会使用到。

</Notice>

### Table.Column 写法

你也可以把 `Table.Column` 写成 Table 的子组件来定义列：列的数据写在属性上，单元格和标题的自定义内容写在它的 `#cell`、`#title` 等插槽中。Table 只读取直接子项，你不能够使用任何组件包裹 `Table.Column`，`v-if`、`v-for` 展开后的直接子项可以。

<Notice type="primary" title="注意事项">

- 点击行的选择框会选中当前行。它的回调函数为 `onSelect`；

### 自定义渲染

<Framework only="solid">

用户可以使用 `Column.render` 来自定义某一列单元格的渲染，该功能适用于需要渲染较为复杂的单元格内容时。`render` 每次行数据或序号变化时重新调用，返回的 JSX 中读取 `options` 的字段即可跟随行状态更新，无需额外订阅。

`render` 函数的第四个参数 `options` 是一个对象，包含以下属性：

- `expandIcon`: 展开图标的渲染函数（当使用树形数据或可展开行时），在插入处调用，如 `{options.expandIcon?.()}`
- `selection`: 选择框的渲染函数（当开启行选择时）
- `indentText`: 缩进内容的渲染函数（当使用树形数据时）
- `isHovering`: 当前行是否处于悬停状态

通过 `isHovering` 参数，可以实现鼠标悬停时显示操作按钮等交互效果。

</Framework>

<Framework only="vue">

用户可以使用 `#cell` 作用域插槽来自定义单元格的渲染，该功能适用于需要渲染较为复杂的单元格内容时。Table 上的 `#cell` 对所有数据列调用，用 `column.dataIndex` 或 `column.key` 区分列；插槽输出为空时显示原始值。只想定制一列时，也可以把 `#cell` 写在该列的 `Table.Column` 上，它优先于 Table 上的插槽。

`#cell` 的参数是一个对象，包含以下属性：

- `text`: `column.dataIndex` 对应的值，没有 `dataIndex` 的列为数据项本身
- `record`: 当前行的数据项
- `index`: 数据项在同级中的序号
- `column`: 当前列的配置
- `expandIcon`: 展开图标（当使用树形数据或可展开行时）
- `isHovering`: 当前行是否处于悬停状态
- `selection`、`indentText`: 选择框与缩进内容，仅在列开启 `useFullRender` 时提供，见[完全自定义渲染](#完全自定义渲染)

通过 `isHovering` 参数，可以实现鼠标悬停时显示操作按钮等交互效果。

### 带分页组件的表格

表格分页目前支持两种模式：受控和非受控模式。

- 受控模式下，分页的状态完全由外部传入，依据为是否往 Table 传入了 `pagination.currentPage` 这个字段。一般情况下，受控模式适用于远程拉取数据并渲染。
- 非受控模式下，Table 默认会将传入的 `dataSource` 长度作为 `total` 传给 Pagination 组件，当然你也可以传入一个 `total` 字段来覆盖 Table 组件的取值，不过我们并不推荐用户在非受控分页模式下传入这个字段。

### 拉取远程数据

正常情况下，数据往往不是一次性获取的，我们会在点击页码、过滤器或者排序按钮时从接口重新获取数据，这种情况下请使用**受控模式**来处理分页。用户需往 Table 传入 `pagination.currentPage` 这个字段，此时分页组件的渲染完全依赖于传入的 `pagination` 对象。

<Framework only="react">

<Notice type="primary" title="注意事项">
    <div>1. 非受控时，pagination 如果是对象类型则不推荐使用字面量写法，原因是字面量写法会导致表格渲染至初始状态（看起来像是分页器没有生效）。请尽量将引用型参数定义在 render 方法之外，如果使用了 hooks 请利用 useMemo 或 useState 进行存储；</div>
    <div>2. 受控模式下，Table 不会对 dataSource 分页，请给 dataSource 传入当前页数据</div>
</Notice>

### 固定列或表头

可以通过设置 column 的 `fixed` 属性以及 `scroll.x` 来进行列固定，通过设置 `scroll.y` 来进行表头固定。

如果是固定值，设置为 >=所有固定列宽之和 + 所有表格列宽之和 的数值。

> - 建议指定 `scroll.x` 为大于表格宽度的**固定值**或百分比。如果是固定值，设置为 `>=所有固定列宽之和+所有表格列宽之和` 的数值。
> - 若列头与内容不对齐或出现列重复或者固定列失效的情况，请指定固定列的宽度 `width`，若指定宽度后仍不生效，请尝试建议留一列不设宽度以适应弹性布局，或者检查是否有超长连续字段破坏布局。
> - 请确保表格内部的所有元素在渲染后不会对单元格的高度造成影响（例如含有未加载完成的图片等），这种情况下请给定子元素一个确定的高度，以此确保左右固定列单元格不会错乱。

<Demo id="fixed" />

通过 `sticky` 属性可以将表头固定在页面顶部。传入 `top` 时可以控制距离滚动容器的距离。

开启 sticky 后，Table 会自动打开 fixed 布局，列宽将由 `column.width` 决定。没有给定 width 的列宽由浏览器自动分配。

import React, { useState, useMemo } from 'react';
import { Table, Avatar } from '@fibrae/semi-ui-react';
import { IconMore } from '@fibrae/semi-icons-react';
import * as dateFns from 'date-fns';

const DAY = 24 * 60 * 60 * 1000;
const figmaIconUrl = '/assets/placeholder/app.svg';

const columns = [
    {
        title: '标题',
        dataIndex: 'name',
        fixed: true,
        width: 250,
        render: (text, record, index) => {
            return (
                <div>
                    <Avatar size="small" shape="square" src={figmaIconUrl} style={{ marginRight: 12 }}></Avatar>
                    {text}
                </div>
            );
        },
        filters: [
            {
                text: 'Semi Design 设计稿',
                value: 'Semi Design 设计稿',
            },
            {
                text: 'Semi D2C 设计稿',
                value: 'Semi D2C 设计稿',
            },
        ],
        onFilter: (value, record) => record.name.includes(value),
    },
    {
        title: '大小',
        dataIndex: 'size',
        width: 200,
        sorter: (a, b) => (a.size - b.size > 0 ? 1 : -1),
        render: (text) => `${text} KB`,
    },
    {
        title: '所有者',
        dataIndex: 'owner',
        width: 200,
        render: (text, record, index) => {
            return (
                <div>
                    <Avatar size="small" color={record.avatarBg} style={{ marginRight: 4 }}>
                        {typeof text === 'string' && text.slice(0, 1)}
                    </Avatar>
                    {text}
                </div>
            );
        },
    },
    {
        title: '更新日期',
        dataIndex: 'updateTime',
        width: 200,
        sorter: (a, b) => (a.updateTime - b.updateTime > 0 ? 1 : -1),
        render: (value) => {
            return dateFns.format(new Date(value), 'yyyy-MM-dd');
        },
    },
    {
        title: '',
        dataIndex: 'operate',
        fixed: 'right',
        align: 'center',
        width: 100,
        render: () => {
            return <IconMore />;
        },
    },
];

function App() {
    const [dataSource, setData] = useState([]);

    const scroll = useMemo(() => ({ y: 300, x: 1200 }), []);
    const rowSelection = useMemo(
        () => ({
            onChange: (selectedRowKeys, selectedRows) => {
                console.log(`selectedRowKeys: ${selectedRowKeys}`, 'selectedRows: ', selectedRows);
            },
            getCheckboxProps: (record) => ({
                disabled: record.name === 'Michael James', // 这一行不可勾选
                name: record.name,
            }),
            fixed: true,
        }),
        []
    );

    const getData = () => {
        const data = [];
        for (let i = 0; i < 46; i++) {
            const isSemiDesign = i % 2 === 0;
            const randomNumber = (i * 1000) % 199;
            data.push({
                key: '' + i,
                name: isSemiDesign ? `Semi Design 设计稿${i}.fig` : `Semi D2C 设计稿${i}.fig`,
                owner: isSemiDesign ? '姜鹏志' : '郝宣',
                size: randomNumber,
                updateTime: new Date().valueOf() + randomNumber * DAY,
                avatarBg: isSemiDesign ? 'grey' : 'red',
            });
        }
        return data;
    };

    useEffect(() => {
        const data = getData();
        setData(data);
    }, []);

    return <Table sticky={{ top: 60 }} columns={columns} dataSource={dataSource} rowSelection={rowSelection} scroll={scroll} />;
}

render(App);

### 可伸缩列

#### 基本伸缩列

对于一些内容比较多的列，可以选择打开伸缩列功能，在表头进行拉拽实现列宽的实时变化。

不过你需要注意一些参数：

- `resizable` 设定为 `true` 或者一个 `object`
- `columns` 里需要伸缩功能的列都要指定 `width` 这个字段（如果不传，该列不具备伸缩功能，且其列宽度会被浏览器自动调整）

- 拖动过的列保留拖动后的宽度，没拖动过的列跟随 `columns` 里的 `width`

> 不推荐与 `scroll.x` 同时使用，scroll.x 指定表格是有宽度范围的，而伸缩列会拓展列宽，这可能会导致表格对不齐

## onHeaderRow / onRow 用法

`onHeaderRow` 中可以返回 th 支持的属性或者事件 `onRow` 中可以返回 tr 支持的属性或者事件

`onRow` 的第三个参数 `rowStatus` 可以获取当前行的状态信息，包括 `disabled` 和 `selected` 属性。这在需要根据行的选中或禁用状态执行不同逻辑时非常有用，例如点击行时判断是否允许选中。

<Framework only="vue">

返回对象里的事件监听按 Vue 的 `onXxx` 命名（`onClick`、`onMouseenter`、`onMouseleave`），样式类用 `class`。

```vue
<script setup lang="ts">
    import { Table } from '@fibrae/semi-ui-vue';

    const onRow = (record, index, rowStatus) => ({
        onClick: () => {
            // rowStatus.disabled 表示当前行是否被禁用
            // rowStatus.selected 表示当前行是否被选中
            if (rowStatus.disabled) {
                return;
            }
            console.log('点击行', index, rowStatus);
        },
        onMouseenter: () => {}, // 鼠标移入行
        onMouseleave: () => {}, // 鼠标移出行
        class: '',
        // 其他可以作用于 tr 的属性或事件
    });

    const onHeaderRow = (columns, index) => ({
        onClick: () => {}, // 点击表头行
        class: '',
        // 其他可以作用于 tr 的属性或事件
    });
</script>

<template>
    <Table :columns="columns" :dataSource="dataSource" :onRow="onRow" :onHeaderRow="onHeaderRow" />
</template>
```

</Framework>

## Accessibility

### ARIA

Table 按 [WAI-ARIA Table](https://www.w3.org/WAI/ARIA/apg/patterns/table/) 输出静态表格语义，单元格之间不用方向键移动，可交互内容（排序、筛选、展开、选择）都是可以 Tab 聚焦的原生控件。

- 表格的 role 为 table，行为 row，表头单元格为 columnheader，单元格为 cell；树形表格同样是 table，不输出行的层级
- 排序按钮是表头里的原生 `button`，以列标题命名；当前排序方向写在表头单元格的 `aria-sort` 上（`ascending` 或 `descending`），未排序的列不带该属性。`showSortTip` 的提示在按钮聚焦时显示
- 展开按钮是原生 `button`，名称为「展开此行」，`aria-expanded` 表示该行是否展开
- 行选择的复选框带有「选择此行」「全选所有行」等可访问名称

<Framework only="react">

- 默认的列筛选图标是原生 `button`，可用 Tab 聚焦，Enter、Space 或下箭头打开筛选菜单，并带有 `aria-haspopup="menu"` 与 `aria-expanded`；自定义 `filterIcon` 时由使用方保证其可聚焦

</Framework>

<Framework only="vue">

- 列筛选按钮是原生 `button`，可用 Tab 聚焦，Enter、Space 或下箭头打开筛选菜单，并带有 `aria-haspopup="menu"` 与 `aria-expanded`；名称为「筛选此列数据」，有筛选值时为「筛选此列数据，筛选已生效」。`#filterIcon` 插槽只替换按钮内的图标，按钮的名称和键盘操作不变

</Framework>

- 固定表头（`scroll.y`、`sticky`）或虚拟化时，表头和表体渲染为两个 table 元素，二者的共同容器是 role 为 table 的元素，内部 table 为 role none，单元格仍与列头关联
- 虚拟化表格的 `aria-rowcount` 为表头行数加数据总行数，数据行的 `aria-rowindex` 接在表头行之后，屏幕阅读器据此报出不在 DOM 中的行

已知限制：

- 带排序的列，`title` 渲染在排序按钮里，`title` 中不要放按钮、链接等可交互内容

<Framework only="solid">

- 默认的列筛选图标是原生 `button`，可用 Tab 聚焦，Enter、Space 或下箭头打开筛选菜单，并带有 `aria-haspopup="menu"` 与 `aria-expanded`；自定义 `filterIcon` 时由使用方保证其可聚焦

</Framework>

## RTL/LTR

- Table 的 RTL 默认值为 [ConfigProvider](/zh-CN/react/other/config-provider) direction，可以通过 Table direction 覆盖
- Table 列的 align 与 fixed 属性会在 RTL 时会自动切换，left \<-> right
- Table 的树形数据暂不支持 RTL（[Chrome、Safari 浏览器表现与 Firefox 表现不同](https://codesandbox.io/s/table-rtl-treedata-uy7gzl?file=/src/App.jsx)）

- 表格标题
    - 表格标题应清晰的让用户感知到表格的目的；

## FAQ

- **点击第二页的行选择按钮，会跳转到第一页？**

    Table 的 dataSource 更新后，会将页码重置到初始态。请检查数据源是否在组件渲染时发生了变化。

      <Framework only="vue">

    Vue 的 Table 逐项比较新旧 `dataSource`，每一项都是原来的记录时不会重置，新增或删除记录会重置。不要在模板里写字面量，也不要在每次渲染时重新生成记录对象。

    ```vue
    <script setup lang="ts">
        import { shallowRef } from 'vue';

        const dataSource = shallowRef<Record<string, any>[]>([]);

        // 只在需要时整体替换
        const load = async () => {
            dataSource.value = await fetchData();
        };
    </script>

    <template>
        <!-- 错误：每次渲染都会生成新的记录对象 -->
        <Table :dataSource="list.map((item) => ({ ...item }))" :columns="columns" />
    </template>
    ```

      </Framework>

      <Framework only="react">

    ```typescript
    function App() {
        const [dataSource, setDataSource] = useState([]);

        useEffect(() => {
            // ✅ 正确
            const getData = () => {
                // 获取数据
                const newData = fetch(/**/);
                // 设置数据
                setDataSource(dataSource);
            };

            getData();
        }, []);

        // ❌ 错误
        const data = [];

        return <Table dataSource={data} columns={[/*...*/]} />;
    }
    ```

      </Framework>

      <Framework only="solid">

    组件只执行一次，`dataSource` 应放在 signal 中，并在 JSX 里读取（如 `dataSource={data()}`）。替换整个数组会触发更新；原地修改数组（如 `push`）不会触发，需要改为生成新数组后 `setData`。

      </Framework>

- **筛选后的数据条数不对？**

    请检查你的筛选列和数据源是否配置正确。

    筛选列需设置独立的 dataIndex，同时 dataSource 需要设置独立的 key，请参考 dataSource API。否则筛选功能无法正常工作。

- **表格数据为何没有更新？**

      <Framework only="react">

    Table 组件目前所有参数都为浅层对比，也就是说如果该参数值类型为一个 Array 或者 Object，你需要手动改变其引用才能触发更新。同理，如果你不想触发额外更新，尽量不要直接在传参的时候使用字面量或是在 render 过程中定义引用型参数值：

    ```text
    // ...render() {
        <Table dataSource={[/*...*/]} columns={[/*...*/]} />}
    ```

    上述的写法在每次 render 时都会触发表格内部对数据的更新（会清空当前的选中行以及展开行 key 数组等）。为了性能及避免一些异常，**请尽量将一些引用型参数定义在 render 方法之外（如果使用了 hooks 请利用 useMemo 或者 useState 进行存储）。**

      </Framework>

      <Framework only="vue">

    Vue 通过响应式追踪变化：`dataSource` 用 `ref` 或 `shallowRef` 保存，替换整个数组或调用 `push`、`splice` 等方法都会触发更新；`shallowRef` 下直接修改某条记录的字段不会触发，需要整体替换数组。`columns` 同理，依赖响应式数据时用 `computed`，不依赖时定义在 `script setup` 顶层，避免写在模板里的字面量。

      </Framework>

      <Framework only="solid">

    Table 按 props 的读取位置更新，`columns`、`dataSource` 等在 JSX 中读取 signal 即可跟随变化。`columns` 数组定义在组件内部时只会创建一次，依赖 signal 的列配置请使用 getter 或在 `render` 中读取。

      </Framework>

- **为何我的表格行不能选中以及展开？**

    请指定 rowKey 或者给 dataSource 的每项设置一个各不相同的 "key" 属性。**表格内所有行相关的操作都需要使用到。**

- **如何实现点击排序按钮时自定义排序或传参给服务端排序？**

    onChange 方法的入参包括 pagination、filters、sorter，用户可以根据 sorter 对 dataSource 进行自定义排序。

- **如何给某一行添加 className？**

    使用 onRow 或 onHeaderRow。

- **如何给 table cell 设置样式？**

    涉及到单个 cell 需要控制样式的，可以通过 column.onHeaderCell、column.onCell 控制。

- **为何 rowSelection onChange 的第一个参数缓存了之前选中的 keys？**

    这么做为了在分页受控时，在第一页选中数据后，去第二页选择数据，回到第一页后选择的 row keys 丢失的场景。如果不想用缓存的 keys，可以从当前 dataSource 过滤一遍，或者使用 rowSelection onChange 的第二个参数。

- **支持单行选择吗**

    Table 暂不支持单行选择功能，用户可以通过自定义方式实现单选。
