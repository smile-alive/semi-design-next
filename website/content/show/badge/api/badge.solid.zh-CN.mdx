**Props**

| 属性           | 说明                                                                                                 | 类型                          | 默认值      |
| -------------- | ---------------------------------------------------------------------------------------------------- | ----------------------------- | ----------- |
| count          | 徽章内容，数字或字符串按文字显示；传入 JSX 元素时直接渲染该元素，并去掉 type 与 theme 对应的样式类。 | `JSX.Element`                 | -           |
| countClassName | 内容区域的类名。                                                                                     | `string`                      | -           |
| countStyle     | 内容区域的样式，可传 CSS 对象（键为 kebab-case）或字符串。                                           | `JSX.CSSProperties \| string` | -           |
| dot            | 显示为小圆点，不展示内容。                                                                           | `boolean`                     | `false`     |
| overflowCount  | 数字内容的最大展示值，超出后显示为 `${overflowCount}+`；只对数字生效，0 视为未设置。                 | `number`                      | -           |
| position       | 徽章相对被包裹元素的位置；缺省时 RTL 的 ConfigProvider 下为 leftTop，否则为 rightTop。               | `BadgePosition`               | -           |
| theme          | 徽章主题，可选 solid、light、inverted。                                                              | `BadgeTheme`                  | `"solid"`   |
| type           | 徽章类型，可选 primary、secondary、tertiary、danger、warning、success。                              | `BadgeType`                   | `"primary"` |
