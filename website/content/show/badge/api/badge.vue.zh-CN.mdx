**Props**

| 属性           | 说明                                                                                   | 类型               | 默认值                                         |
| -------------- | -------------------------------------------------------------------------------------- | ------------------ | ---------------------------------------------- |
| count          | 徽章内容，数字或字符串；其他内容使用 count 插槽。                                      | `string \| number` | `semiGlobalDefault("Badge", "count")`          |
| countClassName | 内容区域的类名。                                                                       | `string`           | `semiGlobalDefault("Badge", "countClassName")` |
| countStyle     | 内容区域的样式。                                                                       | `CSSProperties`    | `semiGlobalDefault("Badge", "countStyle")`     |
| dot            | 显示为小圆点，不展示内容。                                                             | `boolean`          | `false`                                        |
| overflowCount  | 数字内容的最大展示值，超出后显示为 `${overflowCount}+`；只对数字生效，0 视为未设置。   | `number`           | `semiGlobalDefault("Badge", "overflowCount")`  |
| position       | 徽章相对被包裹元素的位置；缺省时 RTL 的 ConfigProvider 下为 leftTop，否则为 rightTop。 | `BadgePosition`    | `semiGlobalDefault("Badge", "position")`       |
| theme          | 徽章主题，可选 solid、light、inverted。                                                | `BadgeTheme`       | `"solid"`                                      |
| type           | 徽章类型，可选 primary、secondary、tertiary、danger、warning、success。                | `BadgeType`        | `"primary"`                                    |

**Slots**

| 插槽    | 说明                                                                  | 作用域参数 |
| ------- | --------------------------------------------------------------------- | ---------- |

| default | 徽章依附的元素；缺省时徽章独立显示。                                  | `any`      |
