**Props**

| Property      | Description                                                                                                                                     | Type                                                                                | Default     |
| ------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------- | ----------- |
| children      | Snippet for the element the badge is attached to. Without it the badge stands alone.                                                            | `Snippet`                                                                           | -           |
| classNames    | Class names of the inner parts, keyed by count; values take anything class takes (string, array or object) and merge with the built-in classes. | <ApiType detail={"Partial\u003cRecord\u003cBadgePart, ClassValue>>"}>Type</ApiType> | -           |
| count         | Badge content as a number, string or snippet. A snippet is rendered as given and removes the type and theme classes.                            | `number \| string \| Snippet \| null`                                               | -           |
| dot           | Shows a small dot instead of the content.                                                                                                       | `boolean`                                                                           | `false`     |
| overflowCount | Maximum number shown; larger numbers display as `${overflowCount}+`. Applies to numbers only, and 0 counts as unset.                            | `number`                                                                            | -           |
| position      | Badge position relative to the wrapped element. Defaults to leftTop under an RTL ConfigProvider and rightTop otherwise.                         | `BadgePosition`                                                                     | -           |
| styles        | Style strings of the inner parts, keyed like classNames.                                                                                        | <ApiType detail={"Partial\u003cRecord\u003cBadgePart, string>>"}>Type</ApiType>     | -           |
| theme         | Badge theme: solid, light or inverted.                                                                                                          | `BadgeTheme`                                                                        | `"solid"`   |
| type          | Badge type: primary, secondary, tertiary, danger, warning or success.                                                                           | `BadgeType`                                                                         | `"primary"` |
