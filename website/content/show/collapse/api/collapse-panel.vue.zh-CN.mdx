**Props**

| 属性      | 说明                                                 | 类型      | 默认值      |
| --------- | ---------------------------------------------------- | --------- | ----------- |
| itemKey   | 必填且唯一，用于匹配 activeKey 与 defaultActiveKey。 | `string`  | `undefined` |
| showArrow | 是否展示箭头。                                       | `boolean` | `true`      |
| disabled  | 面板是否被禁用。                                     | `boolean` | `false`     |

**Events**

| 事件      | 说明                       | 回调参数 |
| --------- | -------------------------- | -------- |
| motionEnd | 展开或收起动画结束时触发。 | `[]`     |

**Slots**

| 插槽    | 说明                                                 | 作用域参数 |
| ------- | ---------------------------------------------------- | ---------- |
| default | 面板内容。                                           | `any`      |
| header  | 面板头内容，渲染在切换按钮内，不能包含交互元素。     | `any`      |
| extra   | 面板头右侧的辅助内容，位于切换按钮之外，可以放控件。 | `any`      |

**Exposes**

| 名称 | 说明 | 类型 |
| ---- | ---- | ---- |
| 无   |      |      |
