**Props**

| 属性        | 说明                                                 | 类型                                          | 默认值  |
| ----------- | ---------------------------------------------------- | --------------------------------------------- | ------- |
| children    | 面板内容。                                           | `JSX.Element`                                 | -       |
| disabled    | 面板是否被禁用。                                     | `boolean`                                     | `false` |
| extra       | 面板头右侧的辅助内容，位于切换按钮之外，可以放控件。 | `JSX.Element`                                 | -       |
| header      | 面板头内容，渲染在切换按钮内，不能包含交互元素。     | `JSX.Element`                                 | -       |
| itemKey     | 必填且唯一，用于匹配 activeKey 与 defaultActiveKey。 | `string`                                      | -       |
| onMotionEnd | 展开或收起动画结束时调用。                           | <ApiType detail={"() => void"}>Type</ApiType> | -       |
| showArrow   | 是否展示箭头。                                       | `boolean`                                     | `true`  |
