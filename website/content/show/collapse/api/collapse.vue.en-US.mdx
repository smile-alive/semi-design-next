**Props**

| Property            | Description                                                                                                                                          | Type                         | Default                                      |
| ------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------- | -------------------------------------------- |
| accordion           | Accordion mode.                                                                                                                                      | `boolean`                    | `semiGlobalDefault("Collapse", "accordion")` |
| activeKey           | Controlled property, key of the currently expanded panel; null and the empty string mean all panels are collapsed.                                   | `string \| string[] \| null` | `undefined`                                  |
| clickHeaderToExpand | Clicking anywhere in the header row toggles the panel; when false only the toggle button and the arrow respond.                                      | `boolean`                    | `true`                                       |
| defaultActiveKey    | Key of the panel expanded initially.                                                                                                                 | `string \| string[]`         | `""`                                         |
| expandIconPosition  | Position of the expand icon: left or right.                                                                                                          | `"left" \| "right"`          | `"right"`                                    |
| keepDOM             | Whether to keep the DOM tree of hidden panels; destroyed by default. When omitted it reads the global default of Collapse, then that of Collapsible. | `boolean`                    | `semiGlobalDefault("Collapse", "keepDOM")`   |
| lazyRender          | Used with keepDOM; when true, panel content is not rendered until the panel is first expanded.                                                       | `boolean`                    | `false`                                      |
| motion              | Whether to enable the animation; enabled by default. When omitted it reads the global default of Collapse, then that of Collapsible.                 | `boolean`                    | `semiGlobalDefault("Collapse", "motion")`    |

**Events**

| Event            | Description                                                                                                                                                | Callback parameters                        |
| ---------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------ |
| change           | Emitted when a panel is toggled, with the array of expanded keys and the native MouseEvent (keyboard use also produces a click through the native button). | `[activeKey: string[], event: MouseEvent]` |
| update:activeKey | Emitted when the expanded panels change, always with a string[]; used by v-model:activeKey.                                                                | `[activeKey: string[]]`                    |

**Slots**

| Slot         | Description                                                                                     | Scope parameters |
| ------------ | ----------------------------------------------------------------------------------------------- | ---------------- |
| collapseIcon | Icon shown while a panel is expanded, IconChevronUp by default; empty content shows no icon.    | `any`            |
| default      | Collapse.Panel panels.                                                                          | `any`            |
| expandIcon   | Icon shown while a panel is collapsed, IconChevronDown by default; empty content shows no icon. | `any`            |
