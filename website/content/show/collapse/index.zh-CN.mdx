## Accessibility

### ARIA

- 面板头遵循 WAI-ARIA Accordion 模式：原生 `button` 外包 `role="heading"`、`aria-level="3"` 的元素，按钮的可访问名称是 `header` 内容。
- 按钮带 `aria-expanded`；面板内容仍在 DOM 中时一律带指向它的 `aria-controls`：展开时总在；收起时内容在 DOM 中的情况包括 `keepDOM` 生效（含只在 Collapsible 的全局默认值里设置 `keepDOM`）且内容已经渲染过，例如 `keepDOM` 加 `lazyRender` 下展开过一次再收起；`lazyRender` 尚未渲染的收起面板没有内容，不带 `aria-controls`。
- 面板内容是 `role="region"`，通过 `aria-labelledby` 以按钮为名称；`keepDOM` 保留的收起内容设置 `inert`。
- 展开图标是装饰，设置 `aria-hidden="true"`；`extra` 位于按钮之外。
- `disabled` 面板使用按钮的原生 `disabled` 属性。

### 键盘和焦点

- 每个面板头按钮是一个 Tab 停靠点，禁用面板被跳过。
- 焦点在按钮上时按 `Enter` 或 `Space` 展开或收起面板，`clickHeaderToExpand` 为 `false` 时同样有效。
- `extra` 中的控件是各自的 Tab 停靠点。

## FAQ

- ##### Collapse 内嵌表单收起后表单数据会清空 ?

    Collapse 收起之后，默认会销毁相应的 DOM 。所以相应的 field 被卸载了，数据也被清空。可以将 Collapse 的 `keepDOM` 设为 true，保留对应的 DOM 节点。

- ##### 面板头整行是折叠、展开的点击热区，在这一行放置控件（例如 Input）后，点击它会导致 Collapse 收起/展开。如何避免？
    控件放在 `extra` 而不是 `header` 中：`header` 位于切换按钮内，不能包含控件。设置 `clickHeaderToExpand` 为 `false` 时只有切换按钮和箭头响应点击；否则在控件的点击回调中阻止事件冒泡至面板头即可，若控件未提供 event 对象，在外层包裹元素的点击回调中阻止冒泡亦可，见下方示例。

<Framework only="react">

```jsx
import React from 'react';
import { Collapse, Input } from '@fibrae/semi-ui-react';

() => (
    <Collapse>
        <Collapse.Panel
            header="Panel header"
            extra={
                <span onClick={(e) => e.stopPropagation()}>
                    <Input aria-label="面板备注" />
                </span>
            }
            itemKey="1"
        >
            <p>Hi, bytedance dance dance. This is the docsite of Semi UI. </p>
        </Collapse.Panel>
    </Collapse>
);
```
