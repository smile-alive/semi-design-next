### 基本用法

<Framework only="react">

- 在 Dropdown 的 children 中为它的 Trigger 触发器：默认为 hover 展示，可通过 props.trigger 修改为 `click`、`custom`、`contextMenu`等值指定不同触发方式
- 通过 render 指定下拉框的具体内容：使用 `Dropdown.Menu` 作为父容器，组合使用 `Dropdown.Item`、`Dropdown.Divider`、`Dropdown.Title` 。  
  当然简单场景你也可以仅搭配 `Dropdown.Menu` 与 `Dropdown.Item`，其他元素不是必须的。
- `Dropdown.Item` 通过设置 `disabled` 可以禁用某个选项，配置 `type`，可以展示不同颜色的文本，上设置 `icon` 可以快速配置图标。更复杂的自定义结构，你可以通过 children 传入 ReactNode自定义渲染

</Framework>

<Framework only="vue">

- 默认插槽放 Dropdown 的 Trigger 触发器：默认为 hover 展示，可通过 `trigger` 修改为 `click`、`custom`、`contextMenu` 等值指定不同触发方式
- 通过 `#content` 插槽指定下拉框的具体内容：使用 `Dropdown.Menu` 作为父容器，组合使用 `Dropdown.Item`、`Dropdown.Divider`、`Dropdown.Title` 。  
  当然简单场景你也可以仅搭配 `Dropdown.Menu` 与 `Dropdown.Item`，其他元素不是必须的。
- `Dropdown.Item` 通过设置 `disabled` 可以禁用某个选项，配置 `type`，可以展示不同颜色的文本，用 `#icon` 插槽可以快速配置图标。更复杂的自定义结构，直接写在 `Dropdown.Item` 的默认插槽里。

</Framework>

<Framework only="solid">

- 触发器作为函数 children 传入：函数接收 `getTriggerProps`，把它的返回值展开到 `Button` 等可聚焦元素上；默认为 hover 展示，可通过 `trigger` 修改为 `click`、`focus`、`custom`、`contextMenu` 等值指定不同触发方式。其他 children 会被 span 包裹。
- 通过 `render` 指定下拉框的具体内容：使用 `Dropdown.Menu` 作为父容器，组合使用 `Dropdown.Item`、`Dropdown.Divider`、`Dropdown.Title` 。  
  当然简单场景你也可以仅搭配 `Dropdown.Menu` 与 `Dropdown.Item`，其他元素不是必须的。
- `Dropdown.Item` 通过设置 `disabled` 可以禁用某个选项，配置 `type`，可以展示不同颜色的文本，通过 `icon` 传入图标元素可以快速配置图标。更复杂的自定义结构，直接写在 `Dropdown.Item` 的 children 中。

</Framework>

### 嵌套使用

<Framework only="react">

用户可以对 `Dropdown` 进行嵌套使用，此类情况适合具有多个子级选项的情况。键盘上 `右箭头` 打开子菜单、`左箭头` 回到父项，`Enter` 或 `Space` 触发任意层菜单项的 `onClick`（详见 [Accessibility](#accessibility)）。

</Framework>

<Framework only="vue">

用户可以对 `Dropdown` 进行嵌套使用，此类情况适合具有多个子级选项的情况。键盘上 `右箭头` 打开子菜单、`左箭头` 回到父项，`Enter` 或 `Space` 触发任意层菜单项的 `@click`（详见 [Accessibility](#accessibility)）。嵌套的子菜单默认 `spacing` 为 2；`showTick`、`selectionMode` 与 `trigger` 不从外层继承，按子菜单 Dropdown 自身的设置生效。

</Framework>

</Framework>

## Accessibility

Dropdown 按 WAI-ARIA APG 的 [Menu Button](https://www.w3.org/WAI/ARIA/apg/patterns/menu-button/) 与 [Menu and Menubar](https://www.w3.org/WAI/ARIA/apg/patterns/menubar/) 模式实现。

### ARIA

- 触发元素带 `aria-haspopup="menu"` 与 `aria-expanded`，菜单显示时 `aria-expanded` 为 `true`，否则为 `false`
- Dropdown.Menu 的 `role` 为 `menu`，`aria-orientation` 为 `vertical`
- Dropdown.Item 的 `role` 为 `menuitem`；Dropdown 的 `selectionMode` 为 `single` 时为 `menuitemradio`，为 `multiple` 或开启 `showTick` 时为 `menuitemcheckbox`，这三种情况都以 `aria-checked` 暴露 `active`；√ 图标不计入菜单项名称；禁用项带 `aria-disabled="true"`
- 作为嵌套 Dropdown 触发元素的 Dropdown.Item（父项）同样带 `aria-haspopup="menu"` 与 `aria-expanded`
- Dropdown.Divider 渲染为 `role="separator"` 的 `li`，Dropdown.Title 渲染为 `role="presentation"` 的 `li`
- 包裹菜单的弹层容器 `role` 为 `presentation`，不是 `tooltip`

### 键盘和焦点

焦点在触发元素上时：

| 按键             | 行为                                                                                                                                     |
| ---------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| `Enter`、`Space` | trigger 为 `click` 时打开菜单，焦点移到第一个可用项                                                                                      |
| `下箭头`         | 菜单已打开时，焦点移到第一个可用项；触发元素是按钮（`button`、带 `href` 的链接、Semi Button 等）且菜单关闭时，打开菜单并聚焦第一个可用项 |
| `上箭头`         | 菜单已打开时，焦点移到最后一个可用项；触发元素是按钮且菜单关闭时，打开菜单并聚焦最后一个可用项                                           |
| `Tab`            | 菜单已打开时关闭菜单，焦点按浏览器默认顺序移动                                                                                           |

`render`（Vue 中为 `#content` 插槽）中没有菜单项时，弹层打开后按 `下箭头`、`上箭头` 分别聚焦弹层中第一个、最后一个可聚焦元素。

触发元素是文本或多个节点时，Dropdown 用一个 `span` 包裹它们，上表按键对这个 `span` 同样生效。

trigger 为 `hover` 或 `focus` 时，键盘聚焦触发元素即打开菜单（`disableFocusListener` 可关闭），失焦后关闭。

trigger 为 `contextMenu` 时，右键打开菜单后焦点移到第一个可用项。

焦点在菜单项上时：

| 按键               | 行为                                                                                                                                       |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------ |
| `下箭头`、`上箭头` | 移到当前层的下一项、上一项，跳过禁用项，到首尾后循环                                                                                       |
| `Home`、`End`      | 移到当前层的第一项、最后一项                                                                                                               |
| `Enter`、`Space`   | 父项：打开子菜单并把焦点移到子菜单第一项；其他项：触发 `onClick`（Vue 中为 `@click`），开启 `clickToHide` 时随后关闭菜单                   |
| `右箭头`           | 父项：打开子菜单并把焦点移到子菜单第一项；其他项无效果                                                                                     |
| `左箭头`           | 在子菜单中：关闭子菜单，焦点回到父项，与 `closeOnEsc` 无关                                                                                 |
| `Tab`              | 关闭全部菜单（含子菜单），焦点按浏览器默认顺序移动，不回到触发元素                                                                         |
| `Esc`              | 关闭焦点所在的那一层菜单，焦点回到打开它的元素（父项或触发元素）；焦点在父项且其子菜单已打开时先关闭子菜单；`closeOnEsc` 为 false 时不关闭 |
| 字母键             | 移到当前层下一个以该字符开头的项                                                                                                           |

- RTL（ConfigProvider `direction="rtl"`）下 `左箭头` 与 `右箭头` 的行为互换。
- 菜单项的 `onKeyDown`（Vue 中为 `@keydown`）中调用 `e.preventDefault()` 可以阻止 `Enter`、`Space` 触发 `onClick`（Vue 中为 `@click`）。
- 嵌套 Dropdown 的子菜单项由键盘激活时 `onClick`（Vue 中为 `@click`）收到的是 `click` 事件；鼠标操作时仍在左键按下时触发。

## 文案规范

- 下拉框内选项内容需要表述准确且包含信息，使用户在浏览时更加容易在选项中选择
- 使用语句式的大小写，并且简洁明了地书写选项
- 如果是动作选项，使用动词或者动词短语来描述用户选择该选项后会发生的动作。举个例子，"Move", "Log time", or "Hide labels"
- 不使用介词
