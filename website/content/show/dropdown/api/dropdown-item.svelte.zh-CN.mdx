**Props**

| 属性       | 说明                                                                                                                             | 类型                                                                                       | 默认值  |
| ---------- | -------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------ | ------- |
| active     | 当前项是否处于激活态，激活态时字体加粗、颜色加深；Dropdown 的 showTick 为 true 时左侧还会展示 √。                                | `boolean`                                                                                  | `false` |
| children   | 菜单项的内容。                                                                                                                   | `Snippet`                                                                                  | -       |
| classNames | 内部各部位的类名，键为 `icon`（图标容器 `.semi-dropdown-item-icon`），与组件自带的类名及 Dropdown 的 `itemIcon` 合并，排在其后。 | <ApiType detail={"Partial\u003cRecord\u003cDropdownItemPart, ClassValue>>"}>Type</ApiType> | -       |
| disabled   | 是否禁用该项。                                                                                                                   | `boolean`                                                                                  | `false` |
| icon       | 菜单项的图标；图标容器总会渲染，snippet 无输出时为空。                                                                           | `Snippet`                                                                                  | -       |
| showTick   | 仅在 Dropdown 之外使用时生效；在 Dropdown 内以 Dropdown 的 showTick 为准。                                                       | `boolean`                                                                                  | -       |
| styles     | 内部各部位的内联样式字符串，键同 `classNames`，写在 Dropdown 的 `itemIcon` 之后。                                                | <ApiType detail={"Partial\u003cRecord\u003cDropdownItemPart, string>>"}>Type</ApiType>     | -       |
| type       | 文本颜色类型，可选 primary、secondary、tertiary、warning、danger。                                                               | `'danger' \| 'primary' \| 'secondary' \| 'tertiary' \| 'warning'`                          | -       |
