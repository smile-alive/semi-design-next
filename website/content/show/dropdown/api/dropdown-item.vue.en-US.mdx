**Props**

| Property | Description                                                                                                                 | Type      | Default     |
| -------- | --------------------------------------------------------------------------------------------------------------------------- | --------- | ----------- |
| active   | Whether the item is active: bolder text and a deeper color, plus a tick on its leading side when the Dropdown has showTick. | `boolean` | `false`     |
| disabled | Whether the item is disabled.                                                                                               | `boolean` | `false`     |
| showTick | Takes effect only outside a Dropdown. Inside one, the showTick of the Dropdown applies.                                     | `boolean` | `undefined` |
| type     | Text color type: primary, secondary, tertiary, warning or danger.                                                           | `Type`    | `undefined` |
