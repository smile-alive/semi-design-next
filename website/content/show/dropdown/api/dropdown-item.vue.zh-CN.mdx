**Props**

| 属性     | 说明                                                                                              | 类型      | 默认值      |
| -------- | ------------------------------------------------------------------------------------------------- | --------- | ----------- |
| active   | 当前项是否处于激活态，激活态时字体加粗、颜色加深；Dropdown 的 showTick 为 true 时左侧还会展示 √。 | `boolean` | `false`     |
| disabled | 是否禁用该项。                                                                                    | `boolean` | `false`     |
| showTick | 仅在 Dropdown 之外使用时生效；在 Dropdown 内以 Dropdown 的 showTick 为准。                        | `boolean` | `undefined` |
| type     | 文本颜色类型，可选 primary、secondary、tertiary、warning、danger。                                | `Type`    | `undefined` |
