**Props**

| Property | Description                                                                                                                 | Type                                                              | Default |
| -------- | --------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------- | ------- |
| active   | Whether the item is active: bolder text and a deeper color, plus a tick on its leading side when the Dropdown has showTick. | `boolean`                                                         | `false` |
| children | Content of the item.                                                                                                        | `Snippet`                                                         | -       |
| disabled | Whether the item is disabled.                                                                                               | `boolean`                                                         | `false` |
| icon     | Icon of the item. The icon container is always rendered and is empty when the snippet outputs nothing.                      | `Snippet`                                                         | -       |
| showTick | Takes effect only outside a Dropdown. Inside one, the showTick of the Dropdown applies.                                     | `boolean`                                                         | -       |
| type     | Text color type: primary, secondary, tertiary, warning or danger.                                                           | `'primary' \| 'secondary' \| 'tertiary' \| 'warning' \| 'danger'` | -       |
