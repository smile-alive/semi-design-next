import ApiType from '#/components/ApiType.astro';

**Props**

| Property   | Description                                                                                                                                                                              | Type                                                                                       | Default |
| ---------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------ | ------- |
| active     | Whether the item is active: bolder text and a deeper color, plus a tick on its leading side when the Dropdown has showTick.                                                              | `boolean`                                                                                  | `false` |
| children   | Content of the item.                                                                                                                                                                     | `Snippet`                                                                                  | -       |
| classNames | Class names of the inner parts, keyed by `icon` (the icon container `.semi-dropdown-item-icon`); merged with the built-in classes and the `itemIcon` of the Dropdown, coming after them. | <ApiType detail={"Partial\u003cRecord\u003cDropdownItemPart, ClassValue>>"}>Type</ApiType> | -       |
| disabled   | Whether the item is disabled.                                                                                                                                                            | `boolean`                                                                                  | `false` |
| icon       | Icon of the item. The icon container is always rendered and is empty when the snippet outputs nothing.                                                                                   | `Snippet`                                                                                  | -       |
| showTick   | Takes effect only outside a Dropdown. Inside one, the showTick of the Dropdown applies.                                                                                                  | `boolean`                                                                                  | -       |
| styles     | Inline style strings of the inner parts, keyed like `classNames`; applied after the `itemIcon` of the Dropdown.                                                                          | <ApiType detail={"Partial\u003cRecord\u003cDropdownItemPart, string>>"}>Type</ApiType>     | -       |
| type       | Text color type: primary, secondary, tertiary, warning or danger.                                                                                                                        | `'danger' \| 'primary' \| 'secondary' \| 'tertiary' \| 'warning'`                          | -       |
