**Props**

| Property | Description | Type | Default |
| --- | --- | --- | --- |
| afterClose | Called after the menu has closed and its leave animation has ended. | <ApiType detail={"() => void"}>Type</ApiType> | - |
| afterOpen | Called after the menu has opened and its enter animation has ended, or right after opening when there is no enter animation. An opening closed before the enter animation ends does not call it. | <ApiType detail={"() => void"}>Type</ApiType> | - |
| aria-label | `aria-label` of the popup when its `role` is `dialog`. | `string` | - |
| aria-labelledby | `aria-labelledby` of the popup when its `role` is `dialog`. | `string` | - |
| arrowPointAtCenter | Whether the arrow points at the center of the trigger. Takes effect only when `showArrow` is `true`. Defaults to `true`. | `boolean` | - |
| autoAdjustOverflow | Whether the menu flips to another side when it would be clipped. Defaults to `true`. | `boolean` | - |
| children | The trigger. A single element receives the trigger events and ARIA attributes; text or several nodes are wrapped in a `span`. | `React.ReactNode` | - |
| className | Class name of the popup's outer `.semi-dropdown-wrapper` element. | `string` | - |
| clickToHide | Whether a click inside the popup closes it. Defaults to `false`. | `boolean` | - |
| clickTriggerToHide | Whether a click on the trigger closes an open menu. | `boolean` | - |
| closeOnEsc | Whether Esc on the trigger or in the popup closes the menu. With `trigger` `custom` it only calls `onEscKeyDown`, and the caller decides whether to close. | `TooltipProps['closeOnEsc']` | `true` |
| condition | Whether the trigger may show the menu. Defaults to `true`. Only an explicit `false` disables the hover, click and focus triggers; with `trigger` `custom`, `visible` still shows the menu. Changing it from `true` to `false` closes an open menu at once. | `boolean` | - |
| content | Dropdown sets this to the menu content, so a value passed here has no effect. Use `render` or `menu` for the content. | `React.ReactNode \| RenderContent` | - |
| contentClassName | Class name of the menu container `.semi-dropdown`. | `string \| any[]` | - |
| disableArrowKeyDown | Dropdown always sets this to `true` and handles the arrow keys itself, so a value passed here has no effect. | `boolean` | - |
| disableFocusListener | Whether keyboard focus is ignored when `trigger` is `hover`. Defaults to `false`. | `boolean` | - |
| guardFocus | Whether Tab cycles inside the popup while focus is in it. Defaults to `false`. | `boolean` | - |
| keepDOM | Whether the menu's DOM is kept instead of destroyed when it closes. Defaults to `false`. | `boolean` | - |
| menu | Configures the menu from data: objects whose `node` is `item`, `title` or `divider`, see DropdownMenuItem below. `render` takes precedence when it is provided. | `DropDownMenuItem[]` | - |
| motion | Whether the popup plays its enter and leave animations. | `boolean` | `true` |
| mouseEnterDelay | Milliseconds before the menu shows after the pointer enters the trigger. Defaults to `50`. Applies to the `hover` and `focus` triggers. | `number` | - |
| mouseLeaveDelay | Milliseconds before the menu hides after the pointer leaves the popup. Applies to the `hover` and `focus` triggers. | `number` | `100` |
| onClickOutSide | Called when the mouse is pressed outside the trigger and the popup, with the native `MouseEvent`. Takes effect only for `trigger` `click`, `contextMenu` or `custom`, or with `clickTriggerToHide`. | <ApiType detail={"(e: MouseEvent) => void"}>Type</ApiType> | - |
| onEscKeyDown | Called when Esc is pressed while the menu is open, with the native `KeyboardEvent`. | `TooltipProps['onEscKeyDown']` | - |
| onOpen | Called once per opening when the menu is shown and its enter animation starts, before `afterOpen`. An opening withdrawn because the pointer already left does not call it. | <ApiType detail={"() => void"}>Type</ApiType> | - |
| onVisibleChange | Called with `visible` when the visibility of the menu changes. With a controlled `visible` it reports only requests from user interaction, not changes the caller makes to `visible`. | <ApiType detail={"(visible: boolean) => void"}>Type</ApiType> | - |
| position | Position of the menu relative to the trigger. Common values are `bottom`, `bottomLeft` and `bottomRight`. See the Tooltip positions for more. | `Position` | `"bottom"` |
| prefixCls | Class prefix of the popup. | `string` | `"semi-dropdown"` |
| preventScroll | Whether focusing an element avoids scrolling it into view. Defaults to `false`. | `boolean` | - |
| ref | Receives the `DropdownHandle` when mounted, and `null` when unmounted. | <ApiType detail={"React.Ref\u003cDropdownHandle>"}>Type</ApiType> | - |
| render | Content of the popup, made of `Dropdown.Menu` with `Dropdown.Item`, `Dropdown.Title` and `Dropdown.Divider`. It takes precedence over `menu` when provided. | `React.ReactNode` | - |
| returnFocusOnClose | Whether focus returns to the trigger after the menu closes. Defaults to `true`. | `boolean` | - |
| role | ARIA role of the popup container around the menu, `presentation` by default. The menu itself has role `menu`. | `string` | - |
| selectionMode | How the items of this menu are selected; `active` marks the selected ones. With `single` the items are `menuitemradio` with `aria-checked`, with `multiple` `menuitemcheckbox` with `aria-checked`; unset, they are `menuitemcheckbox` with `aria-checked` when `showTick` is on, otherwise `menuitem`. It sets roles and states only: `showTick` alone shows the tick. Nested submenus do not inherit it. | `DropdownSelectionMode` | - |
| showArrow | Whether the arrow is shown. Defaults to `false`. | `boolean \| React.ReactNode` | - |
| showTick | Whether an active `Dropdown.Item` shows a tick on its leading side. It applies to the menu of this Dropdown only; nested submenus do not inherit it. | `boolean` | `false` |
| spacing | Distance in pixels between the popup and the trigger. Defaults to `4` for a top-level menu and `2` for a nested submenu. | `number \| { x: number; y: number }` | - |
| stopPropagation | Whether click, mousedown and focus in/out events on the popup stop propagating. Defaults to `false`. | `boolean` | - |
| style | Inline style of the menu container `.semi-dropdown`. | `React.CSSProperties` | - |
| trigger | What shows the menu: `hover`, `focus`, `click`, `custom` or `contextMenu`. With `custom`, `visible` alone decides. | `Trigger` | `"hover"` |
| visible | Whether the menu is shown. Used with `trigger` `custom`. When given, this value decides, and the trigger, a click outside and Esc only request a change through `onVisibleChange`. | `boolean` | - |
| wrapperClassName | Class name of the `span` that wraps the trigger when a wrapper is needed. | `string` | - |
| wrapperId | id of the popup element, referenced by the trigger's ARIA attributes. Generated when omitted. | `string` | - |
| wrapWhenSpecial | Whether a special trigger, such as a disabled or loading Button, is wrapped in a `span` so that it still triggers the menu. Defaults to `true`. | `boolean` | - |

**Methods**

| Method | Description | Type |
| --- | --- | --- |
| focusTrigger | Focuses the trigger element. Takes effect only when `returnFocusOnClose` is `true` and `trigger` is not `custom`. | <ApiType detail={"() => void"}>Type</ApiType> |
| rePosition | Recomputes the popup position from the trigger's current position at once. The popup already follows scrolling, window resizing, trigger moves and size changes of the trigger or popup, so this is rarely needed; following a trigger move lands a frame late, so call this to align within the same frame. | <ApiType detail={"() => void"}>Type</ApiType> |
