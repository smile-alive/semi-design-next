**Events**

| Event          | Description                                                                                                                                                                                                                 | Callback parameters      |
| -------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------ |
| afterClose     | Emitted after the menu has closed and its leave animation has finished.                                                                                                                                                     | `[]`                     |
| afterOpen      | Emitted after the menu has opened and its enter animation has finished, or right after opening when there is no enter animation, controlled or not; not emitted for an open that is closed before the enter animation ends. | `[]`                     |
| clickOutSide   | Emitted when the mouse is pressed outside of the trigger and the open popup. Only for trigger click, contextMenu or custom, or with clickTriggerToHide.                                                                     | `[event: MouseEvent]`    |
| escKeyDown     | Emitted when Esc is pressed while the menu is open and closeOnEsc is true.                                                                                                                                                  | `[event: KeyboardEvent]` |
| open           | Emitted once per opening when the menu is shown, as its enter animation starts, before afterOpen, controlled or not; not emitted for a hover open withdrawn because the pointer already left.                               | `[]`                     |
| update:visible | Emitted when the menu should show or hide, for v-model:visible to write back.                                                                                                                                               | `[visible: boolean]`     |
| visibleChange  | Emitted when the visibility of the menu changes; with a controlled visible it reports only requests from user interaction, not changes the parent makes to visible.                                                         | `[visible: boolean]`     |

**Slots**

| Slot     | Description                                                                                                                                                             | Scope parameters            |
| -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------- |
| content  | Menu content made of Dropdown.Menu with Dropdown.Item, Dropdown.Title and Dropdown.Divider. It takes precedence over menu once provided.                                | `any`                       |
| default  | The trigger. A single element or component receives the trigger attributes directly; text or several nodes are wrapped in a span that responds to the keyboard as well. | `any`                       |
| menuIcon | Icon of each item entry of menu, with the entry and its index as scope parameters. An empty result renders no icon.                                                     | `DropdownMenuIconSlotProps` |

**Exposes**

| Name | Description | Type |
| --- | --- | --- |
| focusTrigger | Focuses the trigger element. Takes effect only when returnFocusOnClose is true and trigger is not custom. | <ApiType detail={"() => void"}>Type</ApiType> |
| rePosition | Recomputes the popup position from the trigger's current position at once. The popup already follows scrolling, window resizing, trigger moves and size changes of the trigger or popup, so this is rarely needed; following a trigger move lands a frame late, so call this to align within the same frame. | <ApiType detail={"() => void"}>Type</ApiType> |
