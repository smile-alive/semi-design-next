| condition | Whether the trigger may show the menu. Only an explicit false disables the hover, click and focus triggers; with trigger custom, visible still shows the menu. Changing it from true to false closes an open menu at once. | `boolean` | - |

| guardFocus | Whether Tab cycles inside the popup while focus is in it. Defaults to false. | `boolean` | - |
| keepDOM | Whether the menu's DOM is kept instead of destroyed when it closes. Defaults to false. | `boolean` | - |
| menu | Configures the menu from data: objects whose node is item, title or divider, see DropdownMenuItem below. render takes precedence when it is provided. | `DropDownMenuItem[]` | - |
| motion | Whether the popup plays its enter and leave animations. | `boolean` | `true` |
| mouseEnterDelay | Milliseconds before the menu shows after the pointer enters the trigger. Defaults to 50. Applies to the hover and focus triggers. | `number` | - |
| mouseLeaveDelay | Milliseconds before the menu hides after the pointer leaves the popup. Applies to the hover and focus triggers. | `number` | `100` |
| onClickOutSide | Called when the mouse is pressed outside the trigger and the popup, with the native `MouseEvent`. Takes effect only for trigger click, contextMenu or custom, or with clickTriggerToHide. | <ApiType detail={"(e: MouseEvent) => void"}>Type</ApiType> | - |
| onEscKeyDown | Called when Esc is pressed while the menu is open, with the native `KeyboardEvent`. | <ApiType detail={"(e: KeyboardEvent) => void"}>Type</ApiType> | - |
| onOpen | Called once per opening when the menu is shown and its enter animation starts, before afterOpen. An opening withdrawn because the pointer already left does not call it. | <ApiType detail={"() => void"}>Type</ApiType> | - |
| onVisibleChange | Called when the visibility of the menu changes. With a controlled visible it reports only requests from user interaction, not changes the caller makes to visible. | <ApiType detail={"(visible: boolean) => void"}>Type</ApiType> | - |

| preventScroll | Whether focusing an element avoids scrolling it into view. Defaults to false. | `boolean` | - |
| ref | Receives the DropdownHandle once, when the component is created. | <ApiType detail={"Ref\u003cDropdownHandle>"}>Type</ApiType> | - |
| render | Content of the popup, made of Dropdown.Menu with Dropdown.Item, Dropdown.Title and Dropdown.Divider. It takes precedence over menu when provided. | `JSX.Element` | - |
| returnFocusOnClose | Whether focus returns to the trigger after the menu closes. | `boolean` | `true` |
| role | ARIA role of the popup container around the menu. The menu itself has role menu. | `string` | `"presentation"` |
| selectionMode | How the items of this menu are selected; active marks the selected ones. It sets roles and states only: showTick alone shows the tick. Nested submenus do not inherit it. | `DropdownSelectionMode` | - |
| showArrow | Whether the arrow is shown. Defaults to false. | `boolean \| JSX.Element` | - |
| showTick | Whether an active Dropdown.Item shows a tick on its leading side. It applies to the menu of this Dropdown only; nested submenus do not inherit it. | `boolean` | `false` |
| spacing | Distance in pixels between the popup and the trigger. Defaults to 4 for a top-level menu and 2 for a nested submenu. | `number \| { x: number; y: number }` | - |
| stopPropagation | Whether click, mousedown and focus in/out events on the popup stop propagating. Defaults to false. | `boolean` | - |

| trigger | What shows the menu: hover, focus, click, custom or contextMenu. With custom, visible alone decides. | `'hover' \| 'focus' \| 'click' \| 'custom' \| 'contextMenu'` | `"hover"` |
| visible | Whether the menu is shown. Used with trigger custom. When given, this value decides, and the trigger, a click outside and Esc only request a change through onVisibleChange. | `boolean` | - |
| wrapperClassName | Class name of the span that wraps the trigger when a wrapper is needed. | `string` | - |
| wrapperId | id of the popup element, referenced by the trigger's ARIA attributes. Generated when omitted. | `string` | - |
| wrapWhenSpecial | Whether a special trigger, such as a disabled or loading Button, is wrapped in a span so that it still triggers the menu. Defaults to true. | `boolean` | - |
