### Basic Usage

<Framework only="react">

- For the Trigger of the Dropdown within its children: By default, it is displayed on hover. You can modify it to values like `click`, `custom`, `contextMenu`, etc. through the `props.trigger` to specify different triggering methods.
- Use `render` to specify the specific content of the dropdown box: Use `Dropdown.Menu` as the parent container, and use `Dropdown.Item`, `Dropdown.Divider`, and `Dropdown.Title` in combination. Of course, in simple scenarios, you can also just combine `Dropdown.Menu` with `Dropdown.Item`, and the other elements are not mandatory.
- `Dropdown.Item` can disable a certain option by setting `disabled`. By configuring `type`, text in different colors can be displayed. By setting `icon`, icons can be quickly configured. For more complex custom structures, you can pass in `ReactNode` through `children` for custom rendering.

</Framework>

<Framework only="vue">

- Put the Trigger of the Dropdown in the default slot: By default, it is displayed on hover. You can modify it to values like `click`, `custom`, `contextMenu`, etc. through `trigger` to specify different triggering methods.
- Use the `#content` slot to specify the specific content of the dropdown box: Use `Dropdown.Menu` as the parent container, and use `Dropdown.Item`, `Dropdown.Divider`, and `Dropdown.Title` in combination. Of course, in simple scenarios, you can also just combine `Dropdown.Menu` with `Dropdown.Item`, and the other elements are not mandatory.
- `Dropdown.Item` can disable a certain option by setting `disabled`. By configuring `type`, text in different colors can be displayed. The `#icon` slot configures an icon quickly. For more complex custom structures, write them directly in the default slot of `Dropdown.Item`.

</Framework>

<Framework only="solid">

- The Trigger is passed as a function child: the function receives `getTriggerProps`, and its result is spread onto an element that takes focus, such as `Button`. By default it is displayed on hover. You can modify it to values like `click`, `focus`, `custom`, `contextMenu`, etc. through `trigger` to specify different triggering methods. Other children are wrapped in a `span`.
- Use `render` to specify the specific content of the dropdown box: Use `Dropdown.Menu` as the parent container, and use `Dropdown.Item`, `Dropdown.Divider`, and `Dropdown.Title` in combination. Of course, in simple scenarios, you can also just combine `Dropdown.Menu` with `Dropdown.Item`, and the other elements are not mandatory.
- `Dropdown.Item` can disable a certain option by setting `disabled`. By configuring `type`, text in different colors can be displayed. Pass an icon element through `icon` to configure an icon quickly. For more complex custom structures, write them directly in the children of `Dropdown.Item`.

</Framework>

### Nested Usage

<Framework only="react">

Users can nested `Dropdown`, which is suitable for situations with multiple sublevel options. From the keyboard, `Right Arrow` opens a submenu and `Left Arrow` returns to the parent item, and `Enter` or `Space` calls the `onClick` of an item at any level (see [Accessibility](#accessibility)).

</Framework>

<Framework only="vue">

Users can nested `Dropdown`, which is suitable for situations with multiple sublevel options. From the keyboard, `Right Arrow` opens a submenu and `Left Arrow` returns to the parent item, and `Enter` or `Space` calls the `@click` of an item at any level (see [Accessibility](#accessibility)). A nested submenu defaults to a `spacing` of 2. `showTick`, `selectionMode` and `trigger` are not inherited from the outer menu: the submenu Dropdown's own settings apply.

</Framework>

<Framework only="solid">

Users can nested `Dropdown`, which is suitable for situations with multiple sublevel options. The trigger of a parent item is also a function child, which spreads `getTriggerProps` onto the `Dropdown.Item`. From the keyboard, `Right Arrow` opens a submenu and `Left Arrow` returns to the parent item, and `Enter` or `Space` calls the `onClick` of an item at any level (see [Accessibility](#accessibility)).

</Framework>

The default is the move-in Trigger, which can be expanded by getting focus, clicking, right-clicking (`contextMenu`), or customizing the event trigger menu. After a right click opens the menu, focus moves to the first enabled item.

## Accessibility

Dropdown follows the WAI-ARIA APG [Menu Button](https://www.w3.org/WAI/ARIA/apg/patterns/menu-button/) and [Menu and Menubar](https://www.w3.org/WAI/ARIA/apg/patterns/menubar/) patterns.

### ARIA

- The trigger has `aria-haspopup="menu"` and `aria-expanded`, which is `true` while the menu is shown and `false` otherwise
- Dropdown.Menu has `role="menu"` and `aria-orientation="vertical"`
- Dropdown.Item has `role="menuitem"`; with the Dropdown's `selectionMode` set to `single` it has `role="menuitemradio"`, with `multiple` or with `showTick` it has `role="menuitemcheckbox"`, and in these three cases it exposes `active` as `aria-checked`; the tick icon is left out of the item name; a disabled item has `aria-disabled="true"`
- A Dropdown.Item that triggers a nested Dropdown (a parent item) also has `aria-haspopup="menu"` and `aria-expanded`
- Dropdown.Divider renders an `li` with `role="separator"`, and Dropdown.Title an `li` with `role="presentation"`
- The popup container around the menu has `role="presentation"`, not `tooltip`

### Keyboard and Focus

With focus on the trigger:

| Key              | Behavior                                                                                                                                                                                                    |
| ---------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Enter`, `Space` | With `trigger="click"`, opens the menu and moves focus to the first enabled item                                                                                                                            |
| `Down Arrow`     | While the menu is open, moves focus to the first enabled item; on a button trigger (`button`, a link with `href`, Semi Button, ...) with the menu closed, opens the menu and focuses the first enabled item |
| `Up Arrow`       | While the menu is open, moves focus to the last enabled item; on a button trigger with the menu closed, opens the menu and focuses the last enabled item                                                    |
| `Tab`            | While the menu is open, closes it and moves focus in the browser's default order                                                                                                                            |

When `render` (the `#content` slot in Vue) holds no menu items, `Down Arrow` and `Up Arrow` on the open popup's trigger focus its first and last focusable element.

When the trigger is text or several nodes, Dropdown wraps them in a `span`, and the keys above work on that `span` as well.

With `trigger` set to `hover` or `focus`, focusing the trigger from the keyboard opens the menu (turn this off with `disableFocusListener`), and moving focus away closes it.

With `trigger` set to `contextMenu`, focus moves to the first enabled item after a right click opens the menu.

With focus on a menu item:

| Key                      | Behavior                                                                                                                                                                                                                        |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Down Arrow`, `Up Arrow` | Moves to the next or previous item of the current menu, skipping disabled items and wrapping at either end                                                                                                                      |
| `Home`, `End`            | Moves to the first or last item of the current menu                                                                                                                                                                             |
| `Enter`, `Space`         | On a parent item, opens the submenu and moves focus to its first item; on any other item, calls `onClick` (`@click` in Vue), then closes the menu with `clickToHide`                                                            |
| `Right Arrow`            | On a parent item, opens the submenu and moves focus to its first item; no effect on other items                                                                                                                                 |
| `Left Arrow`             | In a submenu, closes it and returns focus to the parent item, regardless of `closeOnEsc`                                                                                                                                        |
| `Tab`                    | Closes every menu (submenus included) and moves focus in the browser's default order, not back to the trigger                                                                                                                   |
| `Esc`                    | Closes the menu that contains focus and returns focus to the element that opened it (the parent item or the trigger); on a parent item whose submenu is open, closes the submenu first; does nothing when `closeOnEsc` is false |
| Printable characters     | Moves to the next item of the current menu that starts with the character                                                                                                                                                       |

- In RTL (ConfigProvider `direction="rtl"`), `Left Arrow` and `Right Arrow` are swapped.
- Calling `e.preventDefault()` in an item's `onKeyDown` (`@keydown` in Vue) keeps `Enter` and `Space` from calling `onClick` (`@click` in Vue).
- When an item of a nested Dropdown is activated from the keyboard, its `onClick` (`@click` in Vue) receives a `click` event; with the mouse it still fires on the left button press.

## Content Guidelines

- The content of the options in the drop-down box needs to be expressed accurately and contain information to make it easier for users to choose among the options when browsing
- Use statement-like capitalization and write options concisely and clearly
- In the case of an action option, use a verb or verb phrase to describe the action that will occur when the user selects the option. For example, "Move", "Log time", or "Hide labels"
- do not use prepositions
