### Basic Usage

By default, SideSheet slides from the right side of the screen and could be closed by clicking on the mask.

<Framework only="vue">

Use `v-model:visible` to control visibility: the close button, the mask and Esc update `visible` first, then emit `@cancel`. With `:visible` and `@cancel` only, the sheet does not close by itself; set `visible` to `false` in the `@cancel` handler.

</Framework>

<Framework only="solid">

Control visibility with the controlled `visible` prop: the close button, the mask and Esc trigger `onCancel` first, and the sheet does not close by itself; set `visible` to `false` in the `onCancel` handler.

</Framework>

<Framework only="svelte">

Use `bind:visible` to control visibility: the close button, the mask and Esc write `false` back to `visible` first, then call `onCancel`. With a one-way `visible` and `onCancel` only, the sheet does not close by itself; set `visible` to `false` in the `onCancel` handler.

</Framework>

## Accessibility

### ARIA

- SideSheet has a `dialog` role to indicate that it is a pop-up component. The title element (`.semi-sidesheet-title`) has the `heading` role and `aria-level="2"` and names the dialog through `aria-labelledby`; the header itself has no role. When `aria-label` is passed it wins and that reference is not generated.
- Every `aria-*` attribute and `style` land on the `role="dialog"` element; other undeclared props land on the outer element.
- `aria-modal` is output only when the dialog is modal. A dialog is modal when it has a mask (`mask`) and is rendered in the body (judged by the actual container, so the `getPopupContainer` of ConfigProvider counts). With `mask` set to `false`, or a mask confined to a custom container, it is not output.

### Keyboard and focus

- Focus moves into the sheet when it opens.
- With `closeOnEsc` set, pressing `Esc` closes the sheet (off by default).
- A modal dialog (with a mask, rendered in the body): Tab cycles inside the sheet, the rest of the page is inert, and focus returns to the element focused before it opened when it closes. A sheet with a mask rendered in a custom container does not make the page inert; see the next item.
- A non-modal dialog (`mask` set to `false`, or a mask confined to a custom container): Tab can leave the sheet for the page and the page outside the container stays usable; focus returns on close only if it is still inside the sheet or has fallen to the body, and focus the user has moved elsewhere on the page stays. With a mask confined to a custom container, other content inside that container can still be reached by Tab.

## FAQ

- Does SideSheet disable body scrolling automatically? When a SideSheet with a mask is rendered in the body by default (no `getPopupContainer`), it adds `overflow: hidden` to the body on open to block scrolling. Set `disableScroll` to `false` to allow scrolling; scrolling is not locked when `mask` is `false`.
