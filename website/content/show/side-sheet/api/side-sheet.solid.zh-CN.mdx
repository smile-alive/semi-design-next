| 属性                | 说明                                                                                                                                                         | 类型                                                                            | 默认值    |
| ------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------- | --------- |
| afterVisibleChange  | 面板显示时在 visible 变为 true 的那次更新中立即触发，不等进场动画；隐藏时在离场动画结束后触发；显示期间被卸载时以 false 触发一次。                           | <ApiType detail={"(isVisible: boolean) => void"}>Type</ApiType>                 | -         |
| bodyStyle           | 面板内容区的样式，可以是对象（键用 kebab-case，如 `'border-bottom'`）或字符串。                                                                              | `JSX.CSSProperties \| string`                                                   | -         |
| canVerticalSetWidth | placement 为 top、bottom 时 width 是否生效；默认这两种位置横向铺满。                                                                                         | `boolean`                                                                       | -         |
| closable            | 是否显示右上角的关闭按钮。                                                                                                                                   | `boolean`                                                                       | `true`    |
| closeIcon           | 关闭按钮中的图标；传入 `null` 或 `undefined` 时回落到默认图标，隐藏关闭按钮请用 `closable={false}`。                                                         | `JSX.Element`                                                                   | -         |
| closeOnEsc          | 是否允许按 Esc 关闭面板。                                                                                                                                    | `boolean`                                                                       | `false`   |

| footer              | 面板底部，传入 JSX 元素；内容为空时不渲染底部。                                                                                                              | `JSX.Element`                                                                   | `null`    |
| getPopupContainer   | 指定弹层渲染到的父级 DOM。自定义容器需要设置 `position: relative`；这会改变浮层的 DOM 位置，不改变视图位置。                                                 | <ApiType detail={"() => HTMLElement"}>Type</ApiType>                            | -         |
| headerStyle         | 面板头部的样式，写法同 bodyStyle。                                                                                                                           | `JSX.CSSProperties \| string`                                                   | -         |
| height              | 高度，placement 为 top、bottom 时生效；数字按像素处理，字符串为合法 CSS 长度。未设置时为 448。                                                               | `number \| string`                                                              | -         |
| keepDOM             | 关闭时是否保留面板内部节点而不销毁。                                                                                                                         | `boolean`                                                                       | `false`   |
| mask                | 是否显示遮罩；为 false 时允许操作外部区域，且不锁定 body 滚动。                                                                                              | `boolean`                                                                       | `true`    |
| maskClosable        | 是否允许点击遮罩关闭面板。                                                                                                                                   | `boolean`                                                                       | `true`    |
| maskStyle           | 遮罩的样式，写法同 bodyStyle。                                                                                                                               | `JSX.CSSProperties \| string`                                                   | -         |
| motion              | 是否开启动画。                                                                                                                                               | `boolean`                                                                       | `true`    |
| onCancel            | 用户通过关闭按钮、遮罩或 Esc 关闭面板时触发，参数为原生 MouseEvent，按 Esc 时为原生 KeyboardEvent。面板不会自行关闭，需要在回调中把 `visible` 设为 `false`。 | <ApiType detail={"(e: MouseEvent \u007c KeyboardEvent) => void"}>Type</ApiType> | -         |
| placement           | 面板滑出的位置，支持 `top`、`bottom`、`left`、`right`。                                                                                                      | `Placement`                                                                     | `"right"` |

| style               | 对话框元素（`.semi-sidesheet-inner`）的样式，与组件计算出的 width、height 合并，计算出的尺寸优先。                                                           | `JSX.CSSProperties \| string`                                                   | -         |
| title               | 标题，传入 JSX 元素；内容为空时不渲染标题，并作为对话框的可访问名称。                                                                                        | `JSX.Element`                                                                   | -         |
| visible             | 面板是否可见，受控属性；关闭时需在 onCancel 中同步设为 false。                                                                                               | `boolean`                                                                       | `false`   |
| width               | 宽度，placement 为 left、right 时生效；数字按像素处理，字符串为合法 CSS 长度。未设置时由 size 决定。                                                         | `number \| string`                                                              | -         |
| zIndex              | 弹层的 z-index。                                                                                                                                             | `number`                                                                        | `1000`    |
