**Props**

| Property | Description | Type | Default |
| --- | --- | --- | --- |
| afterVisibleChange | Called with `true` after the enter animation ends, or right after showing without motion; called with `false` after the leave animation ends, and once with `false` when unmounted while shown, or when its subtree is hidden by `Activity`. | <ApiType detail={"(isVisible: boolean) => void"}>Type</ApiType> | - |
| aria-label | Accessible name of the dialog. When set, it takes the place of the name generated from `title`. | `string` | - |
| canVerticalSetWidth | Whether `width` applies when `placement` is `top` or `bottom`. By default those sheets span the full width. | `boolean` | - |
| children | Content of the sheet, rendered in `.semi-sidesheet-body`. | `React.ReactNode` | - |
| className | Class name of the root element, the outermost `.semi-sidesheet` element inside the portal. | `string` | - |
| classNames | Class names of the inner parts, keyed by `mask`, `content`, `header`, `body` and `footer`; merged with the built-in classes. `content` lands on the dialog element (`.semi-sidesheet-inner`). | <ApiType detail={"Partial\u003cRecord\u003cSideSheetPart, string>>"}>Type</ApiType> | - |
| closable | Whether the close button in the top right corner is shown. | `boolean` | `true` |
| closeIcon | Icon inside the close button. `null` or `undefined` falls back to the default icon; hide the button with `closable={false}`. | `any` | - |
| closeOnEsc | Whether pressing `Esc` closes the sheet. | `boolean` | `false` |
| disableScroll | Whether body scrolling is locked (`overflow: hidden` on body) while a masked sheet is rendered in `document.body`. | `boolean` | `true` |
| footer | Footer of the sheet. Nothing is rendered when it is empty. | `React.ReactNode` | `null` |
| getPopupContainer | Parent element the sheet is rendered into. When omitted, it is rendered in `document.body`. A custom container needs `position: relative`; this changes where the sheet sits in the DOM, not where it is shown. | <ApiType detail={"() => HTMLElement"}>Type</ApiType> | - |
| height | Height, used when `placement` is `top` or `bottom`. A number is in pixels; a string is any valid CSS length. 448 when omitted. | `number \| string` | - |
| keepDOM | Whether the sheet content stays mounted while closed. | `boolean` | `false` |
| mask | Whether the mask is shown. When `false`, the content outside stays operable and body scrolling is not locked. | `boolean` | `true` |
| maskClosable | Whether clicking the mask closes the sheet. | `boolean` | `true` |
| motion | Whether animation is enabled. | `boolean` | `true` |
| onCancel | Called when the user closes the sheet with the close button, the mask or `Esc`. The argument is the native `MouseEvent`, or the native `KeyboardEvent` for `Esc`. The sheet does not close by itself; set `visible` to `false` in the callback. | <ApiType detail={"(e: React.MouseEvent \u007c KeyboardEvent) => void"}>Type</ApiType> | - |
| placement | Edge the sheet slides in from: `top`, `bottom`, `left` or `right`. | `Placement` | `"right"` |
| ref | Reference to the root element, the outermost `.semi-sidesheet` element inside the portal. It is `null` while nothing is rendered. | <ApiType detail={"React.Ref\u003cHTMLDivElement>"}>Type</ApiType> | - |
| size | Size: `small` (448px), `medium` (684px) or `large` (920px). Used only when `placement` is `left` or `right`; `width` takes precedence when set. | `'large' \| 'medium' \| 'small'` | `"small"` |
| style | Style of the dialog element (`.semi-sidesheet-inner`), merged with the computed width and height, which take precedence. | `CSSProperties` | - |
| styles | Inline styles of the inner parts, keyed like `classNames`. Like `style`, `content` is merged with the computed width and height, which take precedence. | <ApiType detail={"Partial\u003cRecord\u003cSideSheetPart, CSSProperties>>"}>Type</ApiType> | - |
| title | Title of the sheet. Nothing is rendered when it is empty, and it names the dialog. | `React.ReactNode` | - |
| visible | Whether the sheet is visible. A controlled prop: set it to `false` in `onCancel` to close the sheet. | `boolean` | `false` |
| width | Width, used when `placement` is `left` or `right`, and also when `placement` is `top` or `bottom` with `canVerticalSetWidth`. A number is in pixels; a string is any valid CSS length. Decided by `size` when omitted. | `number \| string` | - |
| zIndex | `z-index` of the layer. | `number` | `1000` |
