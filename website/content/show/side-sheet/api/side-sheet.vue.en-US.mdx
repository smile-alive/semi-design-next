import ApiType from '#/components/ApiType.astro';

**Props**

| Property | Description | Type | Default |
| --- | --- | --- | --- |
| canVerticalSetWidth | Whether width applies when placement is top or bottom. By default those sheets span the full width. | `boolean` | `semiGlobalDefault("SideSheet", "canVerticalSetWidth")` |
| classNames | Class names of the inner parts, keyed by mask, content, header, body and footer; values take anything class takes and merge with the built-in classes. content lands on the dialog element (.semi-sidesheet-inner). | <ApiType detail={"Partial\u003cRecord\u003cSideSheetPart, ClassValue>>"}>Type</ApiType> | `semiGlobalDefault("SideSheet", "classNames")` |
| closable | Whether the close button in the corner is shown. | `boolean` | `true` |
| closeOnEsc | Whether Esc closes the sheet. | `boolean` | `false` |
| disableScroll | Whether body scrolling is locked (overflow: hidden on body) while a masked sheet is rendered in document.body. | `boolean` | `true` |
| getPopupContainer | Parent element the sheet is rendered into. A custom container needs position: relative; this changes where the sheet sits in the DOM, not where it is shown. | <ApiType detail={"(() => HTMLElement)"}>Type</ApiType> | `undefined` |
| height | Height, used when placement is top or bottom. A number is in pixels; a string is any valid CSS length. 448 when omitted. | `string \| number` | `semiGlobalDefault("SideSheet", "height")` |
| keepDOM | Whether the sheet content stays mounted while closed. | `boolean` | `false` |
| mask | Whether the mask is shown. When false the content outside stays operable. | `boolean` | `true` |
| maskClosable | Whether clicking the mask closes the sheet. | `boolean` | `true` |
| motion | Whether animation is enabled. | `boolean` | `true` |
| placement | Edge the sheet slides in from. | `Placement` | `"right"` |
| size | Size: small is 448px, medium 684px, large 920px. Used only when placement is left or right. | `"large" \| "medium" \| "small"` | `"small"` |
| styles | Inline styles of the inner parts, keyed like classNames; values take anything style takes. Like style, content is merged with the computed width and height, which take precedence. | <ApiType detail={"Partial\u003cRecord\u003cSideSheetPart, StyleValue>>"}>Type</ApiType> | `semiGlobalDefault("SideSheet", "styles")` |
| title | Plain-text title. The title slot wins when both are given. | `string` | `semiGlobalDefault("SideSheet", "title")` |
| visible | Whether the sheet is visible, used with v-model:visible. | `boolean` | `semiGlobalDefault("SideSheet", "visible")` |
| width | Width, used when placement is left or right. A number is in pixels; a string is any valid CSS length. Decided by size when omitted. | `string \| number` | `semiGlobalDefault("SideSheet", "width")` |
| zIndex | z-index of the layer. | `number` | `1000` |

**Events**

| Event              | Description                                                                                                                                                                                                                                                   | Callback parameters                    |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------- |
| afterVisibleChange | Emitted with true after the enter animation ends, or right after showing without motion. Emitted with false after the leave animation, and once with false if the sheet is unmounted while shown. Not emitted when a KeepAlive deactivates or reactivates it. | `[visible: boolean]`                   |
| cancel             | Emitted after update:visible when the user closes the sheet with the close button, the mask or Esc. The payload is the native MouseEvent, or the native KeyboardEvent for Esc.                                                                                | `[event: KeyboardEvent \| MouseEvent]` |
| update:visible     | Emitted with false before cancel when the close button, the mask or Esc closes the sheet, for v-model:visible to write back.                                                                                                                                  | `[visible: boolean]`                   |

**Slots**

| Slot      | Description                                                                                                             | Scope parameters |
| --------- | ----------------------------------------------------------------------------------------------------------------------- | ---------------- |
| closeIcon | Icon inside the close button. An empty slot falls back to the default icon; hide the button with closable set to false. | `any`            |
| default   | Body of the sheet.                                                                                                      | `any`            |
| footer    | Footer of the sheet. Nothing is rendered when it is empty.                                                              | `any`            |
| title     | Title. It wins over the title prop and names the dialog. Nothing is rendered when it is empty.                          | `any`            |

**Exposes**

| Name | Description                                                                             | Type                     |
| ---- | --------------------------------------------------------------------------------------- | ------------------------ |
| root | The outer .semi-sidesheet element inside the portal, or null while nothing is rendered. | `HTMLDivElement \| null` |
