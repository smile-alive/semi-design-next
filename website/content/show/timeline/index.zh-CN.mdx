### 基本用法

<Framework only="svelte">

Svelte 版不提供 `Timeline.Item`，节点统一写在 `dataSource` 中：`time`、`extra`、`content` 是字符串或数字，`type`、`color` 设置圆点样式。

</Framework>

<Demo id="basic" />

### 节点类型

通过 type 可以设置节点类型，对应原点会变成相应的颜色，可选：`default`，`ongoing`， `success`， `warning`， `error`。

<Demo id="type" />

### 自定义节点

<Framework only="react">

可以通过 `dot` 自定义图标，`color` 自定义圆点色值。通过设置 `children` 的样式可以自定义节点样式。

</Framework>

<Framework only="vue">

可以通过 `#dot` 插槽自定义图标，`color` 自定义圆点色值。通过设置默认插槽内容的样式可以自定义节点样式。时间与辅助内容使用 `#time`、`#extra` 插槽。

</Framework>

<Framework only="solid">

可以通过 `dot` 自定义图标，`color` 自定义圆点色值。通过设置 `children` 的样式可以自定义节点样式。

</Framework>

<Framework only="svelte">

可以通过 `dataSource` 项的 `dot` snippet 自定义该节点的图标，`color` 自定义圆点色值；未设置 `dot` 的节点画默认圆点。通过 `content` snippet 为节点内容设置样式。时间与辅助内容使用 `time`、`extra` snippet，参数都是 `{ item, index }`。

</Framework>

### 使用 dataSource

<Framework only="vue">

`dataSource` 项的 `content`、`time`、`extra` 只接受字符串或数字；自定义内容使用作用域插槽 `#content`、`#dot`、`#time`、`#extra`，参数为 `{ item, index }`。

</Framework>

<Framework only="solid">

`dataSource` 项的 `content`、`time`、`extra` 只接受字符串或数字。需要自定义渲染时，传入 `renderContent`、`renderDot`、`renderTime`、`renderExtra`，参数为 `(item, index)`。

</Framework>

<Framework only="svelte">

`dataSource` 项的 `content`、`time`、`extra` 只接受字符串或数字；自定义内容使用 snippet `content`、`time`、`extra`，参数为 `{ item, index }`；自定义圆点使用项的 `dot` snippet，无参数。

</Framework>

## API 参考

### TimeLine

<Framework only="react">

<TimelineReactApi />

其他原生属性（如 `id`、`aria-label`）落在根元素 `ul` 上。

</Framework>

<Framework only="vue">

<TimelineVueApi />

`class`、`style` 与原生属性经 attrs 传入根元素 `ul`。

`dataSource` 项的字段：

| 字段     | 说明                                         | 类型                                                          | 默认值    |
| -------- | -------------------------------------------- | ------------------------------------------------------------- | --------- |
| content  | 节点内容，自定义内容使用 `#content` 插槽     | `string \| number`                                            | -         |
| time     | 时间文本，自定义内容使用 `#time` 插槽        | `string \| number`                                            | -         |
| extra    | 辅助内容，自定义内容使用 `#extra` 插槽       | `string \| number`                                            | -         |
| color    | 自定义的圆圈色值                             | `string`                                                      | -         |
| type     | 当前圆圈的模式                               | `'default' \| 'ongoing' \| 'success' \| 'warning' \| 'error'` | `default` |
| position | 自定义节点位置，可以覆盖 TimeLine 的模式选项 | `'left' \| 'right'`                                           | -         |
| class    | 类名                                         | `string`                                                      | -         |
| style    | 样式                                         | `StyleValue`                                                  | -         |
| onClick  | 鼠标点击事件的回调                           | `(event: MouseEvent) => void`                                 | -         |

</Framework>

<Framework only="solid">

<TimelineSolidApi />

`class`、`style`、`ref` 与原生属性落在根元素 `ul` 上。

`dataSource` 项的字段：

| 字段     | 说明                                         | 类型                                                          | 默认值    |
| -------- | -------------------------------------------- | ------------------------------------------------------------- | --------- |
| content  | 节点内容，自定义渲染使用 `renderContent`     | `string \| number`                                            | -         |
| time     | 时间文本，自定义渲染使用 `renderTime`        | `string \| number`                                            | -         |
| extra    | 辅助内容，自定义渲染使用 `renderExtra`       | `string \| number`                                            | -         |
| color    | 自定义的圆圈色值                             | `string`                                                      | -         |
| type     | 当前圆圈的模式                               | `'default' \| 'ongoing' \| 'success' \| 'warning' \| 'error'` | `default` |
| position | 自定义节点位置，可以覆盖 TimeLine 的模式选项 | `'left' \| 'right'`                                           | -         |
| class    | 类名                                         | `string`                                                      | -         |
| style    | 样式                                         | `JSX.CSSProperties \| string`                                 | -         |
| onClick  | 鼠标点击事件的回调                           | `JSX.EventHandlerUnion<HTMLLIElement, MouseEvent>`            | -         |

</Framework>

<Framework only="svelte">

<TimelineSvelteApi />

`class`、`style`（字符串）与原生属性（如 `id`、`aria-label`）落在根元素 `ul` 上。

`dataSource` 项的字段：

| 字段     | 说明                                                           | 类型                                                          | 默认值    |
| -------- | -------------------------------------------------------------- | ------------------------------------------------------------- | --------- |
| content  | 节点内容，自定义内容使用 `content` snippet                     | `string \| number`                                            | -         |
| time     | 时间文本，自定义内容使用 `time` snippet                        | `string \| number`                                            | -         |
| extra    | 辅助内容，自定义内容使用 `extra` snippet                       | `string \| number`                                            | -         |
| dot      | 自定义圆点，未设置时画默认圆点                                 | `Snippet`                                                     | -         |
| color    | 自定义的圆圈色值                                               | `string`                                                      | -         |
| type     | 当前圆圈的模式                                                 | `'default' \| 'ongoing' \| 'success' \| 'warning' \| 'error'` | `default` |
| position | 自定义节点位置，可以覆盖 TimeLine 的模式选项                   | `'left' \| 'right'`                                           | -         |
| onClick  | 点击节点的回调，参数为 `MouseEvent`；点击 `extra` 区域不会触发 | `(event: MouseEvent) => void`                                 | -         |
| class    | `li` 的类名                                                    | `ClassValue`                                                  | -         |
| style    | `li` 的样式字符串                                              | `string`                                                      | -         |

</Framework>

### TimeLine.Item

<Framework only="react">

<TimelineItemReactApi />

其他原生属性（如 `id`）落在根元素 `li` 上。`onClick` 为 `li` 的点击事件，回调参数为 `MouseEvent`。有 `onClick` 时，内容区域带 `role="button"` 与 `tabIndex` 为 `0`，支持 `Enter` 和 `Space`。

</Framework>

<Framework only="vue">

<TimelineItemVueApi />

`class`、`style` 与原生属性经 attrs 传入 `li`。点击事件写作 `@click`，点击 `extra` 区域不会触发。有 `@click` 时，内容区域带 `role="button"` 与 `tabindex="0"`，支持 `Enter` 和 `Space`。`#dot`、`#time`、`#extra` 插槽内容为空时不渲染对应容器。

</Framework>

<Framework only="solid">

<TimelineItemSolidApi />

`class`、`style`、`ref` 与原生属性落在 `li` 上。点击事件写作 `onClick`，点击 `extra` 区域不会触发。有 `onClick` 时，内容区域带 `role="button"` 与 `tabindex="0"`，支持 `Enter` 和 `Space`。`time`、`extra` 为空时不渲染对应容器。

</Framework>

<Framework only="svelte">

Svelte 版没有 `TimeLine.Item`，节点由 `dataSource` 的项表示，字段见上方表格：`class`、`style` 与其他 `li` 属性写在项里并落在 `li` 上；有 `onClick` 时，内容区域带 `role="button"` 与 `tabindex="0"`，支持 `Enter` 和 `Space`。`time`、`extra` 为空时不渲染对应容器。

</Framework>

## Accessibility

### ARIA

- 组件中时间点的连线以及时间点本身被设置了 `aria-hidden`，不会响应 Accessibility API
- 可以通过传入 `aria-label` 设置 TimeLine 组件的标签

<Framework only="react">

```text
<Timeline aria-label="xx事故处理过程时间线">
    <Timeline.Item time="2015-09-01">创建服务现场</Timeline.Item>
    <Timeline.Item time="2015-09-02">初步排除网络异常</Timeline.Item>
    <Timeline.Item time="2015-09-03">技术测试异常</Timeline.Item>
    <Timeline.Item time="2015-09-05">网络异常正在修复</Timeline.Item>
</Timeline>
```

</Framework>

<Framework only="vue">

```vue
<template>
    <Timeline aria-label="xx事故处理过程时间线">
        <Timeline.Item>
            <template #time>2015-09-01</template>
            创建服务现场
        </Timeline.Item>
        <Timeline.Item>
            <template #time>2015-09-02</template>
            初步排除网络异常
        </Timeline.Item>
    </Timeline>
</template>
```

</Framework>

<Framework only="solid">

```jsx
<Timeline aria-label="xx事故处理过程时间线">
    <Timeline.Item time="2015-09-01">创建服务现场</Timeline.Item>
    <Timeline.Item time="2015-09-02">初步排除网络异常</Timeline.Item>

    <Timeline.Item time="2015-09-05">网络异常正在修复</Timeline.Item>

```

</Framework>

<Framework only="svelte">

```svelte
<script lang="ts">
    import { Timeline } from '@fibrae/semi-ui-svelte';

    const dataSource = [
        { time: '2015-09-01', content: '创建服务现场' },
        { time: '2015-09-02', content: '初步排除网络异常' },
    ];
</script>

<Timeline aria-label="xx事故处理过程时间线" {dataSource} />
```
