### Basic Usage

<Framework only="svelte">

The Svelte version has no `Timeline.Item`: write every node in `dataSource`. `time`, `extra` and `content` are strings or numbers, and `type` and `color` style the dot.

</Framework>

<Demo id="basic" />

### Type

You can use `type` to set the type of a time node, using one of: `default`,`ongoing`, `success`, `warning`, `Error`. The corresponding dot will have a corresponding color.

<Demo id="type" />

### Custom node

<Framework only="react">

You can use `dot` to customize icon, `color` to customize color or pass in `children` with style.

</Framework>

<Framework only="vue">

You can use the `#dot` slot to customize icon, `color` to customize color or style the default slot content. Time and extra content use the `#time` and `#extra` slots.

</Framework>

<Framework only="solid">

You can use `dot` to customize icon, `color` to customize color or pass in `children` with style.

</Framework>

<Framework only="svelte">

You can use the `dot` snippet of a `dataSource` item to customize the icon of that node and `color` to customize the dot color; nodes without `dot` draw the default circle. Style the node content through the `content` snippet. Use the `time` and `extra` snippets for the time and the extra content; both take the parameter `{ item, index }`.

</Framework>

### DataSource

<Framework only="vue">

`content`, `time` and `extra` of a `dataSource` item only take a string or number. Use the scoped slots `#content`, `#dot`, `#time` and `#extra` for custom content, with `{ item, index }` as the parameters.

</Framework>

<Framework only="solid">

`content`, `time` and `extra` of a `dataSource` item accept only strings or numbers. For custom rendering, pass `renderContent`, `renderDot`, `renderTime` and `renderExtra`, called with `(item, index)`.

</Framework>

<Framework only="svelte">

`content`, `time` and `extra` of a `dataSource` item accept only strings or numbers. For custom rendering, use the snippets `content`, `time` and `extra`, called with `{ item, index }`; for a custom dot, set the `dot` snippet of the item, which takes no argument.

</Framework>

## API reference

### TimeLine

<Framework only="react">

<TimelineReactApi />

Other native attributes, such as `id` and `aria-label`, are passed to the root `ul` element.

</Framework>

<Framework only="vue">

<TimelineVueApi />

`class`, `style` and native attributes are passed through attrs to the root `ul`.

Fields of a `dataSource` item:

| Field    | Instruction                                              | type                                                          | Default   |
| -------- | -------------------------------------------------------- | ------------------------------------------------------------- | --------- |
| content  | Item content; use the `#content` slot for custom content | `string \| number`                                            | -         |
| time     | Time value; use the `#time` slot for custom content      | `string \| number`                                            | -         |
| extra    | Extra content; use the `#extra` slot for custom content  | `string \| number`                                            | -         |
| color    | Color of dot                                             | `string`                                                      | -         |
| type     | Pattern of dot                                           | `'default' \| 'ongoing' \| 'success' \| 'warning' \| 'error'` | `default` |
| position | Custom node location to override TimeLine's mode setting | `'left' \| 'right'`                                           | -         |
| class    | Class name                                               | `string`                                                      | -         |
| style    | Inline style                                             | `StyleValue`                                                  | -         |
| onClick  | Click event                                              | `(event: MouseEvent) => void`                                 | -         |

</Framework>

<Framework only="solid">

<TimelineSolidApi />

`class`, `style`, `ref` and native attributes are passed to the root `ul`.

Fields of a `dataSource` item:

| Field    | Instruction                                              | type                                                          | Default   |
| -------- | -------------------------------------------------------- | ------------------------------------------------------------- | --------- |
| content  | Item content; custom rendering uses `renderContent`      | `string \| number`                                            | -         |
| time     | Time value; custom rendering uses `renderTime`           | `string \| number`                                            | -         |
| extra    | Extra content; custom rendering uses `renderExtra`       | `string \| number`                                            | -         |
| color    | Color of dot                                             | `string`                                                      | -         |
| type     | Pattern of dot                                           | `'default' \| 'ongoing' \| 'success' \| 'warning' \| 'error'` | `default` |
| position | Custom node location to override TimeLine's mode setting | `'left' \| 'right'`                                           | -         |
| class    | Class name                                               | `string`                                                      | -         |
| style    | Inline style                                             | `JSX.CSSProperties \| string`                                 | -         |
| onClick  | Click event                                              | `JSX.EventHandlerUnion<HTMLLIElement, MouseEvent>`            | -         |

</Framework>

<Framework only="svelte">

<TimelineSvelteApi />

`class`, `style` (a string) and native attributes such as `id` and `aria-label` are passed to the root `ul`.

Fields of a `dataSource` item:

| Field    | Description                                                                                        | Type                                                          | Default   |
| -------- | -------------------------------------------------------------------------------------------------- | ------------------------------------------------------------- | --------- |
| content  | Node content; use the `content` snippet for custom content                                         | `string \| number`                                            | -         |
| time     | Time text; use the `time` snippet for custom content                                               | `string \| number`                                            | -         |
| extra    | Extra content; use the `extra` snippet for custom content                                          | `string \| number`                                            | -         |
| dot      | Custom dot; the default circle is drawn when unset                                                 | `Snippet`                                                     | -         |
| color    | Custom color of the dot                                                                            | `string`                                                      | -         |
| type     | Mode of the dot                                                                                    | `'default' \| 'ongoing' \| 'success' \| 'warning' \| 'error'` | `default` |
| position | Custom position of the node, overriding the mode of TimeLine                                       | `'left' \| 'right'`                                           | -         |
| onClick  | Called when the node is clicked, with a `MouseEvent`; clicks in the `extra` area do not trigger it | `(event: MouseEvent) => void`                                 | -         |
| class    | Class name of the `li`                                                                             | `ClassValue`                                                  | -         |
| style    | Style string of the `li`                                                                           | `string`                                                      | -         |

</Framework>

### TimeLine.Item

<Framework only="react">

<TimelineItemReactApi />

Other native attributes, such as `id`, are passed to the root `li` element. `onClick` is the click event of the `li`, receiving a `MouseEvent`. With `onClick`, the content area has `role="button"` and `tabIndex` `0` and responds to `Enter` and `Space`.

</Framework>

<Framework only="vue">

<TimelineItemVueApi />

`class`, `style` and native attributes are passed through attrs to the `li`. Listen to clicks with `@click`; clicks in the `extra` area do not trigger it. With `@click`, the content area has `role="button"` and `tabindex="0"` and responds to `Enter` and `Space`. A container is not rendered when its `#dot`, `#time` or `#extra` slot is empty.

</Framework>

<Framework only="solid">

<TimelineItemSolidApi />

`class`, `style`, `ref` and native attributes are passed to the `li`. Listen to clicks with `onClick`; clicks in the `extra` area do not trigger it. With `onClick`, the content area has `role="button"` and `tabindex="0"` and responds to `Enter` and `Space`. A container is not rendered when its `time` or `extra` is empty.

</Framework>

<Framework only="svelte">

The Svelte version has no `TimeLine.Item`: a node is an item of `dataSource`, with the fields in the table above. `class`, `style` and other `li` attributes are written in the item and land on the `li`. With `onClick`, the content area has `role="button"` and `tabindex="0"` and responds to `Enter` and `Space`. A container is not rendered when its `time` or `extra` is empty.

</Framework>

## Accessibility

### ARIA

- The element of dot and line between dots in TimeLine have a `aria-hidden`, indicates that they do not support Accessibility API.
- Supporting API `aria-label` to specify TimeLine's label.

<Framework only="react">

```text
<Timeline aria-label="Accident timeline">
    <Timeline.Item time="2015-09-01">Accident started</Timeline.Item>
    <Timeline.Item time="2015-09-01">Process</Timeline.Item>
</Timeline>
```

</Framework>

<Framework only="vue">

```vue
<template>
    <Timeline aria-label="Accident timeline">
        <Timeline.Item>
            <template #time>2015-09-01</template>
            Accident started
        </Timeline.Item>
        <Timeline.Item>
            <template #time>2015-09-01</template>
            Process
        </Timeline.Item>
    </Timeline>
</template>
```

</Framework>

<Framework only="solid">

```jsx
<Timeline aria-label="Accident timeline">
    <Timeline.Item time="2015-09-01">Accident started</Timeline.Item>
    <Timeline.Item time="2015-09-01">Process</Timeline.Item>
</Timeline>
```

</Framework>

<Framework only="svelte">

```svelte
<script lang="ts">
    import { Timeline } from '@fibrae/semi-ui-svelte';

    const dataSource = [
        { time: '2015-09-01', content: 'Accident started' },
        { time: '2015-09-01', content: 'Process' },
    ];
</script>

<Timeline aria-label="Accident timeline" {dataSource} />
```

</Framework>
