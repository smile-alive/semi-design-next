**Props**

| 属性       | 说明                                                                                                | 类型                                                                | 默认值   |
| ---------- | --------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------- | -------- |
| children   | 时间轴的节点，通常为 `Timeline.Item`；dataSource 非空时被忽略。                                     | `React.ReactNode`                                                   | -        |
| className  | 根元素 `ul` 的类名。                                                                                | `string`                                                            | -        |
| dataSource | 数据数组，非空时按数据渲染节点并忽略子节点；每项的属性与 Timeline.Item 相同，`content` 为节点内容。 | `Data[]`                                                            | -        |
| mode       | 时间轴与内容的相对位置，可选 `left`、`right`、`center` 或 `alternate`。                             | `'left' \| 'right' \| 'center' \| 'alternate'`                      | `"left"` |
| ref        | 根元素 `ul` 的引用。                                                                                | <ApiType detail={"React.Ref\u003cHTMLUListElement>"}>Type</ApiType> | -        |
| style      | 根元素 `ul` 的样式。                                                                                | `React.CSSProperties`                                               | -        |
