**Props**

| Property | Description | Type | Default |
| --- | --- | --- | --- |
| children | Content of the item. | `React.ReactNode` | - |
| className | Class name of the root `li` element. | `string` | - |
| classNames | Class names of the inner parts, keyed by `rail`, `icon`, `content`, `extra` and `time`; merged with the built-in classes, after the `item*` class names of the Timeline. `rail` is the connecting line and `icon` holds the dot or the custom dot. | <ApiType detail={"Partial\u003cRecord\u003cTimelineItemPart, string>>"}>Type</ApiType> | - |
| color | Background color of the dot, overriding the color of type. | `string` | - |
| dot | Custom dot content, replacing the default dot. | `React.ReactNode` | - |
| extra | Extra content, not rendered when empty. Clicks in this area do not trigger onClick. | `React.ReactNode` | - |
| position | Overrides the mode of the Timeline for this item: `left` or `right`. | `'left' \| 'right'` | - |
| ref | Reference to the root `li` element. | <ApiType detail={"React.Ref\u003cHTMLLIElement>"}>Type</ApiType> | - |
| style | Style of the root `li` element. | `React.CSSProperties` | - |
| styles | Inline styles of the inner parts, keyed like `classNames`, applied after the `item*` styles of the Timeline. | <ApiType detail={"Partial\u003cRecord\u003cTimelineItemPart, React.CSSProperties>>"}>Type</ApiType> | - |
| time | Time text, not rendered when empty. | `React.ReactNode` | `""` |
| type | Dot type: `default`, `ongoing`, `success`, `warning` or `error`. | `'default' \| 'error' \| 'ongoing' \| 'success' \| 'warning'` | `"default"` |
