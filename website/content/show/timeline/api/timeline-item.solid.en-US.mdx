**Props**

| Property | Description                                                                | Type                                                          | Default |
| -------- | -------------------------------------------------------------------------- | ------------------------------------------------------------- | ------- |
| color    | Color of the dot, used as its background and overriding the color of type. | `string`                                                      | -       |
| dot      | Custom dot content, replacing the default dot.                             | `JSX.Element`                                                 | -       |
| extra    | Extra content, not rendered when empty.                                    | `JSX.Element`                                                 | -       |
| position | Overrides the mode of the Timeline for this item: left or right.           | `'left' \| 'right'`                                           | -       |
| time     | Time text, not rendered when empty.                                        | `JSX.Element`                                                 | -       |
| type     | Dot type: default, ongoing, success, warning or error.                     | `'default' \| 'ongoing' \| 'success' \| 'warning' \| 'error'` | -       |
