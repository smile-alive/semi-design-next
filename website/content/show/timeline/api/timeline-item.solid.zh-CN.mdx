**Props**

| 属性       | 说明                                                                                                                                                                          | 类型                                                                                                            | 默认值 |
| ---------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------- | ------ |
| classNames | 内部各部位的类名，键为 `rail`、`icon`、`content`、`extra`、`time`，与组件自带的类名合并，在 Timeline 的 `item*` 类名之后；`rail` 是连接线，`icon` 是圆点或自定义 dot 的容器。 | <ApiType detail={"Partial\u003cRecord\u003cTimelineItemPart, string>>"}>Type</ApiType>                          | -      |
| color      | 节点的颜色，作为圆点的背景色，覆盖 type 对应的颜色。                                                                                                                          | `string`                                                                                                        | -      |
| dot        | 自定义节点图标，替换默认圆点。                                                                                                                                                | `JSX.Element`                                                                                                   | -      |
| extra      | 辅助说明内容，为空时不渲染。                                                                                                                                                  | `JSX.Element`                                                                                                   | -      |
| position   | 覆盖 Timeline 的 mode，指定该项所在的一侧，可选 left 或 right。                                                                                                               | `'left' \| 'right'`                                                                                             | -      |
| styles     | 内部各部位的内联样式，键同 `classNames`，后于 Timeline 的 `item*` 样式写入。                                                                                                  | <ApiType detail={"Partial\u003cRecord\u003cTimelineItemPart, JSX.CSSProperties \u007c string>>"}>Type</ApiType> | -      |
| time       | 时间文本，为空时不渲染。                                                                                                                                                      | `JSX.Element`                                                                                                   | -      |
| type       | 节点类型，可选 default、ongoing、success、warning、error。                                                                                                                    | `'default' \| 'error' \| 'ongoing' \| 'success' \| 'warning'`                                                   | -      |
