**Props**

| 属性     | 说明                                                       | 类型                   | 默认值      |
| -------- | ---------------------------------------------------------- | ---------------------- | ----------- |
| color    | 节点的颜色。                                               | `string`               | `undefined` |
| position | 覆盖 Timeline 的 mode，指定该项所在的一侧。                | `TimelineItemPosition` | `undefined` |
| type     | 节点类型，可选 default、ongoing、success、warning、error。 | `TimelineItemType`     | `"default"` |

**Events**

| 事件 | 说明 | 回调参数 |
| ---- | ---- | -------- |
| 无   |      |          |

**Slots**

| 插槽    | 说明             | 作用域参数 |
| ------- | ---------------- | ---------- |
| default | 节点内容。       | `any`      |
| dot     | 自定义节点图标。 | `any`      |
| extra   | 辅助说明。       | `any`      |
| time    | 时间。           | `any`      |

**Exposes**

| 名称 | 说明 | 类型 |
| ---- | ---- | ---- |
| 无   |      |      |
