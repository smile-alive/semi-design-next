**Props**

| Property | Description                                            | Type                   | Default     |
| -------- | ------------------------------------------------------ | ---------------------- | ----------- |
| color    | Color of the dot.                                      | `string`               | `undefined` |
| position | Overrides the mode of the Timeline for this item.      | `TimelineItemPosition` | `undefined` |
| type     | Dot type: default, ongoing, success, warning or error. | `TimelineItemType`     | `"default"` |

**Slots**

| Slot    | Description         | Scope parameters |
| ------- | ------------------- | ---------------- |
| default | Item content.       | `any`            |
| dot     | Custom dot content. | `any`            |
| extra   | Extra content.      | `any`            |
| time    | Time.               | `any`            |
