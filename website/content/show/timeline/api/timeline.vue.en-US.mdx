**Props**

| Property   | Description                                                                                                                 | Type             | Default                                       |
| ---------- | --------------------------------------------------------------------------------------------------------------------------- | ---------------- | --------------------------------------------- |
| dataSource | Data array. When it is not empty the items are rendered from it and the default slot is ignored. See the item fields below. | `TimelineData[]` | `semiGlobalDefault("Timeline", "dataSource")` |
| mode       | Position of the timeline relative to the content: left, right, center or alternate.                                         | `TimelineMode`   | `"left"`                                      |

**Events**

| Event | Description | Callback parameters |
| ----- | ----------- | ------------------- |
| None  |             |                     |

**Slots**

| Slot    | Description                                                    | Scope parameters    |
| ------- | -------------------------------------------------------------- | ------------------- |
| content | Content of each dataSource item. Defaults to item.content.     | `TimelineSlotProps` |
| default | Timeline.Item children, used when dataSource is empty.         | `any`               |
| dot     | Custom dot of each dataSource item.                            | `TimelineSlotProps` |
| extra   | Extra content of each dataSource item. Defaults to item.extra. | `TimelineSlotProps` |
| time    | Time of each dataSource item. Defaults to item.time.           | `TimelineSlotProps` |

**Exposes**

| Name | Description | Type |
| ---- | ----------- | ---- |
| None |             |      |
