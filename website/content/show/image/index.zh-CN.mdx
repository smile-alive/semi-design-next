### 渲染在指定容器

可以通过 `getPopupContainer` 指定预览组件的父级 DOM（需要指定 `position: relative`)，图片预览将会渲染至该 DOM 中。这会改变浮层 DOM 树位置，但不会改变视图渲染位置。

容器不是 `document.body` 时（包括只在 ConfigProvider 上设置 `getPopupContainer`），预览为非模态：不输出 `aria-modal`，不锁定 Tab，也不锁定页面滚动。`getPopupContainer` 返回 `document.body` 与不传相同。

## API 参考

### Image

<Framework only="react">

<ImageReactApi />

`onLoad`、`onError` 分别在图片加载成功、失败时调用，参数为 `SyntheticEvent<HTMLImageElement>`；其他原生属性（如 `data-*`、`aria-*`）透传至底层的 img 节点。

单个 Image 的 `preview` 对象接受下表 ImagePreview 的属性，但不含 `lazyLoad`、`lazyLoadMargin`、`children`、`className`、`style`（预览样式请用 `previewCls`、`previewStyle`）。`preview.src` 为数组时，切换图片后回到「适应页面」。

</Framework>

<Framework only="vue">

<ImageVueApi />

`width`、`height` 的数值按 px 处理。`class`、`style` 落在根元素上，其余未声明的原生属性与监听落在内部的 img 上。`preview` 对象接受 ImagePreview 的 props 与回调（`onVisibleChange`、`onChange`、`onClose`、`onZoomIn`、`onZoomOut`、`onPrev`、`onNext`、`onRatioChange`、`onRotateLeft`、`onDownload`、`onDownloadError`），但不含 `lazyLoad`、`lazyLoadMargin`、`class`、`style`（预览样式请用 `previewCls`、`previewStyle`）；自定义节点不放在 `preview` 里，使用 Image 的插槽。`preview.src` 为数组时，切换图片后回到「适应页面」。处于 ImagePreview 内的 Image 不使用 `#title`、`#previewMenu`、`#leftIcon`、`#rightIcon`、`#closeIcon`，以 ImagePreview 的插槽为准。

</Framework>

<Framework only="solid">

<ImageSolidApi />

`class`、`style` 落在缩略图的根元素上；`ref`、`id`、`aria-*` 与原生事件（如 `onClick`）落在内部的 img 上。

</Framework>

<Framework only="svelte">

<ImageSvelteApi />

`width`、`height` 的数值按 px 处理。`class`、`style` 落在根元素上，其余未声明的原生属性与事件处理落在内部的 img 上。`preview` 对象接受 ImagePreview 的 props 与回调（`onVisibleChange`、`onChange`、`onClose`、`onZoomIn`、`onZoomOut`、`onPrev`、`onNext`、`onRatioChange`、`onRotateLeft`、`onDownload`、`onDownloadError`），但不含 `lazyLoad`、`lazyLoadMargin`、`class`、`style`（预览样式请用 `previewCls`、`previewStyle`）；自定义节点不放在 `preview` 里，使用 Image 的 snippet。`preview.src` 为数组时，切换图片后回到「适应页面」。处于 ImagePreview 内的 Image 不使用 `title`、`previewMenu`、`leftIcon`、`rightIcon`、`closeIcon` snippet，以 ImagePreview 的 snippet 为准。

</Framework>

### MenuProps

`min`、`max`、`step`、`zoom` 是百分比数值（如 `min` 为 `10` 表示 10%，`step` 为 `10` 表示每次 10%），与 ImagePreview 的 `minZoom`、`maxZoom`、`zoomStep`、`initialZoom`（倍数，如 `0.1`、`5`）单位不同。

## Accessibility

### ARIA

- 预览渲染在 `document.body`（默认）时是 `role="dialog"`、`aria-modal="true"` 的模态对话框；渲染到自定义容器（`getPopupContainer` 返回其他元素，含 ConfigProvider 设置的容器）时是非模态对话框，不输出 `aria-modal`。有标题（`previewTitle`，或组内图片的 `preview.previewTitle`）时由标题命名，否则以语言包的「预览」作为名称
- 关闭、左右切换箭头，以及底部的上一张、下一张、缩小、放大、原始尺寸 / 适应页面、旋转、下载都是原生 `button`，读屏名称取自对应的 `prevTip`、`nextTip` 等属性，未设置时取自语言包；缩放滑块的名称是语言包的「缩放」，`aria-valuetext` 为当前百分比
- 到达首张、末张或缩放上下限时，底部对应按钮带 `aria-disabled="true"`，仍可聚焦，焦点不会丢失。没有当前图片（`src` 为空列表）时下载按钮同样禁用
- 底部页码带 `aria-live="polite"`，切换图片时读屏会读出新的位置
- 开启预览且图片加载成功后，Image 缩略图的根元素是 `role="button"`、`tabindex="0"`、`aria-haspopup="dialog"` 的可聚焦按钮，名称取自图片的 `alt`；`preview` 为 false 或图片未加载成功时不可聚焦。关闭预览后焦点回到缩略图。ImagePreview 分组内的缩略图鼠标可点开，键盘同样可以：加载中或加载失败时也带按钮角色、可聚焦，Enter 或空格打开分组预览
- 预览图的 `alt` 取自对应缩略图的 `alt`（`ImagePreview` 的 `src` 数组没有 alt，为空字符串）

### 键盘交互

- 焦点在缩略图上时，Enter 或空格打开预览
- 打开预览后焦点移入预览层。模态预览中 Tab 与 Shift + Tab 在预览层内的控件间循环，关闭后焦点回到打开前聚焦的元素；渲染到自定义容器的非模态预览不锁定 Tab，关闭时只有焦点仍在预览内或落在 body 上才回到打开前聚焦的元素，焦点已移到页面其他位置时保持不变
- Enter 或空格触发聚焦的按钮
- ← 与 → 切换上一张、下一张，RTL（ConfigProvider `direction="rtl"`）下左右互换。到首张或末张时与按钮一致：`infinite` 为 true 时循环，否则不切换
- 焦点在输入框、文本域、下拉框或可编辑元素中（例如自定义页脚里的输入框），或同时按下 Alt、Ctrl、Meta、Shift 时，← 与 → 不切换图片；缩放滑块聚焦时 ← 与 → 调整缩放比例
- Esc 关闭预览（`closeOnEsc` 为 false 时不关闭）
- 操作区因 `viewerVisibleDelay` 隐藏后，按键或焦点移到操作区上会重新显示；焦点停在操作区时不再自动隐藏
