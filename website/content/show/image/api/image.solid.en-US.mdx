**Props**

| Property | Description | Type | Default |
| --- | --- | --- | --- |
| alt | Image description, also the accessible name of a previewable thumbnail. | `string` | - |
| classNames | Class names of the inner parts, keyed by `img` (the inner img element); merged with the built-in classes. | <ApiType detail={"Partial\u003cRecord\u003cImagePart, string>>"}>Type</ApiType> | - |
| crossOrigin | The crossorigin attribute passed to the native img element. | `'anonymous' \| 'use-credentials'` | - |
| fallback | Content shown when loading fails: a string is the fallback image URL, and a JSX element is shown as it is. Without it, the default failure icon is shown. | `JSX.Element` | - |
| height | Display height of the image; a number is in px. | `string \| number` | - |
| onError | Called when the image fails to load. | <ApiType detail={"JSX.EventHandlerUnion\u003cHTMLImageElement, Event>"}>Type</ApiType> | - |
| onLoad | Called when the image has loaded. | <ApiType detail={"JSX.EventHandlerUnion\u003cHTMLImageElement, Event>"}>Type</ApiType> | - |
| placeholder | Placeholder content shown until the image has loaded. | `JSX.Element` | - |
| preview | Preview options; false disables preview. The object accepts the ImagePreview props except lazyLoad, lazyLoadMargin, children, class and style (use `classNames.preview` and `styles.preview` to style the preview layer). | `boolean \| ImagePreviewProps` | `true` |
| setDownloadName | Sets the download file name of the image. | <ApiType detail={"(src: string) => string"}>Type</ApiType> | - |
| src | Image source URL. | `string` | - |
| style | Custom style of the thumbnail root element, as a style object (kebab-case keys) or a string. | `JSX.CSSProperties \| string` | - |
| styles | Styles of the inner parts, keyed like `classNames`; each value is a style object (kebab-case keys) or a string. | <ApiType detail={"Partial\u003cRecord\u003cImagePart, JSX.CSSProperties \u007c string>>"}>Type</ApiType> | - |
| width | Display width of the image; a number is in px. | `string \| number` | - |
