**Props**

| 属性            | 说明                                                                                                                                                                                | 类型                                                                                                     | 默认值 |
| --------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------- | ------ |
| alt             | 图像描述，同时作为可预览缩略图的读屏名称。                                                                                                                                          | `string`                                                                                                 | -      |
| classNames      | 内部各部位的类名，键为 `img`（内部的 img 节点），与组件自带的类名合并。                                                                                                             | <ApiType detail={"Partial\u003cRecord\u003cImagePart, string>>"}>Type</ApiType>                          | -      |
| crossOrigin     | 透传给原生 img 标签的 crossorigin。                                                                                                                                                 | `'anonymous' \| 'use-credentials'`                                                                       | -      |
| fallback        | 加载失败时显示的内容：字符串作为容错图片地址，JSX 元素原样显示；未设置时显示默认的加载失败图标。                                                                                    | `JSX.Element`                                                                                            | -      |
| height          | 图片显示高度，数值按 px 处理。                                                                                                                                                      | `string \| number`                                                                                       | -      |
| onError         | 图片加载失败时触发。                                                                                                                                                                | <ApiType detail={"JSX.EventHandlerUnion\u003cHTMLImageElement, Event>"}>Type</ApiType>                   | -      |
| onLoad          | 图片加载成功时触发。                                                                                                                                                                | <ApiType detail={"JSX.EventHandlerUnion\u003cHTMLImageElement, Event>"}>Type</ApiType>                   | -      |
| placeholder     | 图片未加载成功时的占位内容。                                                                                                                                                        | `JSX.Element`                                                                                            | -      |
| preview         | 预览配置，为 false 时禁用预览。对象接受 ImagePreview 的属性，但不含 lazyLoad、lazyLoadMargin、children、class 与 style（预览层的样式请用 `classNames.preview`、`styles.preview`）。 | `boolean \| ImagePreviewProps`                                                                           | `true` |
| setDownloadName | 设置图片下载名称。                                                                                                                                                                  | <ApiType detail={"(src: string) => string"}>Type</ApiType>                                               | -      |
| src             | 图片获取地址。                                                                                                                                                                      | `string`                                                                                                 | -      |
| style           | 缩略图根元素的自定义样式，可以是样式对象（键用 kebab-case）或字符串。                                                                                                               | `JSX.CSSProperties \| string`                                                                            | -      |
| styles          | 内部各部位的样式，键同 `classNames`，值可以是样式对象（键用 kebab-case）或字符串。                                                                                                  | <ApiType detail={"Partial\u003cRecord\u003cImagePart, JSX.CSSProperties \u007c string>>"}>Type</ApiType> | -      |
| width           | 图片显示宽度，数值按 px 处理。                                                                                                                                                      | `string \| number`                                                                                       | -      |
