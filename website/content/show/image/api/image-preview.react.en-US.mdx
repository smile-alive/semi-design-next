| onZoomIn | Called when the image zooms in, with the new zoom factor. | <ApiType detail={"(zoom: number) => void"}>Type</ApiType> | - |

| prevTip | Tip of the previous-image button, also its accessible name; without it, the locale text is used. | `string` | - |

| rotateTip | Tip of the rotate button; without it, the locale text is used. | `string` | - |

| showTooltip | Whether to show tooltips on the bottom action area, `false` by default. | `boolean` | - |

| style | Style of the group root div. | `CSSProperties` | - |
| viewerVisibleDelay | Idle time in milliseconds before the preview action buttons hide, `10000` by default. | `number` | - |
| visible | Controlled visibility of the preview. | `boolean` | - |
| zIndex | z-index of the preview layer, `1070` by default. | `number` | - |
| zoomInTip | Tip of the zoom-in button; without it, the locale text is used. | `string` | - |
