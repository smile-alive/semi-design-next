**Props**

| 属性               | 说明                                                                                                                                                                                | 类型                                                                              | 默认值               |
| ------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------- | -------------------- |
| aspectRatio        | 固定的裁切框宽高比；加载后改变时，裁切框按新比例重排。                                                                                                                              | `number`                                                                          | -                    |
| cropperBoxCls      | 裁切框类名。                                                                                                                                                                        | `string`                                                                          | -                    |
| cropperBoxStyle    | 裁切框样式字符串。                                                                                                                                                                  | `string`                                                                          | -                    |
| defaultAspectRatio | 裁切框的初始宽高比，拖动时会随之变化。                                                                                                                                              | `number`                                                                          | `1`                  |
| fill               | 裁切结果中非图片部分的填充色。                                                                                                                                                      | `string`                                                                          | `"rgba(0, 0, 0, 0)"` |
| imgProps           | 传给被裁切图片 img 标签的属性。src 与布局样式由组件决定，class 与 style 和组件自身的合并，onload 在组件处理完成后调用；alt 默认为空字符串，crossorigin 默认为 anonymous，均可覆盖。 | `HTMLImgAttributes`                                                               | -                    |
| maxZoom            | 最大缩放倍数。                                                                                                                                                                      | `number`                                                                          | `3`                  |
| minZoom            | 最小缩放倍数。                                                                                                                                                                      | `number`                                                                          | `0.1`                |
| onZoomChange       | 滚轮缩放时调用，参数为新的缩放比例。                                                                                                                                                | <ApiType detail={"(zoom: number) => void"}>Type</ApiType>                         | -                    |
| preview            | 返回预览容器 DOM 的函数，裁切效果会实时镜像到该容器；可返回 null，表示容器尚未挂载。                                                                                                | <ApiType detail={"() => HTMLElement \u007c null \u007c undefined"}>Type</ApiType> | -                    |
| rotate             | 图片旋转角度，单向绑定，组件不会改变它。                                                                                                                                            | `number`                                                                          | -                    |
| shape              | 裁切框形状。                                                                                                                                                                        | `CropperShape`                                                                    | `"rect"`             |
| showResizeBox      | 是否展示裁切框边角的调整块。                                                                                                                                                        | `boolean`                                                                         | `true`               |
| src                | 被裁切图片的地址。                                                                                                                                                                  | `string`                                                                          | -                    |
| zoom               | 缩放比例，叠加在图片适应裁切区域的初始缩放之上；可用 `bind:zoom`、函数绑定或单向传值，滚轮缩放时更新绑定值并调用 `onZoomChange`。                                                   | `number`                                                                          | -                    |
| zoomStep           | 滚轮缩放的步长。                                                                                                                                                                    | `number`                                                                          | `0.1`                |

**Methods**

| 方法             | 说明                                                                                   | 类型                                                       |
| ---------------- | -------------------------------------------------------------------------------------- | ---------------------------------------------------------- |
| getCropperCanvas | 按图片原始分辨率，把裁切框内的区域绘制到新的 canvas 并返回；图片加载前调用会抛出错误。 | <ApiType detail={"() => HTMLCanvasElement"}>Type</ApiType> |
