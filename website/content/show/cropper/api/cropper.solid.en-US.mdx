**Props**

| Property | Description | Type | Default |
| --- | --- | --- | --- |
| aspectRatio | Fixed aspect ratio of the crop box. When it changes after loading, the box is laid out again at the new ratio. | `number` | - |
| cropperBoxCls | Class name of the crop box. | `string` | - |
| cropperBoxStyle | Style of the crop box, merged with the size and offset the component computes; the size and offset win. | `JSX.CSSProperties` | - |
| defaultAspectRatio | Initial aspect ratio of the crop box, which changes while dragging. | `number` | `1` |
| fill | Fill color of the parts of the result that are not the image. | `string` | `"rgba(0, 0, 0, 0)"` |
| imgProps | Attributes passed to the img element being cropped. src and the layout belong to the component; class is merged with its own class name, style sits under its layout (the size and offset win), and onLoad is called after the component has handled it. alt defaults to an empty string and crossorigin to anonymous; both can be overridden. | `CropperImgProps` | - |
| maxZoom | Maximum zoom factor. | `number` | `3` |
| minZoom | Minimum zoom factor. | `number` | `0.1` |
| onZoomChange | Called with the new zoom when the wheel changes it. | <ApiType detail={"(zoom: number) => void"}>Type</ApiType> | - |
| preview | Function returning the DOM element of the preview container; the crop result is mirrored into it in real time. It may return null while the container is not mounted yet. | <ApiType detail={"() => HTMLElement \u007c null"}>Type</ApiType> | - |
| ref | The root div element, which carries the `getCropperCanvas` method. | <ApiType detail={"Ref\u003cCropperElement>"}>Type</ApiType> | - |
| rotate | Image rotation angle. It is one-way: the component never changes it. | `number` | - |
| shape | Shape of the crop box. | `'rect' \| 'round' \| 'roundRect'` | `"rect"` |
| showResizeBox | Whether to show the resize handles on the corners of the crop box. | `boolean` | `true` |
| src | Address of the image to crop. | `string` | - |
| zoom | Controlled zoom, applied on top of the initial scaling that fits the image into the cropper. | `number` | - |
| zoomStep | Zoom change per wheel step. | `number` | `0.1` |

**Methods**

| Method           | Description                                                                           | Type                                                       |
| ---------------- | ------------------------------------------------------------------------------------- | ---------------------------------------------------------- |
| getCropperCanvas | Draws the area inside the crop box, at the image's own resolution, onto a new canvas. | <ApiType detail={"() => HTMLCanvasElement"}>Type</ApiType> |
