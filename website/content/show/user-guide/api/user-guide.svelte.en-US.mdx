import ApiType from '#/components/ApiType.astro';

**Props**

| Property          | Description                                                                                                                                                                                                   | Type                                                         | Default     |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------ | ----------- |
| class             | Lands on the popover card in popup mode and on the outermost element of the Modal in modal mode.                                                                                                              | `string`                                                     | -           |
| current           | Index of the current step, bound with `bind:current`. Without it the component keeps the index itself, starting at 0.                                                                                         | `number`                                                     | -           |
| finishText        | Text of the finish button on the last step. When empty, the text from the locale pack is used.                                                                                                                | `string`                                                     | -           |
| getPopupContainer | In modal mode the dialog is rendered into this DOM node. In popup mode body scrolling is not locked when it points to an element other than body. The popover card sits in the top layer and is not affected. | <ApiType detail={"() => HTMLElement"}>Type</ApiType>         | -           |
| mask              | Whether to show the mask. A step's own mask overrides it.                                                                                                                                                     | `boolean`                                                    | `true`      |
| mode              | Guide mode: popup for a bubble card, modal for a dialog.                                                                                                                                                      | `'popup' \| 'modal'`                                         | `"popup"`   |
| nextButtonProps   | Props of the next button. onclick is called before the built-in handling; use the nextText snippet for the button text.                                                                                       | `UserGuideButtonProps`                                       | -           |
| nextText          | Snippet for the text of the next button; the last step shows finishText. Without it the text from the locale pack is used.                                                                                    | `Snippet`                                                    | -           |
| onChange          | Called with the new index when the step changes, after current was written.                                                                                                                                   | <ApiType detail={"(current: number) => void"}>Type</ApiType> | -           |
| onFinish          | Called when the finish button on the last step is clicked, after visible was written.                                                                                                                         | <ApiType detail={"() => void"}>Type</ApiType>                | -           |
| onNext            | Called with the new index when the next button is clicked. The last step calls onFinish instead.                                                                                                              | <ApiType detail={"(current: number) => void"}>Type</ApiType> | -           |
| onPrev            | Called with the new index when the previous button is clicked.                                                                                                                                                | <ApiType detail={"(current: number) => void"}>Type</ApiType> | -           |
| onSkip            | Called when the skip button is clicked or Escape is pressed, after visible was written.                                                                                                                       | <ApiType detail={"() => void"}>Type</ApiType>                | -           |
| position          | Position of the bubble card relative to the target element. A step's own position overrides it.                                                                                                               | `Position`                                                   | `"bottom"`  |
| prevButtonProps   | Props of the previous button. onclick is called before the built-in handling; use the prevText snippet for the button text.                                                                                   | `UserGuideButtonProps`                                       | -           |
| prevText          | Snippet for the text of the previous button. Without it the text from the locale pack is used.                                                                                                                | `Snippet`                                                    | -           |
| showPrevButton    | Whether to show the previous button. It is never shown on the first step.                                                                                                                                     | `boolean`                                                    | `true`      |
| showSkipButton    | Whether to show the skip button. It is never shown on the last step.                                                                                                                                          | `boolean`                                                    | `true`      |
| spotlightPadding  | Extra space in pixels around the highlighted area. A step's own spotlightPadding overrides it; 5 when neither is set.                                                                                         | `number`                                                     | -           |
| steps             | Data of the guide steps. A title or description is a string or a snippet, a cover is a snippet; a snippet receives `{ item, index }`.                                                                         | `UserGuideStepItem[]`                                        | `[]`        |
| style             | Style string. Lands on the popover card in popup mode and on `.semi-modal` in modal mode.                                                                                                                     | `string`                                                     | -           |
| theme             | Theme of the popup mode. A step's own theme overrides it.                                                                                                                                                     | `'default' \| 'primary'`                                     | `"default"` |
| visible           | Whether the guide is shown, bound with `bind:visible`. Skip, Escape and finish write `false` back.                                                                                                            | `boolean`                                                    | -           |
| zIndex            | The z-index of the mask in popup mode and of the dialog in modal mode. The popover card sits in the top layer, always above the mask.                                                                         | `number`                                                     | `1030`      |
