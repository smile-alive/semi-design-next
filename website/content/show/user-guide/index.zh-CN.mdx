### 主题

`popup` 气泡卡片模式下提供两种主题 `default` 和 `primary`，通过 `theme` 属性设置。

### 气泡卡片弹出位置

`popup` 气泡卡片模式下提供 16 种弹出位置，可选值有 `top`, `topLeft`, `topRight`, `left`, `leftTop`, `leftBottom`, `right`, `rightTop`, `rightBottom`, `bottom`, `bottomLeft`, `bottomRight`, `leftTopOver`, `rightTopOver`, `leftBottomOver`, `rightBottomOver`，还可以通过 `showArrow` 属性设置是否显示箭头。

<Demo id="position" />

通过 `spotlightPadding` 属性设置。

### 定制按钮

通过 `nextButtonProps` 和 `prevButtonProps` 属性设置按钮的样式。

<Framework only="vue">

按钮文本使用 `nextText`、`prevText` 插槽；最后一步的按钮文本由 `finishText` 决定。

</Framework>

<Framework only="solid">

### 受控

通过 `current` 属性设置当前引导步骤。

<Framework only="vue">

用 `v-model:current` 绑定当前步骤，`v-model:visible` 绑定显示状态。

</Framework>

<Framework only="solid">

用 `current` 绑定当前步骤，并在 `onChange` 中回写；用 `visible` 绑定显示状态，在 `onSkip`、`onFinish` 中关闭引导。

</Framework>

<Demo id="controlled" />

### 弹窗式引导

通过 `mode` 属性设置为 `modal` 开启弹窗式引导。

<Framework only="vue">

封面使用 `cover` 插槽，富文本描述使用 `description` 插槽。

</Framework>

<Framework only="solid">

</Framework>

通过 `mask` 属性设置为 `false` 开启无遮罩引导。

## API 参考

---

<Framework only="react">

<UserGuideReactApi />

UserGuide 没有根元素：popup 模式下 `className`、`style` 落在气泡卡片上；modal 模式下 `className`、`style` 交给 Modal，落点与 Modal 一致。未声明的属性（包括 `aria-*` 与原生事件）会被丢弃。对话框的可访问名称只来自当前步骤的 `title`。

</Framework>

<Framework only="vue">

<UserGuideVueApi />

UserGuide 没有根元素：popup 模式下 `class`、`style` 落在气泡卡片上；modal 模式下按 Modal 的落点，`class` 落在 portal 内最外层元素上，`style` 落在 `.semi-modal` 上。`aria-*` 等其余未声明的属性会被丢弃。对话框的可访问名称只来自当前步骤的标题（`title` 插槽或 `item.title`）。

</Framework>

<Framework only="solid">

<UserGuideSolidApi />

UserGuide 没有根元素：popup 模式下 `class`、`style` 落在气泡卡片上；modal 模式下 `class`、`style` 交给 Modal，落点与 Modal 一致。未声明的属性（包括 `ref`、`aria-*` 与原生事件）会被丢弃。对话框的可访问名称只来自当前步骤的 `title`。

</Framework>

## Accessibility

- 每一步是以步骤 `title` 命名的对话框，按 Esc 等同点击「跳过」。
- 两种模式下每一步出现时，焦点都移到主按钮（「下一步」或「完成」）上。popup 模式下 Tab 在卡片内循环，引导关闭时焦点回到打开前的元素；modal 模式的焦点循环与归还由 Modal 管理。
