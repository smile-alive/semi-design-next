**Props**

| Property                | Description                                                                                                                    | Type                                                                                     | Default                                             |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------- | --------------------------------------------------- |
| classNames              | Class names of the inner parts, keyed by `wrapper` (the scroll wrapper in scroll mode); merged with the built-in classes.      | <ApiType detail={"Partial\u003cRecord\u003c\"wrapper\", ClassValue>>"}>Type</ApiType>    | `semiGlobalDefault("OverflowList", "classNames")`   |
| collapseFrom            | Collapse direction in collapse mode: start or end.                                                                             | `"end" \| "start"`                                                                       | `"end"`                                             |
| itemKey                 | Property name of each item's key, or a function returning it. Defaults to the key property, then the item's position in items. | <ApiType detail={"((item: T) => OverflowListKey) \u007c OverflowListKey"}>Type</ApiType> | `undefined`                                         |
| items                   | The items to render. They are data, not nodes; scroll mode requires a key on each item.                                        | `T[]`                                                                                    | `semiGlobalDefault("OverflowList", "items")`        |
| minVisibleItems         | Minimum number of visible items in collapse mode.                                                                              | `number`                                                                                 | `0`                                                 |
| overflowRenderDirection | Where scroll mode renders the overflow nodes: both, start or end. Used by Tabs, not meant for end users.                       | `"both" \| "end" \| "start"`                                                             | `"both"`                                            |
| renderMode              | Render mode: collapse or scroll.                                                                                               | `"collapse" \| "scroll"`                                                                 | `"collapse"`                                        |
| styles                  | Inline styles of the inner parts, keyed like `classNames`.                                                                     | <ApiType detail={"Partial\u003cRecord\u003c\"wrapper\", StyleValue>>"}>Type</ApiType>    | `semiGlobalDefault("OverflowList", "styles")`       |
| threshold               | Visible ratio at which scroll mode reports an item as overflowing.                                                             | `number`                                                                                 | `0.75`                                              |
| wrapperProps            | Other attributes of the scroll wrapper in scroll mode, such as a role that owns the visible items.                             | <ApiType detail={"(HTMLAttributes & Record\u003cstring, unknown>)"}>Type</ApiType>       | `semiGlobalDefault("OverflowList", "wrapperProps")` |

**Events**

| Event              | Description                                                                                                      | Callback parameters                                                                      |
| ------------------ | ---------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| intersect          | Emitted in scroll mode when the intersection state of the items changes.                                         | <ApiType detail={"[res: Record\u003cstring, IntersectionObserverEntry>]"}>Type</ApiType> |
| overflow           | Emitted in collapse mode when the overflowing items change; the argument is an empty array when everything fits. | `[overflowItems: T[]]`                                                                   |
| visibleStateChange | Emitted in scroll mode when the visible or hidden state of the items changes.                                    | <ApiType detail={"[visibleState: Map\u003cstring, boolean>]"}>Type</ApiType>             |

**Slots**

| Slot     | Description                                                                                                                                                                                                   | Scope parameters                                                         |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------ |
| item     | Content of one visible item, with the item and its position in items.                                                                                                                                         | <ApiType detail={"OverflowListItemSlotProps\u003cT>"}>Type</ApiType>     |
| overflow | Content for the overflowing items. Collapse mode calls it once with the items that do not fit; scroll mode calls it once per side, with position set to start or end and the items scrolled out on that side. | <ApiType detail={"OverflowListOverflowSlotProps\u003cT>"}>Type</ApiType> |
