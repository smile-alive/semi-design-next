**Props**

| 属性        | 说明                                                                                                     | 类型         | 默认值                                     |
| ----------- | -------------------------------------------------------------------------------------------------------- | ------------ | ------------------------------------------ |
| bodyStyle   | 内容区的内联样式。                                                                                       | `StyleValue` | `semiGlobalDefault("Card", "bodyStyle")`   |
| bordered    | 是否显示卡片外边框。                                                                                     | `boolean`    | `semiDefault("Card", "bordered", true)`    |
| footerLine  | 页脚区与内容区之间是否有边线。                                                                           | `boolean`    | `semiDefault("Card", "footerLine", false)` |
| footerStyle | 页脚区的内联样式。                                                                                       | `StyleValue` | `semiGlobalDefault("Card", "footerStyle")` |
| headerLine  | 标题区与内容区之间是否有边线。                                                                           | `boolean`    | `semiDefault("Card", "headerLine", true)`  |
| headerStyle | 标题区的内联样式。                                                                                       | `StyleValue` | `semiGlobalDefault("Card", "headerStyle")` |
| loading     | 是否在内容区显示加载占位，开启时根元素的 aria-busy 为 true。                                             | `boolean`    | `semiDefault("Card", "loading", false)`    |
| shadows     | 显示阴影的时机，可选 hover 或 always；不设置则没有阴影。                                                 | `Shadows`    | `semiGlobalDefault("Card", "shadows")`     |
| title       | 标题文字，按 6 号标题的样式渲染为 div，超长时省略并显示提示；与 title 插槽等价，两者同时给出时插槽优先。 | `string`     | `undefined`                                |

**Slots**

| 插槽               | 说明                                                                | 作用域参数 |
| ------------------ | ------------------------------------------------------------------- | ---------- |
| default            | 卡片内容。                                                          | `any`      |
| title              | 卡片标题；只有一段文字时按 title 属性的样式渲染，其他内容原样渲染。 | `any`      |
| headerExtraContent | 标题右侧的额外内容。                                                | `any`      |
| header             | 自定义整个标题区，会取代 title 和 headerExtraContent。              | `any`      |
| cover              | 卡片封面。                                                          | `any`      |
| actions            | 操作区，每个直接子节点作为一个操作，位于内容区底部，间距 12px。     | `any`      |
| footer             | 自定义页脚。                                                        | `any`      |
