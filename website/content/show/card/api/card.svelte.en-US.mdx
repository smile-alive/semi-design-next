**Props**

| Property           | Description                                                                                                                            | Type                | Default |
| ------------------ | -------------------------------------------------------------------------------------------------------------------------------------- | ------------------- | ------- |
| actions            | Actions at the bottom of the content area, spaced 12px apart; every snippet becomes one action.                                        | `Snippet[]`         | -       |
| bodyStyle          | Inline style of the content area.                                                                                                      | `string`            | -       |
| bordered           | Whether the card has an outer border.                                                                                                  | `boolean`           | `true`  |
| children           | Card content.                                                                                                                          | `Snippet`           | -       |
| cover              | Card cover.                                                                                                                            | `Snippet`           | -       |
| footer             | Custom footer.                                                                                                                         | `Snippet`           | -       |
| footerLine         | Whether there is a border between the footer and the content area.                                                                     | `boolean`           | `false` |
| footerStyle        | Inline style of the footer area.                                                                                                       | `string`            | -       |
| header             | Custom header that replaces title and headerExtraContent.                                                                              | `Snippet`           | -       |
| headerExtraContent | Extra content to the right of the title.                                                                                               | `Snippet`           | -       |
| headerLine         | Whether there is a border between the header and the content area.                                                                     | `boolean`           | `true`  |
| headerStyle        | Inline style of the header area.                                                                                                       | `string`            | -       |
| loading            | Whether the content area shows a loading placeholder; the root element's aria-busy is true while on.                                   | `boolean`           | `false` |
| shadows            | When to show the shadow: hover or always. No shadow when unset.                                                                        | `Shadows`           | -       |
| title              | Title. A string renders as a div styled like a level-6 heading and truncated with a tooltip when too long; a snippet renders as it is. | `string \| Snippet` | -       |
