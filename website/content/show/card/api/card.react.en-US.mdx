**Props**

| Property           | Description                                                                                                                                    | Type                                                              | Default |
| ------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------- | ------- |
| actions            | Actions at the bottom of the content area. Each array item is one action, spaced 12px apart horizontally.                                      | `ReactNode[]`                                                     | -       |
| aria-label         | Accessible name of the card. The root element gets `role="group"` when it is set.                                                              | `string`                                                          | -       |
| bodyStyle          | Inline style of the content area.                                                                                                              | `CSSProperties`                                                   | -       |
| bordered           | Whether the card has an outer border.                                                                                                          | `boolean`                                                         | `true`  |
| children           | Content of the content area. A placeholder is shown while loading.                                                                             | `React.ReactNode`                                                 | -       |
| className          | Class name of the root element.                                                                                                                | `string`                                                          | -       |
| cover              | Card cover, below the header.                                                                                                                  | `ReactNode`                                                       | -       |
| footer             | Custom footer at the bottom of the card.                                                                                                       | `ReactNode`                                                       | -       |
| footerLine         | Whether there is a border between the footer and the content area.                                                                             | `boolean`                                                         | `false` |
| footerStyle        | Inline style of the footer area.                                                                                                               | `CSSProperties`                                                   | -       |
| header             | Custom header that replaces `title` and `headerExtraContent`.                                                                                  | `ReactNode`                                                       | -       |
| headerExtraContent | Extra content to the right of the title.                                                                                                       | `ReactNode`                                                       | -       |
| headerLine         | Whether there is a border between the header and the content area.                                                                             | `boolean`                                                         | `true`  |
| headerStyle        | Inline style of the header area.                                                                                                               | `CSSProperties`                                                   | -       |
| loading            | Whether the content area shows a loading placeholder. The root element's `aria-busy` is `true` while on.                                       | `boolean`                                                         | `false` |
| ref                | Reference to the root element (`div`).                                                                                                         | <ApiType detail={"React.Ref\u003cHTMLDivElement>"}>Type</ApiType> | -       |
| shadows            | When to show the shadow: `hover` or `always`. No shadow when unset.                                                                            | `Shadows`                                                         | -       |
| style              | Inline style of the root element.                                                                                                              | `CSSProperties`                                                   | -       |
| title              | Card title. A string renders as a `div` styled like a level-6 heading and truncated with a tooltip when too long. A `ReactNode` renders as is. | `ReactNode`                                                       | -       |
