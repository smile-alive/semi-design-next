**Props**

| Property    | Description                                                                                                                                                           | Type         | Default                                    |
| ----------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------ | ------------------------------------------ |
| bodyStyle   | Inline style of the content area.                                                                                                                                     | `StyleValue` | `semiGlobalDefault("Card", "bodyStyle")`   |
| bordered    | Whether the card has an outer border.                                                                                                                                 | `boolean`    | `semiDefault("Card", "bordered", true)`    |
| footerLine  | Whether there is a border between the footer and the content area.                                                                                                    | `boolean`    | `semiDefault("Card", "footerLine", false)` |
| footerStyle | Inline style of the footer area.                                                                                                                                      | `StyleValue` | `semiGlobalDefault("Card", "footerStyle")` |
| headerLine  | Whether there is a border between the header and the content area.                                                                                                    | `boolean`    | `semiDefault("Card", "headerLine", true)`  |
| headerStyle | Inline style of the header area.                                                                                                                                      | `StyleValue` | `semiGlobalDefault("Card", "headerStyle")` |
| loading     | Whether the content area shows a loading placeholder; the root element's aria-busy is true while on.                                                                  | `boolean`    | `semiDefault("Card", "loading", false)`    |
| shadows     | When to show the shadow: hover or always. No shadow when unset.                                                                                                       | `Shadows`    | `semiGlobalDefault("Card", "shadows")`     |
| title       | Title text, rendered as a div styled like a level-6 heading and truncated with a tooltip when too long; equivalent to the title slot, which wins when both are given. | `string`     | `undefined`                                |

**Events**

| Event | Description | Callback parameters |
| ----- | ----------- | ------------------- |
| None  |             |                     |

**Slots**

| Slot               | Description                                                                                          | Scope parameters |
| ------------------ | ---------------------------------------------------------------------------------------------------- | ---------------- |
| default            | Card content.                                                                                        | `any`            |
| title              | Card title. A single text renders like the title prop; other content renders as is.                  | `any`            |
| headerExtraContent | Extra content to the right of the title.                                                             | `any`            |
| header             | Custom header that replaces title and headerExtraContent.                                            | `any`            |
| cover              | Card cover.                                                                                          | `any`            |
| actions            | Actions at the bottom of the content area, spaced 12px apart; every direct child becomes one action. | `any`            |
| footer             | Custom footer.                                                                                       | `any`            |
