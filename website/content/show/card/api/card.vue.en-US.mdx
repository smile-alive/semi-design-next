**Props**

| Property   | Description                                                                                                                                                           | Type                                                                               | Default                                   |
| ---------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------- | ----------------------------------------- |
| bordered   | Whether the card has an outer border.                                                                                                                                 | `boolean`                                                                          | `true`                                    |
| classNames | Class names of the inner parts, keyed by header, title, extra, cover, body, actions and footer; values take any class binding and merge with the built-in classes.    | <ApiType detail={"Partial\u003cRecord\u003cCardPart, ClassValue>>"}>Type</ApiType> | `semiGlobalDefault("Card", "classNames")` |
| footerLine | Whether there is a border between the footer and the content area.                                                                                                    | `boolean`                                                                          | `false`                                   |
| headerLine | Whether there is a border between the header and the content area.                                                                                                    | `boolean`                                                                          | `true`                                    |
| loading    | Whether the content area shows a loading placeholder; the root element's aria-busy is true while on.                                                                  | `boolean`                                                                          | `false`                                   |
| shadows    | When to show the shadow: hover or always. No shadow when unset.                                                                                                       | `Shadows`                                                                          | `semiGlobalDefault("Card", "shadows")`    |
| styles     | Inline styles of the inner parts, keyed like classNames.                                                                                                              | <ApiType detail={"Partial\u003cRecord\u003cCardPart, StyleValue>>"}>Type</ApiType> | `semiGlobalDefault("Card", "styles")`     |
| title      | Title text, rendered as a div styled like a level-6 heading and truncated with a tooltip when too long; equivalent to the title slot, which wins when both are given. | `string`                                                                           | `undefined`                               |

**Slots**

| Slot               | Description                                                                                          | Scope parameters |
| ------------------ | ---------------------------------------------------------------------------------------------------- | ---------------- |
| actions            | Actions at the bottom of the content area, spaced 12px apart; every direct child becomes one action. | `any`            |
| cover              | Card cover.                                                                                          | `any`            |
| default            | Card content.                                                                                        | `any`            |
| footer             | Custom footer.                                                                                       | `any`            |
| header             | Custom header that replaces title and headerExtraContent.                                            | `any`            |
| headerExtraContent | Extra content to the right of the title.                                                             | `any`            |
| title              | Card title. A single text renders like the title prop; other content renders as is.                  | `any`            |
