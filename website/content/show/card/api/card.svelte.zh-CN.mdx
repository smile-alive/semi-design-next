**Props**

| 属性               | 说明                                                                                                                                      | 类型                                                                               | 默认值  |
| ------------------ | ----------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------- | ------- |
| actions            | 操作区，每个 snippet 作为一个操作，位于内容区底部，间距 12px。                                                                            | `Snippet[]`                                                                        | -       |
| bordered           | 是否显示卡片外边框。                                                                                                                      | `boolean`                                                                          | `true`  |
| children           | 卡片内容。                                                                                                                                | `Snippet`                                                                          | -       |
| classNames         | 内部各部位的类名，键为 header、title、extra、cover、body、actions、footer，值的写法同 class（字符串、数组或对象），与组件自带的类名合并。 | <ApiType detail={"Partial\u003cRecord\u003cCardPart, ClassValue>>"}>Type</ApiType> | -       |
| cover              | 卡片封面。                                                                                                                                | `Snippet`                                                                          | -       |
| footer             | 自定义页脚。                                                                                                                              | `Snippet`                                                                          | -       |
| footerLine         | 页脚区与内容区之间是否有边线。                                                                                                            | `boolean`                                                                          | `false` |
| header             | 自定义整个标题区，会取代 title 和 headerExtraContent。                                                                                    | `Snippet`                                                                          | -       |
| headerExtraContent | 标题右侧的额外内容。                                                                                                                      | `Snippet`                                                                          | -       |
| headerLine         | 标题区与内容区之间是否有边线。                                                                                                            | `boolean`                                                                          | `true`  |
| loading            | 是否在内容区显示加载占位，开启时根元素的 aria-busy 为 true。                                                                              | `boolean`                                                                          | `false` |
| shadows            | 显示阴影的时机，可选 hover 或 always；不设置则没有阴影。                                                                                  | `Shadows`                                                                          | -       |
| styles             | 内部各部位的样式字符串，键同 classNames。                                                                                                 | <ApiType detail={"Partial\u003cRecord\u003cCardPart, string>>"}>Type</ApiType>     | -       |
| title              | 标题。字符串按 6 号标题的样式渲染为 div，超长时省略并显示提示；snippet 原样渲染。                                                         | `string \| Snippet`                                                                | -       |
