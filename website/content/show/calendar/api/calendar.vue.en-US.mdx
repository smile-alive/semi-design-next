**Props**

| Property       | Description                                                                                                      | Type               | Default                                           |
| -------------- | ---------------------------------------------------------------------------------------------------------------- | ------------------ | ------------------------------------------------- |
| displayValue   | Display date. When omitted it is the current date and updates at midnight.                                       | `Date`             | `semiGlobalDefault("Calendar", "displayValue")`   |
| range          | Date range shown in range mode, left-closed and right-open. Required in range mode.                              | `Date[]`           | `semiGlobalDefault("Calendar", "range")`          |
| events         | Events to render, see Event Object.                                                                              | `EventObject[]`    | `semiDefault("Calendar", "events", [])`           |
| mode           | View mode: day, week, month or range. The view switches as soon as it changes.                                   | `CalendarMode`     | `semiDefault("Calendar", "mode", "week")`         |
| showCurrTime   | Shows the red line of the current time in the day, week and range views.                                         | `boolean`          | `semiDefault("Calendar", "showCurrTime", true)`   |
| weekStartsOn   | Day of the week that starts the week, 0 for Sunday, 1 for Monday and so on. Applies to the month and week views. | `WeekStartsOn`     | `semiDefault("Calendar", "weekStartsOn", 0)`      |
| scrollTop      | Default scroll offset of the content in the day, week and range views.                                           | `number`           | `semiDefault("Calendar", "scrollTop", 400)`       |
| markWeekend    | Shows weekend columns in grey to tell them from weekdays.                                                        | `boolean`          | `semiDefault("Calendar", "markWeekend", false)`   |
| minEventHeight | Minimum height in pixels of events in the day, range and week views.                                             | `number`           | `semiGlobalDefault("Calendar", "minEventHeight")` |
| width          | Width of the calendar; a number is in pixels.                                                                    | `string \| number` | `semiGlobalDefault("Calendar", "width")`          |
| height         | Height of the calendar; a number is in pixels.                                                                   | `string \| number` | `semiDefault("Calendar", "height", 600)`          |

**Events**

| Event | Description | Callback parameters |
| --- | --- | --- |
| click | Emitted when a date cell is clicked, with the event and the date of the cell. The unit is half an hour in the day, week and range views and one day in the month view. | `[event: MouseEvent, value: Date]` |
| close | Emitted when the card showing all events of a day closes in the month view: the click event for the close button or a second click on "N more", the keyboard event for Esc, and null for a click outside or when the component is deactivated in KeepAlive. | `[event: MouseEvent \| KeyboardEvent \| null]` |
| moreClick | Emitted when a click on "N more" opens the card in the month view, with the event, the date and the number of collapsed events. It is not emitted when a second click closes the card. | `[event: MouseEvent, date: Date, remaining: number]` |

**Slots**

| Slot         | Description                                                                                                                                                                      | Scope parameters                |
| ------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------- |
| header       | Custom header content.                                                                                                                                                           | `any`                           |
| event        | Custom event content. event is the original object from events and the slot is called once for each place the event appears. The text of children is rendered when it is absent. | `CalendarEventSlotProps`        |
| dateDisplay  | Custom date text: the column titles of the week and range views and every cell of the month view. The day view does not use it.                                                  | `CalendarDateDisplaySlotProps`  |
| dateGrid     | Custom content of a date cell or column, with the date and its dateString (date.toString()). Use absolute positioning for elements.                                              | `CalendarDateGridSlotProps`     |
| timeDisplay  | Custom time text in the day, week and range views; time is the hour.                                                                                                             | `CalendarTimeDisplaySlotProps`  |
| allDayEvents | Custom area for events at the top of the day, range and week views; events is the whole events array that was passed in, to be filtered by the slot.                             | `CalendarAllDayEventsSlotProps` |
