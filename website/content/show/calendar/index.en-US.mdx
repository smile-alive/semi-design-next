### Render Events

You could pass in an array of event objects to `events` to render items. For detailed format, refer to Event Object below.

<Framework only="vue">

The content of an event renders the text of `children` by default. Use the `#event="{ event }"` scoped slot for custom DOM: `event` is the original object from `events` and may carry any custom field. When one event is shown in several places (such as a multi-day event), the slot is called once for each place.

</Framework>

<Framework only="solid">

`children` holds the content of an event: a JSX element, or a function that returns one. When one event is shown in several places (such as a multi-day event), the function is called once for each place; for an element, the original element is shown in one place and the other places show copies without event handlers.

</Framework>

<Framework only="svelte">

The content of an event defaults to the `children` text. For custom DOM use the `event` snippet; its `{ event }` argument is the original object from `events`, which may carry any custom fields. When one event is shown in several places (such as a multi-day event), the snippet is called once for each place.

</Framework>

### Event Object

`events` is an array of event objects.  
An event needs at least a start or an end time to be valid; an event with neither is skipped with a warning. An all-day event with only an end time starts on the day of its end. A timed event with only one end is extended by 1 hour, without crossing into another day. The end time is exclusive: a timed event that ends exactly at 00:00 is shown only on its start day, with no extra segment on the next day.

<Notice type="primary" title="Attention">
    Key property is required and must be unique. It identifies the event. When `events` changes, the layout is recomputed from its content, so an event that keeps its key but changes its time or children is updated as well.
</Notice>

<Framework only="react">

| Properties | Instructions                   | type       | Default |
| ---------- | ------------------------------ | ---------- | ------- |
| allDay     | Whether it is an all-day event | boolean    | false   |
| children   | Displayed content              | React.node | -       |
| end        | End time of the event          | Date       | -       |
| key        | Required and must be unique.   | string     | -       |
| start      | Start time of the event        | Date       | -       |

</Framework>

## Accessibility

### Keyboard and Focus

- The day, week and range views scroll, and the view itself is one Tab stop that the arrow keys scroll
- In the month view, "N more" for the collapsed events is a button: `Enter` or `Space` opens the card of the day and moves focus to its close button; `Esc` or the close button closes the card and returns focus to "N more"
- Clicks on a day cell or a time slot (`onClick` in React, `@click` in Vue, `onClick` in Svelte) respond to the pointer only and have no keyboard equivalent

## Content Guidelines

- Both 12-hour and 24-hour clocks can be used when the time needs to be displayed
- If the 12-hour clock is used, it needs to be used together with AM/PM. For details, please refer to [Time Specification](/en-US/react/experience/content-guidelines#8.%20%E6%97%A5%E6%9C%9F%E4%B8%8E%E6%97%B6%E9%97%B4)
- For the abbreviation rules for month, week and time, please refer to [Abbreviation Specification](/en-US/react/experience/content-guidelines#1.%20%E7%BC%A9%E5%86%99)
