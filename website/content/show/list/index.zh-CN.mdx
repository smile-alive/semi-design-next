## 无障碍

List 支持传入 `aria-label` 或 `aria-labelledby` 来表示列表的作用，传入后根元素带 `role="group"`。

<Framework only="react">

设置了 `onClick` 或 `onRightClick`（包括 List 上的）的 List.Item 仍是 `<li>` 列表项，内部渲染一个原生 `<button type="button">` 作为唯一的焦点目标，读屏会读成「按钮」。

- 按钮包住 `header` 和 `main`（没有这两项时包住 `children`），点击区域铺满整行；Tab 聚焦后按 Enter 或空格触发 `onClick`，上下文菜单键触发 `onRightClick`
- `extra` 渲染在按钮外面且层级更高，其中的按钮、链接可以正常聚焦和点击，点击它们不会触发 Item 的 `onClick`
- 同时设置 `header` 或 `main` 和 `children` 时，`children` 在按钮外面，会被铺满整行的按钮覆盖，其中的交互内容请放进 `extra`
- 没有点击回调的 List.Item 不渲染按钮，也不可聚焦

</Framework>

<Framework only="vue">

设置了 `@click` 或 `@rightClick`（包括 List 上的）的 List.Item 仍是 `<li>` 列表项，内部渲染一个原生 `<button type="button">` 作为唯一的焦点目标，读屏会读成「按钮」。

- 按钮包住 `#header` 和 `#main` 的内容（没有这两个插槽时包住默认插槽），点击区域铺满整行；Tab 聚焦后按 Enter 或空格触发 `@click`，上下文菜单键触发 `@rightClick`
- `#extra` 渲染在按钮外面且层级更高，其中的按钮、链接可以正常聚焦和点击，点击它们不会触发 Item 的 `@click`
- 同时设置 `#header` 或 `#main` 和默认插槽时，默认插槽在按钮外面，会被铺满整行的按钮覆盖，其中的交互内容请放进 `#extra`
- 没有点击回调的 List.Item 不渲染按钮，也不可聚焦

</Framework>

<Framework only="solid">

设置了 `onClick` 或 `onRightClick`（包括 List 上的）的 List.Item 仍是 `<li>` 列表项，内部渲染一个原生 `<button type="button">` 作为唯一的焦点目标，读屏会读成「按钮」。

- 按钮包住 `header` 和 `main`（没有这两项时包住 `children`），点击区域铺满整行；Tab 聚焦后按 Enter 或空格触发 `onClick`，上下文菜单键触发 `onRightClick`
- `extra` 渲染在按钮外面且层级更高，其中的按钮、链接可以正常聚焦和点击，点击它们不会触发 Item 的 `onClick`
- 同时设置 `header` 或 `main` 和 `children` 时，`children` 在按钮外面，会被铺满整行的按钮覆盖，其中的交互内容请放进 `extra`
- 没有点击回调的 List.Item 不渲染按钮，也不可聚焦

</Framework>

List.Item 脱离 List 使用时按没有 `grid` 的普通列表项渲染。使用 `grid` 时，承载条目的 Row 带 `role="list"`，包裹每个条目的 Col 带 `role="none"`，读屏把条目读作这个列表的项。

## API 参考

### List

<Framework only="react">

<ListReactApi />

其他原生属性（如 `data-*`、`id`）落在根元素上；传入 `aria-label` 或 `aria-labelledby` 且没有 `role` 时，根元素带 `role="group"`。`onClick`、`onRightClick` 作用于列表项而不是根元素。

</Framework>

<Framework only="vue">

<ListVueApi />

`class`、`style` 与原生属性经 attrs 落在根元素；传入 `aria-label` 或 `aria-labelledby` 且没有 `role` 时，根元素带 `role="group"`。`@click`、`@rightClick` 的载荷为原生 `MouseEvent`，作用于列表项而不是根元素。

</Framework>

<Framework only="solid">

<ListSolidApi />

`class`、`style`、`ref` 与原生属性（如 `data-*`）落在根元素上；传入 `aria-label` 或 `aria-labelledby` 且没有 `role` 时，根元素带 `role="group"`。`onClick`、`onRightClick` 的参数为原生 `MouseEvent`，作用于列表项而不是根元素。

</Framework>

### List grid props

<Framework only="react">

`grid` 只接受 Row 的 `align`、`gutter`、`justify`、`type` 与 Col 的 `span`、`offset`、`order`、`push`、`pull`、响应式断点、`className`、`style`，不接受其他 div 属性。参数含义请参考 [Grid](/zh-CN/react/basic/grid)

</Framework>

<Framework only="vue">

`grid` 只接受 Row 的 `align`、`gutter`、`justify`、`type` 与 Col 的 `span`、`offset`、`order`、`push`、`pull`、响应式断点、`class`、`style`，不接受其他属性；`class` 与 `style` 落在每项外层的 Col 上。参数含义请参考 [Grid](/zh-CN/react/basic/grid)

</Framework>

<Framework only="solid">

`grid` 只接受 Row 的 `align`、`gutter`、`justify`、`type` 与 Col 的 `span`、`offset`、`order`、`push`、`pull`、响应式断点、`class`、`style`，不接受其他属性；`class` 与 `style` 落在每项外层的 Col 上。参数含义请参考 [Grid](/zh-CN/react/basic/grid)

</Framework>

| sm     | `≥576px` 响应式栅格，可为栅格数或一个包含其他属性的对象  | number\|object | -      |
| md     | `≥768px` 响应式栅格，可为栅格数或一个包含其他属性的对象  | number\|object | -      |
| lg     | `≥992px` 响应式栅格，可为栅格数或一个包含其他属性的对象  | number\|object | -      |
| xl     | `≥1200px` 响应式栅格，可为栅格数或一个包含其他属性的对象 | number\|object | -      |
| xxl    | `≥1600px` 响应式栅格，可为栅格数或一个包含其他属性的对象 | number\|object | -      |

### List.Item

<Framework only="react">

<ListItemReactApi />

其他原生属性（如 `data-*`）落在 `li` 上；可点击时 `aria-*` 与 `tabIndex` 落在内部的按钮上。`onClick` 作用于 `li`，优先于 List 的 `onClick`。

</Framework>

<Framework only="vue">

<ListItemVueApi />

`class`、`style`、`data-*`、`aria-*` 与原生属性经 attrs 落在 `li` 上，不落在 grid 模式下外层的 Col 上。

</Framework>

<Framework only="solid">

<ListItemSolidApi />

`class`、`style`、`ref` 与原生属性（如 `data-*`）落在 `li` 上，不落在 grid 模式下外层的 Col 上；可点击时 `aria-*` 与 `tabIndex` 落在内部的按钮上，`ref.focus()` 转到该按钮。

</Framework>
