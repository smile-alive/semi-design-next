**Props**

| Property | Description | Type | Default |
| --- | --- | --- | --- |
| bordered | Whether to show a border. | `boolean` | `false` |
| children | Child elements rendered after the items generated from dataSource; the empty state is hidden when children are present. | `React.ReactNode` | - |
| className | Class name of the root element. | `string` | - |
| dataSource | Data source of the list; each entry is rendered by renderItem, and nothing is rendered without renderItem. | `T[]` | - |
| emptyContent | Content shown when there is no data; the locale's empty text by default. | `React.ReactNode` | - |
| footer | List footer, rendered after the list content. | `React.ReactNode` | - |
| grid | Grid configuration: `align`, `gutter`, `justify` and `type` of Row, and `span`, `offset`, `order`, `push`, `pull`, the responsive breakpoints, `className` and `style` of Col. `className` and `style` land on the Col around each item. | `Grid` | - |
| header | List header, rendered before the list content. | `React.ReactNode` | - |
| layout | List layout: `vertical` or `horizontal`. | `'vertical' \| 'horizontal'` | `"vertical"` |
| loading | Whether the list is loading; a Spin is shown over the list content when `true`. | `boolean` | `false` |
| loadMore | Load-more button, rendered at the end of the root element. | `React.ReactNode` | - |
| onClick | Click handler for the items that have no onClick of their own; an item with a handler renders a native button. | <ApiType detail={"React.MouseEventHandler\u003cHTMLLIElement>"}>Type</ApiType> | - |
| onRightClick | Context-menu handler for the items that have no onRightClick of their own; those items also render a native button. | <ApiType detail={"React.MouseEventHandler\u003cHTMLLIElement>"}>Type</ApiType> | - |
| ref | Reference to the root `div` element. | <ApiType detail={"React.Ref\u003cHTMLDivElement>"}>Type</ApiType> | - |
| renderItem | Renders each entry of dataSource, receiving the entry and its index and returning a ReactNode, usually a List.Item. | <ApiType detail={"(item: T, ind: number) => React.ReactNode"}>Type</ApiType> | - |
| size | List size: `small`, `default` or `large`. | `Size` | `"default"` |
| split | Whether to show dividers between items. | `boolean` | `true` |
| style | Style of the root element. | `React.CSSProperties` | - |
