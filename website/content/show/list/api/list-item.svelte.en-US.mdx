**Props**

| Property     | Description                                                                                                                                                                    | Type                                                                                   | Default        |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------- | -------------- |
| align        | Vertical alignment of header and main: flex-start, flex-end, center, baseline or stretch; flex-start when omitted.                                                             | `'baseline' \| 'center' \| 'flex-end' \| 'flex-start' \| 'stretch'`                    | `"flex-start"` |
| children     | Item content written inside the tag; inside the button when the item is clickable and has no header or main, otherwise outside it.                                             | `Snippet`                                                                              | -              |
| classNames   | Class names of the inner parts, keyed by `header`, `main` and `extra`; merged with the built-in classes, after the `item*` class names of the List.                            | <ApiType detail={"Partial\u003cRecord\u003cListItemPart, ClassValue>>"}>Type</ApiType> | -              |
| extra        | Snippet for additional item content, rendered outside the button; interactive elements in it stay focusable and clickable, and clicking them does not trigger the row's click. | `Snippet`                                                                              | -              |
| header       | Snippet for the item header content.                                                                                                                                           | `Snippet`                                                                              | -              |
| main         | Snippet for the item main content.                                                                                                                                             | `Snippet`                                                                              | -              |
| onClick      | Click handler, taking precedence over the List's onClick; an item with a handler renders a native button.                                                                      | <ApiType detail={"(event: MouseEvent) => void"}>Type</ApiType>                         | -              |
| onRightClick | Context-menu handler, taking precedence over the List's onRightClick; an item with only this handler also renders a native button.                                             | <ApiType detail={"(event: MouseEvent) => void"}>Type</ApiType>                         | -              |
| styles       | Inline styles of the inner parts, keyed like `classNames`; the values are CSS text, applied after the `item*` styles of the List.                                              | <ApiType detail={"Partial\u003cRecord\u003cListItemPart, string>>"}>Type</ApiType>     | -              |
