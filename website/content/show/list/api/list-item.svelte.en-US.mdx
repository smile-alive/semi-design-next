| Property     | Description                                                                                                                                                                    | Type                                                                | Default        |

| align        | Vertical alignment of header and main: flex-start, flex-end, center, baseline or stretch; flex-start when omitted.                                                             | `'flex-start' \| 'flex-end' \| 'center' \| 'baseline' \| 'stretch'` | `"flex-start"` |

| header       | Snippet for the item header content.                                                                                                                                           | `Snippet`                                                           | -              |
| main         | Snippet for the item main content.                                                                                                                                             | `Snippet`                                                           | -              |
| onClick      | Click handler, taking precedence over the List's onClick; an item with a handler renders a native button.                                                                      | <ApiType detail={"(event: MouseEvent) => void"}>Type</ApiType>      | -              |
| onRightClick | Context-menu handler, taking precedence over the List's onRightClick; an item with only this handler also renders a native button.                                             | <ApiType detail={"(event: MouseEvent) => void"}>Type</ApiType>      | -              |
