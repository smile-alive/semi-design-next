**Props**

| 属性         | 说明                                                                                                         | 类型                                                                | 默认值 |
| ------------ | ------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------- | ------ |
| align        | header 与 main 的垂直对齐方式，可选 flex-start、flex-end、center、baseline 或 stretch，未传时为 flex-start。 | `'flex-start' \| 'flex-end' \| 'center' \| 'baseline' \| 'stretch'` | -      |
| extra        | 列表项附加内容，渲染在按钮外，其中的交互元素可正常聚焦与点击，点击不会触发整行的点击。                       | `JSX.Element`                                                       | -      |
| header       | 列表项头部内容。                                                                                             | `JSX.Element`                                                       | -      |
| main         | 列表项主体内容。                                                                                             | `JSX.Element`                                                       | -      |
| onClick      | 点击回调，优先于 List 的 onClick；有处理函数时项渲染为原生按钮。                                             | `ListItemEventHandler`                                              | -      |
| onRightClick | 右键（上下文菜单）回调，优先于 List 的 onRightClick；只设置它时项同样渲染为原生按钮。                        | `ListItemEventHandler`                                              | -      |
