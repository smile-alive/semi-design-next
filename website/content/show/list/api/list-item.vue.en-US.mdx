**Props**

| Property     | Description                                                                                                                                                                                | Type                                                                | Default     |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------- | ----------- |
| align        | Vertical alignment of header and main: flex-start, flex-end, center, baseline or stretch; flex-start when omitted.                                                                         | `"flex-start" \| "flex-end" \| "center" \| "baseline" \| "stretch"` | `undefined` |
| onClick      | Click handler, taking precedence over the List's onClick; an item with a handler renders a native button. Callers write @click; it remains a function prop for the same reason as on List. | <ApiType detail={"((event: MouseEvent) => void)"}>Type</ApiType>    | `undefined` |
| onRightClick | Context-menu handler, taking precedence over the List's onRightClick; an item with only this handler also renders a native button. Callers write @rightClick.                              | <ApiType detail={"((event: MouseEvent) => void)"}>Type</ApiType>    | `undefined` |

**Slots**

| Slot    | Description                                                                                                                                                        | Scope parameters |
| ------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------- |
| default | Item content; inside the button when the item is clickable and has no header or main slot, otherwise outside it.                                                   | `any`            |
| header  | Item header content.                                                                                                                                               | `any`            |
| main    | Item main content.                                                                                                                                                 | `any`            |
| extra   | Additional item content, rendered outside the button; interactive elements in it stay focusable and clickable, and clicking them does not trigger the row's click. | `any`            |
