**Props**

| Property     | Description                                                                                                                                                                   | Type                                                                           | Default        |
| ------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------ | -------------- |
| align        | Vertical alignment of header and main: `flex-start`, `flex-end`, `center`, `baseline` or `stretch`.                                                                           | `'flex-start' \| 'flex-end' \| 'center' \| 'baseline' \| 'stretch'`            | `"flex-start"` |
| children     | Item content. On a clickable item set together with header or main, it renders outside the button and is covered by the full-row button, so put interactive content in extra. | `React.ReactNode`                                                              | -              |
| className    | Class name of the `li`; with grid it lands on the `li`, not on the outer Col.                                                                                                 | `string`                                                                       | -              |
| extra        | Additional item content, rendered outside the button; interactive elements in it stay focusable and clickable, and clicking them does not trigger the row's click.            | `React.ReactNode`                                                              | -              |
| header       | Item header content.                                                                                                                                                          | `React.ReactNode`                                                              | -              |
| main         | Item main content.                                                                                                                                                            | `React.ReactNode`                                                              | -              |
| onRightClick | Context-menu handler, taking precedence over the List's onRightClick; an item with only this handler also renders a native button.                                            | <ApiType detail={"React.MouseEventHandler\u003cHTMLLIElement>"}>Type</ApiType> | -              |
| ref          | Reference to the `li` element.                                                                                                                                                | <ApiType detail={"React.Ref\u003cHTMLLIElement>"}>Type</ApiType>               | -              |
| style        | Style of the `li` element; with grid it lands on the `li`, not on the outer Col.                                                                                              | `React.CSSProperties`                                                          | -              |
