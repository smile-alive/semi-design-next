**Props**

| 属性         | 说明                                                                                                                                                                                        | 类型                                                                           | 默认值       |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------ | ------------ |
| bordered     | 是否显示边框。                                                                                                                                                                              | `boolean`                                                                      | `false`      |
| children     | 直接写在列表中的子元素，渲染在 dataSource 生成的项之后；有子元素时不显示空状态。                                                                                                            | `React.ReactNode`                                                              | -            |
| className    | 根元素的类名。                                                                                                                                                                              | `string`                                                                       | -            |
| dataSource   | 列表数据源，每一项通过 renderItem 渲染；未设置 renderItem 时不渲染任何项。                                                                                                                  | `T[]`                                                                          | -            |
| emptyContent | 没有数据时的展示内容，缺省为语言包中的空文案。                                                                                                                                              | `React.ReactNode`                                                              | -            |
| footer       | 列表底部，渲染在列表内容之后。                                                                                                                                                              | `React.ReactNode`                                                              | -            |
| grid         | 栅格配置：Row 的 `align`、`gutter`、`justify`、`type` 与 Col 的 `span`、`offset`、`order`、`push`、`pull`、响应式断点、`className`、`style`。`className` 与 `style` 落在每项外层的 Col 上。 | `Grid`                                                                         | -            |
| header       | 列表头部，渲染在列表内容之前。                                                                                                                                                              | `React.ReactNode`                                                              | -            |
| layout       | 列表布局，可选 `vertical` 或 `horizontal`。                                                                                                                                                 | `'vertical' \| 'horizontal'`                                                   | `"vertical"` |
| loading      | 是否处于加载中，为 `true` 时在列表内容上显示 Spin。                                                                                                                                         | `boolean`                                                                      | `false`      |
| loadMore     | 加载更多的按钮，渲染在列表根元素的末尾。                                                                                                                                                    | `React.ReactNode`                                                              | -            |
| onClick      | 列表项的点击回调，作用于每个没有自己 onClick 的项；有处理函数的项渲染为原生按钮。                                                                                                           | <ApiType detail={"React.MouseEventHandler\u003cHTMLLIElement>"}>Type</ApiType> | -            |
| onRightClick | 列表项的右键（上下文菜单）回调，作用于每个没有自己 onRightClick 的项，这些项同样渲染为原生按钮。                                                                                            | <ApiType detail={"React.MouseEventHandler\u003cHTMLLIElement>"}>Type</ApiType> | -            |
| ref          | 根元素（`div`）的引用。                                                                                                                                                                     | <ApiType detail={"React.Ref\u003cHTMLDivElement>"}>Type</ApiType>              | -            |
| renderItem   | 渲染 dataSource 中的每一项，接收数据项与下标，返回 ReactNode，通常是 List.Item。                                                                                                            | <ApiType detail={"(item: T, ind: number) => React.ReactNode"}>Type</ApiType>   | -            |
| size         | 列表尺寸，可选 `small`、`default` 或 `large`。                                                                                                                                              | `Size`                                                                         | `"default"`  |
| split        | 是否展示分割线。                                                                                                                                                                            | `boolean`                                                                      | `true`       |
| style        | 根元素的样式。                                                                                                                                                                              | `React.CSSProperties`                                                          | -            |
