**Props**

| Property     | Description                                                                                                                                                        | Type                                                                | Default |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------- | ------- |
| align        | Vertical alignment of header and main: flex-start, flex-end, center, baseline or stretch; flex-start when omitted.                                                 | `'flex-start' \| 'flex-end' \| 'center' \| 'baseline' \| 'stretch'` | -       |
| extra        | Additional item content, rendered outside the button; interactive elements in it stay focusable and clickable, and clicking them does not trigger the row's click. | `JSX.Element`                                                       | -       |
| header       | Item header content.                                                                                                                                               | `JSX.Element`                                                       | -       |
| main         | Item main content.                                                                                                                                                 | `JSX.Element`                                                       | -       |
| onClick      | Click handler, taking precedence over the List's onClick; an item with a handler renders a native button.                                                          | `ListItemEventHandler`                                              | -       |
| onRightClick | Context-menu handler, taking precedence over the List's onRightClick; an item with only this handler also renders a native button.                                 | `ListItemEventHandler`                                              | -       |
