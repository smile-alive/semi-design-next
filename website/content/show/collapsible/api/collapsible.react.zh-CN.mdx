**Props**

| 属性                   | 说明                                                                                                | 类型                                                              | 默认值  |
| ---------------------- | --------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------- | ------- |
| children               | 需要展开或收起的内容。                                                                              | `React.ReactNode`                                                 | -       |
| className              | 外层 wrapper 的类名。                                                                               | `string`                                                          | -       |
| collapseHeight         | 收起时的高度，单位为像素。大于 0 时收起后仍露出部分内容。                                           | `number`                                                          | `0`     |
| collapseHeightAdaptive | 内容高度小于 `collapseHeight` 时，收起高度是否取内容高度，即 `Math.min(内容高度, collapseHeight)`。 | `boolean`                                                         | `false` |
| duration               | 动画执行的时间，单位为毫秒。                                                                        | `number`                                                          | `250`   |
| fade                   | 是否开启淡入淡出。                                                                                  | `boolean`                                                         | `false` |
| id                     | 内层内容元素的 id，可配合触发器的 `aria-controls` 使用。                                            | `string`                                                          | -       |
| isOpen                 | 是否展开内容区域。                                                                                  | `boolean`                                                         | `false` |
| keepDOM                | 是否保留隐藏的内容 DOM 树，默认销毁。                                                               | `boolean`                                                         | `false` |
| lazyRender             | 配合 `keepDOM` 使用，为 `true` 时挂载时不渲染内容，首次展开后才渲染。                               | `boolean`                                                         | `false` |
| motion                 | 是否开启动画。                                                                                      | `boolean`                                                         | `true`  |
| onMotionEnd            | 展开或收起动画结束时调用。                                                                          | <ApiType detail={"() => void"}>Type</ApiType>                     | -       |
| ref                    | 外层 wrapper（`div`）的引用。                                                                       | <ApiType detail={"React.Ref\u003cHTMLDivElement>"}>Type</ApiType> | -       |
| style                  | 外层 wrapper 的样式。                                                                               | `React.CSSProperties`                                             | -       |
