**Props**

| 属性    | 说明                                                                                                                         | 类型                                                                       | 默认值       |
| ------- | ---------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------- | ------------ |
| align   | 对齐方式，可选 center、justify、left、plain；row 为 true 时无效。                                                            | `DescriptionsAlign`                                                        | `"center"`   |
| column  | 横向布局下每行的总列数。                                                                                                     | `number`                                                                   | `3`          |
| data    | 列表显示的数据，每项为 `DescriptionsData`。                                                                                  | `DescriptionsData[]`                                                       | `[]`         |
| itemKey | 每个数据项 key 的 snippet，参数为 `{ item, index }`，`index` 是该项在 `data` 中的位置（含 hidden 的项）；默认渲染 item.key。 | <ApiType detail={"Snippet\u003c[DescriptionsSnippetArgs]>"}>Type</ApiType> | -            |
| layout  | 布局模式，可选 vertical、horizontal。                                                                                        | `DescriptionsLayout`                                                       | `"vertical"` |
| row     | 是否双行显示。                                                                                                               | `boolean`                                                                  | `false`      |
| size    | 双行显示时的尺寸，可选 small、medium、large。                                                                                | `DescriptionsSize`                                                         | `"medium"`   |
| value   | 每个数据项值的 snippet，参数为 `{ item, index }`，`index` 是该项在 `data` 中的位置（含 hidden 的项）；默认渲染 item.value。  | <ApiType detail={"Snippet\u003c[DescriptionsSnippetArgs]>"}>Type</ApiType> | -            |
