**Props**

| Property | Description                                                                                                                                                                    | Type                                                                       | Default      |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------- | ------------ |
| align    | Alignment: center, justify, left or plain; ignored when row is true.                                                                                                           | `DescriptionsAlign`                                                        | `"center"`   |
| column   | Total number of columns per row in the horizontal layout.                                                                                                                      | `number`                                                                   | `3`          |
| data     | Data to display, each item a `DescriptionsData`.                                                                                                                               | `DescriptionsData[]`                                                       | `[]`         |
| itemKey  | Snippet for the key of each data item, with the parameter `{ item, index }`, where `index` is the position in `data` (hidden items included); renders item.key by default.     | <ApiType detail={"Snippet\u003c[DescriptionsSnippetArgs]>"}>Type</ApiType> | -            |
| layout   | Layout mode: vertical or horizontal.                                                                                                                                           | `DescriptionsLayout`                                                       | `"vertical"` |
| row      | Whether to display key and value in two rows.                                                                                                                                  | `boolean`                                                                  | `false`      |
| size     | Size in two-row mode: small, medium or large.                                                                                                                                  | `DescriptionsSize`                                                         | `"medium"`   |
| value    | Snippet for the value of each data item, with the parameter `{ item, index }`, where `index` is the position in `data` (hidden items included); renders item.value by default. | <ApiType detail={"Snippet\u003c[DescriptionsSnippetArgs]>"}>Type</ApiType> | -            |
