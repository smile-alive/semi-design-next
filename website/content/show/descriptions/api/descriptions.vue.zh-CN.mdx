**Props**

| 属性       | 说明                                                                                                                                            | 类型                                                                                       | 默认值                                            |
| ---------- | ----------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------ | ------------------------------------------------- |
| align      | 对齐方式，可选 center、justify、left、plain；row 为 true 时无效。                                                                               | `DescriptionsAlign`                                                                        | `"center"`                                        |
| classNames | 内部各部位的类名，键为 itemKey、itemValue，分别作用到全部条目的键与值，值的写法同 class，与组件自带的类名合并，排在条目自己的 classNames 之前。 | <ApiType detail={"Partial\u003cRecord\u003cDescriptionsPart, ClassValue>>"}>Type</ApiType> | `semiGlobalDefault("Descriptions", "classNames")` |
| column     | 横向布局下每行的总列数。                                                                                                                        | `number`                                                                                   | `3`                                               |
| data       | 列表显示的数据；为空时使用默认插槽中的 Descriptions.Item。                                                                                      | `DescriptionsData[]`                                                                       | `[]`                                              |
| layout     | 布局模式，可选 vertical、horizontal。                                                                                                           | `DescriptionsLayout`                                                                       | `"vertical"`                                      |
| row        | 是否双行显示。                                                                                                                                  | `boolean`                                                                                  | `false`                                           |
| size       | 双行显示时的尺寸，可选 small、medium、large。                                                                                                   | `DescriptionsSize`                                                                         | `"medium"`                                        |
| styles     | 内部各部位的内联样式，键同 classNames；条目自己的 styles 后写。                                                                                 | <ApiType detail={"Partial\u003cRecord\u003cDescriptionsPart, StyleValue>>"}>Type</ApiType> | `semiGlobalDefault("Descriptions", "styles")`     |
