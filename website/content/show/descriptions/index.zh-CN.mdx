### 基本用法

可以通过 `data` 以键值对 `{ key: value }` 数组方式传入数据

<Framework only="react">

key、value 均支持 ReactNode 类型，你可以传入字符串或更高自由度的 ReactNode 自由定制渲染效果

</Framework>

<Framework only="vue">

`data` 中的 key、value 只接受字符串或数字。需要自定义渲染时，使用作用域插槽 `#itemKey`、`#value`，参数为 `{ item, index }`，其中 `index` 是该项在 `data` 中的位置（包含 `hidden` 的项）

</Framework>

<Framework only="solid">

`data` 中的 key、value 只接受字符串或数字。需要自定义渲染时，传入 `renderKey(item, index)`、`renderValue(item, index)`，其中 `index` 是该项在 `data` 中的位置（包含 `hidden` 的项）；隐藏的项不调用它们。

</Framework>

<Framework only="svelte">

`data` 中的 key、value 只接受字符串或数字。需要自定义渲染时，使用 `itemKey`、`value` snippet，参数为 `{ item, index }`，其中 `index` 是该项在 `data` 中的位置（包含 `hidden` 的项）。

</Framework>

### 设置对齐方式

可以通过设置 `align` 值选择对齐方式，支持 `center`, `justify`, `left`, 和 `plain`。默认对齐方式为 `center`  
当 row 为 true 时，该配置无效  
`left` 指起始侧，在 RTL 下随页面方向镜像为靠右，与 `center`、`justify` 一致

### 设置布局模式

可以通过 `layout` 设置布局模式，默认为 `vertical` 纵向布局 。

<Demo id="layout" />

横向布局可设置 layout为 `horizontal` 。当设置 horizontal 时，可配合 column 指定每行最大列数

<Demo id="layout-horizontal" />

### 双行显示

可以通过设置 `row` 可选择双行显示，支持三种不同的大小：`small`, `medium`, `large`。默认大小为 `medium`，此时 align 配置不再生效

<Demo id="row" />

可以通过 `keyStyle` 属性自定义 key 的样式，例如设置固定宽度实现对齐效果。该属性支持所有 CSS 样式，如 `width`、`maxWidth`、`textAlign`、`color` 等。

### DataItem

<Framework only="react">

| 属性     | 说明                                         | 类型                           | 默认值 |
| -------- | -------------------------------------------- | ------------------------------ | ------ |
| key      | 键值                                         | ReactNode                      | -      |
| value    | 属性值                                       | ReactNode \| (() => ReactNode) | -      |
| hidden   | 该数据是否需要展示                           | boolean                        | -      |
| span     | 单元格应跨越的列数                           | number                         | 1      |
| keyStyle | key 的自定义样式，可用于设置宽度、对齐方式等 | CSSProperties                  | -      |
