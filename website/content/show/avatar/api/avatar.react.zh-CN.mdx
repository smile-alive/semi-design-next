| --- | --- | --- | --- |

| color | 头像的预设背景颜色，可选 `amber`、`blue`、`cyan`、`green`、`grey`、`indigo`、`light-blue`、`light-green`、`lime`、`orange`、`pink`、`purple`、`red`、`teal`、`violet`、`yellow`；图片头像不使用。 | `AvatarColor` | `"grey"` |
| contentMotion | 启用头像内容区域的动画。 | `boolean` | - |

| shape | 头像形状，可选 `circle` 或 `square`。 | `AvatarShape` | `"circle"` |
| size | 头像尺寸，可选 `extra-extra-small`、`extra-small`、`small`、`default`、`medium`、`large`、`extra-large`，也可以传合法的 CSS 尺寸，如 `10px`。 | `string` | `"medium"` |
| src | 图片头像的资源地址。 | `string` | - |
| srcSet | 图片头像的响应式资源集合。 | `string` | - |
