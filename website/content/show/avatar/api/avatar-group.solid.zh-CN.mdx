**Props**

| 属性        | 说明                                                                                                                                                        | 类型                                                                                                                          | 默认值     |
| ----------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- | ---------- |
| children    | 组内的 Avatar。                                                                                                                                             | `JSX.Element`                                                                                                                 | -          |
| maxCount    | 显示的最大头像数，超出后显示 `+N`。                                                                                                                         | `number`                                                                                                                      | -          |

| shape       | 组内头像的形状。                                                                                                                                            | `AvatarGroupShape`                                                                                                            | `"circle"` |
| size        | 组内头像的尺寸。                                                                                                                                            | `string`                                                                                                                      | `"medium"` |
