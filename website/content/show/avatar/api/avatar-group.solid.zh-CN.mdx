**Props**

| 属性        | 说明                                                                                                                                                        | 类型                                                                                                                          | 默认值     |
| ----------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- | ---------- |
| children    | 组内的 Avatar。                                                                                                                                             | `JSX.Element`                                                                                                                 | -          |
| classNames  | 内部各部位的类名，键为 more，对应超出 maxCount 后显示「+N」的头像（用 renderMore 自定义时同样合并到其 Avatar 上），与组件自带的类名合并。                   | <ApiType detail={"Partial\u003cRecord\u003cAvatarGroupPart, string>>"}>Type</ApiType>                                         | -          |

| overlapFrom | 头像重叠方向，可选 `start` 或 `end`。                                                                                                                       | `AvatarGroupOverlapFrom`                                                                                                      | `"start"`  |
| renderMore  | 自定义溢出标签。调用时传入剩余数量和被隐藏头像的渲染函数数组，返回的内容替代默认的 `+N`。被隐藏的头像在调用渲染函数处才创建，传入的属性覆盖头像自身的属性。 | <ApiType detail={"(restNumber: number, restAvatars: ((props?: AvatarProps) => JSX.Element)[]) => JSX.Element"}>Type</ApiType> | -          |

| size        | 组内头像的尺寸。                                                                                                                                            | `string`                                                                                                                      | `"medium"` |
| styles      | 内部各部位的内联样式，键同 classNames；样式对象的键使用 kebab-case 的 CSS 属性名，也可以写样式字符串。                                                      | <ApiType detail={"Partial\u003cRecord\u003cAvatarGroupPart, JSX.CSSProperties \u007c string>>"}>Type</ApiType>                | -          |
