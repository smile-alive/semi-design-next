import ApiType from '#/components/ApiType.astro';

**Props**

| 属性        | 说明                                                                                            | 类型                                                                                                         | 默认值     |
| ----------- | ----------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------ | ---------- |
| children    | 组内的 Avatar。                                                                                 | `React.ReactNode`                                                                                            | -          |
| maxCount    | 显示的最大头像数，超出后显示 `+N` 标签。                                                        | `number`                                                                                                     | -          |
| overlapFrom | 头像重叠方向，可选 `start` 或 `end`：`start` 时左边的头像覆盖右边，`end` 时右边的头像覆盖左边。 | `AvatarGroupOverlapFrom`                                                                                     | `"start"`  |
| ref         | 根元素（`role="list"`）的引用。                                                                 | <ApiType detail={"React.Ref\u003cHTMLDivElement>"}>Type</ApiType>                                            | -          |
| renderMore  | 自定义溢出标签。调用时传入剩余数量和被隐藏的头像节点数组，返回的内容替代默认的 `+N`。           | <ApiType detail={"(restNumber?: number, restAvatars?: React.ReactNode[]) => React.ReactNode"}>Type</ApiType> | -          |
| shape       | 组内头像的形状，可选 `circle` 或 `square`。                                                     | `AvatarGroupShape`                                                                                           | `"circle"` |
| size        | 组内头像的尺寸，取值同 Avatar 的 `size`。                                                       | `string`                                                                                                     | `"medium"` |
