**Props**

| 属性               | 说明                                                                                                                                   | 类型                    | 默认值   |
| ------------------ | -------------------------------------------------------------------------------------------------------------------------------------- | ----------------------- | -------- |
| autoEscape         | 是否自动转义 `searchWords` 中的正则特殊字符。关闭后 `searchWords` 按正则表达式匹配。                                                   | `boolean`               | `true`   |
| caseSensitive      | 是否区分大小写。                                                                                                                       | `boolean`               | `false`  |
| component          | 渲染高亮文本的标签名，如 `span`。                                                                                                      | `string`                | `"mark"` |
| highlightClassName | 高亮标签的类名，与对象项的 `className` 一起添加到标签上。                                                                              | `string`                | -        |
| highlightStyle     | 高亮标签的内联样式，键使用驼峰写法（如 `borderRadius`），长度数值按 React 规则补 `px`。与对象项的 `style` 合并，对象项的同名属性优先。 | `React.CSSProperties`   | -        |
| searchWords        | 需要高亮的文本，可以是字符串、字符串数组，或带 `text`、`className`、`style` 的对象数组。未设置时为空数组，不高亮任何文本。             | `string \| SearchWords` | -        |
| sourceString       | 源文本。                                                                                                                               | `string`                | `""`     |
