**Props**

| Property | Description | Type | Default |
| --- | --- | --- | --- |
| autoEscape | Whether to escape regular expression characters in `searchWords`. When off, each search word is matched as a regular expression. | `boolean` | `true` |
| caseSensitive | Whether matching is case sensitive. | `boolean` | `false` |
| classNames | Class names of the inner parts, keyed by `highlight` (each highlight tag); merged with the built-in classes and the `className` of an object item in `searchWords`. | <ApiType detail={"Partial\u003cRecord\u003cHighlightPart, string>>"}>Type</ApiType> | - |
| component | Tag name of the element that wraps highlighted text, such as `span`. | `string` | `"mark"` |
| searchWords | Text to highlight: a string, an array of strings, or an array of objects with `text`, `className` and `style`. Defaults to an empty array, which highlights nothing. | `string \| (string \| ComplexSearchWord \| undefined)[]` | - |
| sourceString | Source text to search in. | `string` | `""` |
| styles | Inline styles of the inner parts, keyed like `classNames`, with camelCase properties such as `borderRadius`. Merged with the `style` of an object item in `searchWords`, where the item wins on conflicts. | <ApiType detail={"Partial\u003cRecord\u003cHighlightPart, React.CSSProperties>>"}>Type</ApiType> | - |
