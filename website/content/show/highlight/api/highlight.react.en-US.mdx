**Props**

| Property           | Description                                                                                                                                                                                                            | Type                    | Default  |
| ------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------- | -------- |
| autoEscape         | Whether to escape regular expression characters in `searchWords`. When off, each search word is matched as a regular expression.                                                                                       | `boolean`               | `true`   |
| caseSensitive      | Whether matching is case sensitive.                                                                                                                                                                                    | `boolean`               | `false`  |
| component          | Tag name of the element that wraps highlighted text, such as `span`.                                                                                                                                                   | `string`                | `"mark"` |
| highlightClassName | Class name of the highlight tags. It is added together with the `className` of an object item in `searchWords`.                                                                                                        | `string`                | -        |
| highlightStyle     | Inline style of the highlight tags. Keys are camelCase such as `borderRadius`, and numeric lengths get `px` as in React. Merged with the `style` of an object item in `searchWords`, where the item wins on conflicts. | `React.CSSProperties`   | -        |
| searchWords        | Text to highlight: a string, an array of strings, or an array of objects with `text`, `className` and `style`. Defaults to an empty array, which highlights nothing.                                                   | `string \| SearchWords` | -        |
| sourceString       | Source text to search in.                                                                                                                                                                                              | `string`                | `""`     |
