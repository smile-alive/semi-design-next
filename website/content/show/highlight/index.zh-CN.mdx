### 基本用法

你可以通过 `searchWords` 指定需要高亮的关键字，通过 `sourceString` 指定源文本

<Notice title="注意事项">Highlight 组件会将文本被拆分成多个独立的行内元素，任何分割文本流的 CSS 布局（如 flex 布局）可能会将高亮文本断开，为避免高亮内容被浏览器拆分到不同行或列，请按需使用元素包裹 Highlight 组件。</Notice>

### 指定高亮样式

默认情况下，高亮文本会自带文本样式，背景颜色 --semi-yellow-4, 文本颜色为黑色  
暗色模式下，背景颜色为 --semi-yellow-2，文本颜色为白色  
当你需要自定义不同的高亮样式时，你可以通过 `highlightClassName`, `highlightStyle`来指定

<Framework only="vue">

Vue 不会给数值样式补 `px`，`highlightStyle` 与高亮词的 `style` 中的长度要写成 `'4px'` 这样的字符串；`fontWeight: 600` 等无单位属性不受影响。

</Framework>

<Framework only="solid">

数值不会补 `px`，`highlightStyle` 与高亮词的 `style` 中的长度要写成 `'4px'` 这样的字符串；`'font-weight': 600` 等无单位属性不受影响。样式的键要写成 CSS 属性名，`backgroundColor` 这样的驼峰写法不会生效。

</Framework>

<Framework only="svelte">

`highlightStyle` 与高亮词的 `style` 是样式对象，键可用驼峰或 kebab-case；数值不会补 `px`，长度要写成 `'4px'` 这样的字符串，`fontWeight: 600` 等无单位属性不受影响。

</Framework>

### 不同文本使用差异化样式

支持针对不同的高亮文本使用不同的高亮样式 searchWords 默认为字符串数组。当传入对象数组时，可以通过 text指定高亮文本，同时单独指定 className、style

<Framework only="vue">

Vue 中对象项的类名字段写作 `class`，与模板里的写法一致。

</Framework>

<Framework only="solid">

对象项的类名字段写作 `class`，与 JSX 中的 `class` 属性一致。

</Framework>

<Framework only="svelte">

对象项的类名字段写作 `class`，与 Svelte 模板里的写法一致。

</Framework>

## API 参考

### Highlight

<Framework only="react">

<HighlightReactApi />

Highlight 没有根元素，渲染的是若干行内片段：`className`、`style`、`id` 等额外属性无处可落，不会生效，也不能挂 `ref`。

</Framework>

<Framework only="vue">

<HighlightVueApi />

Highlight 没有根元素，渲染的是 Fragment：`class`、`style`、`id` 等 attrs 无处可落，会被丢弃且不告警，也没有可用的 ref。

</Framework>

<Framework only="solid">

<HighlightSolidApi />

Highlight 没有根元素，渲染的是若干行内片段，`class`、`style`、`ref` 和 `id` 等原生属性无处可落，会被丢弃。

</Framework>

<Framework only="svelte">

<HighlightSvelteApi />

Highlight 没有根元素，渲染的是若干行内片段：`class`、`style`、`id` 等未声明的属性无处可落，会被丢弃，也不能用 `bind:this` 取元素。

</Framework>
