### Basic usage

You can specify keywords to be highlighted with `searchWords` and source text with `sourceString`

<Notice title="Attension">
    The Highlight component will split the text into multiple independent inline elements. Any CSS layout that splits the text flow (such as flex layout) may break the highlighted text. To prevent the highlighted content from being split into different rows or columns by the browser, please wrap the Highlight component
    with a wrapper element as needed.
</Notice>

### Specify highlight style

By default, the highlighted text will have its own text style, the text color is black, and the background color is `--semi-yellow-4`.  
In dark mode, the text color is white, and the background color is `--semi-yellow-2`.  
When you need to customize different highlight styles, you can specify them through `highlightClassName`, `highlightStyle`

<Framework only="vue">

Vue adds no `px` to numeric styles: write lengths as strings such as `'4px'` in `highlightStyle` and in a search word's `style`. Unitless properties such as `fontWeight: 600` still work.

</Framework>

<Framework only="solid">

Numbers get no `px`: write lengths in `highlightStyle` and in a search word's `style` as strings such as `'4px'`. Unitless properties such as `'font-weight': 600` still work. Keys must be CSS property names; camelCase keys such as `backgroundColor` have no effect.

</Framework>

### Use Different Styles for Different Texts

It supports using different highlight styles for different highlighted texts. The `searchWords` is a string array by default. When an array of objects is passed in, the highlighted text can be specified through `text`, and the `className` and `style` can be specified separately at the same time.

<Framework only="vue">

In Vue the class field of an object item is `class`, as in templates.

</Framework>

<Framework only="solid">

The class field of an object item is `class`, as in JSX.

</Framework>

## API Reference

### Highlight

<Framework only="react">

<HighlightReactApi />

Highlight has no root element and renders inline chunks: extra props such as `className`, `style` and `id` have nowhere to land and have no effect, and it cannot take a `ref`.

</Framework>

<Framework only="vue">

<HighlightVueApi />

Highlight has no root element and renders a Fragment: attrs such as `class`, `style` and `id` have nowhere to land and are dropped without a warning, and there is no usable ref.

</Framework>

<Framework only="solid">

<HighlightSolidApi />

Highlight has no root element and renders inline chunks, so `class`, `style`, `ref` and native attributes such as `id` have nowhere to land and are dropped.

</Framework>
