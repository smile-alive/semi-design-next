import ApiType from '#/components/ApiType.astro';

**Props**

| 属性               | 说明                                                                                                                       | 类型                             | 默认值                                                                                                             |
| ------------------ | -------------------------------------------------------------------------------------------------------------------------- | -------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| activeIndex        | 当前展示的索引，配合 v-model:activeIndex 使用；传 undefined 时交还控制权，从最后一次受控的索引继续。                       | `number`                         | `semiGlobalDefault("Carousel", "activeIndex")`                                                                     |
| animation          | 切换动画，可选 slide 或 fade。                                                                                             | `"fade" \| "slide"`              | `semiDefault("Carousel", "animation", "slide")`                                                                    |
| arrowProps         | 上一项、下一项箭头按钮的数据，只放属性；onClick 与 class 会和内置处理、内置类名合并。图标使用 leftArrow、rightArrow 插槽。 | `ArrowProps`                     | `semiGlobalDefault("Carousel", "arrowProps")`                                                                      |
| arrowType          | 箭头展示时机，可选 always 或 hover。                                                                                       | `"always" \| "hover"`            | `semiDefault("Carousel", "arrowType", "always")`                                                                   |
| autoPlay           | 是否自动循环播放，也可传入 interval（切换间隔，默认 2000 毫秒）和 hoverToPause（悬浮时是否暂停，默认 true）。              | `CarouselAutoPlay`               | `semiDefault("Carousel", "autoPlay", true)`                                                                        |
| defaultActiveIndex | 初始展示的索引，非受控时使用。                                                                                             | `number`                         | <ApiType detail={"semiDefault(\"Carousel\", \"defaultActiveIndex\", numbers.DEFAULT_ACTIVE_INDEX)"}>Type</ApiType> |
| indicatorPosition  | 指示器位置，可选 left、center 或 right。                                                                                   | `"left" \| "right" \| "center"`  | `semiDefault("Carousel", "indicatorPosition", "center")`                                                           |
| indicatorSize      | 指示器尺寸，可选 small 或 medium。                                                                                         | `"small" \| "medium"`            | `semiDefault("Carousel", "indicatorSize", "small")`                                                                |
| indicatorType      | 指示器类型，可选 dot、line 或 columnar。                                                                                   | `"dot" \| "line" \| "columnar"`  | `semiDefault("Carousel", "indicatorType", "dot")`                                                                  |
| showArrow          | 是否展示箭头。                                                                                                             | `boolean`                        | `semiDefault("Carousel", "showArrow", true)`                                                                       |
| showIndicator      | 是否展示指示器。                                                                                                           | `boolean`                        | `semiDefault("Carousel", "showIndicator", true)`                                                                   |
| slideDirection     | 动画为 slide 时的滑动方向，可选 left 或 right。                                                                            | `"left" \| "right"`              | `semiDefault("Carousel", "slideDirection", "left")`                                                                |
| speed              | 切换速度，单位为毫秒。                                                                                                     | `number`                         | `semiDefault("Carousel", "speed", numbers.DEFAULT_SPEED)`                                                          |
| theme              | 指示器和箭头的主题，可选 primary、light 或 dark。                                                                          | `"dark" \| "primary" \| "light"` | `semiDefault("Carousel", "theme", "light")`                                                                        |
| trigger            | 指示器触发切换的时机，可选 click 或 hover。                                                                                | `"hover" \| "click"`             | `semiDefault("Carousel", "trigger", "click")`                                                                      |

**Events**

| 事件               | 说明                                             | 回调参数                            |
| ------------------ | ------------------------------------------------ | ----------------------------------- |
| update:activeIndex | 切换到新的一项时触发，用于 v-model:activeIndex。 | `[index: number]`                   |
| change             | 切换到新的一项时触发，参数为新索引和上一个索引。 | `[index: number, preIndex: number]` |

**Slots**

| 插槽       | 说明                                                                                               | 作用域参数 |
| ---------- | -------------------------------------------------------------------------------------------------- | ---------- |
| default    | 幻灯片，每个直接子节点是一张。幻灯片需要把 id、role、inert、class、style 等属性落到自己的 DOM 上。 | `any`      |
| leftArrow  | 上一项箭头按钮的内容；传入空插槽时按钮内容为空。                                                   | `any`      |
| rightArrow | 下一项箭头按钮的内容；传入空插槽时按钮内容为空。                                                   | `any`      |

**Exposes**

| 名称 | 说明                                         | 类型                                                             |
| ---- | -------------------------------------------- | ---------------------------------------------------------------- |
| next | 切换到下一项。                               | <ApiType detail={"() => void"}>Type</ApiType>                    |
| prev | 切换到上一项。                               | <ApiType detail={"() => void"}>Type</ApiType>                    |
| goTo | 切换到指定索引，超出范围时循环。             | <ApiType detail={"(targetIndex: number) => void"}>Type</ApiType> |
| play | 开始自动播放，autoPlay 为 false 时同样生效。 | <ApiType detail={"() => void"}>Type</ApiType>                    |
| stop | 停止自动播放。                               | <ApiType detail={"() => void"}>Type</ApiType>                    |
