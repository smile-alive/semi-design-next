| 属性              | 说明                                                                                                                                                                                 | 类型                                                                                   | 默认值      |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------- | ----------- |
| afterClose        | 对话框完全关闭后触发；显示期间被卸载时也会触发一次。                                                                                                                                 | <ApiType detail={"() => void"}>Type</ApiType>                                          | -           |
| bodyStyle         | 对话框内容区的样式，字符串。                                                                                                                                                         | `string`                                                                               | -           |
| cancelButtonProps | 取消按钮的属性。autoFocus 为 true 时打开后聚焦该按钮；class、style 落在按钮上；onclick 先于内置的取消处理调用，不会替换内置处理。                                                    | `ModalButtonProps`                                                                     | -           |

| cancelText        | 取消按钮文字，缺省取语言包 Modal.cancel。                                                                                                                                            | `string`                                                                               | -           |
| centered          | 是否垂直居中显示。                                                                                                                                                                   | `boolean`                                                                              | `false`     |
| children          | 对话框的正文，写在标签内。                                                                                                                                                           | `Snippet`                                                                              | -           |

| closeIcon         | 关闭按钮中图标的 snippet。                                                                                                                                                           | `Snippet`                                                                              | -           |
| closeOnEsc        | 是否允许按 Esc 取消对话框。                                                                                                                                                          | `boolean`                                                                              | `true`      |
| confirmLoading    | 确认按钮是否加载中；不传时跟随 onOk 返回的 Promise，显式传入 false 关闭该行为。                                                                                                      | `boolean`                                                                              | -           |
| footer            | 完全替换默认页脚按钮的 snippet。写一个空 snippet 或传 null 时不渲染页脚区域。                                                                                                        | `Snippet \| null`                                                                      | -           |
| footerFill        | 默认页脚的两个按钮是否撑满排列。                                                                                                                                                     | `boolean`                                                                              | -           |
| fullScreen        | 是否全屏显示，开启后 width、height 不再生效。                                                                                                                                        | `boolean`                                                                              | `false`     |
| getPopupContainer | 指定弹层渲染到的父级 DOM。自定义容器需要设置 position: relative；这会改变浮层的 DOM 位置，不改变视图位置。                                                                           | <ApiType detail={"() => HTMLElement"}>Type</ApiType>                                   | -           |
| hasCancel         | 默认页脚是否显示取消按钮。                                                                                                                                                           | `boolean`                                                                              | `true`      |
| header            | 完全替换默认头部（图标、标题与关闭按钮）的 snippet。写一个空 snippet 或传 null 时不渲染头部区域。                                                                                    | `Snippet \| null`                                                                      | -           |
| height            | 对话框高度，数字按像素处理，字符串为合法 CSS 长度。                                                                                                                                  | `string \| number`                                                                     | -           |
| icon              | 标题前图标的 snippet。                                                                                                                                                               | `Snippet`                                                                              | -           |
| keepDOM           | 关闭时是否保留对话框内部节点而不销毁。                                                                                                                                               | `boolean`                                                                              | `false`     |
| lazyRender        | 配合 keepDOM 使用；为 true 时，首次显示之前不渲染对话框。                                                                                                                            | `boolean`                                                                              | `true`      |
| mask              | 是否显示遮罩。                                                                                                                                                                       | `boolean`                                                                              | `true`      |
| maskClosable      | 是否允许点击遮罩取消对话框。                                                                                                                                                         | `boolean`                                                                              | `true`      |
| maskFixed         | 遮罩限定在自定义容器内时，是否仍以 fixed 定位覆盖整个视口并按模态处理（aria-modal、页面 inert、Tab 锁定、body 滚动锁定）。                                                           | `boolean`                                                                              | `false`     |
| maskStyle         | 遮罩的样式，字符串。                                                                                                                                                                 | `string`                                                                               | -           |
| modal             | 自定义渲染对话框本身的 snippet，参数为 `{ modal }`，`modal` 是 role=dialog 元素对应的 snippet，用 `{@render modal()}` 放置。                                                         | <ApiType detail={"Snippet\u003c[{ modal: Snippet }]>"}>Type</ApiType>                  | -           |
| modalContentClass | 对话框内容元素的类名。                                                                                                                                                               | `string`                                                                               | -           |
| motion            | 是否启用进出场动画。                                                                                                                                                                 | `boolean`                                                                              | `true`      |
| okButtonProps     | 确认按钮的属性。autoFocus 为 true 时打开后聚焦该按钮；class、style 落在按钮上；onclick 先于内置的确认处理调用，不会替换内置处理。                                                    | `ModalButtonProps`                                                                     | -           |
| okText            | 确认按钮文字，缺省取语言包 Modal.confirm。                                                                                                                                           | `string`                                                                               | -           |
| okType            | 确认按钮的类型。                                                                                                                                                                     | `OKType`                                                                               | `"primary"` |
| onCancel          | 取消按钮、关闭按钮、遮罩和 Esc 触发；按 Esc 时参数为原生 KeyboardEvent。返回 Promise 时取消按钮保持加载，fulfill 后才写回 visible，reject 时保持打开；回调执行时 visible 仍为 true。 | <ApiType detail={"(event: MouseEvent \u007c KeyboardEvent) => unknown"}>Type</ApiType> | -           |
| onOk              | 点击确认按钮时调用；返回 Promise 时确认按钮保持加载直到落定。组件不会自行关闭，由使用方把 visible 设为 false。                                                                       | <ApiType detail={"(event: MouseEvent) => unknown"}>Type</ApiType>                      | -           |
| preventScroll     | 组件内部调用 focus 时是否阻止浏览器滚动到被聚焦元素，不影响使用方自己的 focus 调用。                                                                                                 | `boolean`                                                                              | -           |
| role              | 对话框元素的 role，可选 dialog 或 alertdialog。                                                                                                                                      | `'dialog' \| 'alertdialog'`                                                            | -           |
| size              | 对话框宽度档位：small 为 448px，medium 为 684px，large 为 920px，full-width 为 100vw - 64px。                                                                                        | `Size`                                                                                 | `"small"`   |
| title             | 标题，纯文本或 snippet，同时作为对话框的可访问名称。声明为 prop，不会作为原生 title 属性落到元素上。                                                                                 | `string \| Snippet`                                                                    | -           |
| visible           | 对话框是否可见，配合 bind:visible 使用。取消按钮、关闭按钮、遮罩和 Esc 在 onCancel 返回后写回 false；确认只调用 onOk，由使用方把 visible 设为 false。                                | `boolean`                                                                              | -           |
| width             | 对话框宽度，数字按像素处理，字符串为合法 CSS 长度；不传时由 size 决定。                                                                                                              | `string \| number`                                                                     | -           |
| zIndex            | 弹层外层的 z-index。                                                                                                                                                                 | `number`                                                                               | `1000`      |
