| maskFixed | 遮罩限定在自定义容器内时，是否仍以 fixed 定位覆盖整个视口并按模态处理（aria-modal、页面 inert、Tab 锁定、body 滚动锁定）。 | `boolean` | `false` |
| maskStyle | 遮罩的样式。 | `CSSProperties` | - |
| modalContentClass | 对话框内容元素的类名。 | `string` | - |

| preventScroll | 组件内部调用 focus 时是否阻止浏览器滚动到被聚焦元素，不影响使用方自己的 focus 调用；未设置时聚焦会滚动到该元素。 | `boolean` | - |
