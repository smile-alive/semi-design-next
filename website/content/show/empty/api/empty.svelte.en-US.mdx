**Props**

| Property      | Description                                                                                                                                        | Type                | Default      |
| ------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------- | ------------ |
| children      | Actions below the description.                                                                                                                     | `Snippet`           | -            |
| darkModeImage | Placeholder image in dark mode, following the theme-mode attribute of document.body. Takes the same values as image.                               | `EmptyImage`        | -            |
| description   | Description content.                                                                                                                               | `Snippet`           | -            |
| image         | Placeholder image: an image URL, an in-page SVG sprite symbol as `{ id }`, or a snippet for any other content. An empty string counts as no image. | `EmptyImage`        | -            |
| imageStyle    | Style string of the placeholder image box.                                                                                                         | `string`            | -            |
| layout        | Layout mode: vertical or horizontal.                                                                                                               | `EmptyLayout`       | `"vertical"` |
| title         | Title, a string or a snippet.                                                                                                                      | `string \| Snippet` | -            |
