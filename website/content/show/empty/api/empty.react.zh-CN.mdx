**Props**

| 属性          | 说明                                                                                                                     | 类型                                                                                         | 默认值       |
| ------------- | ------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------- | ------------ |
| children      | 描述下方的操作区内容，如按钮。                                                                                           | `React.ReactNode`                                                                            | -            |
| className     | 根元素的类名。                                                                                                           | `string`                                                                                     | -            |
| classNames    | 内部各部位的类名，键为 `image`（占位图区域），与组件自带的类名合并。                                                     | <ApiType detail={"Partial\u003cRecord\u003cEmptyPart, string>>"}>Type</ApiType>              | -            |
| darkModeImage | 暗色模式下的占位图，跟随 document.body 的 theme-mode 属性变化；取值同 image。                                            | `React.ReactNode \| SVGNode`                                                                 | -            |
| description   | 描述内容，显示在标题下方。                                                                                               | `React.ReactNode`                                                                            | -            |
| image         | 占位图，可以是 ReactNode（如插画组件）、图片地址字符串，或 `{ id }` 形式的页面内 SVG sprite 符号；空字符串视为没有图片。 | `React.ReactNode \| SVGNode`                                                                 | -            |
| layout        | 布局模式，可选 `vertical` 或 `horizontal`。                                                                              | `'horizontal' \| 'vertical'`                                                                 | `"vertical"` |
| ref           | 根 `div` 元素的引用。                                                                                                    | <ApiType detail={"React.Ref\u003cHTMLDivElement>"}>Type</ApiType>                            | -            |
| style         | 根元素的内联样式。                                                                                                       | `React.CSSProperties`                                                                        | -            |
| styles        | 内部各部位的内联样式，键同 `classNames`。                                                                                | <ApiType detail={"Partial\u003cRecord\u003cEmptyPart, React.CSSProperties>>"}>Type</ApiType> | -            |
| title         | 标题，按标题样式渲染，可以是任意 ReactNode。                                                                             | `React.ReactNode`                                                                            | -            |
