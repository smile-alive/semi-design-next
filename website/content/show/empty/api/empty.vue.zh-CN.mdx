**Props**

| 属性          | 说明                                                                                                    | 类型                         | 默认值                                        |
| ------------- | ------------------------------------------------------------------------------------------------------- | ---------------------------- | --------------------------------------------- |
| layout        | 布局模式，可选 vertical、horizontal。                                                                   | `"vertical" \| "horizontal"` | `semiDefault("Empty", "layout", "vertical")`  |
| imageStyle    | 占位图的样式。                                                                                          | `CSSProperties`              | `semiGlobalDefault("Empty", "imageStyle")`    |
| title         | 纯文本标题；同时传入 title 插槽时以插槽为准。                                                           | `string`                     | `semiGlobalDefault("Empty", "title")`         |
| image         | 占位图的 URL，或 `{ id }` 形式的页面内 SVG sprite 符号；空字符串视为没有图片。其他内容使用 image 插槽。 | `string \| EmptySvgNode`     | `semiGlobalDefault("Empty", "image")`         |
| darkModeImage | 暗色模式下的占位图，跟随 document.body 的 theme-mode 变化；取值同 image。                               | `string \| EmptySvgNode`     | `semiGlobalDefault("Empty", "darkModeImage")` |

**Slots**

| 插槽          | 说明                                                  | 作用域参数 |
| ------------- | ----------------------------------------------------- | ---------- |
| default       | 描述下方的操作区。                                    | `any`      |
| title         | 自定义标题，优先于 title 属性。                       | `any`      |
| description   | 描述内容。                                            | `any`      |
| image         | 自定义占位图，优先于 image 属性。                     | `any`      |
| darkModeImage | 暗色模式下的自定义占位图，优先于 darkModeImage 属性。 | `any`      |
