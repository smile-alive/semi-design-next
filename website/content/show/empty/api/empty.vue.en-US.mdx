**Props**

| Property      | Description                                                                                                                                   | Type                         | Default                                       |
| ------------- | --------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------- | --------------------------------------------- |
| darkModeImage | Placeholder image in dark mode, following the theme-mode attribute of document.body. Takes the same values as image.                          | `string \| EmptySvgNode`     | `semiGlobalDefault("Empty", "darkModeImage")` |
| image         | Placeholder image URL, or an in-page SVG sprite symbol as `{ id }`. An empty string counts as no image. Use the image slot for other content. | `string \| EmptySvgNode`     | `semiGlobalDefault("Empty", "image")`         |
| imageStyle    | Style of the placeholder image.                                                                                                               | `CSSProperties`              | `semiGlobalDefault("Empty", "imageStyle")`    |
| layout        | Layout mode: vertical or horizontal.                                                                                                          | `"horizontal" \| "vertical"` | `"vertical"`                                  |
| title         | Plain-text title. The title slot wins when both are given.                                                                                    | `string`                     | `semiGlobalDefault("Empty", "title")`         |
