**Props**

| Property      | Description                                                                                                                                                               | Type                          | Default      |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------- | ------------ |
| darkModeImage | Placeholder image in dark mode, following the theme-mode attribute of document.body. Takes the same values as image.                                                      | `JSX.Element \| SVGNode`      | -            |
| description   | Description content, shown below the title.                                                                                                                               | `JSX.Element`                 | -            |
| image         | Placeholder image: a JSX element such as an illustration component, an image URL string, or an in-page SVG sprite symbol as `{ id }`. An empty string counts as no image. | `JSX.Element \| SVGNode`      | -            |
| imageStyle    | Style of the placeholder image, as a style object with kebab-case keys or a string.                                                                                       | `JSX.CSSProperties \| string` | -            |
| layout        | Layout mode: vertical or horizontal.                                                                                                                                      | `'vertical' \| 'horizontal'`  | `"vertical"` |
| title         | Title, rendered in the title style. Accepts any JSX content.                                                                                                              | `JSX.Element`                 | -            |
