| 属性          | 说明                                                                                                                    | 类型                                                                                                     | 默认值       |
| ------------- | ----------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------- | ------------ |
| classNames    | 内部各部位的类名，键为 image，与组件自带的类名合并。                                                                    | <ApiType detail={"Partial\u003cRecord\u003cEmptyPart, string>>"}>Type</ApiType>                          | -            |
