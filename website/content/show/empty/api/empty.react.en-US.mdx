**Props**

| Property      | Description                                                                                                                                                             | Type                                                                                         | Default      |
| ------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------- | ------------ |
| children      | Actions below the description, such as buttons.                                                                                                                         | `React.ReactNode`                                                                            | -            |
| className     | Class name of the root element.                                                                                                                                         | `string`                                                                                     | -            |
| classNames    | Class names of the inner parts, keyed by `image` (the placeholder image area); merged with the built-in classes.                                                        | <ApiType detail={"Partial\u003cRecord\u003cEmptyPart, string>>"}>Type</ApiType>              | -            |
| darkModeImage | Placeholder image in dark mode, following the theme-mode attribute of document.body. Takes the same values as image.                                                    | `React.ReactNode \| SVGNode`                                                                 | -            |
| description   | Description content, shown below the title.                                                                                                                             | `React.ReactNode`                                                                            | -            |
| image         | Placeholder image: a ReactNode such as an illustration component, an image URL string, or an in-page SVG sprite symbol as `{ id }`. An empty string counts as no image. | `React.ReactNode \| SVGNode`                                                                 | -            |
| layout        | Layout mode: `vertical` or `horizontal`.                                                                                                                                | `'horizontal' \| 'vertical'`                                                                 | `"vertical"` |
| ref           | Reference to the root `div` element.                                                                                                                                    | <ApiType detail={"React.Ref\u003cHTMLDivElement>"}>Type</ApiType>                            | -            |
| style         | Inline style of the root element.                                                                                                                                       | `React.CSSProperties`                                                                        | -            |
| styles        | Inline styles of the inner parts, keyed like `classNames`.                                                                                                              | <ApiType detail={"Partial\u003cRecord\u003cEmptyPart, React.CSSProperties>>"}>Type</ApiType> | -            |
| title         | Title, rendered in the title style. Accepts any ReactNode.                                                                                                              | `React.ReactNode`                                                                            | -            |
