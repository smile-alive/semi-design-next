### 基本用法

<Framework only="react">

通过 `image` 设置占位图片，可以从 `@fibrae/semi-illustrations-react` 中手动引入对应的插画（插画默认宽高是200x200），也可以传入自定义的插画。目前拥有的插画可以查看[占位图插画](#占位图插画_建设中_)。

增加一系列暗色模式的插画，并支持通过 `darkModeImage` 传入暗色模式下需要使用的插画，以更好地适配暗色模式。

</Framework>

<Framework only="vue">

通过 `#image` 插槽设置占位图片，可以从 `@fibrae/semi-illustrations-vue` 中手动引入对应的插画（插画默认宽高是200x200），也可以放入自定义的插画。目前拥有的插画可以查看[占位图插画](#占位图插画_建设中_)。`image` 属性只接收图片地址字符串或 `{ id }`。

增加一系列暗色模式的插画，并支持通过 `#darkModeImage` 插槽放入暗色模式下需要使用的插画，以更好地适配暗色模式。

</Framework>

<Framework only="solid">

通过 `image` 设置占位图片，可以从 `@fibrae/semi-illustrations-solid` 中手动引入对应的插画（插画默认宽高是200x200），也可以传入自定义的 JSX 元素。目前拥有的插画可以查看[占位图插画](#占位图插画_建设中_)。`image` 还接受图片地址字符串，以及 `{ id }` 形式的 SVG sprite 符号。

增加一系列暗色模式的插画，并支持通过 `darkModeImage` 传入暗色模式下需要使用的插画，以更好地适配暗色模式。

</Framework>

<Framework only="svelte">

通过 `image` 设置占位图片，可以从 `@fibrae/semi-illustrations-svelte` 中手动引入对应的插画（插画默认宽高是200x200），用 snippet 传入；也可以传入自定义内容的 snippet。目前拥有的插画可以查看[占位图插画](#占位图插画_建设中_)。`image` 还接受图片地址字符串，以及 `{ id }` 形式的 SVG sprite 符号。

增加一系列暗色模式的插画，并支持通过 `darkModeImage` 传入暗色模式下需要使用的插画，以更好地适配暗色模式。

</Framework>

`image` 传入空字符串时视为没有图片，标题按无图片排版。

## API 参考

<Framework only="react">

<EmptyReactApi />

其他原生属性（如 `id`、`aria-*`）落在根元素 `div` 上。

</Framework>

<Framework only="vue">

<EmptyVueApi />

`class`、`style` 与原生属性经 attrs 传入根元素。`title` 是组件属性，不会作为 HTML 属性落到根元素。暗色模式下，每个 Empty 在挂载后观察 `document.body` 的 `theme-mode`，服务端渲染与激活时使用亮色图片。

</Framework>

<Framework only="solid">

<EmptySolidApi />

`class`、`style`、`ref` 与原生属性落在根元素 `div` 上。`title`、`description`、`image`、`darkModeImage`、`imageStyle` 与 `layout` 是组件属性，不会落到根元素上。

</Framework>

<Framework only="svelte">

<EmptySvelteApi />

`class`、`style` 与原生属性落在根元素 `div` 上。`title`、`description`、`image`、`darkModeImage`、`imageStyle` 与 `layout` 是组件属性，不会落到根元素上。暗色模式下，只有传了 `darkModeImage` 的 Empty 在挂载后观察 `document.body` 的 `theme-mode`，服务端渲染与激活时使用亮色图片。

</Framework>

## Accessibility

### ARIA

- Empty 插图是装饰性的：SVG 插图的 aria-hidden 为 true，图片地址渲染的 `img` 的 `alt` 为空
- `title` 按标题样式渲染，但元素是 `div`，不带标题语义，不会打乱页面的标题层级

## 文案规范

- 标题
    - 标题应该简洁易懂
- 正文
    - 可以展示展示空状态的具体原因，也可以展示后续的操作行为去帮助用户消除空状态
    - 不要重复标题上的内容
    - 尽量保持正文在 1-2 句话内
- 动作按钮
    - 按钮文案需要足够清晰和容易理解
    - 使用 动词 + 名词 的格式
