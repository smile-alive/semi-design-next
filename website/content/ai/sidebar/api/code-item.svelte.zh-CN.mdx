**Props**

| 属性               | 说明                                                                                                                                                                                 | 类型                                                                          | 默认值  |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------- | ------- |
| codeHighlightProps | 传给 CodeHighlight 的其他属性，以及追加的 class 与 style。                                                                                                                           | <ApiType detail={"Partial\u003cCodeHighlightProps>"}>Type</ApiType>           | -       |
