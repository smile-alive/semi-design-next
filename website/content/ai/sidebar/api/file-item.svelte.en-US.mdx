**Props**

| Property        | Description                                                                                                                                       | Type                                                         | Default |
| --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------ | ------- |
| content         | Rich text as HTML. Later changes are synced to the editor; content equal to the editor's is not reset, and syncing does not call onContentChange. | `string`                                                     | -       |
| editable        | Whether it is editable; later changes are synced to the editor.                                                                                   | `boolean`                                                    | `true`  |
| extensions      | tiptap extensions appended to the built-in ones, read when the editor is created; later changes have no effect.                                   | `Extensions`                                                 | `[]`    |
| imgUploadProps  | Image upload options, read when the editor is created; later changes have no effect.                                                              | `ImageUploadNodeOptions`                                     | -       |
| name            | File name, used as the accessible name of the editing area; later changes are synced to the editor.                                               | `string`                                                     | -       |
| onContentChange | Called after an edit, with the content as HTML.                                                                                                   | <ApiType detail={"(content: string) => void"}>Type</ApiType> | -       |
