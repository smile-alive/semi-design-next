**Props**

| Property  | Description                                                                                                                                                | Type                                                                                                | Default |
| --------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------- | ------- |
| activeKey | Keys of the expanded code panels, one or several.                                                                                                          | `string \| string[]`                                                                                | -       |
| className | Class name of the Collapse root element.                                                                                                                   | `string`                                                                                            | -       |
| codes     | The code entries, each with the CodeItem props and a key identifying its panel.                                                                            | `CodeItemProps[]`                                                                                   | `[]`    |
| onChange  | Called when the expanded panels change, with the expanded keys.                                                                                            | <ApiType detail={"(activeKey: string \u007c string[]) => void"}>Type</ApiType>                      | -       |
| onExpand  | Called when the expand button in a panel header is clicked, with the event, the code entry and the mode `code`; the button is shown only when this is set. | <ApiType detail={"(e: React.MouseEvent, code: CodeItemProps, mode: string) => void"}>Type</ApiType> | -       |
| style     | Inline style of the Collapse root element.                                                                                                                 | `React.CSSProperties`                                                                               | -       |
