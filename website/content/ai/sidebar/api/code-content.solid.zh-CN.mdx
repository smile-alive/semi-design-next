import ApiType from '#/components/ApiType.astro';

**Props**

| 属性       | 说明                                                                                                   | 类型                                                                                            | 默认值 |
| ---------- | ------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------- | ------ |
| activeKey  | 当前展开的代码面板 key，支持单个或多个。                                                               | `string \| string[]`                                                                            | -      |
| classNames | 内部各部位的类名，键为 itemHeader、itemExpand，作用于每个代码面板，与组件自带的类名合并。              | <ApiType detail={"Partial\u003cRecord\u003cSidebarCodeContentPart, string>>"}>Type</ApiType>    | -      |
| codes      | 代码条目列表，每项为 CodeItem 的属性加用于标识面板的 key。                                             | `CodeItemProps[]`                                                                               | -      |
| onChange   | 展开的面板变化时触发，参数为当前展开的 key。                                                           | <ApiType detail={"(activeKey: string \u007c string[]) => void"}>Type</ApiType>                  | -      |
| onExpand   | 点击面板头部的展开按钮时触发，参数为事件、该代码条目和 code；设置后才显示展开按钮。                    | <ApiType detail={"(e: MouseEvent, code: CodeItemProps, mode: string) => void"}>Type</ApiType>   | -      |
| styles     | 内部各部位的内联样式，键同 classNames；样式对象的键使用 kebab-case 的 CSS 属性名，也可以写样式字符串。 | <ApiType detail={"Partial\u003cRecord\u003cSidebarCodeContentPart, PartStyle>>"}>Type</ApiType> | -      |
