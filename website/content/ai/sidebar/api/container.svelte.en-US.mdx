import ApiType from '#/components/ApiType.astro';

**Props**

| Property           | Description                                                                                                                                         | Type                                                                                | Default |
| ------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------- | ------- |
| afterVisibleChange | Called after the show or hide animation ends, with whether the container is visible.                                                                | <ApiType detail={"(visible: boolean) => void"}>Type</ApiType>                       | -       |
| children           | The content area of the container.                                                                                                                  | `Snippet`                                                                           | -       |
| closeOnEsc         | Whether pressing Esc calls onCancel; off by default.                                                                                                | `boolean`                                                                           | `false` |
| defaultSize        | Initial width and height; applies only when resizable is true.                                                                                      | `{ width?: number \| string; height?: number \| string }`                           | -       |
| header             | Replaces the whole header, the title and close button included.                                                                                     | `Snippet`                                                                           | -       |
| maxWidth           | Maximum width when resizing; applies only when resizable is true.                                                                                   | `number \| string`                                                                  | -       |
| minWidth           | Minimum width when resizing; applies only when resizable is true.                                                                                   | `number \| string`                                                                  | `150`   |
| motion             | Whether showing and hiding use the expand animation.                                                                                                | `boolean`                                                                           | `true`  |
| onCancel           | Called when the close button is clicked, or when Esc is pressed while closeOnEsc is true.                                                           | <ApiType detail={"(event: MouseEvent \u007c KeyboardEvent) => void"}>Type</ApiType> | -       |
| resizable          | Whether the width can be resized by dragging; minWidth, maxWidth and defaultSize apply only when true.                                              | `boolean`                                                                           | `true`  |
| showClose          | Whether the header shows the close button.                                                                                                          | `boolean`                                                                           | `true`  |
| title              | Title, either plain text or a snippet.                                                                                                              | `Snippet \| string`                                                                 | -       |
| visible            | Whether the container is shown; bind it with `bind:visible`. When the close button or Esc cancels, false is written first, then onCancel is called. | `boolean`                                                                           | -       |

**Methods**

| Method  | Description                                                            | Type                                                                |
| ------- | ---------------------------------------------------------------------- | ------------------------------------------------------------------- |
| getRoot | Returns the `.semi-sidebar-container` root element; null while hidden. | <ApiType detail={"() => HTMLDivElement \u007c null"}>Type</ApiType> |
