**Props**

| Property   | Description                                                                                                                                     | Type                                                                                            | Default |
| ---------- | ----------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------- | ------- |
| activeKey  | Keys of the expanded code panels, one or several.                                                                                               | `string \| string[]`                                                                            | -       |
| classNames | Class names of the inner parts, keyed by itemHeader and itemExpand; they apply to every code panel and merge with the built-in classes.         | <ApiType detail={"Partial\u003cRecord\u003cSidebarCodeContentPart, string>>"}>Type</ApiType>    | -       |
| codes      | The code entries, each with the CodeItem props and a key identifying its panel.                                                                 | `CodeItemProps[]`                                                                               | -       |
| onChange   | Called when the expanded panels change, with the expanded keys.                                                                                 | <ApiType detail={"(activeKey: string \u007c string[]) => void"}>Type</ApiType>                  | -       |
| onExpand   | Called when the expand button in a panel header is clicked, with the event, the code entry and code; the button is shown only when this is set. | <ApiType detail={"(e: MouseEvent, code: CodeItemProps, mode: string) => void"}>Type</ApiType>   | -       |
| styles     | Inline styles of the inner parts, keyed like classNames; style objects use kebab-case CSS property names, and style strings work too.           | <ApiType detail={"Partial\u003cRecord\u003cSidebarCodeContentPart, PartStyle>>"}>Type</ApiType> | -       |
