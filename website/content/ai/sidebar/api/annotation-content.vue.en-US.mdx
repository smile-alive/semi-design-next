import ApiType from '#/components/ApiType.astro';

**Props**

| Property   | Description                                                                                                                                                                            | Type                                                                                     | Default     |
| ---------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------- | ----------- |
| activeKey  | Keys of the expanded groups; bind it with v-model:activeKey.                                                                                                                           | `string \| string[]`                                                                     | `undefined` |
| classNames | Class names of the inner parts, keyed by groupHeader, groupContent, item, itemTitle, itemDetail and itemFooter; merged with the built-in classes. Values take the same forms as class. | <ApiType detail={"Partial\u003cRecord\u003cAnnotationPart, ClassValue>>"}>Type</ApiType> | `undefined` |
| info       | Groups of references; each has a header, a key and its annotations.                                                                                                                    | `AnnotationInfo[]`                                                                       | `[]`        |
| styles     | Inline styles of the inner parts, keyed like classNames.                                                                                                                               | <ApiType detail={"Partial\u003cRecord\u003cAnnotationPart, StyleValue>>"}>Type</ApiType> | `undefined` |

**Events**

| Event            | Description                                                                                                                   | Callback parameters                         |
| ---------------- | ----------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------- |
| change           | Emitted when a group opens or closes, with the expanded keys.                                                                 | `[activeKey: string \| string[]]`           |
| click            | Emitted when a reference is clicked, with the event and its item; the native click of the root is not reported apart from it. | `[event: MouseEvent, item: AnnotationItem]` |
| update:activeKey | Emitted before change when a group opens or closes, so v-model:activeKey follows.                                             | `[activeKey: string[]]`                     |

**Slots**

| Slot   | Description                                                                                           | Scope parameters            |
| ------ | ----------------------------------------------------------------------------------------------------- | --------------------------- |
| header | Content of a group header after its icon, with item and index; the header field is shown when absent. | `AnnotationHeaderSlotProps` |
| item   | Replaces the built-in reference item, with item and index (its position in the group).                | `AnnotationItemSlotProps`   |
