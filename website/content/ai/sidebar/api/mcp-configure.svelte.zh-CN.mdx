import ApiType from '#/components/ApiType.astro';

**Props**

| 属性               | 说明                                                                                                                    | 类型                                                                                           | 默认值 |
| ------------------ | ----------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- | ------ |
| afterVisibleChange | 显示或隐藏动画结束后调用，参数为当前是否可见。                                                                          | <ApiType detail={"(visible: boolean) => void"}>Type</ApiType>                                  | -      |
| closeOnEsc         | 按下 Esc 键时是否调用 onCancel。                                                                                        | `boolean`                                                                                      | -      |
| customOptions      | 自定义 MCP 工具列表，可用 `bind:customOptions` 绑定。切换启用状态时先写回绑定，再调用 onStatusChange。                  | `MCPConfigureOption[]`                                                                         | -      |
| defaultSize        | 初始宽高，仅在 resizable 为 true 时生效。                                                                               | `{ width?: number \| string; height?: number \| string }`                                      | -      |
| desc               | 选项的描述，参数为 item、index 和 custom；未提供时显示 desc 字段。                                                      | <ApiType detail={"Snippet\u003c[MCPConfigureItemSnippetProps]>"}>Type</ApiType>                | -      |
| filter             | 自定义搜索过滤，参数为转为小写的输入值和选项；默认按 label 与 desc 匹配。                                               | <ApiType detail={"(inputValue: string, option: MCPConfigureOption) => boolean"}>Type</ApiType> | -      |
| header             | 替换整个头部，标题与关闭按钮也由它负责。                                                                                | `Snippet`                                                                                      | -      |
| icon               | 选项的图标，参数为 item、index 和 custom；提供后所有选项都使用它，icon 字段只在未提供时作为图片地址。                   | <ApiType detail={"Snippet\u003c[MCPConfigureItemSnippetProps]>"}>Type</ApiType>                | -      |
| item               | 替换整行内置选项，参数为 item、index 和 custom。                                                                        | <ApiType detail={"Snippet\u003c[MCPConfigureItemSnippetProps]>"}>Type</ApiType>                | -      |
| maxWidth           | 可调整的最大宽度，仅在 resizable 为 true 时生效。                                                                       | `number \| string`                                                                             | -      |
| minWidth           | 可调整的最小宽度，仅在 resizable 为 true 时生效。                                                                       | `number \| string`                                                                             | -      |
| motion             | 显示与隐藏时是否使用展开动画。                                                                                          | `boolean`                                                                                      | -      |
| onAddClick         | 点击自定义页的新增按钮时调用。                                                                                          | <ApiType detail={"(event: MouseEvent) => void"}>Type</ApiType>                                 | -      |
| onCancel           | 点击关闭按钮，或在 closeOnEsc 为 true 时按下 Esc 调用。                                                                 | <ApiType detail={"(event: MouseEvent \u007c KeyboardEvent) => void"}>Type</ApiType>            | -      |
| onConfigureClick   | 点击内置工具的配置按钮时调用，参数为点击事件和对应选项。                                                                | <ApiType detail={"(event: MouseEvent, option: MCPConfigureOption) => void"}>Type</ApiType>     | -      |
| onEditClick        | 点击自定义工具的编辑按钮时调用，参数为点击事件和对应选项。                                                              | <ApiType detail={"(event: MouseEvent, option: MCPConfigureOption) => void"}>Type</ApiType>     | -      |
| onSearch           | 搜索输入变化时调用，参数为输入值，以及当前是否为自定义列表。                                                            | <ApiType detail={"(inputValue: string, custom: boolean) => void"}>Type</ApiType>               | -      |
| onStatusChange     | 切换启用状态后调用，参数为 active 已更新的列表，以及它是否为自定义列表。                                                | <ApiType detail={"(options: MCPConfigureOption[], custom: boolean) => void"}>Type</ApiType>    | -      |
| options            | 内置 MCP 工具列表，可用 `bind:options` 绑定；每项的 value 必填且唯一。切换启用状态时先写回绑定，再调用 onStatusChange。 | `MCPConfigureOption[]`                                                                         | -      |
| placeholder        | 搜索框的占位文字，默认使用语言包文案。                                                                                  | `string`                                                                                       | -      |
| resizable          | 宽度是否可拖拽调整；为 true 时 minWidth、maxWidth 与 defaultSize 生效。                                                 | `boolean`                                                                                      | -      |
| showClose          | 是否显示头部的关闭按钮。                                                                                                | `boolean`                                                                                      | -      |
| title              | 标题，可以是纯文本或 snippet，默认使用语言包中的 MCP 配置。                                                             | `Snippet \| string`                                                                            | -      |
| visible            | 是否显示，可用 `bind:visible` 绑定。                                                                                    | `boolean`                                                                                      | -      |

**Methods**

| 方法    | 说明                                                      | 类型                                         |
| ------- | --------------------------------------------------------- | -------------------------------------------- |
| getRoot | 返回容器根元素 `.semi-sidebar-container`；隐藏时为 null。 | <ApiType detail={"() => any"}>Type</ApiType> |
