**Props**

| 属性            | 说明                                                                                                | 类型                                                         | 默认值 |
| --------------- | --------------------------------------------------------------------------------------------------- | ------------------------------------------------------------ | ------ |
| content         | 富文本 HTML。挂载后变化会同步到编辑器，与编辑器当前内容相同时不会重置，同步不调用 onContentChange。 | `string`                                                     | -      |
| editable        | 是否可编辑，挂载后变化会同步到编辑器。                                                              | `boolean`                                                    | `true` |
| extensions      | 追加到内置扩展之后的 tiptap 扩展，编辑器创建时读取，之后变化不生效。                                | `Extensions`                                                 | `[]`   |
| imgUploadProps  | 图片上传配置，编辑器创建时读取，之后变化不生效。                                                    | `ImageUploadNodeOptions`                                     | -      |
| name            | 文件名称，作为编辑区域的可访问名称，挂载后变化会同步到编辑器。                                      | `string`                                                     | -      |
| onContentChange | 编辑后调用，参数为 HTML 字符串。                                                                    | <ApiType detail={"(content: string) => void"}>Type</ApiType> | -      |
