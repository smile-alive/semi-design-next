**Props**

| 属性            | 说明                                                                                                                                                                                                                       | 类型                                                         | 默认值 |
| --------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------ | ------ |
| className       | 根元素的类名。                                                                                                                                                                                                             | `string`                                                     | -      |
| content         | 富文本 HTML 字符串。挂载后变化会同步到编辑器，与编辑器当前内容相同时不会重置，同步不触发 `onContentChange`。                                                                                                               | `string`                                                     | -      |
| editable        | 是否可编辑，挂载后变化会同步到编辑器。                                                                                                                                                                                     | `boolean`                                                    | `true` |
| extensions      | 追加在内置扩展之后的 tiptap 扩展（Extension、Node 或 Mark），编辑器创建时读取，之后变化不生效。                                                                                                                            | `Extensions`                                                 | `[]`   |
| imgUploadProps  | 图片上传配置，编辑器创建时读取，之后变化不生效。设置 `action` 或 `customRequest` 后工具栏才显示图片按钮；`getUploadImageSrc(response)` 从上传响应得到图片地址，未提供时响应为字符串则直接作为地址，否则取 `response.src`。 | `ImageUploadNodeOptions`                                     | -      |
| key             | 面板的唯一标识，用于 FileContent 的 `activeKey`，也决定 Sidebar 详情的重新挂载。                                                                                                                                           | `string`                                                     | -      |
| name            | 名称，显示在面板头部、Sidebar 详情头部，并作为编辑区的 `aria-label`。                                                                                                                                                      | `string`                                                     | -      |
| onContentChange | 编辑后触发，参数为 HTML 字符串。                                                                                                                                                                                           | <ApiType detail={"(content: string) => void"}>Type</ApiType> | -      |
| style           | 根元素的内联样式。                                                                                                                                                                                                         | `React.CSSProperties`                                        | -      |
