import ApiType from '#/components/ApiType.astro';

**Props**

| Property           | Description                                                                                                                                                 | Type                                                                                           | Default |
| ------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- | ------- |
| afterVisibleChange | Called after the show or hide animation ends, with whether it is visible.                                                                                   | <ApiType detail={"(visible: boolean) => void"}>Type</ApiType>                                  | -       |
| closeOnEsc         | Whether pressing Esc calls onCancel.                                                                                                                        | `boolean`                                                                                      | -       |
| customOptions      | Custom MCP tools; bind it with `bind:customOptions`. Switching a tool writes the new list back before onStatusChange is called.                             | `MCPConfigureOption[]`                                                                         | -       |
| defaultSize        | Initial width and height; applies only when resizable is true.                                                                                              | `{ width?: number \| string; height?: number \| string }`                                      | -       |
| desc               | Description of an option, with item, index and custom; the desc field is shown when absent.                                                                 | <ApiType detail={"Snippet\u003c[MCPConfigureItemSnippetProps]>"}>Type</ApiType>                | -       |
| filter             | Custom search filter, called with the lower-cased input and an option; the label and desc are matched by default.                                           | <ApiType detail={"(inputValue: string, option: MCPConfigureOption) => boolean"}>Type</ApiType> | -       |
| header             | Replaces the whole header, the title and close button included.                                                                                             | `Snippet`                                                                                      | -       |
| icon               | Icon of an option, with item, index and custom. When provided it is used for every option; the icon field is an image URL only when it is absent.           | <ApiType detail={"Snippet\u003c[MCPConfigureItemSnippetProps]>"}>Type</ApiType>                | -       |
| item               | Replaces the whole built-in row, with item, index and custom.                                                                                               | <ApiType detail={"Snippet\u003c[MCPConfigureItemSnippetProps]>"}>Type</ApiType>                | -       |
| maxWidth           | Maximum width when resizing; applies only when resizable is true.                                                                                           | `number \| string`                                                                             | -       |
| minWidth           | Minimum width when resizing; applies only when resizable is true.                                                                                           | `number \| string`                                                                             | -       |
| motion             | Whether showing and hiding use the expand animation.                                                                                                        | `boolean`                                                                                      | -       |
| onAddClick         | Called when the add button of the custom page is clicked.                                                                                                   | <ApiType detail={"(event: MouseEvent) => void"}>Type</ApiType>                                 | -       |
| onCancel           | Called when the close button is clicked, or when Esc is pressed while closeOnEsc is true.                                                                   | <ApiType detail={"(event: MouseEvent \u007c KeyboardEvent) => void"}>Type</ApiType>            | -       |
| onConfigureClick   | Called when the configure button is clicked, with the event and its option.                                                                                 | <ApiType detail={"(event: MouseEvent, option: MCPConfigureOption) => void"}>Type</ApiType>     | -       |
| onEditClick        | Called when the edit button of a custom tool is clicked, with the event and its option.                                                                     | <ApiType detail={"(event: MouseEvent, option: MCPConfigureOption) => void"}>Type</ApiType>     | -       |
| onSearch           | Called when the search input changes, with the input value and whether the custom list is shown.                                                            | <ApiType detail={"(inputValue: string, custom: boolean) => void"}>Type</ApiType>               | -       |
| onStatusChange     | Called after a tool is switched, with the list whose active flag changed and whether it is the custom list.                                                 | <ApiType detail={"(options: MCPConfigureOption[], custom: boolean) => void"}>Type</ApiType>    | -       |
| options            | Built-in MCP tools; bind it with `bind:options`. Each item needs a unique value. Switching a tool writes the new list back before onStatusChange is called. | `MCPConfigureOption[]`                                                                         | -       |
| placeholder        | Placeholder of the search input, the locale text by default.                                                                                                | `string`                                                                                       | -       |
| resizable          | Whether the width can be resized by dragging; minWidth, maxWidth and defaultSize apply only when true.                                                      | `boolean`                                                                                      | -       |
| showClose          | Whether the header shows the close button.                                                                                                                  | `boolean`                                                                                      | -       |
| title              | Title, plain text or a snippet; the locale's MCP configure text by default.                                                                                 | `Snippet \| string`                                                                            | -       |
| visible            | Whether it is shown; bind it with `bind:visible`.                                                                                                           | `boolean`                                                                                      | -       |

**Methods**

| Method  | Description                                                            | Type                                         |
| ------- | ---------------------------------------------------------------------- | -------------------------------------------- |
| getRoot | Returns the `.semi-sidebar-container` root element; null while hidden. | <ApiType detail={"() => any"}>Type</ApiType> |
