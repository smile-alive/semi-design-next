import ApiType from '#/components/ApiType.astro';

**Props**

| Property           | Description                                                                                                                                                                                      | Type                                                                                 | Default |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------ | ------- |
| activeKey          | Keys of the expanded groups; bind it with `bind:activeKey`.                                                                                                                                      | `string \| string[]`                                                                 | -       |
| afterVisibleChange | Called after the show or hide animation ends, with whether it is visible.                                                                                                                        | <ApiType detail={"(visible: boolean) => void"}>Type</ApiType>                        | -       |
| closeOnEsc         | Whether pressing Esc calls onCancel.                                                                                                                                                             | `boolean`                                                                            | -       |
| defaultSize        | Initial width and height; applies only when resizable is true.                                                                                                                                   | `{ width?: number \| string; height?: number \| string }`                            | -       |
| header             | Replaces the whole header, the title and close button included.                                                                                                                                  | `Snippet`                                                                            | -       |
| info               | Groups of references; each has a header, a key and its annotations.                                                                                                                              | `AnnotationInfo[]`                                                                   | -       |
| infoHeader         | Content of a group header after its icon, with item and index; the header field is shown when absent. The container's header replaces the whole header, so the group header is named infoHeader. | <ApiType detail={"Snippet\u003c[AnnotationHeaderSnippetProps]>"}>Type</ApiType>      | -       |
| item               | Replaces the built-in reference item, with item and index (its position in the group).                                                                                                           | <ApiType detail={"Snippet\u003c[AnnotationItemSnippetProps]>"}>Type</ApiType>        | -       |
| maxWidth           | Maximum width when resizing; applies only when resizable is true.                                                                                                                                | `number \| string`                                                                   | -       |
| minWidth           | Minimum width when resizing; applies only when resizable is true.                                                                                                                                | `number \| string`                                                                   | -       |
| motion             | Whether showing and hiding use the expand animation.                                                                                                                                             | `boolean`                                                                            | -       |
| onCancel           | Called when the close button is clicked, or when Esc is pressed while closeOnEsc is true.                                                                                                        | <ApiType detail={"(event: MouseEvent \u007c KeyboardEvent) => void"}>Type</ApiType>  | -       |
| onChange           | Called when a group opens or closes, with the expanded keys.                                                                                                                                     | <ApiType detail={"(activeKey: string \u007c string[]) => void"}>Type</ApiType>       | -       |
| onClick            | Called when a reference is clicked, with the event and its item; the native click of the root is not reported apart from it.                                                                     | <ApiType detail={"(event: MouseEvent, item: AnnotationItem) => void"}>Type</ApiType> | -       |
| resizable          | Whether the width can be resized by dragging; minWidth, maxWidth and defaultSize apply only when true.                                                                                           | `boolean`                                                                            | -       |
| showClose          | Whether the header shows the close button.                                                                                                                                                       | `boolean`                                                                            | -       |
| title              | Title, plain text or a snippet; the locale text by default.                                                                                                                                      | `Snippet \| string`                                                                  | -       |
| visible            | Whether it is shown; bind it with `bind:visible`.                                                                                                                                                | `boolean`                                                                            | -       |

**Methods**

| Method  | Description                                                            | Type                                         |
| ------- | ---------------------------------------------------------------------- | -------------------------------------------- |
| getRoot | Returns the `.semi-sidebar-container` root element; null while hidden. | <ApiType detail={"() => any"}>Type</ApiType> |
