## 使用场景

侧边信息栏主要用于在 AI 场景下，用于信息展示，功能配置。包括 MCP 配置、参考来源、代码预览、富文本预览及编辑等功能

### MCP 配置

使用 `MCPConfigure` 进行 MCP 工具的展示、启用/关闭、配置及搜索

<Framework only="react">

- 通过 `options` 和 `customOptions` 设置内置的 MCP 工具和自定义 MCP 工具
- 通过 `visible` 设置组件的显示和隐藏, 使用 `onCancel` 监听用户的关闭行为
- 使用 `onStatusChange` 自定义处理 MCP 工具的启用/关闭
- 使用 `onAddClick` 处理自定义 MCP 页的点击添加按钮后的操作
- 可通过 `onConfigureClick` 监听内置 MCP 工具的配置，通过 `onEditClick` 监听自定义 MCP 工具的配置

其他 MCPConfigure 的 API 见 [MCPConfigure](#MCPConfigure)

传入 MCP 工具项的类型如下

```ts
interface MCPOption {
    icon?: ReactNode;
    label?: string;
    value: string; // 必填，标识工具项，需唯一
    desc?: ReactNode;
    active?: boolean;
    disabled?: boolean;
    configure?: boolean; //是否显示配置按钮
}
```

</Framework>

<Framework only="vue">

- 通过 `v-model:options` 和 `v-model:customOptions` 绑定内置的 MCP 工具和自定义 MCP 工具，切换启用/关闭时先更新绑定值，再触发 `statusChange`
- 通过 `v-model:visible` 设置组件的显示和隐藏，使用 `cancel` 监听用户的关闭行为
- 使用 `statusChange` 自定义处理 MCP 工具的启用/关闭
- 使用 `addClick` 处理自定义 MCP 页的点击添加按钮后的操作
- 可通过 `configureClick` 监听内置 MCP 工具的配置，通过 `editClick` 监听自定义 MCP 工具的配置
- 工具项的图标和描述使用 `#icon`、`#desc` 插槽，整行用 `#item` 替换；插槽参数为 `{ item, index, custom }`

其他 MCPConfigure 的 API 见 [MCPConfigure](#MCPConfigure)

传入 MCP 工具项的类型如下

```ts
interface MCPConfigureOption {
    icon?: string; // 图片地址，其他内容使用 #icon 插槽
    label?: string;
    value: string; // 必填，标识工具项，需唯一
    desc?: string; // 纯文本，其他内容使用 #desc 插槽
    active?: boolean;
    disabled?: boolean;
    configure?: boolean; // 是否显示配置按钮
}
```

</Framework>

<Framework only="svelte">

- 通过 `bind:options` 和 `bind:customOptions` 绑定内置的 MCP 工具和自定义 MCP 工具，切换启用/关闭时先更新绑定值，再调用 `onStatusChange`

- 工具项的图标和描述使用 `icon`、`desc` snippet，整行用 `item` snippet 替换；snippet 参数为 `{ item, index, custom }`

其他 MCPConfigure 的 API 见 [MCPConfigure](#MCPConfigure)

传入 MCP 工具项的类型如下

```ts

    icon?: string; // 图片地址，其他内容使用 icon snippet
```

### 代码展示

可通过 `Sidebar` 中的 `CodeItem` 展示代码，`CodeItem` 基于 [JsonViewer](/zh-CN/react/plus/json-viewer) 以及 [CodeHighlight](/zh-CN/react/plus/code-highlight) 实现。

- `content`: 内容字符串
- `isJson`: 是否为 json
- `language`: 编程语言名称，同 `CodeHighlight` 的 language，需先通过 `CodeHighlight.register` 注册
- `jsonViewerProps`: 配置其他 JsonViewer 参数
- `codeHighlightProps`: 配置其他 CodeHighlight 参数

<Framework only="vue">

`jsonViewerProps` 中 JsonViewer 的 value 在 Vue 中叫 `modelValue`，`jsonViewerProps` 与 `codeHighlightProps` 还可以带 `class`、`style`。JsonViewer 的自定义渲染与搜索按钮通过 `CodeItem` 的 `#customRender`、`#searchButton` 插槽使用。

</Framework>

<Framework only="svelte">

`jsonViewerProps` 中 JsonViewer 的 value 默认取 `content`，`jsonViewerProps` 与 `codeHighlightProps` 还可以带 `class`、`style`。JsonViewer 的自定义渲染与搜索按钮通过 `CodeItem` 的 `customRender`、`searchButton` snippet 使用。

</Framework>

<Framework only="solid">

`jsonViewerProps` 与 `codeHighlightProps` 是 Solid 版 JsonViewer 与 CodeHighlight 的属性，晚于内置默认值展开，因此其中的 `value`、`width`、`height` 等会覆盖默认值，也可以带 `class`、`style`。

</Framework>

### 侧边信息栏

侧边信息栏 `Sidebar` 有主视图（`mode` 为 `main`）和详情视图（`mode` 为 `code`、`file` 及其他）。

<Framework only="react">

主视图可以通过 `title` 配置标题，通过 `showClose` 决定是否展示关闭按钮，通过 `options` 设置顶部的按钮组。

对于主视图的内容渲染，可通过 `renderMainContent` 传入渲染函数。可使用 `Annotation` 中的 `AnnotationContent` 渲染参考来源，使用 `Sidebar` 中内置的 `FileContent` 渲染富文本, `CodeContent` 渲染代码。

对于详情视图，如果是富文本或者代码，分别设置 `mode` 为 `code`、`file`，通过 `detailContent` 设置显示内容，即可通过内置的代码显示组件， 富文本编辑器进行显示，如果想要自定义详情视图的展示，则通过 `renderDetailContent` 自行处理渲染即可。

</Framework>

<Framework only="vue">

主视图可以通过 `title` 或 `#title` 插槽配置标题，通过 `showClose` 决定是否展示关闭按钮，通过 `options` 设置顶部的按钮组（每项为 `{ name, key }`），`v-model:activeKey` 绑定当前选中的项。按钮图标使用 `#optionIcon="{ item, index }"` 插槽，需要替换整个按钮时使用 `#optionItem`，其参数 `onClick` 用于选中该项。

对于主视图的内容渲染，可通过 `#mainContent="{ activeKey }"` 插槽，根据当前选中项渲染。可使用 `Annotation` 中的 `AnnotationContent` 渲染参考来源，使用 `Sidebar` 中内置的 `FileContent` 渲染富文本, `CodeContent` 渲染代码。

对于详情视图，如果是富文本或者代码，分别设置 `mode` 为 `code`、`file`，通过 `detailContent` 设置显示内容，即可通过内置的代码显示组件， 富文本编辑器进行显示；`detailContent` 的 `key` 变化时会重新挂载。如果想要自定义详情视图的展示，则通过 `#detailContent="{ mode }"` 插槽自行渲染，详情头部通过 `#detailHeader="{ mode, detailContent }"` 自定义，两者内容为空时回退到内置内容。点击详情头部的返回按钮触发 `backWard`。

</Framework>
