## Usage Scenarios

In AI chat scenarios, users can use `AIChatInput` to achieve rich text input, uploading, quoting, suggestions, templates, feature configuration, and rich custom display.

`AIChatInput`'s rich text input is based on `tiptap` (https://tiptap.dev/docs/editor/getting-started/overview), a modern rich text editor development framework that supports mainstream front-end frameworks such as React and Vue, and boasts strong customizability and extensibility. Its componentization capabilities are excellent, performance is high, it has many built-in commonly used extensions, and it supports user-defined nodes, commands, plugins, and menus, enabling flexible adaptation and expansion of rich text input capabilities in complex AI scenarios. Semi's `AIChatInput` component encapsulates tiptap, allowing developers to use it out of the box or extend it as needed according to business requirements.

You can extend any custom component for configuration using `getConfigureItem`.

<Framework only="react">

```ts
function getConfigureItem<P, VK extends keyof P = 'value', CK extends keyof P = 'onChange'>(
    component: React.ComponentType<P>,
    opts?: {
        // the prop that receives the value, value by default
        valueKey?: VK;
        // the prop called when the value changes, onChange by default
        onKeyChangeFnName?: CK;
        // where the value sits in the change callback's first argument, the argument itself by default
        valuePath?: string;
        className?: string;
        defaultProps?: Partial<P>;
    }
): React.ComponentType<
    Omit<P, VK | CK | 'onChange' | 'className'> & {
        // the key of this item in the Configure value, required
        field: string;
        initValue?: P[VK];
        onChange?: (value: unknown) => void;
        className?: string;
    }
>;
```

The returned component checks its props against the wrapped component's props: `field` is required, and `initValue` has the type of the prop named by `valueKey`. `onChange` belongs to the item and receives its new value; the wrapped component's own `onChange` is not accepted.

</Framework>

<Framework only="vue">

```ts
function getConfigureItem<C extends Component, VK extends keyof PropsOf<C>, CK extends keyof PropsOf<C>>(
    component: C,
    opts?: {
        // the prop that receives the value, modelValue by default
        valueKey?: VK;
        // the listener called when the value changes, onUpdate:modelValue by default
        onKeyChangeFnName?: CK;
        className?: string;
        defaultProps?: Partial<PropsOf<C>>;
    }
): Component<
    Omit<PropsOf<C>, VK | CK | 'onChange'> & {
        // the key of this item in the AIChatInput configure value, required
        field: string;
        initValue?: PropsOf<C>[VK];
    }
>;
```

The returned component checks its props against the wrapped component's props: `field` is required, and `initValue` has the type of the prop named by `valueKey`. The other props, listeners and slots of the wrapped component are passed on as they are. The first argument of the value listener must be the new value, which the item also emits through its `@change` event.

</Framework>

### Custom Extensions

Rich text areas support custom extensions. For implementation details, see [Tiptap Custom Extensions](https://tiptap.dev/docs/editor/extensions/custom-extensions/create-new). Custom extensions can be added to the AIChatInput component using the `extensions` API.

<Framework only="react">

If you add a custom extension, you must configure the corresponding transformation rules in `transformer` to ensure that the data returned in `onContentChange` matches your expectations.

</Framework>

<Framework only="vue">

Render the view of a custom node with `VueNodeViewRenderer` of `@tiptap/vue-3`. If you add a custom extension, you must configure the corresponding transformation rules in `transformer` to ensure that the data emitted by `@contentChange` matches your expectations.

</Framework>

<Framework only="solid">

If you add a custom extension, you must configure the corresponding transformation rules in `transformer` to ensure that the data returned in `onContentChange` matches your expectations. The node views in the example are plain DOM (tiptap's `addNodeView`), and the candidate panel mounts a Solid component with `render` from `solid-js/web`.

</Framework>

When adding a custom extension, please note the following:

- Please add the `isCustomSlot` property to your custom extension. This property is related to the cursor height before and after the custom extension.
- Since `AIChatInput` uses `Enter` as the send hotkey, if your custom extension uses `Enter` as a shortcut, you need to manually configure `SemiAIChatInput.allowHotKeySend` in `editor.storage` to indicate whether the hotkey should be used by AIChatInput for sending, in order to avoid hotkey conflicts. When `sendHotKey` is `shift+enter`, a plain `Enter` no longer breaks the line while `allowHotKeySend` is `false`; it is left to the custom extension.
