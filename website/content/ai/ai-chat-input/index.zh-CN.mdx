## 使用场景

在 AI 聊天场景下，用户可通过 `AIChatInput`实现富文本输入、上传、引用、建议、模版、功能配置、及丰富自定义展示等需求。

`AIChatInput` 的富文本输入是基于 [tiptap](https://tiptap.dev/docs/editor/getting-started/overview) 实现，`tiptap` 是一款现代的富文本编辑器开发框架，支持 React、Vue 前端框架，具备极强的可定制性和扩展性。其组件化能力优秀，性能优良，内置多种常用拓展，并支持用户自定义节点、命令、插件与菜单，使复杂 AI 场景下的富文本输入能力能够灵活适配和扩展。Semi 的 `AIChatInput` 组件对 tiptap 进行了封装，开发者可开箱即用或按需按业务扩展。

### 基本用法

支持文本输入以及文件上传，使用时可按需配置以下参数：

<Framework only="react">

- `uploadProps` 配置文件上传相关的参数，详见 [UploadProps](/zh-CN/react/input/upload#API)
- `onUploadChange` 获取文件上传变化
- 删除上传文件时，会触发 `uploadProps.onRemove`，并遵循 `uploadProps.beforeRemove`（支持 Promise）
- `placeholder` 输入框的占位符
- `defaultContent` 输入框的默认内容
- `onContentChange` 输入框内容变化时的回调函数，参数为当前输入框的内容

</Framework>

- `@uploadChange` 获取文件上传变化

### 消息发送

<Framework only="react">

当输入框中有内容（包括输入文本、上传内容），将允许发送消息。点击消息发送按钮，会触发 `onMessageSend` 回调函数，参数为当前输入框的内容，包括输入区域的文本，引用内容，上传文件，配置区域内容。引用内容不参与是否可发送的判断，也可通过 `canSend` 直接指定。

用户可在 `onMessageSend` 中根据判断是否设置 `generating` 表示消息正在处理中，如果 `generating` 为 `true`，则 AIChatInput 会在发送按钮位置显示停止生成按钮，并清空输入区的消息，以及上传文件，另外，引用内容需要用户自行清除。

点击停止生成按钮，会触发 `onStopGenerate` 回调函数，用户可在该回调函数中处理停止生成的逻辑， 如将 `generating` 设为 `false`。

</Framework>

### 富文本输入区

AIChatInput 使用 [tiptap](https://tiptap.dev/docs/editor/getting-started/overview) 作为富文本输入框的编辑器，用户可以在输入框中输入文本，使用 AIChatInput 内置的 extensions（包括 `input-slot`，`select-slot`，`skill-slot`）。用户也可以自定义 extensions 来扩展编辑器的功能。

- `input-slot` 支持用户输入文本，并支持 placeholder 占位符。
- `select-slot` 支持用户进行简单的选择，选项仅支持 string 类型。
- `skill-slot` 是用于技能展示的块，方便用户理解当前输入框中的技能。

<Framework only="react">

可以通过 ref 方法 `setContent` 来设置输入框的内容，使用 `focusEditor` 方法可以将输入框的焦点设置到编辑器中。

</Framework>

<Framework only="vue">

可以通过组件实例（模板 ref）的 `setContent` 方法来设置输入框的内容，使用 `focusEditor` 方法可以将输入框的焦点设置到编辑器中。

</Framework>

<Framework only="solid">

可以通过 ref 的 `setContent` 方法来设置输入框的内容，使用 `focusEditor` 方法可以将输入框的焦点设置到编辑器中。

使用 `getConfigureItem` 扩展自定义组件为 `Configure` 类型组件。

<Framework only="react">

```ts
function getConfigureItem<P, VK extends keyof P = 'value', CK extends keyof P = 'onChange'>(
    component: React.ComponentType<P>,
    opts?: {
        // 指定需要接管的组件的 value 对应的 key，默认是 value
        valueKey?: VK;
        // 指定需要接管的组件的值变化对应的函数名，默认是 onChange
        onKeyChangeFnName?: CK;
        // 指定需要接管的组件的值变化函数参数中 value 对应的路径，默认取参数本身
        valuePath?: string;
        className?: string;
        defaultProps?: Partial<P>;
    }
): React.ComponentType<
    Omit<P, VK | CK | 'onChange' | 'className'> & {
        // 配置项在 Configure 值中的 key，必填
        field: string;
        initValue?: P[VK];
        onChange?: (value: unknown) => void;
        className?: string;
    }
>;
```

返回的组件按被包装组件的 Props 检查属性，`field` 必填，`initValue` 的类型与 `valueKey` 对应的属性一致。`onChange` 由配置项占用，收到该项的新值，被包装组件自己的 `onChange` 不在可接受的属性中。

</Framework>

<Framework only="svelte">

```ts
interface ConfigureItemProps {
    // 被包装的组件：接收配置项的值，并报告变化
    component: Component<any>;
    // 配置项在 AIChatInput 配置值中的 key，必填
    field: string;
    // 配置项挂载时写入的初始值
    initValue?: unknown;
    // 接收值的 prop，默认是 value
    valueKey?: string;
    // 值变化的回调对应的 prop，默认是 onChange
    changeKey?: string;
    // 回调第一个参数中值所在的路径，默认参数本身就是值
    valuePath?: string;
    // 配置项的基础类名，与 class 合并
    baseClass?: ClassValue;
    // 传给被包装组件的默认属性，其余属性覆盖它
    defaultProps?: Record<string, unknown>;
    // 该项的值变化时调用，参数为新值
    onChange?: (value: any) => void;
    // 其余属性原样传给被包装组件
    [key: string]: unknown;
}
```

`<AIChatInput.Configure.Item component={Cascader} field="model" />` 把任意接收值和变化回调的组件变成配置项。被包装组件自己的 `onChange` 不会收到调用，该项的值变化由 `Configure.Item` 的 `onChange` 收到。

</Framework>
