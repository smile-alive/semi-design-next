**Props**

| 属性          | 说明                                                    | 类型          | 默认值      |
| ------------- | ------------------------------------------------------- | ------------- | ----------- |
| options       | MCP 选项列表。选项只含数据，图标使用 #optionIcon 插槽。 | `McpOption[]` | `undefined` |
| num           | 触发器与标题中显示的数量，不传时为 options 的数量。     | `number`      | `undefined` |
| showConfigure | 是否显示配置按钮。                                      | `boolean`     | `true`      |

**Events**

| 事件                 | 说明                 | 回调参数 |
| -------------------- | -------------------- | -------- |
| configureButtonClick | 点击配置按钮时触发。 | `[]`     |

**Slots**

| 插槽       | 说明                                         | 作用域参数               |
| ---------- | -------------------------------------------- | ------------------------ |
| default    | 替换标题下方的内置菜单。                     | `any`                    |
| optionIcon | 每个选项的图标，作用域参数为 item 与 index。 | `McpOptionIconSlotProps` |

**Exposes**

| 名称 | 说明 | 类型 |
| ---- | ---- | ---- |
| 无   |      |      |
