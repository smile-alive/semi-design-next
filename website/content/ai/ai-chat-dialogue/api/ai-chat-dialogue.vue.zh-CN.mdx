import ApiType from '#/components/ApiType.astro';

**Props**

| 属性                  | 说明                                                                                                                           | 类型                                     | 默认值                                                          |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------- | --------------------------------------------------------------- |
| align                 | 对话布局方式，可选 leftRight（左右分布）或 leftAlign（左对齐）。                                                               | `"leftRight" \| "leftAlign"`             | `semiDefault("AIChatDialogue", "align", "leftRight")`           |
| chats                 | 受控对话消息列表，配合 v-model:chats 使用。                                                                                    | `Message[]`                              | `semiGlobalDefault("AIChatDialogue", "chats")`                  |
| disabledFileItemClick | 是否禁用文件卡片的点击。                                                                                                       | `boolean`                                | `semiDefault("AIChatDialogue", "disabledFileItemClick", false)` |
| escapeHtml            | 是否转义用户消息中的 HTML 标签，避免被 Markdown 解析器当作 HTML 处理而丢失内容。                                               | `boolean`                                | `semiDefault("AIChatDialogue", "escapeHtml", true)`             |
| hintCls               | 提示区最外层的类名。                                                                                                           | `string`                                 | `semiGlobalDefault("AIChatDialogue", "hintCls")`                |
| hints                 | 提示信息。点击某条提示后，它成为新的用户消息，并触发 hintClick。                                                               | `string[]`                               | `semiGlobalDefault("AIChatDialogue", "hints")`                  |
| hintStyle             | 提示区最外层的样式。                                                                                                           | `StyleValue`                             | `semiGlobalDefault("AIChatDialogue", "hintStyle")`              |
| selecting             | 是否开启多选模式。                                                                                                             | `boolean`                                | `semiDefault("AIChatDialogue", "selecting", false)`             |
| markdownRenderProps   | 透传给每条消息所用 MarkdownRender 的属性，raw 由消息决定，不可传入；components 与内置组件合并，同名的（如 code）覆盖内置组件。 | `MarkdownRenderProps`                    | `semiGlobalDefault("AIChatDialogue", "markdownRenderProps")`    |
| mode                  | 对话模式，可选 bubble、noBubble 或 userBubble。                                                                                | `"bubble" \| "noBubble" \| "userBubble"` | `semiDefault("AIChatDialogue", "mode", "bubble")`               |
| roleConfig            | 各角色（user、assistant、system 等）的名称、头像与头像颜色，必填，不读取全局默认值。                                           | `RoleConfig`                             | `undefined`                                                     |
| showReset             | 是否展示重置操作。                                                                                                             | `boolean`                                | `semiDefault("AIChatDialogue", "showReset", true)`              |
| showReference         | 是否在文字或文件消息中展示可被引用的图标，仅对用户消息生效。                                                                   | `boolean`                                | `semiDefault("AIChatDialogue", "showReference", false)`         |

**Events**

| 事件                | 说明                                                                                                     | 回调参数                                                           |
| ------------------- | -------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------ |
| update:chats        | 消息列表变化时触发，v-model:chats 据此更新，与 chatsChange 传出同一个数组。                              | `[chats: Message[]]`                                               |
| chatsChange         | 消息列表变化时触发，载荷为新的消息数组。                                                                 | `[chats: Message[]]`                                               |
| annotationClick     | 点击参考来源时触发，载荷为被点击消息块的注释数组。                                                       | `[annotations: Annotation[]]`                                      |
| fileClick           | 点击文件卡片时触发。                                                                                     | `[file?: InputFile \| undefined]`                                  |
| hintClick           | 点击提示词时触发。                                                                                       | `[hint: string]`                                                   |
| imageClick          | 点击图片时触发。                                                                                         | `[image?: InputImage \| undefined]`                                |
| messageBadFeedback  | 对消息点踩时触发。                                                                                       | `[message?: Message \| undefined]`                                 |
| messageCopy         | 复制消息时触发：文本写入剪贴板成功后才触发，复制的文本不含推理内容；没有可复制的文本时既不写入也不触发。 | `[message?: Message \| undefined]`                                 |
| messageDelete       | 删除消息时触发。                                                                                         | `[message?: Message \| undefined]`                                 |
| messageEdit         | 编辑消息时触发。                                                                                         | `[message?: Message \| undefined]`                                 |
| messageGoodFeedback | 对消息点赞时触发。                                                                                       | `[message?: Message \| undefined]`                                 |
| messageReset        | 重置消息时触发。                                                                                         | `[message?: Message \| undefined]`                                 |
| messageShare        | 分享消息时触发。                                                                                         | `[message?: Message \| undefined]`                                 |
| referenceClick      | 点击引用按钮时触发。载荷没有 id，加入 AIChatInput 的 references 前由使用方补上；文件项没有 type。        | <ApiType detail={"[item: Partial\u003cReference>]"}>Type</ApiType> |
| select              | 选中的消息变化时触发。                                                                                   | `[selectedIds: string[]]`                                          |

**Slots**

| 插槽         | 说明                                                                                                                                                     | 作用域参数                            |
| ------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------- |
| avatar       | 自定义头像，参数含默认头像 defaultAvatar、消息 message 与角色 role。                                                                                     | `AIChatDialogueAvatarSlotProps`       |
| title        | 自定义标题，参数含默认标题 defaultTitle、消息 message 与角色 role。                                                                                      | `AIChatDialogueTitleSlotProps`        |
| content      | 自定义内容区域，参数含默认内容 defaultContent、消息 message、角色 role 与 class。defaultContent 与默认渲染一致，包含引用列表与加载指示。                 | `AIChatDialogueContentSlotProps`      |
| action       | 自定义消息操作栏，参数含默认按钮数组 defaultActions、按名称索引的 defaultActionsObj、消息 message 与 class；按钮不显示时（如消息未完成）对应的键不存在。 | `AIChatDialogueActionSlotProps`       |
| fullDialogue | 完全自定义整条对话，参数含 defaultNodes（avatar、title、content、action）、消息 message、角色 role 与 class。                                            | `AIChatDialogueFullDialogueSlotProps` |
| contentItem  | 按内容项自定义渲染，每个内容项都会先经过它，参数含 item、type、message、index 与 parent；返回空内容时由内置渲染接管。                                    | `AIChatDialogueContentItemSlotProps`  |
| messageText  | 替换内容为纯文本的消息的 Markdown 渲染，参数含文本 text 与消息 message。                                                                                 | `AIChatDialogueMessageTextSlotProps`  |
| messageEdit  | 用户消息处于编辑状态时显示的编辑器，参数为消息转换得到的输入内容。                                                                                       | `MessageContent`                      |
| hintBox      | 自定义提示项，参数含提示文本 content、序号 index 与点击回调 onHintClick。                                                                                | `AIChatDialogueHintBoxSlotProps`      |

**Exposes**

| 名称           | 说明                                 | 类型                                                            |
| -------------- | ------------------------------------ | --------------------------------------------------------------- |
| selectAll      | 全选所有消息。                       | <ApiType detail={"() => void"}>Type</ApiType>                   |
| deselectAll    | 取消全选所有消息。                   | <ApiType detail={"() => void"}>Type</ApiType>                   |
| scrollToBottom | 滚动到最底部，参数为 true 时带动画。 | <ApiType detail={"(animation: boolean) => void"}>Type</ApiType> |
| scrollToTop    | 滚动到最顶部，参数为 true 时带动画。 | <ApiType detail={"(animation: boolean) => void"}>Type</ApiType> |
