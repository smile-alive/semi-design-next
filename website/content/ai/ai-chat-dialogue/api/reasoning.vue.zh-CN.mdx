**Props**

| 属性                | 说明                                                                                | 类型                                                            | 默认值      |
| ------------------- | ----------------------------------------------------------------------------------- | --------------------------------------------------------------- | ----------- |
| status              | 推理状态。为 completed 时标题显示已完成，且初次渲染时折叠；其他值显示思考中并展开。 | `string`                                                        | `undefined` |
| summary             | 推理摘要，非空时按换行拼接其中的文本作为推理正文。                                  | `{ text?: string \| undefined; type?: string \| undefined; }[]` | `undefined` |
| content             | 推理内容，summary 为空时按换行拼接其中的文本作为推理正文。                          | `{ text?: string \| undefined; type?: string \| undefined; }[]` | `undefined` |
| markdownRenderProps | 透传给推理正文所用 MarkdownRender 的属性，raw 由推理正文决定。                      | `MarkdownRenderProps`                                           | `undefined` |

**Events**

**Slots**

| 插槽    | 说明                                                                                   | 作用域参数             |
| ------- | -------------------------------------------------------------------------------------- | ---------------------- |
| content | 替换推理正文的 Markdown 渲染，参数为 status、summary、content 与 markdownRenderProps。 | `ReasoningWidgetProps` |
