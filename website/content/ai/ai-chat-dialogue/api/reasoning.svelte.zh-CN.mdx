**Props**

| 属性                | 说明                                                                                                                                                                     | 类型                                                                                  | 默认值 |
| ------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------- | ------ |
| children            | 替换推理正文 Markdown 渲染的 snippet（`content` 已是推理数据的属性名，所以正文 snippet 叫 `children`），参数为 `status`、`summary`、`content` 与 `markdownRenderProps`。 | <ApiType detail={"Snippet\u003c[ReasoningWidgetContentSnippetProps]>"}>Type</ApiType> | -      |

| markdownRenderProps | 透传给推理正文所用 MarkdownRender 的属性，raw 由推理正文决定。                                                                                                           | `MarkdownRenderProps`                                                                 | -      |
| status              | 推理状态。为 completed 时标题显示已完成，且初次渲染时折叠；其他值显示思考中并展开。                                                                                      | `string`                                                                              | -      |
| summary             | 推理摘要，非空时按换行拼接其中的文本作为推理正文。                                                                                                                       | `ReasoningPart[]`                                                                     | -      |
