### 按钮类型

按钮支持以下类型：

- 主按钮（"primary"，默认）
- 次要按钮（"secondary"）
- 第三按钮（"tertiary"）
- 警告按钮（"warning"）
- 危险按钮（"danger"）

<Demo id="types" />

#### 关于类型字体色值

按钮的字体色值使用的都是 [CSS Variables](https://developer.mozilla.org/zh-CN/docs/Web/CSS/Using_CSS_custom_properties)，分别为：

- `var(--semi-color-primary)`：主要
- `var(--semi-color-secondary)`：次要
- `var(--semi-color-tertiary)`：第三
- `var(--semi-color-warning)`：警告
- `var(--semi-color-danger)`：危险

你可以直接使用这些主题色定义你的元素。

### AI 风格 - 多彩按钮

设置 `colorful` 即可获得多彩按钮，多彩按钮支持所有的 `theme` ， `type` 仅支持 `primary` 及 `tertiary`。

<Framework only="solid">

渐变填充只作用于以组件形式传入的图标（`icon={IconAIFilledLevel1}`）；传入元素（`icon={<IconAIFilledLevel1 />}`）时元素已经渲染，按钮无法再给它加填充。

</Framework>

<Framework only="svelte">

多彩按钮给 `icon` snippet 传入参数 `{ fill }`，需要把它传给图标组件：`{#snippet icon({ fill })}<IconAIFilledLevel1 {fill} />{/snippet}`。

</Framework>

<Demo id="colorful" />

### 按钮组合

可以将多个按钮放入`ButtonGroup`的容器中，通过设置`size`，`disabled`，`type`，`theme`，`colorful`可统一设置按钮组合中的按钮尺寸、是否禁用、类型、主题和多彩样式。这些属性只是默认值，按钮自己设置的值优先。`data-*`、`id`、`aria-*` 和事件等其余属性会落在按钮组的根元素（`role="group"`）上。

## Accessibility

### ARIA

- `aria-label` 用于表示按钮的作用，对于图标按钮，我们推荐使用此属性
- `aria-disabled` 在按钮 disabled 或 loading 时为 true，表示按钮不可操作

### 键盘和焦点

- Button 的焦点管理与原生 button 一致，键盘用户可以使用 Tab 及 Shift + Tab 切换焦点
- Button 的触发与原生 button 一致，当按钮聚焦时，可以通过 Enter 或 Space 键激活
- ButtonGroup 中的按钮与单个按钮的焦点管理方式一致，可以通过 Tab 以及 Shift + Tab 进行切换

## 文案规范

- 按钮需要清晰可预测，用户应该能够预测他们点击按钮时会发生什么
- 按钮应该总是以鼓励行动的强动词开头
- 为了给用户提供足够的上下文，在按钮上使用 \{动词\}+\{名词\} 内容公式；除了常见的动作，如“Done”、“Close”、“Cancel”或“OK”

## FAQ

<Framework only="react">

- #### 为什么Button中的icon属性不起作用？
    请检查你的Button import路径，正确的import路径应该为`import { Button } from '@fibrae/semi-ui-react;'`，如果你错误地从 @fibrae/semi-ui-react/button/button中import的话，获取到的是不带icon功能的基础Button组件

</Framework>

<Framework only="vue">

- #### 为什么 Button 的图标不显示？
    图标通过 `#icon` 插槽传入，不是 `icon` 属性：`<Button><template #icon><IconCamera /></template></Button>`。

</Framework>

<Framework only="svelte">

- #### 为什么 Button 的图标不显示？
    图标通过 `icon` snippet 传入，不是 `icon` 组件属性：`<Button>{#snippet icon()}<IconCamera />{/snippet}</Button>`。

</Framework>
