**Props**

| Property            | Description                                                                                                                             | Type                                                                                  | Default                                     |
| ------------------- | --------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------- | ------------------------------------------- |
| block               | Renders the button as a block-level button.                                                                                             | `boolean`                                                                             | `false`                                     |
| classNames          | Class names of the inner parts, keyed by content (the content area); values take any class binding and merge with the built-in classes. | <ApiType detail={"Partial\u003cRecord\u003c\"content\", ClassValue>>"}>Type</ApiType> | `semiGlobalDefault("Button", "classNames")` |
| colorful            | Colorful button, supported for the primary and tertiary types only. Falls back to the ButtonGroup it is in, and finally to false.       | `boolean`                                                                             | `undefined`                                 |
| disabled            | Disabled state, which takes precedence over loading. Falls back to the ButtonGroup it is in, and finally to false.                      | `boolean`                                                                             | `undefined`                                 |
| htmlType            | Native type of the button: button, reset or submit.                                                                                     | `HtmlType`                                                                            | `"button"`                                  |
| iconPosition        | Icon position: left or right.                                                                                                           | `"left" \| "right"`                                                                   | `strings.DEFAULT_ICON_POSITION`             |
| loading             | Loading state. A loading button stays focusable, its click is ignored, and a submit button does not submit its form.                    | `boolean`                                                                             | `false`                                     |
| noHorizontalPadding | Removes horizontal padding: true, left, right or an array of both. Applies only to a button that shows an icon or the loading spinner.  | `boolean \| HorizontalPaddingType[] \| HorizontalPaddingType`                         | `false`                                     |
| size                | Button size: large, default or small. Falls back to the ButtonGroup it is in, and finally to default.                                   | `Size`                                                                                | `undefined`                                 |
| styles              | Inline styles of the inner parts, keyed by content (the content area); values take any style binding.                                   | <ApiType detail={"Partial\u003cRecord\u003c\"content\", StyleValue>>"}>Type</ApiType> | `semiGlobalDefault("Button", "styles")`     |
| theme               | Button theme: solid, borderless, light or outline. Falls back to the ButtonGroup it is in, and finally to light.                        | `Theme`                                                                               | `undefined`                                 |
| type                | Button type: primary, secondary, tertiary, warning or danger. Falls back to the ButtonGroup it is in, and finally to primary.           | `Type`                                                                                | `undefined`                                 |
