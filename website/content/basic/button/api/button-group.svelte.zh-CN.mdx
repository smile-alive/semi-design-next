**Props**

| 属性     | 说明                             | 类型      | 默认值 |
| -------- | -------------------------------- | --------- | ------ |
| children | 组内的 Button。                  | `Snippet` | -      |
| colorful | 多彩样式，作为组内按钮的默认值。 | `boolean` | -      |
| disabled | 禁用状态，作为组内按钮的默认值。 | `boolean` | -      |
| size     | 按钮尺寸，作为组内按钮的默认值。 | `Size`    | -      |
| theme    | 按钮主题，作为组内按钮的默认值。 | `Theme`   | -      |
| type     | 按钮类型，作为组内按钮的默认值。 | `Type`    | -      |
