**Props**

| 属性                | 说明                                                                                                                    | 类型                                                              | 默认值     |
| ------------------- | ----------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------- | ---------- |
| block               | 将按钮设置为块级按钮。                                                                                                  | `boolean`                                                         | `false`    |
| children            | 按钮的文字内容的 snippet；没有 `children` 且有图标或处于加载状态时，按纯图标按钮处理。                                  | `Snippet`                                                         | -          |
| colorful            | 多彩按钮，仅支持 primary 与 tertiary 类型。未设置时使用所在 ButtonGroup 的值，最终默认为 false。                        | `boolean`                                                         | -          |
| contentClassName    | 内容区域的类名。                                                                                                        | `string`                                                          | -          |
| disabled            | 禁用状态，优先于 loading。未设置时使用所在 ButtonGroup 的值，最终默认为 false。                                         | `boolean`                                                         | -          |
| htmlType            | 原生 button 的 type 值，可选 button、reset 或 submit。                                                                  | `HtmlType`                                                        | `"button"` |
| icon                | 按钮图标的 snippet，位置由 iconPosition 决定；参数为 `{ fill }`，多彩按钮给出填充色，需传给图标组件。                   | <ApiType detail={"Snippet\u003c[ButtonIconArgs]>"}>Type</ApiType> | -          |
| iconPosition        | 图标位置，可选 left 或 right。                                                                                          | `'left' \| 'right'`                                               | `"left"`   |
| loading             | 加载状态。加载中按钮保持可聚焦，点击不触发 onclick，submit 按钮也不提交表单。                                           | `boolean`                                                         | `false`    |
| noHorizontalPadding | 去掉水平方向的内边距，可选 true、left、right 或二者的数组；只对设置了图标或处于加载状态的按钮有效。                     | `boolean \| HorizontalPaddingType \| HorizontalPaddingType[]`     | `false`    |
| size                | 按钮尺寸，可选 large、default 或 small。未设置时使用所在 ButtonGroup 的值，最终默认为 default。                         | `Size`                                                            | -          |
| theme               | 按钮主题，可选 solid、borderless、light 或 outline。未设置时使用所在 ButtonGroup 的值，最终默认为 light。               | `Theme`                                                           | -          |
| type                | 按钮类型，可选 primary、secondary、tertiary、warning 或 danger。未设置时使用所在 ButtonGroup 的值，最终默认为 primary。 | `Type`                                                            | -          |
