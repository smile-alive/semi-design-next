**Props**

| 属性     | 说明                             | 类型      | 默认值                                         |
| -------- | -------------------------------- | --------- | ---------------------------------------------- |
| colorful | 多彩样式，作为组内按钮的默认值。 | `boolean` | `semiGlobalDefault("ButtonGroup", "colorful")` |
| disabled | 禁用状态，作为组内按钮的默认值。 | `boolean` | `semiGlobalDefault("ButtonGroup", "disabled")` |
| size     | 按钮尺寸，作为组内按钮的默认值。 | `Size`    | `semiGlobalDefault("ButtonGroup", "size")`     |
| theme    | 按钮主题，作为组内按钮的默认值。 | `Theme`   | `semiGlobalDefault("ButtonGroup", "theme")`    |
| type     | 按钮类型，作为组内按钮的默认值。 | `Type`    | `semiGlobalDefault("ButtonGroup", "type")`     |

**Events**

| 事件 | 说明 | 回调参数 |

| 无   |      |          |

**Slots**

| 插槽    | 说明            | 作用域参数 |
| ------- | --------------- | ---------- |
