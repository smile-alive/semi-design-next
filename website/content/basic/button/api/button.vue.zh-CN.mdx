**Props**

| 属性                | 说明                                                                                                                    | 类型                                                          | 默认值                                                                 |
| ------------------- | ----------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------- | ---------------------------------------------------------------------- |
| block               | 将按钮设置为块级按钮。                                                                                                  | `boolean`                                                     | `semiDefault("Button", "block", false)`                                |
| colorful            | 多彩按钮，仅支持 primary 与 tertiary 类型。未设置时使用所在 ButtonGroup 的值，最终默认为 false。                        | `boolean`                                                     | `undefined`                                                            |
| contentClassName    | 内容区域的类名。                                                                                                        | `string`                                                      | `semiGlobalDefault("Button", "contentClassName")`                      |
| disabled            | 禁用状态，优先于 loading。未设置时使用所在 ButtonGroup 的值，最终默认为 false。                                         | `boolean`                                                     | `undefined`                                                            |
| htmlType            | 原生 button 的 type 值，可选 button、reset 或 submit。                                                                  | `HtmlType`                                                    | `semiDefault("Button", "htmlType", "button")`                          |
| iconPosition        | 图标位置，可选 left 或 right。                                                                                          | `"left" \| "right"`                                           | `semiDefault("Button", "iconPosition", strings.DEFAULT_ICON_POSITION)` |
| loading             | 加载状态。加载中按钮保持可聚焦，点击不触发 click，submit 按钮也不提交表单。                                             | `boolean`                                                     | `semiDefault("Button", "loading", false)`                              |
| noHorizontalPadding | 去掉水平方向的内边距，可选 true、left、right 或二者的数组；只对设置了图标或处于加载状态的按钮有效。                     | `boolean \| HorizontalPaddingType \| HorizontalPaddingType[]` | `semiDefault("Button", "noHorizontalPadding", false)`                  |
| size                | 按钮尺寸，可选 large、default 或 small。未设置时使用所在 ButtonGroup 的值，最终默认为 default。                         | `Size`                                                        | `undefined`                                                            |
| theme               | 按钮主题，可选 solid、borderless、light 或 outline。未设置时使用所在 ButtonGroup 的值，最终默认为 light。               | `Theme`                                                       | `undefined`                                                            |
| type                | 按钮类型，可选 primary、secondary、tertiary、warning 或 danger。未设置时使用所在 ButtonGroup 的值，最终默认为 primary。 | `Type`                                                        | `undefined`                                                            |
