**Props**

| Property | Description                                                      | Type      | Default                                        |
| -------- | ---------------------------------------------------------------- | --------- | ---------------------------------------------- |
| colorful | Colorful style, used as the default of the buttons in the group. | `boolean` | `semiGlobalDefault("ButtonGroup", "colorful")` |
| disabled | Disabled state, used as the default of the buttons in the group. | `boolean` | `semiGlobalDefault("ButtonGroup", "disabled")` |
| size     | Button size, used as the default of the buttons in the group.    | `Size`    | `semiGlobalDefault("ButtonGroup", "size")`     |
| theme    | Button theme, used as the default of the buttons in the group.   | `Theme`   | `semiGlobalDefault("ButtonGroup", "theme")`    |
| type     | Button type, used as the default of the buttons in the group.    | `Type`    | `semiGlobalDefault("ButtonGroup", "type")`     |
