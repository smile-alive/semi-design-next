**Props**

| Property | Description                                                      | Type      | Default |
| -------- | ---------------------------------------------------------------- | --------- | ------- |
| children | Buttons in the group.                                            | `Snippet` | -       |
| colorful | Colorful style, used as the default of the buttons in the group. | `boolean` | -       |
| disabled | Disabled state, used as the default of the buttons in the group. | `boolean` | -       |
| size     | Button size, used as the default of the buttons in the group.    | `Size`    | -       |
| theme    | Button theme, used as the default of the buttons in the group.   | `Theme`   | -       |
| type     | Button type, used as the default of the buttons in the group.    | `Type`    | -       |
