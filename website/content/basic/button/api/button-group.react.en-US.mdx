**Props**

| Property  | Description                                                      | Type                                                              | Default |
| --------- | ---------------------------------------------------------------- | ----------------------------------------------------------------- | ------- |
| children  | Buttons in the group.                                            | `React.ReactNode`                                                 | -       |

| colorful  | Colorful style, used as the default of the buttons in the group. | `boolean`                                                         | -       |

| style     | Style of the root element.                                       | `CSSProperties`                                                   | -       |
| theme     | Button theme, used as the default of the buttons in the group.   | `Theme`                                                           | -       |
| type      | Button type, used as the default of the buttons in the group.    | `Type`                                                            | -       |
