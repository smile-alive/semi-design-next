**Props**

| Property            | Description                                                                                                                                                                              | Type                                                                                          | Default    |
| ------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------- | ---------- |
| aria-label          | Accessible name of the button, needed when it shows only an icon.                                                                                                                        | `React.AriaAttributes['aria-label']`                                                          | -          |
| block               | Renders the button as a block-level button.                                                                                                                                              | `boolean`                                                                                     | `false`    |
| children            | Button text or content.                                                                                                                                                                  | `ReactNode`                                                                                   | -          |
| className           | Class name of the native button element.                                                                                                                                                 | `string`                                                                                      | -          |
| classNames          | Class names of the inner parts, keyed by `content` (the content area); merged with the built-in classes.                                                                                 | <ApiType detail={"Partial\u003cRecord\u003cButtonPart, string>>"}>Type</ApiType>              | -          |
| colorful            | Colorful button, supported for the primary and tertiary types only; the icon element receives the colorful fill. Falls back to the ButtonGroup it is in, and to `false` outside a group. | `boolean`                                                                                     | -          |
| disabled            | Disabled state, which takes precedence over loading. Falls back to the ButtonGroup it is in, and to `false` outside a group.                                                             | `boolean`                                                                                     | -          |
| htmlType            | Native type of the button: `button`, `reset` or `submit`.                                                                                                                                | `HtmlType`                                                                                    | `"button"` |
| icon                | Button icon.                                                                                                                                                                             | `React.ReactNode`                                                                             | -          |
| iconPosition        | Icon position: `left` or `right`.                                                                                                                                                        | `'left' \| 'right'`                                                                           | `"left"`   |
| id                  | Id of the native button element.                                                                                                                                                         | `string`                                                                                      | -          |
| loading             | Loading state. A loading button stays focusable, its onClick is ignored, and a submit button does not submit its form.                                                                   | `boolean`                                                                                     | `false`    |
| noHorizontalPadding | Removes horizontal padding: `true`, `left`, `right` or an array of both. Applies only to a button that shows an icon or the loading spinner.                                             | `boolean \| HorizontalPaddingType \| HorizontalPaddingType[]`                                 | `false`    |
| onClick             | Called when the button is clicked; not called while disabled or loading.                                                                                                                 | <ApiType detail={"React.MouseEventHandler\u003cHTMLButtonElement>"}>Type</ApiType>            | -          |
| onMouseDown         | Called when the mouse button is pressed on the button.                                                                                                                                   | <ApiType detail={"React.MouseEventHandler\u003cHTMLButtonElement>"}>Type</ApiType>            | -          |
| onMouseEnter        | Called when the pointer enters the button.                                                                                                                                               | <ApiType detail={"React.MouseEventHandler\u003cHTMLButtonElement>"}>Type</ApiType>            | -          |
| onMouseLeave        | Called when the pointer leaves the button.                                                                                                                                               | <ApiType detail={"React.MouseEventHandler\u003cHTMLButtonElement>"}>Type</ApiType>            | -          |
| ref                 | Reference to the native button element.                                                                                                                                                  | <ApiType detail={"React.Ref\u003cHTMLButtonElement>"}>Type</ApiType>                          | -          |
| size                | Button size: `large`, `default` or `small`. Falls back to the ButtonGroup it is in, and to `default` outside a group.                                                                    | `Size`                                                                                        | -          |
| style               | Style of the native button element.                                                                                                                                                      | `React.CSSProperties`                                                                         | -          |
| styles              | Inline styles of the inner parts, keyed like `classNames`.                                                                                                                               | <ApiType detail={"Partial\u003cRecord\u003cButtonPart, React.CSSProperties>>"}>Type</ApiType> | -          |
| theme               | Button theme: `solid`, `borderless`, `light` or `outline`. Falls back to the ButtonGroup it is in, and to `light` outside a group.                                                       | `Theme`                                                                                       | -          |
| type                | Button type: `primary`, `secondary`, `tertiary`, `warning` or `danger`. Falls back to the ButtonGroup it is in, and to `primary` outside a group.                                        | `Type`                                                                                        | -          |
