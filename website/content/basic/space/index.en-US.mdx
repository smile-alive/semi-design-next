### Basic Usage

<Demo id="basic" />

### Alignment

You can use `align` to set the alignment, optional: `start`, `center` (default), `end`, `baseline`.

<Demo id="align" />

### Spacing

You can use `spacing` to set the spacing size, optional: `tight` (8px, default), `medium` (16px), `loose` (24px), and allow to pass in number to customize the spacing size, and also support to pass in array to set the horizontal and vertical spacing at the same time.

<Demo id="spacing" />

### Direction

You can use `vertical` to set whether the spacing is vertical, the default is false.

<Demo id="vertical" />

### Wrap

When the spacing is horizontal, you can use `wrap` to set whether to wrap automatically, the default is false.

<Demo id="wrap" />

## API Reference

<Framework only="svelte">

Space renders `children` directly without wrapping them. `class`, `style` and other native attributes and listeners land on the root `div`. A numeric `spacing` is output in pixels, and `column-gap` or `row-gap` in the `style` string take precedence over it.

<SpaceSvelteApi />

</Framework>

<Framework only="vue">

Space renders its default slot directly without wrapping the children. `class`, `style` and other undeclared attributes fall through to the root element. A numeric `spacing` is output in pixels, and `columnGap` or `rowGap` in `style` take precedence over it.

<SpaceVueApi />

</Framework>

<Framework only="solid">

<SpaceSolidApi />

Space renders its children directly without wrapping them. `class`, `style`, `ref` and other native attributes and events fall through to the root `div`. A numeric `spacing` is output in pixels, and `column-gap` or `row-gap` in `style` take precedence over it.

</Framework>

<Framework only="react">

<SpaceReactApi />

Other native attributes (such as `id`, `aria-*`, `data-*` and `onClick`) fall through to the root `div`.

</Framework>
