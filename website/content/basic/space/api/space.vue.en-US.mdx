**Props**

| Property | Description                                                                                                          | Type                            | Default    |
| -------- | -------------------------------------------------------------------------------------------------------------------- | ------------------------------- | ---------- |
| wrap     | Whether to wrap automatically. Only applies to horizontal spacing.                                                   | `boolean`                       | `false`    |
| align    | Alignment: start, center, end or baseline.                                                                           | `Align`                         | `"center"` |
| vertical | Whether the spacing is vertical.                                                                                     | `boolean`                       | `false`    |
| spacing  | Spacing size: loose, medium, tight or a number of pixels. Pass a [horizontal, vertical] array to set each direction. | `Spacing \| [Spacing, Spacing]` | `"tight"`  |

| None  |             |                     |

**Slots**

| Slot    | Description            | Scope parameters |
| ------- | ---------------------- | ---------------- |
| default | Children to space out. | `any`            |
