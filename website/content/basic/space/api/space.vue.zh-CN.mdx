**Props**

| 属性     | 说明                                                                                         | 类型                            | 默认值                                     |
| -------- | -------------------------------------------------------------------------------------------- | ------------------------------- | ------------------------------------------ |
| wrap     | 是否自动换行，仅水平方向生效。                                                               | `boolean`                       | `semiDefault("Space", "wrap", false)`      |
| align    | 对齐方式，可选 start、center、end、baseline。                                                | `Align`                         | `semiDefault("Space", "align", "center")`  |
| vertical | 是否为垂直间距。                                                                             | `boolean`                       | `semiDefault("Space", "vertical", false)`  |
| spacing  | 间距尺寸，可选 loose、medium、tight 或数字（像素）；传入 [水平, 垂直] 数组分别设置两个方向。 | `Spacing \| [Spacing, Spacing]` | `semiDefault("Space", "spacing", "tight")` |
