**Props**

| 属性      | 说明                                                                                                 | 类型                                                              | 默认值     |
| --------- | ---------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------- | ---------- |
| align     | 对齐方式，可选 `start`、`center`、`end`、`baseline`。                                                | `Align`                                                           | `"center"` |
| children  | 子节点，直接渲染在根 `div` 内，不额外包裹元素。                                                      | `ReactNode`                                                       | -          |
| className | 根元素的类名。                                                                                       | `string`                                                          | -          |
| ref       | 根 `div` 元素的引用。                                                                                | <ApiType detail={"React.Ref\u003cHTMLDivElement>"}>Type</ApiType> | -          |
| spacing   | 间距尺寸，可选 `loose`、`medium`、`tight` 或数字（像素）；传入 `[水平, 垂直]` 数组分别设置两个方向。 | `Spacing \| [Spacing, Spacing]`                                   | `"tight"`  |
| style     | 根元素的内联样式，其中 `columnGap`、`rowGap` 优先于 `spacing` 中的数字间距。                         | `CSSProperties`                                                   | -          |
| vertical  | 是否为垂直间距。                                                                                     | `boolean`                                                         | `false`    |
| wrap      | 是否自动换行，仅水平方向生效。                                                                       | `boolean`                                                         | `false`    |
