## 图标列表

彩色图标集从对应图标包的 `/lab` 入口导入，随图标包一起提供，无需单独安装，不可改色。

### 自定义图标

可以使用自定义图标传入Icon组件。Icon组件支持 size、rotate、spin 等属性。

<Framework only="react">

React 使用 `svg` 属性传入自定义 SVG。

</Framework>

<Framework only="vue">

Vue 使用默认插槽传入自定义 SVG。`class`、`style`、`aria-*` 和原生事件监听器透传到外层 span；组件没有公开实例方法。

</Framework>

<Framework only="solid">

`svg` 属性接收组件而不是元素，Icon 会把 `fill` 传给该组件。

</Framework>

<Framework only="svelte">

Svelte 使用 `children` snippet 传入自定义 SVG，snippet 的参数 `{ fill }` 带着 Icon 的 `fill`，需要时可传给自定义 SVG。`class`、`style`、`aria-*` 和原生事件落在外层 span；不支持 `elementType` 与 ref。

</Framework>

<Framework only="react">

### 使用svgr将svg文件转成ReactComponent

如果 Semi 提供的图标不足以满足业务需求，你也可以通过@svgr/webpack引入自定义图标，并以React组件形式使用

```
// webpack.config.js
{
  test: /\.svg$/,
  use: ['@svgr/webpack'],
}

import { Icon } from '@fibrae/semi-ui-react';
import StarIcon from './star.svg';

<Icon svg={<StarIcon />} />
```

</Framework>

## Accessibility

### ARIA

- Icon 默认是装饰性的，带 `aria-hidden="true"`，读屏不会读到它。图标旁边已有文字，或图标在一个有名称的按钮里时，保持默认即可
- 图标本身传达信息时，传入 `aria-label`（或 `aria-labelledby`），此时 Icon 的 role 为 img
- 只有图标的按钮、链接，名称写在按钮或链接的 `aria-label` 上，不写在图标上
- 图标可聚焦时（例如直接作为 Tooltip 的触发元素）不会被隐藏，请为它传入 `aria-label`，Tooltip 的内容作为描述

<Demo id="aria" />

- 内置图标的 SVG 是装饰元素，带 `aria-hidden="true"`。自定义 SVG 也应设置该属性，由外层 Icon 提供名称。
