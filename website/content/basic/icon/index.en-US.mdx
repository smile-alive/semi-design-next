## Icon List

The default icon set includes filled, outlined, and AI icons. React uses `@fibrae/semi-icons-react`; Vue uses `@fibrae/semi-icons-vue`. Filled, outlined, and monochrome AI icons inherit the CSS `color` property. Bicolor and multicolor AI icons have default colors, which can be changed through `fill`.

The color icon set is imported from the `/lab` entry of the corresponding icon package. It ships with that package, requires no separate installation, and its colors cannot be changed.

### Size

> You can change the `font-size` to change the icon size

The Icon component encapsulates the size attribute, which makes it easier to define the icon size. It supports `extra-small` (8x8), `small` (12x12), `default` (16x16), `large` (20x20), `extra-large `(24x24), When size is specified as `inherit`, the icon size inherits the current context font size.

<Demo id="size" />

### Color

Monochrome icons inherit the container's CSS `color` property. You can also set the Icon's `style` to change its color.

Multicolor icons accept up to four colors. Set the colors through `fill`, which supports string and string[].

### Custom icon

You can use custom icons to pass in Icon components Icon component supports size, rotate, spin and other attributes

<Framework only="react">

React accepts custom SVG content through the `svg` prop.

</Framework>

<Framework only="vue">

Vue accepts custom SVG content through the default slot. `class`, `style`, `aria-*`, and native event listeners fall through to the outer span. The component exposes no instance methods.

</Framework>

<Framework only="solid">

The `svg` prop takes a component rather than an element, and Icon passes `fill` to it.

</Framework>

<Framework only="svelte">

Svelte accepts custom SVG content through the `children` snippet. The snippet's `{ fill }` argument carries the Icon's `fill`, which you can pass on to the custom SVG. `class`, `style`, `aria-*` and native events land on the outer span; `elementType` and refs are not supported.

</Framework>

<Demo id="custom" />

<Framework only="react">

### Use svgr to convert svg files into ReactComponent

If the icons provided by Semi are not enough to meet business needs, you can also introduce custom icons through @svgr/webpack and use them as React components

```
// webpack.config.js
{
  test: /\.svg$/,
  use: ['@svgr/webpack'],
}

import { Icon } from '@fibrae/semi-ui-react';
import StarIcon from './star.svg';

<Icon svg={<StarIcon />} />
```

</Framework>

## Accessibility

### ARIA

- An Icon is decorative by default and has `aria-hidden="true"`, so screen readers skip it. Keep the default when text sits next to the icon, or when the icon is inside a named button
- When the icon itself conveys information, pass `aria-label` (or `aria-labelledby`); the Icon then has the img role
- For a button or link that only holds an icon, set `aria-label` on the button or link rather than the icon
- A focusable icon (e.g. used directly as a Tooltip trigger) is not hidden; give it an `aria-label`, and the Tooltip content serves as its description

<Demo id="aria" />

- Built-in SVG icons have `aria-hidden="true"`. Set the same attribute on custom SVG content, and give the outer Icon its accessible name.
