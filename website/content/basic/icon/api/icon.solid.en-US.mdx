**Props**

| Property  | Description                                                                                                    | Type                                                                   | Default  |
| --------- | -------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------- | -------- |
| fill      | Fill colors for bicolor and multicolor icons, as a string or an array of strings.                              | `IconFill`                                                             | -        |
| prefixCls | CSS class prefix; build plugins can replace it.                                                                | `string`                                                               | `"semi"` |
| rotate    | Rotation angle in integer degrees.                                                                             | `number`                                                               | -        |
| size      | Icon size: extra-small, small, default, large, extra-large or inherit, which uses the surrounding font size.   | `IconSize`                                                             | -        |
| spin      | Enables the spinning animation.                                                                                | `boolean`                                                              | `false`  |
| svg       | A custom SVG component, passed as a component rather than an element. Icon renders it and passes `fill` to it. | <ApiType detail={"Component\u003c{ fill?: IconFill }>"}>Type</ApiType> | -        |
| type      | Adds an icon type class name.                                                                                  | `string`                                                               | -        |
