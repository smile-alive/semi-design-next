**Props**

| Property  | Description                                                     | Type                 | Default             |
| --------- | --------------------------------------------------------------- | -------------------- | ------------------- |
| size      | Icon size; inherit uses the surrounding font size.              | `IconSize`           | `"default"`         |
| spin      | Enables the spinning animation.                                 | `boolean`            | `false`             |
| rotate    | Rotation angle in integer degrees.                              | `number`             | `undefined`         |
| prefixCls | CSS class prefix, initially semi; build plugins can replace it. | `string`             | `BASE_CLASS_PREFIX` |
| type      | Adds an icon type class name.                                   | `string`             | `undefined`         |
| fill      | Fill colors for bicolor and multicolor icons.                   | `string \| string[]` | `undefined`         |
