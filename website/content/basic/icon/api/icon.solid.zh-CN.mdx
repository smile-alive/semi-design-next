**Props**

| 属性      | 说明                                                                                                    | 类型                                                                   | 默认值   |
| --------- | ------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------- | -------- |
| fill      | 双色、多色图标的填充颜色，支持字符串或字符串数组。                                                      | `IconFill`                                                             | -        |
| prefixCls | CSS 类名前缀，可由构建插件改写。                                                                        | `string`                                                               | `"semi"` |
| rotate    | 旋转角度，使用整数（单位为度）。                                                                        | `number`                                                               | -        |
| size      | 图标尺寸，可选 extra-small、small、default、large、extra-large 或 inherit，inherit 继承上下文字体大小。 | `IconSize`                                                             | -        |
| spin      | 启用旋转动画。                                                                                          | `boolean`                                                              | `false`  |
| svg       | 自定义 SVG 组件，传入组件而不是元素。Icon 渲染该组件时传入 `fill`。                                     | <ApiType detail={"Component\u003c{ fill?: IconFill }>"}>Type</ApiType> | -        |
| type      | 附加图标类型类名。                                                                                      | `string`                                                               | -        |
