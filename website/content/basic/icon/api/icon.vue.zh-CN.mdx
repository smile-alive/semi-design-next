**Props**

| 属性      | 说明                                        | 类型                 | 默认值              |
| --------- | ------------------------------------------- | -------------------- | ------------------- |
| size      | 图标尺寸；inherit 继承上下文字体大小。      | `IconSize`           | `"default"`         |
| spin      | 启用旋转动画。                              | `boolean`            | `false`             |
| rotate    | 旋转角度，使用整数。                        | `number`             | `undefined`         |
| prefixCls | CSS 类名前缀，默认 semi，可由构建插件改写。 | `string`             | `BASE_CLASS_PREFIX` |
| type      | 附加图标类型类名。                          | `string`             | `undefined`         |
| fill      | 双色、多色图标的填充颜色。                  | `string \| string[]` | `undefined`         |
