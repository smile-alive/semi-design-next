### With Children

<Framework only="vue">

The content of a horizontal divider is passed through the default slot; a vertical divider shows no content.

</Framework>

<Framework only="solid">

The content of a horizontal divider is passed through `children`; a vertical divider shows no content.

</Framework>

<Framework only="svelte">

The content of a horizontal divider is written inside the tag (`children`); a vertical divider shows no content. For a horizontal divider with content, the content is always wrapped in `semi-divider_inner-text`, whether it is plain text or an element.

</Framework>

## API Reference

<Framework only="react">

<DividerReactApi />

`id`, `onClick`, `role`, `aria-*` and other native attributes land on the root element. The default `role` is `separator`, which is not set when the divider has content; a `role` you pass overrides the default.

</Framework>

<Framework only="svelte">

<DividerSvelteApi />

`class`, `style` and other native attributes land on the root element; `style` comes after `margin`, so your value wins. The default `role` is `separator`, which is not set when the divider has content; a `role` you pass overrides the default.

</Framework>

<Framework only="vue">

<DividerVueApi />

`class`, `style` and native attributes passed as attrs land on the root element; the default `separator` role can be overridden with `role`.

</Framework>

<Framework only="solid">

<DividerSolidApi />

`class`, `style`, `ref` and native attributes (such as `role` and `aria-*`) land on the root element. The default `role` is `separator`, which is not set when the divider has content; a `role` you pass overrides the default.

</Framework>
