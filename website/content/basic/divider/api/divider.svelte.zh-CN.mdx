**Props**

| 属性     | 说明                                                         | 类型                            | 默认值         |
| -------- | ------------------------------------------------------------ | ------------------------------- | -------------- |
| align    | 带内容时内容的对齐方式，可选 left、center、right。           | `'left' \| 'right' \| 'center'` | `"center"`     |
| children | 水平分割线的内容；垂直分割线不显示内容。                     | `Snippet`                       | -              |
| dashed   | 是否为虚线。                                                 | `boolean`                       | -              |
| layout   | 分割线方向，可选 horizontal 或 vertical。                    | `'horizontal' \| 'vertical'`    | `"horizontal"` |
| margin   | 分割线上下 margin，垂直方向时为左右 margin；数字按像素处理。 | `number \| string`              | -              |
