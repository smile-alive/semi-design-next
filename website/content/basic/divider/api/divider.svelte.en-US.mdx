**Props**

| Property | Description | Type | Default |

| align | Alignment of the content: left, center or right. | `'center' \| 'left' \| 'right'` | `"center"` |
| children | Content of a horizontal divider. A vertical divider shows no content. | `Snippet` | - |

| dashed | Whether the line is dashed. | `boolean` | - |
| layout | Direction of the divider: horizontal or vertical. | `'horizontal' \| 'vertical'` | `"horizontal"` |
| margin | Margin above and below the divider, or left and right when vertical. A number is in pixels. | `number \| string` | - |
| styles | Inline styles of the inner parts, as strings, keyed like classNames. | <ApiType detail={"Partial\u003cRecord\u003cDividerPart, string>>"}>Type</ApiType> | - |
