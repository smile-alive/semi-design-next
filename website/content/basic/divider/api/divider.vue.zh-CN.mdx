**Props**

| 属性       | 说明                                                                                                           | 类型                                                                                  | 默认值                                       |
| ---------- | -------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------- | -------------------------------------------- |
| align      | 带内容时内容的对齐方式，可选 left、center、right。                                                             | `"center" \| "left" \| "right"`                                                       | `"center"`                                   |
| classNames | 内部各部位的类名，键为 content（中间的文字，仅当内容全是文本时渲染），值的写法同 class，与组件自带的类名合并。 | <ApiType detail={"Partial\u003cRecord\u003c\"content\", ClassValue>>"}>Type</ApiType> | `semiGlobalDefault("Divider", "classNames")` |
| dashed     | 是否为虚线。                                                                                                   | `boolean`                                                                             | `semiGlobalDefault("Divider", "dashed")`     |
| layout     | 分割线方向，可选 horizontal 或 vertical。                                                                      | `"horizontal" \| "vertical"`                                                          | `"horizontal"`                               |
| margin     | 分割线上下 margin，垂直方向时为左右 margin；数字按像素处理。                                                   | `string \| number`                                                                    | `semiGlobalDefault("Divider", "margin")`     |
| styles     | 内部各部位的内联样式，键同 classNames。                                                                        | <ApiType detail={"Partial\u003cRecord\u003c\"content\", StyleValue>>"}>Type</ApiType> | `semiGlobalDefault("Divider", "styles")`     |
