**Props**

| Property | Description                                                                                 | Type                            | Default                                          |
| -------- | ------------------------------------------------------------------------------------------- | ------------------------------- | ------------------------------------------------ |
| align    | Alignment of the content: left, center or right.                                            | `"left" \| "right" \| "center"` | `semiDefault("Divider", "align", "center")`      |
| margin   | Margin above and below the divider, or left and right when vertical. A number is in pixels. | `string \| number`              | `semiGlobalDefault("Divider", "margin")`         |
| dashed   | Whether the line is dashed.                                                                 | `boolean`                       | `semiGlobalDefault("Divider", "dashed")`         |
| layout   | Direction of the divider: horizontal or vertical.                                           | `"vertical" \| "horizontal"`    | `semiDefault("Divider", "layout", "horizontal")` |
