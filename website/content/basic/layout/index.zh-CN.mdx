## 概述

- `Layout`：布局容器，其下可嵌套 `Header` `Sider` `Content` `Footer` 或 `Layout` 本身，可以放在任何父容器中。
- `Header`：顶部布局，其下可嵌套任何元素，只能放在 `Layout` 中。
- `Sider`：侧边栏，其下可嵌套任何元素，只能放在 `Layout` 中。
- `Content`：内容部分，其下可嵌套任何元素，只能放在 `Layout` 中。
- `Footer`：底部布局，其下可嵌套任何元素，只能放在 `Layout` 中。

<Notice title="注意事项">
    1、布局组件采用 Flex 布局实现，无法在非现代浏览器中工作 <br />
    2、Layout 组件仅会帮你实现布局，但不会附带背景色、文本色、宽高度等样式。你可以根据自己实际需求传入 style 或给定特定类名另行编写 css 实现
</Notice>

## Accessibility

### ARIA

- Sider 渲染 `aside`，可传入 `aria-label` 描述该 Sider 的作用。
- Header、Footer 默认渲染 `header`、`footer`，位于 Layout 的 `section` 内时不会成为 banner、contentinfo 地标；作为整页的页头、页脚时传入 `role="banner"`、`role="contentinfo"`。
- Content 默认渲染 `main`，一个页面只应有一个 `main`；嵌套使用时可通过 `tagName` 换成其他标签。
- Header、Content、Footer 可传入 `role`、`aria-label` 描述对应元素的作用。
