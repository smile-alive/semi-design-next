**Props**

| 属性       | 说明                                                                     | 类型           | 默认值              |
| ---------- | ------------------------------------------------------------------------ | -------------- | ------------------- |
| prefixCls  | 类名前缀。                                                               | `string`       | `cssClasses.PREFIX` |
| breakpoint | 触发响应式布局的断点，可选 xs、sm、md、lg、xl、xxl。仅在挂载时读取一次。 | `Breakpoint[]` | `undefined`         |

**Events**

| 事件       | 说明                                                                                                 | 回调参数                               |
| ---------- | ---------------------------------------------------------------------------------------------------- | -------------------------------------- |
| breakpoint | 挂载时对 breakpoint 中的每个断点按当前视口触发一次，之后在命中或离开时触发，参数为断点名与是否命中。 | `[screen: Breakpoint, match: boolean]` |

**Slots**

| 插槽    | 说明           | 作用域参数 |
| ------- | -------------- | ---------- |
| default | 侧边栏的内容。 | `any`      |

**Exposes**

| 名称 | 说明 | 类型 |
| ---- | ---- | ---- |
| 无   |      |      |
