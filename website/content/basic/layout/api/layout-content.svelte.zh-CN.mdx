**Props**

| 属性      | 说明                     | 类型                          | 默认值          |
| --------- | ------------------------ | ----------------------------- | --------------- |
| children  | 内容区域的内容。         | `Snippet`                     | -               |
| prefixCls | 类名前缀。               | `string`                      | `"semi-layout"` |
| tagName   | 根元素的标签名。         | `keyof HTMLElementTagNameMap` | `"main"`        |
| type      | 内部使用，决定类名后缀。 | `string`                      | `"content"`     |
