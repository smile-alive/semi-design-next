**Props**

| Property  | Description                                                                                                                                                                                                                                                 | Type                          | Default         |
| --------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------- | --------------- |
| hasSider  | Indicates that a Sider is inside; usually not needed. A Sider registers with the nearest Layout when it is created, so the has-sider class is present on the first frame, including SSR. Passing false cannot remove the has-sider class that a Sider adds. | `boolean`                     | -               |
| prefixCls | Class name prefix.                                                                                                                                                                                                                                          | `string`                      | `"semi-layout"` |
| tagName   | Tag name of the root element.                                                                                                                                                                                                                               | `keyof HTMLElementTagNameMap` | `"section"`     |
