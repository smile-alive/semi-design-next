**Props**

| Property | Description | Type | Default |
| --- | --- | --- | --- |
| prefixCls | Class name prefix. | `string` | `semiDefault("Layout", "prefixCls", cssClasses.PREFIX)` |
| tagName | Tag name of the root element. | `keyof HTMLElementTagNameMap` | `semiDefault("Layout", "tagName", "section")` |
| hasSider | Indicates that a Sider is inside. A Sider among the direct children is detected automatically; a deeper one registers after mount, so pass true during server rendering to avoid style flashing. Passing false cannot remove the has-sider class that a Sider adds. | `boolean` | `semiGlobalDefault("Layout", "hasSider")` |
