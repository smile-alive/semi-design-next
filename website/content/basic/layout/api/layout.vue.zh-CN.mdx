**Props**

| 属性      | 说明                                                                                                                                                                      | 类型                          | 默认值                                                  |
| --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------- | ------------------------------------------------------- |
| prefixCls | 类名前缀。                                                                                                                                                                | `string`                      | `semiDefault("Layout", "prefixCls", cssClasses.PREFIX)` |
| tagName   | 根元素的标签名。                                                                                                                                                          | `keyof HTMLElementTagNameMap` | `semiDefault("Layout", "tagName", "section")`           |
| hasSider  | 表示子元素里有 Sider。直接子节点中的 Sider 会自动识别；嵌套更深的 Sider 在挂载后才登记，服务端渲染时传 true 可避免样式闪动。传 false 不能去掉 Sider 带来的 has-sider 类。 | `boolean`                     | `semiGlobalDefault("Layout", "hasSider")`               |
