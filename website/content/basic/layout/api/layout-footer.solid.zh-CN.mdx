**Props**

| 属性      | 说明                                      | 类型                          | 默认值 |
| --------- | ----------------------------------------- | ----------------------------- | ------ |
| prefixCls | 类名前缀，默认为 `semi-layout`。          | `string`                      | -      |
| tagName   | 根元素的标签名，默认为 `footer`。         | `keyof HTMLElementTagNameMap` | -      |
| type      | 内部使用，决定类名后缀，默认为 `footer`。 | `string`                      | -      |
