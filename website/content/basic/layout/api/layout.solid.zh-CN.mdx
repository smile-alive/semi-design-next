**Props**

| 属性      | 说明                                                                                                                                                   | 类型                          | 默认值          |
| --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------- | --------------- |
| hasSider  | 表示子元素里有 Sider，一般不用指定。Sider 在创建时向最近的 Layout 登记，首帧（含 SSR）即带 has-sider 类。传 false 不能去掉 Sider 带来的 has-sider 类。 | `boolean`                     | -               |
| prefixCls | 类名前缀。                                                                                                                                             | `string`                      | `"semi-layout"` |
| tagName   | 根元素的标签名。                                                                                                                                       | `keyof HTMLElementTagNameMap` | `"section"`     |
