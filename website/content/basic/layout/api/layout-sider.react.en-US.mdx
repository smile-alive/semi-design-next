**Props**

| Property     | Description                                                                                                                                                                 | Type                                                                                     | Default         |
| ------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------- | --------------- |
| aria-label   | Accessible name of the sider, describing what it is for.                                                                                                                    | `React.AriaAttributes['aria-label']`                                                     | -               |
| breakpoint   | Breakpoints that trigger the responsive layout: `xs`, `sm`, `md`, `lg`, `xl` or `xxl`. Read once at mount.                                                                  | <ApiType detail={"Array\u003ckeyof ResponsiveMap>"}>Type</ApiType>                       | -               |
| children     | Sider content, rendered inside a `div` wrapped by the root element.                                                                                                         | `React.ReactNode`                                                                        | -               |
| className    | Class name of the root element.                                                                                                                                             | `string`                                                                                 | -               |
| onBreakpoint | Called with the breakpoint name and whether it matches: once for each breakpoint in `breakpoint` at mount with the current viewport, then whenever a match starts or stops. | <ApiType detail={"(screen: keyof ResponsiveMap, match: boolean) => void"}>Type</ApiType> | -               |
| prefixCls    | Class name prefix.                                                                                                                                                          | `string`                                                                                 | `"semi-layout"` |
| ref          | Reference to the root `aside` element.                                                                                                                                      | <ApiType detail={"React.Ref\u003cHTMLElement>"}>Type</ApiType>                           | -               |
| role         | `role` of the root `aside` element.                                                                                                                                         | `React.AriaRole`                                                                         | -               |
| style        | Style of the root element.                                                                                                                                                  | `CSSProperties`                                                                          | -               |
