**Props**

| 属性       | 说明                                                                                                                      | 类型               | 默认值      |
| ---------- | ------------------------------------------------------------------------------------------------------------------------- | ------------------ | ----------- |
| badge      | 徽章参数，同 Badge 的 props（不含 children）；class、style 以及 onclick、onmouseenter、onmouseleave 落在 Badge 根元素上。 | `FloatButtonBadge` | -           |
| badgeCount | 自定义徽章内容的 snippet，代替 badge.count。                                                                              | `Snippet`          | -           |
| colorful   | 多彩悬浮按钮。                                                                                                            | `boolean`          | `false`     |
| disabled   | 禁用状态。                                                                                                                | `boolean`          | `false`     |
| href       | 链接地址，设置后渲染为 a；禁用时去掉 href。                                                                               | `string`           | -           |
| icon       | 按钮图标的 snippet。                                                                                                      | `Snippet`          | -           |
| rel        | 与链接目标的关系，仅在设置 href 时生效。                                                                                  | `string`           | -           |
| shape      | 形状，可选 round、square。                                                                                                | `FloatButtonShape` | `"round"`   |
| size       | 尺寸，可选 default、small、large。                                                                                        | `FloatButtonSize`  | `"default"` |
| target     | 指定在何处显示链接的 URL，仅在设置 href 时生效。                                                                          | `string`           | -           |
