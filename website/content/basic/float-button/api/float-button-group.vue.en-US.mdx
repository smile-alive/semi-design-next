import ApiType from '#/components/ApiType.astro';

**Props**

| Property   | Description                                                                                                                                        | Type                                                                               | Default                                               |
| ---------- | -------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------- | ----------------------------------------------------- |
| classNames | Class names of the inner parts, keyed by `item`; merged with the built-in classes. `item` is each button; an item's own class name comes after it. | <ApiType detail={"Partial\u003cRecord\u003c\"item\", ClassValue>>"}>Type</ApiType> | `semiGlobalDefault("FloatButtonGroup", "classNames")` |
| disabled   | Disables every item.                                                                                                                               | `boolean`                                                                          | `false`                                               |
| items      | List of items.                                                                                                                                     | `FloatButtonGroupItem[]`                                                           | `undefined`                                           |
| styles     | Inline styles of the inner parts, keyed like `classNames`; an item's own style is applied after it.                                                | <ApiType detail={"Partial\u003cRecord\u003c\"item\", StyleValue>>"}>Type</ApiType> | `semiGlobalDefault("FloatButtonGroup", "styles")`     |

**Events**

| Event | Description                                                                                                                                        | Callback parameters                               |
| ----- | -------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------- |
| click | Emitted when an enabled item is clicked, with the item's value (undefined if unset) and the native click event. The item's own onClick runs first. | `[value: string \| undefined, event: MouseEvent]` |

**Slots**

| Slot       | Description                                                                    | Scope parameters                |
| ---------- | ------------------------------------------------------------------------------ | ------------------------------- |
| badgeCount | Custom badge content of an item, receiving item and index.                     | `FloatButtonGroupItemSlotProps` |
| content    | Custom content of an item, receiving item and index. Defaults to item.content. | `FloatButtonGroupItemSlotProps` |
| icon       | Icon of an item, receiving item and index.                                     | `FloatButtonGroupItemSlotProps` |
