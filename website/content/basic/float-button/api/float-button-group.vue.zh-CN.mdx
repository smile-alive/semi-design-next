**Props**

| 属性       | 说明                                                                                                 | 类型                                                                               | 默认值                                                |
| ---------- | ---------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------- | ----------------------------------------------------- |
| classNames | 内部各部位的类名，键为 `item`，与组件自带的类名合并；`item` 是每个按钮，单个子项自己的类名排在其后。 | <ApiType detail={"Partial\u003cRecord\u003c\"item\", ClassValue>>"}>Type</ApiType> | `semiGlobalDefault("FloatButtonGroup", "classNames")` |
| disabled   | 禁用全部子项。                                                                                       | `boolean`                                                                          | `false`                                               |
| items      | 子项列表。                                                                                           | `FloatButtonGroupItem[]`                                                           | `undefined`                                           |
| styles     | 内部各部位的内联样式，键同 `classNames`；单个子项自己的样式后写。                                    | <ApiType detail={"Partial\u003cRecord\u003c\"item\", StyleValue>>"}>Type</ApiType> | `semiGlobalDefault("FloatButtonGroup", "styles")`     |

**Events**

| 事件  | 说明                                                                                                               | 回调参数                                          |
| ----- | ------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------- |
| click | 点击未禁用子项时触发，载荷为子项的 value（未设置时为 undefined）与原生 click 事件；子项自己的 onClick 先于它调用。 | `[value: string \| undefined, event: MouseEvent]` |

**Slots**

| 插槽       | 说明                                                            | 作用域参数                      |
| ---------- | --------------------------------------------------------------- | ------------------------------- |
| badgeCount | 自定义子项徽章内容，接收 item 与 index。                        | `FloatButtonGroupItemSlotProps` |
| content    | 自定义子项文本内容，接收 item 与 index；缺省渲染 item.content。 | `FloatButtonGroupItemSlotProps` |
| icon       | 子项图标，接收 item 与 index。                                  | `FloatButtonGroupItemSlotProps` |
