**Props**

| Property   | Description                                                                                                                                    | Type                                                                               | Default                                          |
| ---------- | ---------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------- | ------------------------------------------------ |
| badge      | Badge props, same as Badge. class, style, onClick, onMouseenter and onMouseleave reach the Badge root element.                                 | `FloatButtonBadge`                                                                 | `semiGlobalDefault("FloatButton", "badge")`      |
| classNames | Class names of the inner parts, keyed by `body`; merged with the built-in classes. `body` is the visible body of the button, holding the icon. | <ApiType detail={"Partial\u003cRecord\u003c\"body\", ClassValue>>"}>Type</ApiType> | `semiGlobalDefault("FloatButton", "classNames")` |
| colorful   | Colorful float button.                                                                                                                         | `boolean`                                                                          | `false`                                          |
| disabled   | Disabled state.                                                                                                                                | `boolean`                                                                          | `false`                                          |
| href       | Link address. Renders an a element when set; a disabled link drops it.                                                                         | `string`                                                                           | `semiGlobalDefault("FloatButton", "href")`       |
| rel        | Relationship to the link target. Only takes effect with href.                                                                                  | `string`                                                                           | `semiGlobalDefault("FloatButton", "rel")`        |
| shape      | Shape: round or square.                                                                                                                        | `"round" \| "square"`                                                              | `"round"`                                        |
| size       | Size: default, small or large.                                                                                                                 | `"default" \| "large" \| "small"`                                                  | `"default"`                                      |
| styles     | Inline styles of the inner parts, keyed like `classNames`.                                                                                     | <ApiType detail={"Partial\u003cRecord\u003c\"body\", StyleValue>>"}>Type</ApiType> | `semiGlobalDefault("FloatButton", "styles")`     |
| target     | Where to display the linked URL. Only takes effect with href.                                                                                  | `string`                                                                           | `semiGlobalDefault("FloatButton", "target")`     |

**Events**

| Event | Description                                                               | Callback parameters   |
| ----- | ------------------------------------------------------------------------- | --------------------- |
| click | Emitted on click with the native click event. Not emitted while disabled. | `[event: MouseEvent]` |

**Slots**

| Slot       | Description                                    | Scope parameters |
| ---------- | ---------------------------------------------- | ---------------- |
| badgeCount | Custom badge content, in place of badge.count. | `any`            |
| icon       | Button icon.                                   | `any`            |
