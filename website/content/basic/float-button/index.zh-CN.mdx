### 悬浮按钮组

## API参考

<Framework only="react">

### FloatButton

<FloatButtonReactApi />

其他原生属性（如 `id`、`aria-label`、`title`）经 `...rest` 落在根元素上：设置 `href` 时为 `<a>`，否则为 `<button type="button">`。

### FloatButtonGroupItem

在 FloatButtonProps 基础上增加以下参数。子项的 `href`、`target`、`rel`、`disabled`、`onClick`、`className`、`style`、`ref` 与 FloatButton 含义相同；`shape`、`size`、`colorful` 与单个 FloatButton 的同名属性效果相同（子项带 `semi-floatButton-{shape}`、`semi-floatButton-{size}`、`semi-floatButton-colorful` 类名），设置 `size` 时子项为该尺寸的固定宽高。

| 属性       | 说明                                       | 类型      | 默认值 |
| ---------- | ------------------------------------------ | --------- | ------ |
| aria-label | 子项的可访问名称，只有图标没有文本时必须传 | string    | -      |
| content    | 文本内容                                   | ReactNode | -      |
| value      | item 的标识，作为 `onClick` 的第一个参数   | string    | -      |

### FloatButtonGroup

<FloatButtonGroupReactApi />

其他原生属性（如 `id`、`aria-*`）落在根元素 `div` 上，根元素默认的 `role` 为 `group`。

</Framework>

<Framework only="vue">

### FloatButton

<FloatButtonVueApi />

`class`、`style` 与原生属性经 attrs 传入，落在根元素上：设置 `href` 时为 `<a>`，否则为 `<button>`。`click` 声明为事件，会遮住根元素的原生 click 监听，禁用时不触发。按钮分支的 `type="button"` 与 `aria-disabled` 不可被 attrs 覆盖，链接分支丢弃传入的 `type`。`:style` 中的数字不会自动补 px，需写成字符串。

### FloatButtonGroupItem

在 FloatButton 的 props 基础上增加以下参数。子项的 `href`、`target`、`rel`、`disabled`、`class`、`style` 与 FloatButton 含义相同，`onClick` 等监听器写在数据里；`shape`、`size`、`colorful` 与单个 FloatButton 的同名属性效果相同，设置 `size` 时子项为该尺寸的固定宽高。不支持子项的 `ref`。

| 属性          | 说明                                            | 类型                        | 默认值 |
| ------------- | ----------------------------------------------- | --------------------------- | ------ |
| aria-label    | 子项的可访问名称，只有图标没有文本时必须传      | string                      | -      |
| class         | 类名                                            | string \| object \| array   | -      |
| content       | 文本内容，更丰富的内容用 `#content` 插槽        | string \| number            | -      |
| data-\*       | 自定义数据属性                                  | string                      | -      |
| id            | 元素 id                                         | string                      | -      |
| onClick       | 点击回调，先于 FloatButtonGroup 的 `click` 调用 | (event: MouseEvent) => void | -      |
| onContextmenu | 右键菜单回调                                    | (event: MouseEvent) => void | -      |
| onMouseenter  | 指针进入回调                                    | (event: MouseEvent) => void | -      |
| onMouseleave  | 指针离开回调                                    | (event: MouseEvent) => void | -      |
| style         | 样式                                            | string \| object \| array   | -      |
| title         | 原生 title 属性                                 | string                      | -      |
| value         | item 的标识，作为 `click` 事件的第一个载荷      | string                      | -      |

### FloatButtonGroup

<FloatButtonGroupVueApi />

`class`、`style` 与原生属性（如 `aria-*`）经 attrs 落在根元素（`role="group"`）上。`items` 中的 `icon`、节点型 `content` 与节点型 `badge.count` 分别用 `#icon`、`#content`、`#badgeCount` 作用域插槽提供，参数为 `{ item, index }`。

</Framework>

## Accessibility

### ARIA

- FloatButton 与 FloatButtonGroup 的每个子项都是原生元素：设置 `href` 时为链接 `<a>`，否则为按钮 `<button type="button">`，读屏软件会读出对应的角色
- 可访问名称取自 `aria-label`，没有时取可见文本（子项的 `content`）。FloatButton 通常只有图标，请务必传入 `aria-label` 描述按钮的作用，例如 `aria-label="回到顶部"`；只有图标的子项同样需要在子项上传入 `aria-label`
- 徽标（`badge.count`）显示的文字也是按钮可见文本的一部分，`aria-label` 会覆盖它，因此请把徽标文字写进 `aria-label`，例如 `aria-label="AI 编辑，VIP"`，让语音输入用户能用看到的文字操作按钮
- 禁用的按钮使用原生 `disabled` 并带 `aria-disabled="true"`。链接没有原生禁用状态，禁用的链接会去掉 `href`（无法点击、中键或右键打开，也不在 Tab 顺序中），同时设置 `role="link"` 与 `aria-disabled="true"`，读屏软件仍将其读作不可用的链接
- FloatButtonGroup 的根元素是 `role="group"`，可通过 `aria-label` 或 `aria-labelledby` 给整组命名（`aria-*` 透传到根元素）
- FloatButtonGroup 没有选中态，子项不使用 `aria-pressed`

### 键盘和焦点

- 焦点管理与原生按钮、链接一致：可以使用 Tab 及 Shift + Tab 切换焦点，禁用的项不可聚焦
- 按钮聚焦时可以通过 Enter 或 Space 键激活，链接聚焦时可以通过 Enter 键打开
- 键盘聚焦时显示聚焦轮廓
