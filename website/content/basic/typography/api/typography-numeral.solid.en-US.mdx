**Props**

| Property  | Description                                                                                                                                                                                                                    | Type                                                         | Default |
| --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------ | ------- |
| code      | Whether the text is wrapped in a code element.                                                                                                                                                                                 | `boolean`                                                    | -       |
| component | Element to render: a tag name or a component. Defaults to span; use div when the content has block elements such as p.                                                                                                         | `ValidComponent`                                             | -       |
| copyable  | Whether the text can be copied; pass an object for the Copyable Config.                                                                                                                                                        | `CopyableConfig \| boolean`                                  | -       |
| delete    | Adds a strikethrough.                                                                                                                                                                                                          | `boolean`                                                    | -       |
| disabled  | Disables the text.                                                                                                                                                                                                             | `boolean`                                                    | -       |
| icon      | Prefix icon, an element or an icon component; an icon component receives the size the text implies.                                                                                                                            | `TypographyIcon`                                             | -       |
| link      | Whether the text is a link; with an object, its attributes (href, target, class, style, onClick and so on) are applied to the a element.                                                                                       | `LinkType`                                                   | -       |
| mark      | Adds a highlight.                                                                                                                                                                                                              | `boolean`                                                    | -       |
| parser    | Custom number parser.                                                                                                                                                                                                          | <ApiType detail={"(value: string) => string"}>Type</ApiType> | -       |
| precision | Number of decimal places to keep. Defaults to 0.                                                                                                                                                                               | `number`                                                     | -       |
| rule      | Parsing rule: text only rounds, numbers filters out non-numeric characters, bytes-decimal and bytes-binary convert byte units, percentages converts to percent, exponential converts to scientific notation. Defaults to text. | `TypographyBaseRule`                                         | -       |
| size      | Text size; inherit takes the size of the enclosing Text or Paragraph. Defaults to normal.                                                                                                                                      | `TypographyBaseSize`                                         | -       |
| strong    | Whether the text is bold.                                                                                                                                                                                                      | `boolean`                                                    | -       |
| truncate  | How the kept decimals are rounded, matching Math.round, Math.ceil and Math.floor. Defaults to round.                                                                                                                           | `TypographyBaseTruncate`                                     | -       |
| type      | Text type. Defaults to primary.                                                                                                                                                                                                | `TypographyBaseType`                                         | -       |
| underline | Adds an underline.                                                                                                                                                                                                             | `boolean`                                                    | -       |
