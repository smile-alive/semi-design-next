**Props**

| 属性      | 说明                                                                                      | 类型                        | 默认值 |
| --------- | ----------------------------------------------------------------------------------------- | --------------------------- | ------ |
| component | 自定义渲染元素，可以是标签名或组件，默认 p。                                              | `ValidComponent`            | -      |
| copyable  | 是否可复制；传对象时见 Copyable Config。                                                  | `CopyableConfig \| boolean` | -      |
| delete    | 添加删除线样式。                                                                          | `boolean`                   | -      |
| disabled  | 禁用文本。                                                                                | `boolean`                   | -      |
| ellipsis  | 设置自动溢出省略；传对象时见 Ellipsis Config。                                            | `Ellipsis \| boolean`       | -      |
| link      | 是否为链接；传对象时，其中的属性（href、target、class、style、onClick 等）挂在 a 元素上。 | `LinkType`                  | -      |
| mark      | 添加标记样式。                                                                            | `boolean`                   | -      |
| size      | 文本大小，inherit 继承外层 Text 或 Paragraph 的尺寸，默认 normal。                        | `TypographyBaseSize`        | -      |
| spacing   | 行距，extended 为更宽松的行距，默认 normal。                                              | `TypographyBaseSpacing`     | -      |
| strong    | 是否加粗。                                                                                | `boolean`                   | -      |
| type      | 文本类型，默认 primary。                                                                  | `TypographyBaseType`        | -      |
| underline | 添加下划线样式。                                                                          | `boolean`                   | -      |
