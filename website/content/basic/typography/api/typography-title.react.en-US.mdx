**Props**

| Property | Description | Type | Default |
| --- | --- | --- | --- |
| component | Tag name or component the root element renders as. Defaults to the `h1` to `h6` matching `heading`. | `React.ElementType` | - |
| copyable | Whether the text can be copied; pass an object to configure it, see Copyable Config. | `CopyableConfig \| boolean` | - |
| delete | Adds a strikethrough. | `boolean` | - |
| disabled | Disables the text. A link renders as a `span` that keeps only its style. | `boolean` | - |
| ellipsis | Truncates overflowing text; pass an object to configure it, see Ellipsis Config. | `Ellipsis \| boolean` | - |
| heading | Heading level, matching `h1` to `h6`. | `1 \| 2 \| 3 \| 4 \| 5 \| 6` | `1` |
| link | Whether the text is a link. With an object, its attributes (`href`, `target`, `className`, `style`, `onClick` and so on) are applied to the inner `a` element. When disabled, only `className` and `style` are kept. | `LinkType` | - |
| mark | Adds a highlight. | `boolean` | - |
| ref | Reference to the root element. | <ApiType detail={"React.Ref\u003cHTMLHeadingElement>"}>Type</ApiType> | - |
| strong | Whether the text is bold. | `boolean` | - |
| type | Text type: `primary`, `secondary`, `danger`, `warning`, `success`, `tertiary` or `quaternary`. Defaults to `primary`. | `TypographyBaseType` | - |
| underline | Adds an underline. Link text shows it only on hover and active. | `boolean` | - |
| weight | Font weight: `light`, `regular`, `medium`, `semibold`, `bold`, `default`, or a number. | <ApiType detail={"'light' \u007c 'regular' \u007c 'medium' \u007c 'semibold' \u007c 'bold' \u007c 'default' \u007c number"}>Type</ApiType> | - |
