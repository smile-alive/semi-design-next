**Props**

| 属性      | 说明                                                         | 类型                         | 默认值         |
| --------- | ------------------------------------------------------------ | ---------------------------- | -------------- |
| children  | ResizeItem 与 ResizeHandler，子项挂载后自行向组注册。        | `Snippet`                    | -              |
| direction | 组内的伸缩方向，horizontal 为左右排列，vertical 为上下排列。 | `'horizontal' \| 'vertical'` | `"horizontal"` |
