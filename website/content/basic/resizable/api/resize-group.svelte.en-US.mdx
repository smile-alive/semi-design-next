**Props**

| Property  | Description                                                                                   | Type                         | Default        |
| --------- | --------------------------------------------------------------------------------------------- | ---------------------------- | -------------- |
| children  | ResizeItem and ResizeHandler children, which register themselves with the group once mounted. | `Snippet`                    | -              |
| direction | Resize direction within the group: horizontal lays items side by side, vertical stacks them.  | `'horizontal' \| 'vertical'` | `"horizontal"` |
