### 单个组件 基本使用

通过`defaultSize`设置初始大小，可以通过`onResizeStart`、`onChange`、`onResizeEnd`设置拖拽的回调

<Framework only="vue">

用 `@resizeStart`、`@change`、`@resizeEnd` 监听。`onResizeStart` 是函数 prop（返回 `false` 可取消本次伸缩），使用方照常写 `@resizeStart`；`change`、`resizeEnd` 是事件。

</Framework>

<Framework only="svelte">

`onResizeStart`、`onChange`、`onResizeEnd` 都是回调 prop，`onResizeStart` 返回 `false` 可取消本次伸缩；`style` 只接受字符串。

</Framework>

### 控制伸缩方向

通过设置`enable`的值开启/关闭特定伸缩方向，默认值均为`true`；未写出的方向视为开启，要只开启部分方向，需把其余方向显式设为 `false`。`enable` 传 `false` 时不渲染任何手柄。

```tsx
interface Enable {
    left?: boolean;
    right?: boolean;
    top?: boolean;
    bottom?: boolean;
    topLeft?: boolean;
    topRight?: boolean;
    bottomLeft?: boolean;
    bottomRight?: boolean;
}
```

### 允许阶段性调整宽高

可通过 grid ，snap 属性允许逐渐调整宽高。 grid 属性用于指定调整大小应对齐的增量。默认为 [1, 1]。 snap 属性用于指定调整大小时应对齐的绝对像素值。 x 和 y 都是可选的，允许仅包含要定义的轴。默认为空。以上两个参数可结合 snapGap 使用，该参数用于指定移动到下一个目标所需的最小间隙。默认为 0，这意味着始终使用 grid/snap 设定的目标。

```tsx
interface Snap {
    x?: number[];
    y?: number[];
}
```

### 组合组件 基本使用

<Notice type='primary' title='注意事项'>

`ResizeGroup` 的父元素需要具有主轴方向上的尺寸。

最好不要为 `ResizeItem` 设置 `padding`，会导致最小尺寸不符合预期，可以为子元素设置 `padding`。

`ResizeItem` 与 `ResizeHandler` 必须放在 `ResizeGroup` 内，在组外使用会抛出错误。

</Notice>

通过`direction`设置伸缩方向，可选值为`horizontal`和`vertical`，缺省为`horizontal`。支持`onResizeStart`、`onChange`、`onResizeEnd`回调，支持`min`、`max`设置最大最小宽高

<Framework only="vue">

`ResizeItem` 同样用 `@resizeStart`、`@change`、`@resizeEnd` 监听：`onResizeStart` 是函数 prop，使用方照常写 `@resizeStart`；`change`、`resizeEnd` 是事件。

</Framework>

<Framework only="svelte">

`ResizeItem` 的 `onResizeStart`、`onChange`、`onResizeEnd` 同样是回调 prop。

</Framework>

## Accessibility

- 单个伸缩框每个轴上只有一个手柄是可聚焦的 `separator`：右侧与下侧手柄始终是；对应的右侧或下侧被 `enable` 关闭时，该轴由左侧或上侧手柄接替。名称取自语言包，分别调整宽度与高度；聚焦后按方向键，每次固定改变 10px，不受 `ratio`、`scale` 影响；同时按住 Alt、Ctrl 或 Meta 时不响应。鼠标右键、中键按下手柄不开始调整。
- `ResizeHandler` 是可聚焦的 `separator`，名称同样取自语言包，传入 `aria-label` 可覆盖。沿组的方向按方向键移动它两侧的项，每次移动组尺寸的 1%，按住 Shift 为 10%；`Home`、`End` 把它前一项调到最小、最大尺寸。
- `Resizable`、`ResizeGroup`、`ResizeItem` 的根元素没有语义；传入 `aria-label` 或 `aria-labelledby` 时，根元素带上 `role="group"`。
