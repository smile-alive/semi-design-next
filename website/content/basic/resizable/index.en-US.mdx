### Single Component

Basic Usage and Callbacks You can set the initial size using defaultSize, and set drag callbacks with `onResizeStart`, `onChange`, and `onResizeEnd`.

<Framework only="vue">

</Framework>

<Framework only="svelte">

### Controlling Resize Directions

You can enable or disable specific resizing directions by setting the value of enable. All directions are enabled by default. A direction that is left out counts as enabled, so to enable only some directions, set the others to `false` explicitly. Passing `false` for `enable` renders no handles.

```tsx
interface Enable {
    left?: boolean;
    right?: boolean;
    top?: boolean;
    bottom?: boolean;
    topLeft?: boolean;
    topRight?: boolean;
    bottomLeft?: boolean;
    bottomRight?: boolean;
}
```

### Allowing Incremental Width and Height Adjustment

You can allow gradual adjustments in width and height using the grid and snap properties. The grid property specifies the increments to which resizing should snap. The default value is [1, 1]. The snap property specifies the absolute pixel values to which resizing should snap. Both x and y are optional, allowing you to define only the desired axis. These two parameters can be combined with the snapGap property, which specifies the minimum gap required to move to the next target. The default is 0, meaning the target defined by grid/snap is always used.

```tsx
interface Snap {
    x?: number[];
    y?: number[];
}
```

### Group Component

<Notice type='primary' title='notice'>

The parent element of `ResizeGroup` needs to have a size in the main axis direction.

It's best not to set padding for ResizeItem, as it may cause the minimum size to not match the expected value. You can set padding for child elements instead.

`ResizeItem` and `ResizeHandler` must be placed inside a `ResizeGroup`; using them outside one throws an error.

</Notice>

Use the direction prop to set the resizing direction. Options are `horizontal` and `vertical`, defaulting to `horizontal`. Supports `onResizeStart`, `onChange`, and `onResizeEnd` callbacks, as well as setting `min` and `max` to control the maximum and minimum width/height.

<Framework only="vue">

`ResizeItem` is listened to with `@resizeStart`, `@change` and `@resizeEnd` as well: `onResizeStart` is a function prop, bound with `@resizeStart` as usual; `change` and `resizeEnd` are events.

</Framework>

<Framework only="svelte">

`onResizeStart`, `onChange` and `onResizeEnd` of `ResizeItem` are callback props as well.

</Framework>

### ResizeItem

<Framework only="react">

<ResizeItemReactApi />

Other native `div` attributes are passed through rest onto the root element. ResizeGroup writes the size straight onto the element's `style.width` and `style.height`, so do not set those two through `style`.

</Framework>

<Framework only="vue">

<ResizeItemVueApi />

`class`, `style` and native attributes are passed in through attrs and land on the root element. ResizeGroup writes the size straight onto the element's `style.width` and `style.height`, so pass `style` as an object rather than a string.

</Framework>

<Framework only="solid">

<ResizeItemSolidApi />

`class`, `style` and native attributes are passed in through rest and land on the root element. ResizeGroup writes the size straight onto the element's `style.width` and `style.height`, so pass `style` as an object: a string `style` is written again whole when it changes, which drops the size.

</Framework>

<Framework only="svelte">

<ResizeItemSvelteApi />

`class`, `style` and native attributes land on the root element. ResizeGroup writes the size straight onto the element's `style.width` and `style.height`, and a Svelte `style` can only be a string, which is written again whole when it changes and drops the size, so keep `style` a constant value.

</Framework>

## Accessibility

- Each axis of a single resizable box has one focusable `separator` handle: the right and bottom handles always are; when the right or bottom side is turned off in `enable`, the left or top handle takes over that axis. They are named from the locale pack and adjust the width and the height. Arrow keys change the size by a fixed 10px per press, regardless of `ratio` and `scale`, and are ignored while Alt, Ctrl or Meta is held. Pressing a handle with the right or middle mouse button does not start a resize.
- `ResizeHandler` is a focusable `separator`. Its name also comes from the locale pack, and an `aria-label` you pass overrides it. Arrow keys along the group's direction move the items on either side of it by 1% of the group per press, or 10% with Shift; `Home` and `End` take the item before it to its smallest and largest size.
- The root elements of `Resizable`, `ResizeGroup` and `ResizeItem` carry no semantics. When you pass `aria-label` or `aria-labelledby`, the root gets `role="group"`.
