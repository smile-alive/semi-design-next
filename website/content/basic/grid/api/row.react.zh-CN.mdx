**Props**

| 属性      | 说明                                                                                                              | 类型                                                                | 默认值   |
| --------- | ----------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------- | -------- |
| align     | flex 布局下的垂直对齐方式，可选 `top`、`middle` 或 `bottom`，仅在 `type` 为 `flex` 时生效。                       | `'top' \| 'middle' \| 'bottom'`                                     | -        |
| children  | 行内的 `Col` 栅格。                                                                                               | `React.ReactNode`                                                   | -        |
| className | 根元素的类名。                                                                                                    | `string`                                                            | -        |
| gutter    | 栅格间隔，可以是像素值、响应式对象 `{ xs, sm, md, lg, xl, xxl }`，或 `[水平, 垂直]` 数组，未设置时为 `0`。        | `Gutter \| [Gutter, Gutter]`                                        | -        |
| justify   | flex 布局下的水平排列方式，可选 `start`、`end`、`center`、`space-around` 或 `space-between`，未设置时为 `start`。 | `'start' \| 'end' \| 'center' \| 'space-around' \| 'space-between'` | -        |
| prefixCls | CSS 类名前缀。                                                                                                    | `string`                                                            | `"semi"` |
| ref       | 根元素（`div`）的引用。                                                                                           | <ApiType detail={"React.Ref\u003cHTMLDivElement>"}>Type</ApiType>   | -        |
| style     | 根元素的样式。                                                                                                    | `React.CSSProperties`                                               | -        |
| type      | 布局模式，可选 `flex`。                                                                                           | `'flex'`                                                            | -        |
