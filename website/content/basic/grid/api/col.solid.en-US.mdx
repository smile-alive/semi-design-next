**Props**

| Property  | Description                                                                                                                        | Type                | Default  |
| --------- | ---------------------------------------------------------------------------------------------------------------------------------- | ------------------- | -------- |
| lg        | Responsive grid for screens ≥992px, as a column count or a `{ span, offset, order, push, pull }` object.                           | `number \| ColSize` | -        |
| md        | Responsive grid for screens ≥768px, as a column count or a `{ span, offset, order, push, pull }` object.                           | `number \| ColSize` | -        |
| offset    | Number of columns to offset from the start side. No column can sit inside the offset.                                              | `number`            | -        |
| order     | Column order. Takes effect in flex layout.                                                                                         | `number`            | -        |
| prefixCls | CSS class name prefix.                                                                                                             | `string`            | `"semi"` |
| pull      | Number of columns to move toward the start side.                                                                                   | `number`            | -        |
| push      | Number of columns to move toward the end side.                                                                                     | `number`            | -        |
| sm        | Responsive grid for screens ≥576px, as a column count or a `{ span, offset, order, push, pull }` object.                           | `number \| ColSize` | -        |
| span      | Number of columns the cell spans. 0 behaves like `display: none`.                                                                  | `number`            | -        |
| xl        | Responsive grid for screens ≥1200px, as a column count or a `{ span, offset, order, push, pull }` object.                          | `number \| ColSize` | -        |
| xs        | Base-layer responsive grid. It applies at every screen width, as a column count or a `{ span, offset, order, push, pull }` object. | `number \| ColSize` | -        |
| xxl       | Responsive grid for screens ≥1600px, as a column count or a `{ span, offset, order, push, pull }` object.                          | `number \| ColSize` | -        |
