**Props**

| 属性      | 说明                                                               | 类型                | 默认值   |
| --------- | ------------------------------------------------------------------ | ------------------- | -------- |
| children  | 栅格内的内容。                                                     | `Snippet`           | -        |
| lg        | 屏幕宽度 ≥992px 时生效的响应式栅格，可为栅格数或对象配置。         | `number \| ColSize` | -        |
| md        | 屏幕宽度 ≥768px 时生效的响应式栅格，可为栅格数或对象配置。         | `number \| ColSize` | -        |
| offset    | 栅格起始侧（从左到右排版时为左侧）的间隔格数，间隔内不可以有栅格。 | `number`            | -        |
| order     | 栅格顺序，flex 布局模式下有效。                                    | `number`            | -        |
| prefixCls | CSS 类名前缀。                                                     | `string`            | `"semi"` |
| pull      | 栅格向起始侧（从左到右排版时为左侧）移动的格数。                   | `number`            | -        |
| push      | 栅格向末尾侧（从左到右排版时为右侧）移动的格数。                   | `number`            | -        |
| sm        | 屏幕宽度 ≥576px 时生效的响应式栅格，可为栅格数或对象配置。         | `number \| ColSize` | -        |
| span      | 栅格占位格数，为 0 时相当于 display: none。                        | `number`            | -        |
| xl        | 屏幕宽度 ≥1200px 时生效的响应式栅格，可为栅格数或对象配置。        | `number \| ColSize` | -        |
| xs        | 基础层响应式栅格，所有屏幕宽度都生效，可为栅格数或对象配置。       | `number \| ColSize` | -        |
| xxl       | 屏幕宽度 ≥1600px 时生效的响应式栅格，可为栅格数或对象配置。        | `number \| ColSize` | -        |
