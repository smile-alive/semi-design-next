**Props**

| 属性      | 说明                                                                                       | 类型                                                                | 默认值   |
| --------- | ------------------------------------------------------------------------------------------ | ------------------------------------------------------------------- | -------- |
| align     | flex 布局下的垂直对齐方式，可选 top、middle、bottom。                                      | `'top' \| 'middle' \| 'bottom'`                                     | -        |
| children  | 行内的 Col。                                                                               | `Snippet`                                                           | -        |
| gutter    | 栅格间隔，可以是像素值、响应式对象 `{ xs, sm, md, lg, xl, xxl }`，或 `[水平, 垂直]` 数组。 | `Gutter \| [Gutter, Gutter]`                                        | `0`      |
| justify   | flex 布局下的水平排列方式，可选 start、end、center、space-around、space-between。          | `'start' \| 'end' \| 'center' \| 'space-around' \| 'space-between'` | -        |
| prefixCls | CSS 类名前缀。                                                                             | `string`                                                            | `"semi"` |
| type      | 布局模式，可选 flex。                                                                      | `'flex'`                                                            | -        |
