**Props**

| Property | Description                                                                                                   | Type                                                                | Default |
| -------- | ------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------- | ------- |
| align    | Vertical alignment of the children: top, middle or bottom.                                                    | `'bottom' \| 'middle' \| 'top'`                                     | -       |
| children | Col components in the row.                                                                                    | `Snippet`                                                           | -       |
| gutter   | Grid gutter in pixels, a responsive object `{ xs, sm, md, lg, xl, xxl }`, or a `[horizontal, vertical]` pair. | `Gutter \| [Gutter, Gutter]`                                        | `0`     |
| justify  | Horizontal arrangement of the children: start, end, center, space-around or space-between.                    | `'center' \| 'end' \| 'space-around' \| 'space-between' \| 'start'` | -       |
