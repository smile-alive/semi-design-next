**Props**

| Property  | Description                                                                                                   | Type                                                                | Default  |
| --------- | ------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------- | -------- |
| align     | Vertical alignment in flex layout: top, middle or bottom. Takes effect only when type is flex.                | `'bottom' \| 'middle' \| 'top'`                                     | -        |
| gutter    | Grid gutter in pixels, a responsive object `{ xs, sm, md, lg, xl, xxl }`, or a `[horizontal, vertical]` pair. | `Gutter \| [Gutter, Gutter]`                                        | -        |
| justify   | Horizontal arrangement in flex layout: start, end, center, space-around or space-between.                     | `'center' \| 'end' \| 'space-around' \| 'space-between' \| 'start'` | -        |
| prefixCls | CSS class name prefix.                                                                                        | `string`                                                            | `"semi"` |
| type      | Layout mode: flex.                                                                                            | `'flex'`                                                            | -        |
