**Events**

| Event | Description | Callback parameters |
| --- | --- | --- |
| blur | Emitted when focus leaves the input and the clear button. The event is the focusout of the Input wrapper. | `[event: FocusEvent]` |
| change | Emitted when the value changes. The second argument is the event that caused it: typing, a step button pointerdown, an arrow or Home/End keydown, or blur. Mounting and modelValue changes do not emit it; an out-of-range value is shown as given and is corrected and reported only after a user action. | `[value: string \| number, event: InputNumberChangeEvent]` |
| downClick | Emitted when pressing the decrease button steps the value, once per step while it is held; the arguments are the stepped value and the pointerdown event. | `[value: string, event: PointerEvent]` |
| focus | Emitted when focus enters the input; moving focus between the input and the clear button does not fire it. The event is the focusin of the Input wrapper. | `[event: FocusEvent]` |
| keydown | Emitted when a key is pressed in the input. | `[event: KeyboardEvent]` |
| numberChange | Emitted when the number changes; the event argument is as in change. | `[value: number, event: InputNumberChangeEvent]` |
| upClick | Emitted when pressing the increase button steps the value, once per step while it is held; the arguments are the stepped value and the pointerdown event. | `[value: string, event: PointerEvent]` |
| update:modelValue | Emitted when the value changes, for v-model to write back; emitted together with change. | `[value: string \| number]` |
