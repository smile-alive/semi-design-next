**Props**

| 属性           | 说明                                                                              | 类型      | 默认值                                          |
| -------------- | --------------------------------------------------------------------------------- | --------- | ----------------------------------------------- |
| modelValue     | 是否选中，配合 v-model 使用；传入后由该值决定显示，只传不回写时点击仅触发通知。   | `boolean` | `undefined`                                     |
| defaultChecked | 非受控时的初始选中状态。                                                          | `boolean` | `semiGlobalDefault("Switch", "defaultChecked")` |
| disabled       | 是否禁用。                                                                        | `boolean` | `semiDefault("Switch", "disabled", false)`      |
| loading        | 是否处于加载中；加载中 input 仍可聚焦并带 aria-disabled，切换被忽略且不发出事件。 | `boolean` | `semiDefault("Switch", "loading", false)`       |
| size           | 开关尺寸，可选 large、default 或 small。                                          | `Size`    | `semiDefault("Switch", "size", "default")`      |

**Events**

| 事件              | 说明                                               | 回调参数                           |
| ----------------- | -------------------------------------------------- | ---------------------------------- |
| update:modelValue | 用户切换状态时触发，供 v-model 回写。              | `[checked: boolean]`               |
| change            | 用户切换状态时触发，参数为新的选中状态与原生事件。 | `[checked: boolean, event: Event]` |

**Slots**

| 插槽          | 说明                                         | 作用域参数 |
| ------------- | -------------------------------------------- | ---------- |
| checkedText   | 选中时展示的内容，size 为 small 时不显示。   | `any`      |
| uncheckedText | 未选中时展示的内容，size 为 small 时不显示。 | `any`      |
