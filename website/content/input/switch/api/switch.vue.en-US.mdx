import ApiType from '#/components/ApiType.astro';

**Props**

| Property | Description | Type | Default |
| --- | --- | --- | --- |
| classNames | Class names of the inner parts, keyed by `indicator` and `content`; merged with the built-in classes. `indicator` is the knob, or the loading icon while loading; `content` is the checked or unchecked text. | <ApiType detail={"Partial\u003cRecord\u003cSwitchPart, ClassValue>>"}>Type</ApiType> | `semiGlobalDefault("Switch", "classNames")` |
| defaultChecked | Initial state when uncontrolled. | `boolean` | `semiGlobalDefault("Switch", "defaultChecked")` |
| disabled | Whether the switch is disabled. | `boolean` | `false` |
| loading | Whether the switch is loading. While loading, the input stays focusable with aria-disabled, and toggles are ignored without emitting events. | `boolean` | `false` |
| modelValue | Whether the switch is on, used with v-model. When given, this value decides; without a write-back, a click only notifies. | `boolean` | `undefined` |
| size | Switch size: large, default or small. | `Size` | `"default"` |
| styles | Inline styles of the inner parts, keyed like `classNames`. | <ApiType detail={"Partial\u003cRecord\u003cSwitchPart, StyleValue>>"}>Type</ApiType> | `semiGlobalDefault("Switch", "styles")` |

**Events**

| Event             | Description                                                                        | Callback parameters                |
| ----------------- | ---------------------------------------------------------------------------------- | ---------------------------------- |
| change            | Emitted when the user toggles the switch, with the new state and the native event. | `[checked: boolean, event: Event]` |
| update:modelValue | Emitted when the user toggles the switch, for v-model to write back.               | `[checked: boolean]`               |

**Slots**

| Slot          | Description                                           | Scope parameters |
| ------------- | ----------------------------------------------------- | ---------------- |
| checkedText   | Content shown when on. Not shown when size is small.  | `any`            |
| uncheckedText | Content shown when off. Not shown when size is small. | `any`            |
