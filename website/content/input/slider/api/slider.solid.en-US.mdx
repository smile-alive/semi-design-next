**Props**

| Property | Description | Type | Default |
| --- | --- | --- | --- |
| aria-label | Accessible name of the handle. In range mode, the locale's start and end texts are appended for the two handles. | `string` | - |
| aria-labelledby | The id of the labelling element, used as the handle's accessible name. In range mode each handle adds its start or end text. | `string` | - |
| aria-valuetext | A user-friendly name for the current value. | `string` | - |
| autofocus | Focuses the first handle on mount. | `boolean` | - |
| defaultValue | Initial value when uncontrolled. Defaults to `min`. | `number \| number[]` | - |
| disabled | Whether the slider is disabled. | `boolean` | `false` |
| getAriaValueText | Provides a user-friendly name for the current value, called with the handle's value and its index. | <ApiType detail={"(value: number, index?: number) => string"}>Type</ApiType> | - |
| handleDot | Dot on the handle: one object for a single handle, an array with one per handle for a range. | `HandleDot \| HandleDot[]` | - |
| included | Takes effect when marks is not empty. true makes the marks nested, false makes them independent. | `boolean` | `true` |
| marks | Marks. Keys are numbers in the closed range [min, max], values are strings or numbers; custom nodes go through renderMark. | <ApiType detail={"Record\u003cnumber, string \u007c number>"}>Type</ApiType> | - |
| max | Maximum value. | `number` | `100` |
| min | Minimum value. | `number` | `0` |
| name | Field name submitted with a native form, set on each handle's input. In range mode both inputs share it and submit two values in order. | `string` | - |
| onAfterChange | Fires after a change is complete, with the current value. Not fired when a controlled value goes back to `undefined`. | <ApiType detail={"(value: SliderProps['value']) => void"}>Type</ApiType> | - |
| onBlur | Fires when focus leaves both handles, attached to `.semi-slider-wrapper`. Moving focus between the two handles does not fire it. | <ApiType detail={"JSX.EventHandlerUnion\u003cHTMLDivElement, FocusEvent>"}>Type</ApiType> | - |
| onChange | Fires when the value changes, with the current value. | <ApiType detail={"(value: SliderProps['value']) => void"}>Type</ApiType> | - |
| onFocus | Fires when either handle gets focus, attached to `.semi-slider-wrapper`. | <ApiType detail={"JSX.EventHandlerUnion\u003cHTMLDivElement, FocusEvent>"}>Type</ApiType> | - |
| onKeyDown | Key handler on the handle's input, called before the slider handles the key. Calling `preventDefault` in it stops the slider from handling a value key. | <ApiType detail={"JSX.EventHandlerUnion\u003cHTMLInputElement, KeyboardEvent>"}>Type</ApiType> | - |
| onMouseUp | Fires when the pointer (mouse, touch or pen) that dragged the handle is released or cancelled, and when a value key is released. | <ApiType detail={"(event: PointerEvent \u007c KeyboardEvent) => void"}>Type</ApiType> | - |
| railStyle | Style of the slider rail, an object keyed by CSS property names or a string. | `JSX.CSSProperties \| string` | - |
| range | Whether both ends can be dragged. | `boolean` | `false` |
| renderMark | Renders a mark label, called with (value, label); with tooltipOnMark it is called once for the label and once for the tooltip. Defaults to the label. | <ApiType detail={"(value: number, label: string \u007c number) => JSX.Element"}>Type</ApiType> | - |
| showArrow | Whether the tooltip has an arrow. | `boolean` | `true` |
| showBoundary | Whether to show the maximum and minimum on hover. | `boolean` | `false` |
| showMarkLabel | Whether to show the mark labels. | `boolean` | `true` |
| step | Step, counted from `min`. | `number` | `1` |
| tipFormatter | Format of the tooltip, called once per handle with that handle's value. Shows the current value by default; `null` hides the tooltip. | <ApiType detail={"((value: number) => any) \u007c null"}>Type</ApiType> | <ApiType detail={"(value: number) => value"}>Type</ApiType> |
| tooltipOnMark | Whether the marks on the rail have a tooltip. | `boolean` | `false` |
| tooltipVisible | Whether the tooltip is always visible. | `boolean` | - |
| value | Current value, for controlled use. With value but no write-back in onChange, dragging, clicking and arrow keys only fire onChange and the handle does not move. Back to `undefined` it returns to defaultValue, or min without one, and onAfterChange does not fire. | `number \| number[]` | - |
| vertical | Whether the slider is vertical. | `boolean` | `false` |
| verticalReverse | Reverses the vertical direction, so the larger value is on top. | `boolean` | `false` |
