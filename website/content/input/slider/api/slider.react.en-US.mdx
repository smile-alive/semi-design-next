**Props**

| Property | Description | Type | Default |
| --- | --- | --- | --- |
| aria-label | Accessible name of the handle. In `range` mode, the locale's start and end texts are appended for the two handles. | `string` | - |
| aria-labelledby | The id of the labelling element, used as the handle's accessible name. In `range` mode each handle's name is that label plus its start or end text. | `string` | - |
| aria-valuetext | A user-friendly name for the current value. `getAriaValueText` takes precedence when set. | `string` | - |
| className | Class name of the `.semi-slider-wrapper` element. | `string` | - |
| defaultValue | Initial value when uncontrolled. Defaults to `min`. | `number \| number[]` | - |
| disabled | Whether the slider is disabled. | `boolean` | `false` |
| getAriaValueText | Provides a user-friendly name for the current value, called with the handle's value and its index. Takes precedence over `aria-valuetext`. | <ApiType detail={"(value: number, index?: number) => string"}>Type</ApiType> | - |
| handleDot | Dot on the handle: one object for a single handle, an array with one per handle in `range` mode. | `HandleDot \| HandleDot[]` | - |
| id | Set on the first handle's input, so a `<label htmlFor>` pointing at it focuses the slider when clicked. | `string` | - |
| included | Takes effect when `marks` is not an empty object. `true` makes the values nested, `false` makes them independent. | `boolean` | `true` |
| marks | Marks. Keys must be `number` values in the closed range [min, max]; values are any node, shown next to the mark and in its tooltip. | <ApiType detail={"Record\u003cnumber, React.ReactNode>"}>Type</ApiType> | - |
| max | Maximum value. | `number` | `100` |
| min | Minimum value. | `number` | `0` |
| name | Field name submitted with a native form, set on each handle's input. In `range` mode both inputs share it and submit two values in order. | `string` | - |
| onAfterChange | Fires after a change is complete, with the current value. Not fired when a controlled value goes back to `undefined`. | <ApiType detail={"(value: SliderProps['value']) => void"}>Type</ApiType> | - |
| onChange | Fires when the value changes, with the current value. | <ApiType detail={"(value: SliderProps['value']) => void"}>Type</ApiType> | - |
| onFocus | Fires when either handle gets focus, attached to `.semi-slider-wrapper`. | <ApiType detail={"React.FocusEventHandler\u003cHTMLDivElement>"}>Type</ApiType> | - |
| onMouseUp | Fires when the pointer (mouse, touch or pen) that dragged the handle is released or cancelled, and when a value key is released. | <ApiType detail={"(e: any) => void"}>Type</ApiType> | - |
| railStyle | Style of the slider rail. | `React.CSSProperties` | - |
| range | Whether both ends can be dragged. | `boolean` | `false` |
| ref | Reference to the `.semi-slider-wrapper` element. | <ApiType detail={"React.Ref\u003cHTMLDivElement>"}>Type</ApiType> | - |
| showArrow | Whether the tooltip has an arrow. | `boolean` | `true` |
| showBoundary | Whether to show the maximum and minimum on hover. | `boolean` | `false` |
| showMarkLabel | Whether to show the mark labels. | `boolean` | `true` |
| step | Step, counted from `min`. | `number` | `1` |
| style | Style of the `.semi-slider-wrapper` element. | `React.CSSProperties` | - |
| tipFormatter | Format of the tooltip, called once per handle with that handle's value. Pass `null` to hide the tooltip. | <ApiType detail={"((value: number) => any) \u007c null"}>Type</ApiType> | <ApiType detail={"(value: number) => value"}>Type</ApiType> |
| title | The title attribute set on the `.semi-slider-wrapper` element. | `string` | - |
| tooltipOnMark | Whether the marks on the rail have a tooltip. | `boolean` | `false` |
| tooltipVisible | Whether the tooltip is always visible. | `boolean` | - |
| value | Current value, for controlled use. With `value` but no write-back in `onChange`, dragging, clicking and arrow keys only fire `onChange` and the handle does not move. Back to `undefined` it returns to `defaultValue`, or `min` without one, and `onAfterChange` does not fire. | `number \| number[]` | - |
| vertical | Whether the slider is vertical. | `boolean` | `false` |
| verticalReverse | Reverses the vertical direction, so the larger value is on top. | `boolean` | `false` |
