## 使用场景

- 勾选框可以让用户在两种相反的状态、行为或取值之间选择;
- 适用于在列表中选择单个或多个选项，开启或关闭某个选项

## API参考

### Checkbox

<Framework only="react">

<CheckboxReactApi />

`className`、`style` 落在根元素 `span` 上；`id`、`name`、`tabIndex`、`autoFocus` 与 `aria-label`、`aria-labelledby`、`aria-describedby`、`aria-errormessage`、`aria-invalid`、`aria-required` 落在内部的原生 input 上，其余原生属性与事件（如 `role`、`onFocus`、`onBlur`、`onClick`、`data-*`）落在根元素 `span` 上。

</Framework>

<Framework only="vue">

<CheckboxVueApi />

`class`、`style` 落在根元素上。`id`、`name`、`tabindex`、`autofocus`、`aria-*` 与 focus、blur 监听经 attrs 落在内部的原生 input 上，其余原生属性与事件监听（如 `@mouseenter`）落在根元素上。`name` 在 CheckboxGroup 中以组的 `name` 为准。

</Framework>

<Framework only="solid">

<CheckboxSolidApi />

`class`、`style`、`ref` 落在根元素 `<span>` 上。`id`、`name`、`tabindex`、`autofocus`、`aria-*` 与 `onFocus`、`onBlur` 落在内部的原生 input 上，其余原生属性与事件（如 `onMouseEnter`、`onClick`）落在根元素上。`name` 在 CheckboxGroup 中以组的 `name` 为准。

</Framework>

### Checkbox Group

<Framework only="react">

<CheckboxGroupReactApi />

其他原生属性（如 `aria-label`、`data-*`）落在根元素 `div`（`role="group"`）上；`onBlur` 在焦点离开整个分组时触发，在组内 Checkbox 之间移动焦点不触发。`aria-invalid` 与 `aria-errormessage` 传给组内每个 Checkbox 的原生 input，`aria-required`、`tabIndex` 以及 Tooltip 注入的 `aria-expanded`、`aria-haspopup`、`aria-controls` 不输出。

</Framework>

<Framework only="vue">

<CheckboxGroupVueApi />

`options` 项的字段为 `label`、`value`、`disabled`、`extra`（`string | number`）、`class`、`style`，没有 `onChange`；需要自定义内容时使用 `#label`、`#extra` 作用域插槽。`class`、`style` 与原生属性经 attrs 落在根元素上；`aria-invalid`、`aria-errormessage` 传给组内每个 Checkbox 的原生 input，`aria-required`、`tabindex` 以及 Tooltip 注入的 `aria-expanded`、`aria-haspopup`、`aria-controls` 不输出。

</Framework>

<Framework only="solid">

<CheckboxGroupSolidApi />

`class`、`style`、`ref` 与原生属性和事件落在根元素 `<div>` 上；`onBlur` 在焦点离开整个分组时触发，在组内 Checkbox 之间移动焦点不触发。`aria-invalid`、`aria-errormessage` 传给组内每个 Checkbox 的原生 input，`aria-required`、`tabindex` 以及 Tooltip 注入的 `aria-expanded`、`aria-haspopup`、`aria-controls` 不输出。

</Framework>

## Accessibility

### ARIA

- Checkbox 的 role 为 `checkbox`，CheckboxGroup 的 role 为 `group`，它的子元素没有额外的 role
- `aria-label`：单独使用 Checkbox 时，如果 Children 没有文本，建议传入 `aria-label` prop，用一句话描述 Checkbox 的作用，这会让屏幕阅读器读出这个标签的内容
- 原生 input 的 `aria-labelledby` 指向 `addon` 节点，用于解释当前 Checkbox 的作用；传入的 `aria-labelledby` 也落在 input 上，排在 `addon` id 之前
- `aria-describedby` 指向 `extra` 节点，用于补充解释当前 Checkbox 的作用
- 选中与禁用状态由原生 input 的 `checked`、`disabled` 表达，不输出 `aria-checked`、`aria-disabled`

<Framework only="react">

- 使用 Form.Checkbox 时，可以使用 Form 提供的 label 而无需传入 `aria-label`；Form 注入的 label 同样落在 input 的 `aria-labelledby` 上，排在 `addon` id 之前

</Framework>

### 键盘和焦点

- Checkbox 可被获取焦点，键盘用户可以使用 Tab 及 Shift + Tab 切换焦点。
- 当前获取的焦点为 Checkbox 时，可以通过 Space 切换选中和未选状态。
- Checkbox 的点击区域大于框本身，包含了框后的文案；带辅助文本的 checkbox，辅助文本也包含在点击区域内。
- 禁用的 Checkbox 不可获取焦点。
