import ApiType from '#/components/ApiType.astro';

**Props**

| Property   | Description                                                                                                                                                                 | Type                                                                               | Default      |
| ---------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------- | ------------ |
| children   | Checkbox components in the group. Ignored when options is set.                                                                                                              | `Snippet`                                                                          | -            |
| direction  | Layout direction inside the group: horizontal or vertical.                                                                                                                  | `CheckboxDirection`                                                                | `"vertical"` |
| disabled   | Whether the whole group is disabled.                                                                                                                                        | `boolean`                                                                          | `false`      |
| extra      | Snippet for the extra text of each item in options, with the parameter `{ option, index }`.                                                                                 | <ApiType detail={"Snippet\u003c[CheckboxGroupOptionSnippetProps]>"}>Type</ApiType> | -            |
| label      | Snippet for the label of each item in options, with the parameter `{ option, index }`.                                                                                      | <ApiType detail={"Snippet\u003c[CheckboxGroupOptionSnippetProps]>"}>Type</ApiType> | -            |
| name       | The name of every native input in the group. A unique value is generated per group when omitted.                                                                            | `string`                                                                           | -            |
| onBlur     | Called when focus leaves the whole group; moving focus between its checkboxes does not call it.                                                                             | <ApiType detail={"(event: FocusEvent) => void"}>Type</ApiType>                     | -            |
| onChange   | Called when the selected values change, with the new array of values.                                                                                                       | <ApiType detail={"(value: CheckboxValue[]) => void"}>Type</ApiType>                | -            |
| onfocusout | Callback for the root element's focusout event, called before onBlur.                                                                                                       | <ApiType detail={"FocusEventHandler\u003cT> \u007c null"}>Type</ApiType>           | -            |
| options    | Declares the options as data. Each item is a string or `{ label, value, disabled, extra, class, style }`, where `style` is a string.                                        | <ApiType detail={"Array\u003cstring \u007c CheckboxOptionItem>"}>Type</ApiType>    | -            |
| prefixCls  | CSS class name prefix.                                                                                                                                                      | `string`                                                                           | -            |
| type       | Style type of every Checkbox in the group: default, card or pureCard.                                                                                                       | `CheckboxType`                                                                     | `"default"`  |
| value      | Selected values, matched against each Checkbox's value; bind it with `bind:value`. `bind:value={get, set}` makes it fully controlled; a plain `value` is the initial value. | `CheckboxValue[]`                                                                  | -            |
