**Props**

| Property | Description | Type | Default |
| --- | --- | --- | --- |
| classNames | Class names of the inner parts, keyed by item (the root of every Checkbox), itemIcon, itemLabel and itemExtra. They apply to every Checkbox in the group; values take any class binding and merge with each Checkbox's own classNames, the group's first. | <ApiType detail={"Partial\u003cRecord\u003cCheckboxGroupPart, ClassValue>>"}>Type</ApiType> | `semiGlobalDefault("CheckboxGroup", "classNames")` |
| defaultValue | Values selected by default when uncontrolled, matched against each Checkbox's value. | `CheckboxValue[]` | `[]` |
| direction | Layout direction inside the group: horizontal or vertical. | `CheckboxDirection` | `"vertical"` |
| disabled | Whether the whole group is disabled. | `boolean` | `false` |
| modelValue | Selected values, controlled with v-model. | `CheckboxValue[]` | `undefined` |
| name | The name of every native input in the group. A unique value is generated per group when omitted. | `string` | `semiGlobalDefault("CheckboxGroup", "name")` |
| options | Declares the options as data. Each item is a string or `{ label, value, disabled, extra, class, style }`. | `(string \| CheckboxOptionItem)[]` | `semiGlobalDefault("CheckboxGroup", "options")` |
| styles | Inline styles of the inner parts, keyed like classNames; each Checkbox's own styles are applied after them. | <ApiType detail={"Partial\u003cRecord\u003cCheckboxGroupPart, StyleValue>>"}>Type</ApiType> | `semiGlobalDefault("CheckboxGroup", "styles")` |
| type | Style type of every Checkbox in the group: default, card or pureCard. | `CheckboxType` | `"default"` |

**Events**

| Event             | Description                                                                                      | Callback parameters        |
| ----------------- | ------------------------------------------------------------------------------------------------ | -------------------------- |
| blur              | Emitted when focus leaves the whole group; moving focus between its checkboxes does not emit it. | `[event: FocusEvent]`      |
| change            | Emitted when the selected values change, with the new array of values.                           | `[value: CheckboxValue[]]` |
| update:modelValue | Emitted when the selected values change; drives v-model.                                         | `[value: CheckboxValue[]]` |

**Slots**

| Slot    | Description                                                                            | Scope parameters               |
| ------- | -------------------------------------------------------------------------------------- | ------------------------------ |
| default | Checkbox components in the group. Ignored when options is set.                         | `any`                          |
| extra   | Custom extra text of each item in options, with the option and index scope parameters. | `CheckboxGroupOptionSlotProps` |
| label   | Custom label of each item in options, with the option and index scope parameters.      | `CheckboxGroupOptionSlotProps` |
