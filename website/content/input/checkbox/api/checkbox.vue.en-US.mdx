import ApiType from '#/components/ApiType.astro';

**Props**

| Property       | Description                                                                                                             | Type            | Default                                          |
| -------------- | ----------------------------------------------------------------------------------------------------------------------- | --------------- | ------------------------------------------------ |
| addonId        | Id of the addon node, which aria-labelledby points to. Generated when omitted.                                          | `string`        | `undefined`                                      |
| defaultChecked | Whether the checkbox is initially checked, for uncontrolled use. Ignored inside a CheckboxGroup.                        | `boolean`       | `false`                                          |
| disabled       | Whether the checkbox is disabled.                                                                                       | `boolean`       | `semiGlobalDefault("Checkbox", "disabled")`      |
| extraId        | Id of the extra node, which aria-describedby points to. Generated when omitted.                                         | `string`        | `undefined`                                      |
| indeterminate  | Indeterminate state. It only affects the appearance and the native input's indeterminate flag, never the checked value. | `boolean`       | `false`                                          |
| modelValue     | Whether the checkbox is checked, controlled with v-model. Ignored inside a CheckboxGroup.                               | `boolean`       | `undefined`                                      |
| preventScroll  | Whether focusing prevents the browser from scrolling the element into view; applies to the focus method.                | `boolean`       | `semiGlobalDefault("Checkbox", "preventScroll")` |
| type           | Style type: default, card or pureCard. Inside a CheckboxGroup the group's type applies.                                 | `CheckboxType`  | `"default"`                                      |
| value          | The value this checkbox stands for in a CheckboxGroup. Without it the checkbox is not part of the group.                | `CheckboxValue` | `undefined`                                      |

**Events**

| Event             | Description                                                                                         | Callback parameters      |
| ----------------- | --------------------------------------------------------------------------------------------------- | ------------------------ |
| change            | Emitted when the checked state changes. The event's target is `{ checked, value, name, disabled }`. | `[event: CheckboxEvent]` |
| update:modelValue | Emitted when the checked state changes; drives v-model.                                             | `[checked: boolean]`     |

**Slots**

| Slot    | Description                                                                      | Scope parameters |
| ------- | -------------------------------------------------------------------------------- | ---------------- |
| default | Label content of the checkbox, which is also the native input's accessible name. | `any`            |
| extra   | Supplementary text, which aria-describedby points to.                            | `any`            |

**Exposes**

| Name  | Description                          | Type                                          |
| ----- | ------------------------------------ | --------------------------------------------- |
| blur  | Removes focus from the native input. | <ApiType detail={"() => void"}>Type</ApiType> |
| focus | Focuses the native input.            | <ApiType detail={"() => void"}>Type</ApiType> |
