### 内嵌输入框

使用 insetInput 可以控制日期面板是否展示内嵌输入框，默认为 false。v2.7.0 后支持。内嵌输入框适用于以下场景：

- 日期时间选择，可以直接通过内嵌输入框单独修改时间，无须通过滚轮选择时间
- 自定义触发器时 + 范围选择，使用内嵌输入框可以单独对开始和结束日期进行修改

insetInput 开启后包括以下功能：

- 点击触发器后，面板默认在原有位置弹出。你可以通过 position 自定义弹出位置
- 点击内嵌日期输入框，面板切换到日期选择；点击内嵌时间输入框，面板切换到时间选择
- 和外部的输入框一致，如果输入了非法日期，面板关闭后日期会回到之前的合法日期

<Notice type="primary" title="注意事项">

注意，开启后会对组件做一些调整和限制：

1. 触发器样式：未打开面板时触发器只读，打开时触发器禁用
2. 面板样式：type 包括 time 时，隐藏底部的切换按钮
3. 开启 insetInput 后 format 只支持 `dateFormat[ timeFormat]` 格式，使用其他格式会影响内嵌输入框 placeholder 和触发器文本的展示。timeFormat 为 12 小时制（如 `hh:mm a`）时，内嵌时间输入框按 24 小时制显示和输入

</Notice>

传入 `disabledDate` 可以禁用指定日期，传入 `disabledTime` 可以禁用指定时间，配合 `defaultPickerValue` 可以指定面板打开时所处的年月。

## API 参考

<Framework only="react">

<DatePickerReactApi />

其他原生属性（如 `id`、`title`、`data-*`、`aria-label`、`onClick`）落在根元素上，`tabIndex` 落在输入框上。`aria-labelledby`、`aria-describedby`、`aria-errormessage`、`aria-invalid`、`aria-required` 的落点：

- 单输入框：都落在输入框上
- 范围类型：根元素为 `role="group"`，`aria-labelledby` 落在根元素上，其余四项落在两个输入框上
- `triggerRender` 渲染的内容没有可聚焦元素：`aria-labelledby`、`aria-describedby`、`aria-errormessage`、`aria-invalid` 落在 role 为 `button` 的外层，`aria-required` 不转发
- `triggerRender` 渲染的内容自带可聚焦元素：都不转发，在渲染内容上自行设置

</Framework>

<Framework only="vue">

<DatePickerVueApi />

`modelValue` 配合 `update:modelValue` 即 `v-model`，`open` 配合 `update:open` 即 `v-model:open`。`autofocus` 是小写，`triggerRender`、`renderDate`、`renderFullDate`、`rangeSeparatorNode` 及各 ReactNode 属性改为插槽。

`class`、`style` 与 `id`、`title`、`data-*`、`aria-label` 等未声明的属性落在根元素上，带 `aria-label` 的根元素为 `role="group"`。`aria-labelledby`、`aria-describedby`、`aria-errormessage`、`aria-invalid`、`aria-required` 的落点：

- 单输入框：都落在输入框上
- 范围类型：根元素为 `role="group"`，`aria-labelledby` 落在根元素上，其余四项落在两个输入框上
- `#trigger` 的内容没有可聚焦元素：`aria-labelledby`、`aria-describedby`、`aria-errormessage`、`aria-invalid` 落在 role 为 `button` 的外层，`aria-required` 不转发
- `#trigger` 的内容自带可聚焦元素：都不转发，在插槽内容上自行设置

`change`、`focus`、`blur` 遮住根元素上冒泡的同名原生事件。放在 `<KeepAlive>` 中失活时面板关闭，只触发 `update:open` 与 `openChange`。

</Framework>

<Framework only="svelte">

<DatePickerSvelteApi />

`class`、`style` 与 `id`、`title`、`data-*`、`aria-label` 等未声明的属性落在根元素上，带 `aria-label` 的根元素为 `role="group"`。`aria-labelledby`、`aria-describedby`、`aria-errormessage`、`aria-invalid`、`aria-required` 的落点：

- 单输入框：都落在输入框上
- 范围类型：根元素为 `role="group"`，`aria-labelledby` 落在根元素上，其余四项落在两个输入框上
- `trigger` 的内容没有可聚焦元素：`aria-labelledby`、`aria-describedby`、`aria-errormessage`、`aria-invalid` 落在 role 为 `button` 的外层，`aria-required` 不转发

</Framework>

## Accessibility

### ARIA

- 输入框的 role 为 `combobox`，带 `aria-haspopup="dialog"`、随面板开关变化的 `aria-expanded`，`aria-controls` 指向面板；范围选择的两个输入框都是如此
- 单输入框未选中日期时 `aria-label` 为 `Choose date`，选中日期时为 `Change date`（传入 `aria-labelledby` 时以它为准）
- 自定义触发器（React 的 `triggerRender`，Vue 的 `#trigger` 插槽）渲染的内容没有可聚焦元素时，外层是 role 为 `button` 的焦点目标，名称同上
- 日期面板中月的 role 为 `grid`，以面板顶部的年月标题命名，周的 role 设置为 `row`，日期格子设置为 `gridcell`
- 年、月滚动列是 role 为 `listbox` 的列表，名称为「年」「月」
- 日期和时间禁用时对应选项的 `aria-disabled` 为 true
- 多选或范围选择时，月的 `aria-multiselectable` 为 true，选中时日期格子的 `aria-selected` 为 true
- 面板中一些装饰作用的 icon，它们的 `aria-hidden` 为 true

### 键盘和焦点

- 输入框聚焦时按 `下箭头` 打开面板；面板打开后再按 `下箭头`，焦点移入面板
- 日期网格是一个 Tab 停靠点，`方向键`、`Home`、`End`、`PageUp`、`PageDown`（加 `Shift` 按年）移动当前日期，`Enter` 或 `空格` 选中
- dateTime 面板底部的日期、时间切换是按钮，`Enter` 或 `空格` 切换
- 范围选择有值时，Tab 可以到达结束输入框之后的清除按钮，`Enter` 或 `空格` 清空
- 按 `Esc` 关闭面板；焦点在面板内时回到输入框，使用自定义触发器时回到该触发器
- 自定义触发器渲染的内容没有可聚焦元素时，外层可以用 Tab 到达，`Enter`、`空格` 或 `下箭头` 打开面板

## 日期时间格式

semi-ui 组件库中采用 [date-fns v4](https://date-fns.org/docs/Getting-Started) 作为日期时间引擎，格式化 token 含义如下：

- `"y"` ：年
- `"M"` ：月
- `"d"` ：日
- `"H"` ：小时
- `"m"` ：分钟
- `"s"` ：秒

下面以 `new Date('2023-12-09 08:08:00')` 和 `[new Date('2023-12-09 08:08:00'), new Date('2023-12-10 10:08:00')]` 为例说明不同 `format` 值对展示值的影响：

| 类型          | format              | 展示值                               |
| ------------- | ------------------- | ------------------------------------ |
| date          | yyyy-MM-dd          | 2023-12-09                           |
| dateTime      | yyyy-MM-dd HH:mm:ss | 2023-12-09 08:08:00                  |
| month         | yyyy-MM             | 2023-12                              |
| year          | yyyy                | 2023                                 |
| dateRange     | yyyy-MM-dd          | 2023-12-09 ～ 2023-12-10             |
| dateTimeRange | yyyy-MM-dd HH:mm:ss | 2023-12-09 08:08 ～ 2023-12-10 10:08 |

多个日期或时间默认使用 `","` （英文逗号）分隔。

> 更多 token 可以查阅 [date-fns 官网](https://date-fns.org/docs/Unicode-Tokens)

- **如何设置面板打开时默认显示的时间？**  
   可通过 defaultPickerValue 属性。

- **日期时间选择、范围日期选择，输入部分日期后，面板没有回显日期？**

    输入框需要输入完整后才会回显到面板上。比如，日期时间选择，完整要求日期和时间都已输入。范围日期选择，完整要求开始日期和结束日期都已输入。

- **日期时间选择面板底部的展示的时间是什么？**

    未选择时间时，它为 defaultPickerValue 中时间的值，如果没有设置则是面板打开时的时间。选择时间后，它为已选择的时间。

    由于设计上它有隐含两层含义，可能会导致歧义，建议使用内嵌样式，通过 `insetInput` 打开。使用前推荐阅读相关 <a href="#内嵌输入框">文档</a>。
