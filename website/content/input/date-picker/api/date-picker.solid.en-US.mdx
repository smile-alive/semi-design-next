**Methods**

| Method | Description                                                                                                                                                                        | Type                                                                |
| ------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------- |
| blur   | Blurs the input.                                                                                                                                                                   | <ApiType detail={"() => void"}>Type</ApiType>                       |
| close  | Closes the panel. A controlled open takes precedence; when it is controlled, close does not change the visibility.                                                                 | <ApiType detail={"() => void"}>Type</ApiType>                       |
| focus  | Focuses the input. A range type focuses the start input by default, or the end input with `'rangeEnd'`. With insetInput and the panel open, it focuses the input inside the panel. | <ApiType detail={"(focusType?: RangeInput) => void"}>Type</ApiType> |
| open   | Opens the panel. A controlled open takes precedence; when it is controlled, open does not change the visibility.                                                                   | <ApiType detail={"() => void"}>Type</ApiType>                       |
