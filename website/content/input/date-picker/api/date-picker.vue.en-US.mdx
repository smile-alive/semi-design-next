**Events**

| Event | Description | Callback parameters |
| --- | --- | --- |
| update:modelValue | Emitted when the value changes, for v-model. It is undefined when a single value is cleared and [] for range and multiple. | `[value: Date \| Date[] \| undefined]` |
| change | Emitted when the value changes, with the date and the date string; both are arrays for range and multiple. A range type emits it only after both dates are chosen. Shadows the native change event bubbling from the root. | `[date: Date \| Date[] \| undefined, dateString: string \| string[]]` |
| update:open | Emitted when the panel opens or closes, for v-model:open. | `[open: boolean]` |
| openChange | Emitted when the panel opens or closes, together with update:open. | `[open: boolean]` |
| focus | Emitted when an input gets focus, or when a click or key press on the trigger focuses the range start. rangeType is set for range inputs only, and moving between them does not emit again. Shadows the native focus event. | <ApiType detail={"[event: MouseEvent \u007c FocusEvent \u007c KeyboardEvent, rangeType?: RangeInput \u007c undefined]"}>Type</ApiType> |
| blur | Emitted when the panel closes. The argument is the mousedown that closed it from outside; other ways to close, such as confirming, choosing a date or Esc, pass none. Shadows the native blur event. | `[event?: MouseEvent \| undefined]` |
| clear | Emitted when the clear button is clicked. | `[event: MouseEvent]` |
| cancel | Emitted when the selection is cancelled, with the last confirmed value. Only with needConfirm. | `[date: Date \| Date[], dateString: string \| string[]]` |
| confirm | Emitted when the selection is confirmed, with the selected value. Only with needConfirm. | `[date: Date \| Date[], dateString: string \| string[]]` |
| panelChange | Emitted when the year or month of the panel changes. | `[date: Date \| Date[], dateString: string \| string[]]` |
| presetClick | Emitted when a preset button is clicked; the second argument is the native MouseEvent. | `[item: PresetType, event: MouseEvent]` |
| clickOutSide | Emitted when the panel is open and the user presses outside the panel and the trigger, with the native mousedown event. | `[event: MouseEvent]` |

**Slots**

| Slot | Description | Scope parameters |
| --- | --- | --- |
| trigger | Replaces the trigger. It receives value, inputValue, placeholder, disabled, size, inputReadOnly, rangeInputFocus, type, format, multiple, autofocus and componentProps, plus onChange (sets the input text), onEnterPress (commits it) and onClear. The default clear button no longer applies. | `DatePickerTriggerSlotProps` |
| date | Content of a day cell, with dayNumber and fullDate (yyyy-MM-dd). | `DatePickerDateSlotProps` |
| fullDate | Replaces the whole day cell, with dayNumber, fullDate and dayStatus. The cell keeps only its base and active classes. | `DatePickerFullDateSlotProps` |
| topSlot | Extra area at the top of the panel. | `any` |
| bottomSlot | Extra area at the bottom of the panel. | `any` |
| leftSlot | Extra area at the left of the panel. | `any` |
| rightSlot | Extra area at the right of the panel. | `any` |
| prefix | Prefix of the input. | `any` |
| insetLabel | Inset label of the input. | `any` |
| clearIcon | Custom clear icon, used when showClear is true. | `any` |
| rangeSeparator | How the separator between the range inputs is shown. It does not affect parsing. | `any` |
