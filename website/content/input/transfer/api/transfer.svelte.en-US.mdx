import ApiType from '#/components/ApiType.astro';

**Props**

| Property | Description | Type | Default |
| --- | --- | --- | --- |
| dataSource | Data source: an array of items for list, an array of groups for groupList, or tree data with children for treeList (a leaf writes `children: []`). The tree of a treeList only updates when a new array is passed, changes made in place are not seen. | `TransferDataSource` | `[]` |
| disabled | Whether the whole transfer is disabled. | `boolean` | `false` |
| draggable | Enables drag sorting of the selected items on the right. After a sort, value and onChange carry the new order. | `boolean` | `false` |
| emptyLeft | Shown when the left list has no data. The locale text appears when it is not provided; false hides the empty state. | `Snippet \| false` | - |
| emptyRight | Shown when nothing is selected. The locale text appears when it is not provided; false hides the empty state. | `Snippet \| false` | - |
| emptySearch | Shown when the search matches nothing. The locale text appears when it is not provided; false hides the empty state. | `Snippet \| false` | - |
| filter | Filtering logic. false hides the search box; a function replaces the default case-insensitive label match and returns true to keep an item. For a custom search in treeList, set it to true and pass the matching function as filterTreeNode in treeProps. | <ApiType detail={"boolean \u007c ((searchValue: string, item: TransferDataItem) => boolean)"}>Type</ApiType> | - |
| inputProps | Props passed to the search Input, see Input for the options. Transfer owns its value and onChange; to search from outside, call the search method. | `TransferInputProps` | - |
| label | Content of an item, used by the source row (the tree row in treeList), the selected row and the drag copy; the label of the item by default. | <ApiType detail={"Snippet\u003c[TransferLabelSnippetProps]>"}>Type</ApiType> | - |
| loading | Whether the options on the left are loading. | `boolean` | - |
| onBlur | Called once when the focus moves from inside the Transfer to outside it, with the FocusEvent; moving between the search box, checkboxes, items, remove buttons and drag handles does not call it, and a window blur (empty relatedTarget) does. | <ApiType detail={"(event: FocusEvent) => void"}>Type</ApiType> | - |
| onChange | Called when the selection changes, including after a drag sort, with the array of values and the array of their items. This is the callback of Transfer, not the native change of the root element. | <ApiType detail={"(values: TransferValue, items: TransferDataItem[]) => void"}>Type</ApiType> | - |
| onDeselect | Called when an item is unchecked, with that item. | <ApiType detail={"(item: TransferDataItem) => void"}>Type</ApiType> | - |
| onSearch | Called when the text of the search box changes, with the search value. A search driven by the search method does not call it. | <ApiType detail={"(searchValue: string) => void"}>Type</ApiType> | - |
| onSelect | Called when an item is checked, with that item. | <ApiType detail={"(item: TransferDataItem) => void"}>Type</ApiType> | - |
| pagination | Paging of the left panel, for list and groupList only. onPageChange lives inside the object. | `TransferPagination` | - |
| selectedHeader | Replaces the header of the right panel. | <ApiType detail={"Snippet\u003c[TransferSelectedHeaderSnippetProps]>"}>Type</ApiType> | - |
| selectedItem | Replaces one selected item on the right. With draggable, handle is a `Snippet<[Snippet]>`: write the drag icon as a snippet and wrap it with `{@render handle?.(grip)}`. With treeList and showPath, fullPath holds the whole path. | <ApiType detail={"Snippet\u003c[TransferSelectedItemSnippetProps]>"}>Type</ApiType> | - |
| selectedPanel | Replaces the whole right panel. Call onSortEnd after a drag sort you implemented has finished. | <ApiType detail={"Snippet\u003c[TransferSelectedPanelSnippetProps]>"}>Type</ApiType> | - |
| showPath | treeList only: whether the selected items on the right show their path from the root. | `boolean` | `false` |
| sourceHeader | Replaces the header of the left panel. leafOnlyNum is provided for treeList only. | <ApiType detail={"Snippet\u003c[TransferSourceHeaderSnippetProps]>"}>Type</ApiType> | - |
| sourceItem | Replaces one item on the left. index is the position among the shown items after filtering and paging, not the position in dataSource. | <ApiType detail={"Snippet\u003c[TransferSourceItemSnippetProps]>"}>Type</ApiType> | - |
| sourcePanel | Replaces the whole left panel, reusing the filtering and selection logic of Transfer. | <ApiType detail={"Snippet\u003c[TransferSourcePanelSnippetProps]>"}>Type</ApiType> | - |
| treeProps | treeList only: props passed to the Tree on the left, overriding the defaults multiple, disableStrictly, leafOnly, filterTreeNode and defaultExpandAll. Transfer decides the selection and the tree data, so value, onChange, keyMaps, treeData, treeDataSimpleJson and onChangeWithObject are ignored; of the Tree snippets only label is forwarded. | `TransferTreeProps` | - |
| type | Transfer type: list, groupList or treeList. | `TransferType` | `"list"` |
| value | Array of the values of the selected items, two-way bindable with bind:value. A plain value is the initial selection, which Transfer then maintains itself; `bind:value={get, set}` makes it fully controlled. Its order is the order on the right. | `TransferValue` | - |
| virtualize | Virtualizes the selected list on the right, only with the default right panel and draggable off. A numeric height applies as is; a string such as 100% is measured from the remaining panel height. | `TransferVirtualize` | - |

**Methods**

| Method | Description                                                                      | Type                                                       |
| ------ | -------------------------------------------------------------------------------- | ---------------------------------------------------------- |
| search | Searches as if the value were typed into the search box; onSearch is not called. | <ApiType detail={"(input: string) => void"}>Type</ApiType> |
