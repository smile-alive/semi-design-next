**Methods**

| Method         | Description                                                            | Type                                                                                       |
| -------------- | ---------------------------------------------------------------------- | ------------------------------------------------------------------------------------------ |
| insert         | Adds files at `index`, or at the end when `index` is omitted.          | <ApiType detail={"(files: Array\u003cCustomFile>, index?: number) => void"}>Type</ApiType> |
| openFileDialog | Opens the file dialog.                                                 | <ApiType detail={"() => void"}>Type</ApiType>                                              |
