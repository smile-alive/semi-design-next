import ApiType from '#/components/ApiType.astro';

**Props**

| Property | Description | Type | Default |
| --- | --- | --- | --- |
| autoAdjustOverflow | Whether the dropdown flips automatically when it would be clipped. | `boolean` | - |
| autofocus | Whether to focus the input after mount. | `boolean` | `false` |
| clearIcon | Snippet for the custom clear icon, effective when showClear is true. | `Snippet` | - |
| data | Data source of the candidates: an array of strings, numbers or objects. An object item uses value as the picked value and label as its text (value when label is missing); its disabled, class, style and data-\* fields go to the matching row, where class takes a string, array or object and style is a string. Use the item snippet for markup. | `T[]` | `[]` |
| defaultActiveFirstOption | Whether the first candidate is highlighted when the panel opens, so that Enter picks it directly. | `boolean` | `false` |
| defaultOpen | Whether the dropdown panel is open on mount; AutoComplete has no controlled open state. | `boolean` | - |
| disabled | Whether the component is disabled. | `boolean` | - |
| dropdownClassName | Class name of the dropdown list, applied to the role="listbox" element. | `string` | - |
| dropdownMatchSelectWidth | Whether the minimum width of the dropdown equals the width of the input. | `boolean` | `true` |
| dropdownStyle | Inline style string of the dropdown list, applied to the role="listbox" element. | `string` | - |
| emptyContent | Snippet for the content shown in the dropdown when data is empty. | `Snippet` | - |
| insetLabel | Snippet for the inset label of the input; passing it counts as having content. It is not rendered, and does not name the component, when prefix or trigger is used. | `Snippet` | - |
| insetLabelId | The id of the insetLabel element, which names the combobox and the listbox. When omitted, the component generates one while an insetLabel is rendered. | `string` | - |
| item | Snippet for the content of a candidate row, receiving `{ item, index }`: item is the data item as given and index is its position among the rendered items; without it the row shows the label. | <ApiType detail={"Snippet\u003c[AutoCompleteItemSnippetProps\u003cT>]>"}>Type</ApiType> | - |
| loading | Whether the dropdown shows a loading spinner in place of the candidates and the empty content. | `boolean` | `false` |
| maxHeight | Maximum height of the dropdown list; a number is in px. | `string \| number` | `300` |
| motion | Whether the dropdown animates when it shows and hides. | `boolean` | `true` |
| onBlur | Called once when the focus leaves the input. | <ApiType detail={"(event: FocusEvent) => void"}>Type</ApiType> | - |
| onChange | Called when the input text changes or a candidate is picked. | <ApiType detail={"(value: string \u007c number) => void"}>Type</ApiType> | - |
| onClear | Called after the clear button is used. | <ApiType detail={"() => void"}>Type</ApiType> | - |
| onDropdownVisibleChange | Called when the dropdown shows or hides, with its visibility. | <ApiType detail={"(visible: boolean) => void"}>Type</ApiType> | - |
| onFocus | Called once when the focus enters the input. | <ApiType detail={"(event: FocusEvent) => void"}>Type</ApiType> | - |
| onSearch | Called as the user types, with the typed text. | <ApiType detail={"(inputValue: string) => void"}>Type</ApiType> | - |
| onSelect | Called when a candidate is picked, with its value, or with the item without internal fields when onSelectWithObject is set. | <ApiType detail={"(value: string \u007c number \u007c AutoCompleteDataItem) => void"}>Type</ApiType> | - |
| onSelectWithObject | A boolean attribute, not a callback: when true, onSelect receives the data item without internal fields instead of its value. | `boolean` | `false` |
| placeholder | Placeholder of the input. | `string` | - |
| position | Position of the dropdown; the values are those of the Tooltip position. Unset, it is bottomLeft, or bottomRight when the ConfigProvider direction is rtl. | `Position` | - |
| prefix | Snippet for the prefix of the input. | `Snippet` | - |
| renderSelectedItem | The text the input shows for a picked item; it must return a string. A string or number item receives `{ value, label }`, an object item the item itself. | <ApiType detail={"(option: AutoCompleteSelectedItem\u003cT>) => string"}>Type</ApiType> | - |
| showClear | Whether to show the clear button when there is content. | `boolean` | `false` |
| size | Size of the input. | `Size` | - |
| stopPropagation | Whether click, mousedown and focus in/out events on the dropdown stop propagating. | `boolean \| string` | `true` |
| suffix | Snippet for the suffix of the input. | `Snippet` | - |
| trigger | Snippet that replaces the input. Its parameters are value, inputValue, placeholder, disabled, autofocus, size, validateStatus, showClear, insetLabelId, onChange (updates the input text, calls onSearch and onChange and opens the list), onClear, onFocus, onBlur and controlAttrs (the aria-\* attributes given to the component, for the focusable element of the custom trigger). With it, id lands on the root element. | <ApiType detail={"Snippet\u003c[AutoCompleteTriggerSnippetProps]>"}>Type</ApiType> | - |
| validateStatus | Validation status; it only affects the style. | `ValidateStatus` | `"default"` |
| value | Current value of the input, supports `bind:value`. Left out, the component manages it; a one-way `value={x}` only seeds it, and for a fully controlled input use the function binding `bind:value={get, set}`. There is no defaultValue. | `string \| number` | - |

**Methods**

| Method           | Description                                                      | Type                                                                     |
| ---------------- | ---------------------------------------------------------------- | ------------------------------------------------------------------------ |
| blur             | Removes focus from the input.                                    | <ApiType detail={"() => void"}>Type</ApiType>                            |
| focus            | Focuses the input.                                               | <ApiType detail={"(options?: FocusOptions) => void"}>Type</ApiType>      |
| getNativeElement | Returns the root div that wraps the input or the custom trigger. | <ApiType detail={"() => HTMLDivElement \u007c undefined"}>Type</ApiType> |
