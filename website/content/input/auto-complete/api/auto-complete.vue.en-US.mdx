**Events**

| Event                 | Description                                                                                                                                 | Callback parameters                                 |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------- |
| blur                  | Emitted once when the focus leaves the component. It is a component event and hides the native blur event.                                  | `[event: FocusEvent]`                               |
| change                | Emitted when the input text changes or a candidate is picked. It is a component event and hides the native change event of the input.       | `[value: string \| number]`                         |
| clear                 | Emitted after the clear button is used.                                                                                                     | `[]`                                                |
| dropdownVisibleChange | Emitted when the dropdown shows or hides, with its visibility. It also fires with false when the component is deactivated inside KeepAlive. | `[visible: boolean]`                                |
| focus                 | Emitted once when the focus enters the component. It is a component event and hides the native focus event.                                 | `[event: FocusEvent]`                               |
| keydown               | Emitted after the component has handled the key, with the KeyboardEvent. It hides the native keydown event.                                 | `[event: KeyboardEvent]`                            |
| search                | Emitted as the user types, with the typed text.                                                                                             | `[inputValue: string]`                              |
| select                | Emitted when a candidate is picked, with its value, or with the item without internal fields when selectWithObject is set.                  | `[value: string \| number \| AutoCompleteDataItem]` |
| update:modelValue     | Emitted when the input text changes or a candidate is picked, for v-model to write back. It fires before change.                            | `[value: string \| number]`                         |

**Slots**

| Slot | Description | Scope parameters |
| --- | --- | --- |

| item | Content of a candidate row. item is the data item as given and index is its position among the rendered items; without it the row shows the label. | <ApiType detail={"AutoCompleteItemSlotProps\u003cT>"}>Type</ApiType> |

| suffix | Suffix content of the input. | `any` |
| trigger | Replaces the input. Its parameters are value, inputValue, placeholder, disabled, autofocus, size, validateStatus, showClear, insetLabelId, onChange (updates the input text, emits search and change and opens the list), onClear, onFocus, onBlur, controlAttrs (the aria-\* attributes given to the component, for the focusable element of the custom trigger) and componentProps. With it, id lands on the root element. | <ApiType detail={"AutoCompleteTriggerSlotProps\u003cT>"}>Type</ApiType> |
