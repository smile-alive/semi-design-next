**Props**

| Property | Description | Type | Default |
| --- | --- | --- | --- |
| allowCreate | Whether items missing from the list can be created, used together with `filter`. `onCreate` fires on creation, and `renderCreateItem` customizes the created item. | `boolean` | `false` |
| aria-label | Accessible name of the combobox. It takes precedence over `insetLabel`, and `aria-labelledby` takes precedence over it. | `React.AriaAttributes['aria-label']` | - |
| arrowIcon | Custom dropdown arrow icon on the right. With `showClear` on and a value selected, hovering shows the clear icon first. | `React.ReactNode` | <ApiType detail={"\u003cIconChevronDown />"}>Type</ApiType> |
| autoAdjustOverflow | Whether the dropdown flips its direction automatically when it is covered. | `boolean` | `true` |
| autoClearSearchValue | With both `multiple` and `filter` on, whether the search keyword is cleared after an option is selected. | `boolean` | `true` |
| autoFocus | Whether the Select is focused on the initial render. | `boolean` | - |
| borderless | Whether to use the borderless style. | `boolean` | `false` |
| children | Options. Direct children must be `Select.Option` or `Select.OptGroup`, and fragments are expanded. When `optionList` is passed, it is used and children are ignored. | `React.ReactNode` | - |
| className | Class name, applied to the trigger root element. | `string` | - |
| clearIcon | Custom icon of the clear button, effective when `showClear` is `true`. | `React.ReactNode` | - |
| clickToHide | When the dropdown is open, whether clicking the Select again closes the dropdown. | `boolean` | - |
| defaultActiveFirstOption | Whether the first enabled option is highlighted when nothing is selected, so Enter selects it directly. When a value is selected, opening the dropdown highlights the first selected option. | `boolean` | `true` |
| defaultOpen | Whether the dropdown is open by default. | `boolean` | `false` |
| defaultValue | Initially selected value, for uncontrolled use. An array in multiple mode. | <ApiType detail={"SelectValue\u003cT>"}>Type</ApiType> | - |
| disabled | Whether the Select is disabled. | `boolean` | `false` |
| dropdownClassName | Class name of the dropdown. | `string` | - |
| dropdownMatchSelectWidth | Whether the minimum width of the dropdown matches the Select. The width itself is not fixed; use `dropdownStyle` to set a fixed width. | `boolean` | `true` |
| dropdownStyle | Style of the dropdown, for example `width` to set its width. | `React.CSSProperties` | - |
| ellipsisTrigger | With `maxTagCount` set in multiple mode, whether overflowing tags adapt to the width, truncating the last tag when space runs short. It costs some performance, so it is not recommended for large forms. | `boolean` | `false` |
| emptyContent | Content shown when there are no results. When unset, the locale's empty text is shown; `null` shows nothing in the dropdown. | `React.ReactNode` | - |
| expandRestTagsOnClick | With `maxTagCount` set in multiple mode, whether all remaining tags are shown while the dropdown is open. | `boolean` | `false` |
| filter | Whether the Select is searchable. `true` filters by whether the option label contains the input. | id | Id of the trigger. Option ids are derived from it. Generated by the component when unset. | `string` | - |
| innerBottomSlot | Custom content rendered at the bottom inside the option list. It scrolls with the list and shows when the list is scrolled to the bottom. | `React.ReactNode` | - |
| innerTopSlot | Custom content rendered at the top inside the option list. It scrolls with the list and shows when the list is scrolled to the top. | `React.ReactNode` | - |
| inputProps | Extra props of the search input when `filter` is `true`; see the Input component for the available props. Do not pass `value`, `ref`, `onChange` or `onFocus`, which would override the Select's handlers and break its behavior. | <ApiType detail={"Omit\u003cInputProps, keyof { value?: InputProps['value']; onFocus?: InputProps['onFocus']; onChange?: InputProps['onChange']; }>"}>Type</ApiType> | - |
| insetLabel | Inset label inside the trigger, also the name source of the combobox and the listbox. It is not rendered and is not used as the name when `prefix` is set. | `React.ReactNode` | - |
| insetLabelId | Id of the `insetLabel` element, which the `aria-labelledby` of the combobox points to. Generated by the component when unset. | `string` | - |
| loading | Whether the dropdown shows a loading spinner. Options are hidden while loading. | `boolean` | - |
| max | Maximum number of selectable options, effective in multiple mode only. Options beyond it cannot be selected, and `onExceed` fires. | `number` | - |
| maxHeight | Maximum height of the option list in the dropdown. With virtualization and `virtualize.height` above the default 270px, set it to the same value to avoid a double scrollbar. | `string \| number` | `270` |
| maxTagCount | In multiple mode, selected items beyond this count are shown as `+N`. | `number` | - |
| motion | Whether the dropdown uses motion. | `boolean` | `true` |
| multiple | Whether multiple selection is enabled. | `Multiple` | `false` |
| onBlur | Callback when the Select loses focus. When a click outside closes the open dropdown, the argument is that mousedown's native event. | <ApiType detail={"(e: React.FocusEvent\u003cHTMLElement> \u007c globalThis.MouseEvent) => void"}>Type</ApiType> | - |
| onChange | Callback when the value changes. The argument is `T \| undefined` in single mode and `T[]` in multiple mode, or the option object when `onChangeWithObject` is `true`. | <ApiType detail={"(value: SelectChangeValue\u003cT, Multiple>) => void"}>Type</ApiType> | - |
| onChangeWithObject | Whether the other properties of the option are passed to `onChange`. When `true`, `onChange` receives an object such as `{ value, label, ...rest }`, and `value` and `defaultValue` should also be objects with `value` and `label` keys. | `boolean` | `false` |
| onClear | Callback when the clear button is clicked. | <ApiType detail={"() => void"}>Type</ApiType> | - |
| onCreate | Callback when an option is created with `allowCreate` on. The argument is the created option. | <ApiType detail={"(option: OptionProps) => void"}>Type</ApiType> | - |
| onDeselect | Callback when an option is deselected, in multiple mode only. The first argument is the original option value, and the second is the option object. | <ApiType detail={"(value: OptionProps['value'], option: Record\u003cstring, any>) => void"}>Type</ApiType> | - |
| onDropdownVisibleChange | Callback when the dropdown opens or closes, receiving whether it is visible. | <ApiType detail={"(visible: boolean) => void"}>Type</ApiType> | - |
| onExceed | Callback when the selection would exceed `max`, in multiple mode only. The argument is the option that was rejected. | <ApiType detail={"(option: OptionProps) => void"}>Type</ApiType> | - |
| onFocus | Callback when the Select gets focus. | <ApiType detail={"(e: React.FocusEvent\u003cHTMLElement>) => void"}>Type</ApiType> | - |
| onListScroll | Callback when the option list scrolls. | <ApiType detail={"(e: React.UIEvent\u003cHTMLDivElement>) => void"}>Type</ApiType> | - |
| onMouseEnter | Callback when the mouse enters the Select. | <ApiType detail={"(e: React.MouseEvent) => any"}>Type</ApiType> | - |
| onMouseLeave | Callback when the mouse leaves the Select. | <ApiType detail={"(e: React.MouseEvent) => any"}>Type</ApiType> | - |
| onSearch | Callback when the search input changes. The first argument is the input value, and the second is the event that caused the change. It is `undefined` when triggered through the ref `search` method or `triggerRender`. | <ApiType detail={"(value: string, event?: InputChangeEvent \u007c React.KeyboardEvent \u007c React.MouseEvent \u007c globalThis.MouseEvent) => void"}>Type</ApiType> | - |
| onSelect | Callback when an option is selected. The first argument is always the original option value, even with `onChangeWithObject`, and the second is the option object. | <ApiType detail={"(value: OptionProps['value'], option: Record\u003cstring, any>) => void"}>Type</ApiType> | - |
| optionList | Options as an array. Each item needs `value` and `label`; its other properties are passed back with the option. | `OptionProps[]` | - |
| outerBottomSlot | Custom content rendered at the bottom of the dropdown, beside the option list. It stays visible whether or not the list scrolls. | `React.ReactNode` | - |
| outerTopSlot | Custom content rendered at the top of the dropdown, beside the option list. It stays visible whether or not the list scrolls. | `React.ReactNode` | - |
| placeholder | Text shown when no option is selected. | `React.ReactNode` | `""` |
| position | Position of the dropdown, with the same values as the Tooltip `position`. When unset, it is `bottomLeft` in left-to-right text and `bottomRight` in right-to-left text. | `Position` | - |
| prefix | Prefix of the trigger, as text or a ReactNode. Text and icons get automatic side spacing, while custom nodes get none. | `React.ReactNode` | - |
| preventScroll | Whether focusing through the `focus` method prevents the browser from scrolling the document to show the focused element. | `boolean` | - |
| ref | Points to the `SelectHandle`, whose methods are listed in Methods below. | <ApiType detail={"React.Ref\u003cSelectHandle>"}>Type</ApiType> | - |
| remote | Whether search is remote. When `true`, input changes skip local filtering, so the results must be supplied by updating `optionList`. | `boolean` | `false` |
| renderCreateItem | Custom content of the create item when `allowCreate` is `true`, called with `(inputValue, isFocus, style)`. When unset, it shows the locale's create text followed by the input. With virtualization, apply `style` to the custom node. | <ApiType detail={"(inputValue: OptionProps['value'], focus: boolean, style?: React.CSSProperties) => React.ReactNode"}>Type</ApiType> | - |
| renderOptionItem | Takes over the rendering of each candidate option. The arguments include `id`, `value`, `label`, `selected`, `focused`, `disabled`, `inputValue`, `className`, `style`, `onClick` and `onMouseEnter`. Apply `style`, `className`, `onClick` and `onMouseEnter` to the wrapper element, and write `id` on it together with `role="option"`, `aria-selected` and `aria-disabled`. | <ApiType detail={"(props: optionRenderProps) => React.ReactNode"}>Type</ApiType> | - |
| renderSelectedItem | Custom rendering of the selected item in the trigger. In single mode it receives the option object and returns a ReactNode. In multiple mode it receives the option object and `{ index, disabled, onClose }`, and returns `{ isRenderInTag, content }`; when `isRenderInTag` is `true`, `content` is wrapped in a tag with a background and a close button. | <ApiType detail={"ByMultiple\u003cMultiple, RenderSingleSelectedItemFn, RenderMultipleSelectedItemFn>"}>Type</ApiType> | - |
| restTagsPopoverProps | Popover props for the overflowing tags when `showRestTagsPopover` is on, such as `position` and `trigger`. See the Popover component. | `PopoverProps` | `{}` |
| searchPlaceholder | Placeholder of the search input when it is in the dropdown, that is, when `searchPosition` is `dropdown`. | `string` | - |
| searchPosition | Position of the search input when `filter` is on. `trigger` places it inside the Select, and `dropdown` places it at the top of the dropdown. Combined with `triggerRender`, it allows more flexible interaction. | `'trigger' \| 'dropdown'` | `"trigger"` |
| showArrow | Whether the dropdown arrow is shown. | `boolean` | `true` |
| showClear | Whether the clear button is shown. | `boolean` | `false` |
| showRestTagsPopover | When tags overflow `maxTagCount`, whether hovering over `+N` shows the remaining content in a Popover. | `boolean` | `false` |
| size | Size, one of `small`, `default` and `large`. The default size applies when unset. | `SelectSize` | - |
| spacing | Distance in px between the dropdown and the Select. An `{ x, y }` object sets the horizontal and vertical distances separately. It is `8` when unset. | `number \| { x: number; y: number }` | - |
| stopPropagation | Whether click events on the dropdown stop propagating. | `boolean` | `true` |
| style | Style, applied to the trigger root element. | `React.CSSProperties` | - |
| suffix | Suffix of the trigger, as text or a ReactNode. The rules are the same as for `prefix`. | `React.ReactNode` | - |
| triggerRender | Custom trigger of the Select. Its arguments include `value`, `inputValue`, `onSearch`, `onRemove`, `onClear`, `disabled`, `placeholder` and `componentProps`. | validateStatus | Validation status, one of `warning`, `error` and `default`. It only changes styles such as the background color. `default` applies when unset. | `ValidateStatus` | - |
| value | Selected value. Passing it makes the Select controlled, used together with `onChange`. An array in multiple mode. | <ApiType detail={"SelectValue\u003cT>"}>Type</ApiType> | - |
| virtualize | Enables list virtualization for large option lists. It takes `height` (default 270), `width` (default `100%`) and `itemSize` (the height of each option row, required). | `virtualListProps` | - |

**Methods**

| Method | Description | Type |
| --- | --- | --- |
| clearInput | Clears the value of the search input. | <ApiType detail={"() => void"}>Type</ApiType> |
| close | Closes the dropdown. | <ApiType detail={"() => void"}>Type</ApiType> |
| deselectAll | Clears all selected options. | <ApiType detail={"() => void"}>Type</ApiType> |
| focus | Focuses the trigger, or the search input when the Select is searchable. The dropdown opens only when the Select is searchable. | <ApiType detail={"() => void"}>Type</ApiType> |
| open | Opens the dropdown. | <ApiType detail={"() => void"}>Type</ApiType> |
| rePosition | Recomputes the dropdown position from the trigger's current position at once. The dropdown already follows scrolling, window resizing, trigger moves and size changes of the trigger or list, so this is rarely needed; following a trigger move lands a frame late, so call this to align within the same frame. | <ApiType detail={"() => void"}>Type</ApiType> |
| search | Searches as if the value had been typed, and sets it into the search input. Without an event, the second argument of `onSearch` is `undefined`. | <ApiType detail={"(value: string, event?: unknown) => void"}>Type</ApiType> |
| selectAll | Selects every visible, enabled option. Effective in multiple mode only. | <ApiType detail={"() => void"}>Type</ApiType> |
