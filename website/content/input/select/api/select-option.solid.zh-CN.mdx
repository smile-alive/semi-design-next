**Props**

| 属性     | 说明                                                                                                                                | 类型                          | 默认值 |
| -------- | ----------------------------------------------------------------------------------------------------------------------------------- | ----------------------------- | ------ |
| children | 选项在下拉列表与回显中的内容，设置后代替 label 显示，可以是任意 JSX。它不参与搜索，也不作为回调里的 label；需要搜索时同时传 label。 | `JSX.Element`                 | -      |
| class    | 选项行的类名。                                                                                                                      | `string`                      | -      |
| disabled | 是否禁用。                                                                                                                          | `boolean`                     | -      |
| label    | 选项的文本，用于搜索、高亮与回调；没有 children 时作为显示内容。未设置时取 value。                                                  | `string \| number`            | -      |
| showTick | 选中时是否显示 √ 图标，默认显示。                                                                                                   | `boolean`                     | -      |
| style    | 选项行的样式。                                                                                                                      | `JSX.CSSProperties \| string` | -      |
| value    | 选项的值，用来识别选项，每个选项都应声明。                                                                                          | `string \| number`            | -      |
