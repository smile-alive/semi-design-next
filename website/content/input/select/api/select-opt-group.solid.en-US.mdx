**Props**

| Property | Description                                                                                                                                   | Type                          | Default |
| -------- | --------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------- | ------- |
| children | The options in the group, which must be `Select.Option`.                                                                                      | `JSX.Element`                 | -       |
| class    | Class name of the group title.                                                                                                                | `string`                      | -       |
| id       | The id of the group title, which the aria-labelledby of the group points to. Generated when not set.                                          | `string`                      | -       |
| label    | Text of the group title, which takes part in the default search. When empty no title renders and the options are not wrapped in role="group". | `string \| number`            | -       |
| style    | Style of the group title.                                                                                                                     | `JSX.CSSProperties \| string` | -       |
