**Props**

| 属性     | 说明                                                                    | 类型                          | 默认值 |
| -------- | ----------------------------------------------------------------------- | ----------------------------- | ------ |
| children | 分组内的选项，只能是 `Select.Option`。                                  | `JSX.Element`                 | -      |
| class    | 分组标题的类名。                                                        | `string`                      | -      |
| id       | 分组标题的 id，分组的 aria-labelledby 指向它。未传时由组件生成。        | `string`                      | -      |
| label    | 分组标题文本，参与默认搜索。为空时不渲染标题，分组也不包 role="group"。 | `string \| number`            | -      |
| style    | 分组标题的样式。                                                        | `JSX.CSSProperties \| string` | -      |
