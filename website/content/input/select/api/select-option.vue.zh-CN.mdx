| ---------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------ | ----------- |
| classNames       | 选项内部各部位的类名，键为 icon（选中的对勾图标容器）、content（默认插槽为纯文本时的文本元素），值的写法同 class，在 Select 的 item\* 类名之后追加。 | <ApiType detail={"Partial\u003cRecord\u003cOptionPart, ClassValue>>"}>Type</ApiType> | `undefined` |

| disabled         | 是否禁用。                                                                                                                                           | `boolean`                                                                            | `undefined` |
| empty            | 供 Select 内部使用，渲染空状态行，使用方不需要设置。                                                                                                 | `boolean`                                                                            | `undefined` |
| focused          | 供 Select 内部使用，表示选项被键盘或指针高亮，使用方不需要设置。                                                                                     | `boolean`                                                                            | `undefined` |

| label            | 选项的文本，为字符串或数字。显示与匹配时优先取 label，没有时取默认插槽中的纯文本，再取 value；带标记的内容写在默认插槽里，显示时优先于 label。       | `string \| number`                                                                   | `undefined` |

| parentStyles     | 供 Select 与 AutoComplete 内部使用，父级 styles 中的 item、itemIcon、itemContent，使用方不需要设置。                                                 | <ApiType detail={"Partial\u003cRecord\u003cSelectPart, StyleValue>>"}>Type</ApiType> | `undefined` |
| selected         | 供 Select 内部使用，表示选项被选中，使用方不需要设置。                                                                                               | `boolean`                                                                            | `undefined` |
| semiOptionId     | 供 Select 内部使用，选项行的 id，使用方不需要设置。                                                                                                  | `string`                                                                             | `undefined` |
| showTick         | 选中时是否显示 √ 图标。                                                                                                                              | `boolean`                                                                            | `undefined` |
| styles           | 选项内部各部位的内联样式，键同 classNames。                                                                                                          | <ApiType detail={"Partial\u003cRecord\u003cOptionPart, StyleValue>>"}>Type</ApiType> | `undefined` |
