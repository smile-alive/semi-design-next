| motion | Whether the dropdown layer animates. | `boolean` | `true` |
| multiple | Whether multiple options can be selected. | `boolean` | `false` |
| onBlur | Called once when the focus leaves the Select; a press outside the open dropdown passes its mousedown event. | <ApiType detail={"(event: FocusEvent \u007c MouseEvent) => void"}>Type</ApiType> | - |

| onChangeWithObject | Whether `onChange` and `value` carry option objects instead of option values. | `boolean` | `false` |
| onClear | Called when the clear button is clicked. | <ApiType detail={"() => void"}>Type</ApiType> | - |
| onCreate | Called when an option is created. | <ApiType detail={"(option: SelectOptionProps) => void"}>Type</ApiType> | - |
| onDeselect | Called when an option is deselected in multiple mode. | <ApiType detail={"(value: string \u007c number, option: SelectOptionProps) => void"}>Type</ApiType> | - |
| onDropdownVisibleChange | Called when the dropdown list opens or closes. | <ApiType detail={"(visible: boolean) => void"}>Type</ApiType> | - |
| onExceed | Called when the selection would exceed `max`. | <ApiType detail={"(option: SelectOptionProps) => void"}>Type</ApiType> | - |
| onFocus | Called once when the focus enters the Select. | <ApiType detail={"(event: FocusEvent) => void"}>Type</ApiType> | - |
| onListScroll | Called when the dropdown list scrolls. | <ApiType detail={"(event: Event) => void"}>Type</ApiType> | - |
| onSearch | Called when the search keyword changes; there is no event when it comes from `search()` or the `onSearch` of the `trigger` snippet. | <ApiType detail={"(value: string, event?: Event) => void"}>Type</ApiType> | - |
| onSelect | Called when an option is selected. | <ApiType detail={"(value: string \u007c number, option: SelectOptionProps) => void"}>Type</ApiType> | - |

| optionLabel | Replaces only the text inside an option row, a snippet with `{ option }`. | optionList | The option data. An entry has `value`, `label`, `disabled`, `showTick`, `class`, `style` and an optional `group: { key, label }`; other fields travel with the option record. Entries of one group must be adjacent. | `SelectOptionProps[]` | - |
| outerBottomSlot | Content at the bottom of the dropdown layer, level with the option list, a snippet; always visible while the list scrolls. | `Snippet` | - |
| outerTopSlot | Content at the top of the dropdown layer, level with the option list, a snippet; always visible while the list scrolls. | `Snippet` | - |
| placeholder | Placeholder while nothing is selected. | `string` | - |
| position | Placement of the dropdown layer relative to the trigger. | `Position` | - |
| prefix | Prefix of the selection box, a snippet. The side padding is added when the content is text or an Icon. | `Snippet` | - |
| preventScroll | Whether focusing stops the browser from scrolling the element into view. | `boolean` | - |
| remote | Whether the search is remote. When on, the options are not filtered locally and the caller updates `optionList`. | `boolean` | `false` |
| restTagsPopoverProps | Popover props of the +N popover. | `PopoverProps` | - |
| searchPlaceholder | Placeholder of the search input when it is in the dropdown list (`searchPosition="dropdown"`). | `string` | - |
| searchPosition | Where the search input sits: `trigger` or `dropdown`. | `'trigger' \| 'dropdown'` | `"trigger"` |
| selectedItem | The selected content, a snippet with `{ option, index, disabled, onClose }`. In single mode it replaces the selection box content, in multiple mode the content of each tag. | <ApiType detail={"Snippet\u003c[SelectSelectedItemSnippetProps]>"}>Type</ApiType> | - |
| showArrow | Whether to show the dropdown arrow. | `boolean` | `true` |
| showClear | Whether to show the clear button. | `boolean` | `false` |
| showRestTagsPopover | Whether hovering +N shows the remaining tags in a Popover once `maxTagCount` is exceeded. | `boolean` | `false` |
| size | Size: `small`, `default` or `large`. | `SelectSize` | - |
| spacing | Gap between the dropdown layer and the trigger. | `number \| { x: number; y: number }` | - |
| stopPropagation | Whether clicks inside the dropdown layer are stopped from bubbling out. | `boolean` | `true` |
| suffix | Suffix of the selection box, a snippet. The side padding is added when the content is text or an Icon. | `Snippet` | - |
| tag | Replaces each tag in multiple mode, a snippet with the parameters of `selectedItem`; it takes precedence over `selectedItem`. | <ApiType detail={"Snippet\u003c[SelectSelectedItemSnippetProps]>"}>Type</ApiType> | - |
| trigger | Replaces the trigger content, a snippet with `{ value, inputValue, placeholder, disabled, onSearch, onClear, onRemove }`. | <ApiType detail={"Snippet\u003c[SelectTriggerSnippetProps]>"}>Type</ApiType> | - |
| validateStatus | Validation status: `default`, `warning` or `error`; it only affects styles such as the background color. | `ValidateStatus` | - |
| value | The selected value, supports `bind:value`. A single value in single mode, an array in multiple mode, and option objects with `onChangeWithObject`. | virtualize | Turns on list virtualization; `itemSize` is required. Group titles and `role="group"` are not rendered with it, and the options are laid out flat in order. | `SelectVirtualize` | - |

**Methods**

| Method      | Description                                                                                  | Type                                                                        |
| ----------- | -------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------- |
| clearInput  | Clears the value of the search input.                                                        | <ApiType detail={"() => void"}>Type</ApiType>                               |
| close       | Closes the dropdown list.                                                                    | <ApiType detail={"() => void"}>Type</ApiType>                               |
| deselectAll | Clears all selected options.                                                                 | <ApiType detail={"() => void"}>Type</ApiType>                               |
| focus       | Focuses the trigger, or the search input with the dropdown list opened when searchable.      | <ApiType detail={"() => void"}>Type</ApiType>                               |
| open        | Opens the dropdown list.                                                                     | <ApiType detail={"() => void"}>Type</ApiType>                               |
| rePosition  | Recomputes the dropdown position from the trigger's current position at once; rarely needed. | <ApiType detail={"() => void"}>Type</ApiType>                               |
| search      | Searches as if the keyword were typed into the search input.                                 | <ApiType detail={"(keyword: string, event?: Event) => void"}>Type</ApiType> |
| selectAll   | Selects every shown, enabled option; multiple mode only.                                     | <ApiType detail={"() => void"}>Type</ApiType>                               |
