**Props**

| Property  | Description                                                                    | Type                  | Default |
| --------- | ------------------------------------------------------------------------------ | --------------------- | ------- |
| children  | Options in the group, as `Select.Option` elements.                             | `React.ReactNode`     | -       |
| className | Class name of the group title.                                                 | `string`              | -       |
| label     | Title of the group. Options in the group sit in a `group` named by this title. | `React.ReactNode`     | -       |
| style     | Style of the group title.                                                      | `React.CSSProperties` | -       |
