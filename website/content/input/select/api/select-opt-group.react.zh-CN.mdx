**Props**

| 属性      | 说明                                                          | 类型                  | 默认值 |
| --------- | ------------------------------------------------------------- | --------------------- | ------ |
| children  | 分组内的选项，即 `Select.Option`。                            | `React.ReactNode`     | -      |
| className | 分组标题的类名。                                              | `string`              | -      |
| label     | 分组标题。设置后，分组内的选项位于以该标题命名的 `group` 中。 | `React.ReactNode`     | -      |
| style     | 分组标题的样式。                                              | `React.CSSProperties` | -      |
