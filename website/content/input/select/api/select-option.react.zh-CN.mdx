**Props**

| 属性       | 说明                                                                                                                                     | 类型                                                                                          | 默认值 |
| ---------- | ---------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------- | ------ |
| children   | 选项的内容。未设置 `label` 时作为展示的内容。                                                                                            | `React.ReactNode`                                                                             | -      |
| className  | 选项的类名。                                                                                                                             | `string`                                                                                      | -      |
| classNames | 选项内部各部位的类名，键为 `icon`（选中的对勾图标容器）、`content`（children 为字符串时的文本元素），在 Select 的 `item*` 类名之后追加。 | <ApiType detail={"Partial\u003cRecord\u003cOptionPart, string>>"}>Type</ApiType>              | -      |
| disabled   | 是否禁用该选项。                                                                                                                         | `boolean`                                                                                     | -      |
| label      | 展示的文本，可以是字符串、数字或 ReactNode。渲染时优先取 `label`，未设置时依次取 `children` 与 `value`。                                 | `string \| number \| React.ReactNode`                                                         | -      |
| showTick   | 选中时是否展示 √ 图标。由 Select 渲染的选项默认展示。                                                                                    | `boolean`                                                                                     | -      |
| style      | 选项行的样式。                                                                                                                           | `React.CSSProperties`                                                                         | -      |
| styles     | 选项内部各部位的内联样式，键同 `classNames`。                                                                                            | <ApiType detail={"Partial\u003cRecord\u003cOptionPart, React.CSSProperties>>"}>Type</ApiType> | -      |
| value      | 选项的值。同一个 Select 内 `value` 不应重复，`label` 可以重复。                                                                          | `V`                                                                                           | -      |
