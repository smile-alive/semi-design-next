**Props**

| Property | Description                                                                                                                   | Type               | Default     |
| -------- | ----------------------------------------------------------------------------------------------------------------------------- | ------------------ | ----------- |
| label    | The text of the group title, a string or number, also matched by the default search; a title with markup uses the label slot. | `string \| number` | `undefined` |

| Event | Description | Callback parameters |

| None  |             |                     |

**Slots**

| Slot    | Description                                                                 | Scope parameters |
| ------- | --------------------------------------------------------------------------- | ---------------- |
| default | The options of the group; only Select.Option is accepted as a direct child. | `any`            |
| label   | A custom group title, taking precedence over the label prop.                | `any`            |
