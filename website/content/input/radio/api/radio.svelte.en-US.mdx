import ApiType from '#/components/ApiType.astro';

**Props**

| Property | Description | Type | Default |
| --- | --- | --- | --- |
| addonClassName | Class name of the container wrapping the content. | `string` | - |
| addonId | Id of the addon node, which aria-labelledby points to. Generated when omitted. | `string` | - |
| addonStyle | Inline style of the container wrapping the content. Accepts a string only. | `string` | - |
| checked | Whether the radio is checked; bind it with `bind:checked`. Ignored inside a RadioGroup. `bind:checked={get, set}` makes it fully controlled; a plain `checked` is the initial value, a click overrides it inside the component, and a new value from the parent wins again. | `boolean` | - |
| children | Label content snippet of the radio. The rest of the tag's content is this snippet. | `Snippet` | - |
| disabled | Whether the radio is disabled. | `boolean` | - |
| displayMode | When set to vertical, the radio is displayed as a block and takes a line of its own. | `RadioDisplayMode` | - |
| extra | Snippet of the supplementary text, which aria-describedby points to. Not rendered when type is button. | `Snippet` | - |
| extraId | Id of the extra node, which aria-describedby points to. Generated when omitted. | `string` | - |
| mode | When set to advanced, a checked radio can be unchecked by clicking it or pressing Space. Inside a RadioGroup the group's mode applies. | `RadioMode` | `""` |
| onChange | Called when the checked state changes. The event's `target` is `{ checked, value, name, disabled }`. | <ApiType detail={"(event: RadioChangeEvent) => void"}>Type</ApiType> | - |
| prefixCls | CSS class name prefix. When omitted it falls back to the enclosing RadioGroup's value, then the global default. | `string` | - |
| preventScroll | Whether focusing prevents the browser from scrolling the element into view; applies to the focus method. | `boolean` | - |
| type | Style type: default, button, card or pureCard. Inside a RadioGroup the group's type applies. | `RadioType` | `"default"` |
| value | The radio's value, which a RadioGroup compares to decide whether it is checked. It is also the native input's value in form submission. | `RadioValue` | - |

**Methods**

| Method | Description                          | Type                                          |
| ------ | ------------------------------------ | --------------------------------------------- |
| blur   | Removes focus from the native input. | <ApiType detail={"() => void"}>Type</ApiType> |
| focus  | Focuses the native input.            | <ApiType detail={"() => void"}>Type</ApiType> |
