import ApiType from '#/components/ApiType.astro';

**Props**

| 属性           | 说明                                                                                            | 类型               | 默认值                                         |
| -------------- | ----------------------------------------------------------------------------------------------- | ------------------ | ---------------------------------------------- |
| addonClassName | 包裹内容容器的类名。                                                                            | `string`           | `semiGlobalDefault("Radio", "addonClassName")` |
| addonId        | addon 节点的 id，aria-labelledby 指向这个 id；未设置时随机生成。                                | `string`           | `undefined`                                    |
| addonStyle     | 包裹内容容器的内联样式。                                                                        | `StyleValue`       | `semiGlobalDefault("Radio", "addonStyle")`     |
| defaultChecked | 初始是否选中，非受控使用；在 RadioGroup 中使用时无效。                                          | `boolean`          | `false`                                        |
| disabled       | 是否禁用。                                                                                      | `boolean`          | `semiGlobalDefault("Radio", "disabled")`       |
| displayMode    | 设为 vertical 时 Radio 以块级元素独占一行。                                                     | `RadioDisplayMode` | `semiGlobalDefault("Radio", "displayMode")`    |
| extraId        | extra 节点的 id，aria-describedby 指向这个 id；未设置时随机生成。                               | `string`           | `undefined`                                    |
| mode           | 设为 advanced 时，已选中的 Radio 可以通过点击或空格取消选中；在 RadioGroup 中以组的 mode 为准。 | `RadioMode`        | `""`                                           |
| modelValue     | 是否选中，配合 v-model 受控使用；在 RadioGroup 中使用时无效。                                   | `boolean`          | `undefined`                                    |
| preventScroll  | 聚焦时是否阻止浏览器滚动到该元素，作用于 focus 方法。                                           | `boolean`          | `semiGlobalDefault("Radio", "preventScroll")`  |
| type           | 样式类型，可选 default、button、card、pureCard；在 RadioGroup 中以组的 type 为准。              | `RadioType`        | `"default"`                                    |
| value          | Radio 的值，RadioGroup 据此判断是否选中；同时作为原生 input 的 value 参与表单提交。             | `RadioValue`       | `undefined`                                    |

**Events**

| 事件              | 说明                                                                        | 回调参数                    |
| ----------------- | --------------------------------------------------------------------------- | --------------------------- |
| change            | 选中状态变化时触发，参数的 target 为 `{ checked, value, name, disabled }`。 | `[event: RadioChangeEvent]` |
| update:modelValue | 选中状态变化时触发，用于 v-model。                                          | `[checked: boolean]`        |

**Slots**

| 插槽    | 说明                                                         | 作用域参数 |
| ------- | ------------------------------------------------------------ | ---------- |
| default | Radio 的文本内容，同时是原生 input 的可访问名称。            | `any`      |
| extra   | 辅助文本，aria-describedby 指向它；type 为 button 时不渲染。 | `any`      |

**Exposes**

| 名称  | 说明                    | 类型                                          |
| ----- | ----------------------- | --------------------------------------------- |
| blur  | 使原生 input 失去焦点。 | <ApiType detail={"() => void"}>Type</ApiType> |
| focus | 使原生 input 获得焦点。 | <ApiType detail={"() => void"}>Type</ApiType> |
