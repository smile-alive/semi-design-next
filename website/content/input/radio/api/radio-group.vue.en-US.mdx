**Props**

| Property | Description | Type | Default |
| --- | --- | --- | --- |
| buttonSize | Button size when type is button: small, middle or large. | `RadioGroupButtonSize` | `"middle"` |
| defaultValue | The value selected by default when uncontrolled. | `T` | `semiGlobalDefault("RadioGroup", "defaultValue")` |
| direction | Layout direction of the radios: horizontal or vertical. Not supported when type is button. | `RadioDirection` | `"horizontal"` |
| disabled | Whether the whole group is disabled. | `boolean` | `false` |
| mode | When set to advanced, a checked radio can be unchecked by clicking it or pressing Space, and the selected value becomes undefined. | `RadioMode` | `""` |
| modelValue | The selected value, controlled with v-model. | `T` | `undefined` |
| name | The name of every native input in the group. A unique value is generated per group when omitted. | `string` | `semiGlobalDefault("RadioGroup", "name")` |
| options | Declares the options as data. Each item is a string or `{ label, value, disabled, extra, class, style, addonId, classNames, styles, extraId }`, where classNames and styles are keyed by addon and apply to the matching Radio. | `(string \| RadioOptionItem)[]` | `semiGlobalDefault("RadioGroup", "options")` |
| type | Style type of every Radio in the group: default, button, card or pureCard. | `RadioType` | `"default"` |

**Events**

| Event             | Description                                                                                                            | Callback parameters         |
| ----------------- | ---------------------------------------------------------------------------------------------------------------------- | --------------------------- |
| blur              | Emitted when focus leaves the whole group; moving focus between its radios does not emit it.                           | `[event: FocusEvent]`       |
| change            | Emitted when the selected value changes. The event's target is `{ checked, value, name, disabled }`.                   | `[event: RadioChangeEvent]` |
| update:modelValue | Emitted when the selected value changes; drives v-model. The value is undefined when advanced mode unchecks the radio. | `[value: T \| undefined]`   |

**Slots**

| Slot    | Description                                                                            | Scope parameters            |
| ------- | -------------------------------------------------------------------------------------- | --------------------------- |
| default | Radio components in the group. Ignored when options is set.                            | `any`                       |
| extra   | Custom extra text of each item in options, with the option and index scope parameters. | `RadioGroupOptionSlotProps` |
| label   | Custom label of each item in options, with the option and index scope parameters.      | `RadioGroupOptionSlotProps` |
