import ApiType from '#/components/ApiType.astro';

**Props**

| Property   | Description                                                                                                                                                                                     | Type                                                                             | Default        |
| ---------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------- | -------------- |
| buttonSize | Button size when type is button: small, middle or large.                                                                                                                                        | `RadioGroupButtonSize`                                                           | `"middle"`     |
| children   | Radio components in the group. Ignored when options is set.                                                                                                                                     | `Snippet`                                                                        | -              |
| direction  | Layout direction of the radios: horizontal or vertical. Not supported when type is button.                                                                                                      | `RadioDirection`                                                                 | `"horizontal"` |
| disabled   | Whether the whole group is disabled.                                                                                                                                                            | `boolean`                                                                        | `false`        |
| extra      | Snippet for the extra text of each item in options, with the parameter `{ option, index }`.                                                                                                     | <ApiType detail={"Snippet\u003c[RadioGroupOptionSnippetParams]>"}>Type</ApiType> | -              |
| label      | Snippet for the label of each item in options, with the parameter `{ option, index }`.                                                                                                          | <ApiType detail={"Snippet\u003c[RadioGroupOptionSnippetParams]>"}>Type</ApiType> | -              |
| mode       | When set to advanced, a checked radio can be unchecked by clicking it or pressing Space, and the selected value becomes undefined.                                                              | `RadioMode`                                                                      | `""`           |
| name       | The name of every native input in the group. A unique value is generated per group when omitted.                                                                                                | `string`                                                                         | -              |
| onBlur     | Called when focus leaves the whole group; moving focus between its radios does not call it.                                                                                                     | <ApiType detail={"(event: FocusEvent) => void"}>Type</ApiType>                   | -              |
| onChange   | Called when the selected value changes. The event's `target.value` is the new value, or undefined when mode is advanced and the selected radio is unchecked.                                    | <ApiType detail={"(event: RadioChangeEvent) => void"}>Type</ApiType>             | -              |
| options    | Declares the options as data. Each item is a string or `{ label, value, disabled, extra, class, style, addonId, addonStyle, addonClass, extraId }`, where `style` and `addonStyle` are strings. | <ApiType detail={"Array\u003cstring \u007c RadioOptionItem>"}>Type</ApiType>     | -              |
| prefixCls  | CSS class name prefix.                                                                                                                                                                          | `string`                                                                         | -              |
| type       | Style type of every Radio in the group: default, button, card or pureCard.                                                                                                                      | `RadioType`                                                                      | `"default"`    |
| value      | The selected value, matched against each Radio's value; bind it with `bind:value`. `bind:value={get, set}` makes it fully controlled; a plain `value` is the initial value.                     | `RadioValue`                                                                     | -              |
