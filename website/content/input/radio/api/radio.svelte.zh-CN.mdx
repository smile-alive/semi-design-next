import ApiType from '#/components/ApiType.astro';

**Props**

| 属性           | 说明                                                                                                                                                                              | 类型                                                                 | 默认值      |
| -------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------- | ----------- |
| addonClassName | 包裹内容容器的类名。                                                                                                                                                              | `string`                                                             | -           |
| addonId        | addon 节点的 id，aria-labelledby 指向这个 id；未设置时随机生成。                                                                                                                  | `string`                                                             | -           |
| addonStyle     | 包裹内容容器的内联样式，只接受字符串。                                                                                                                                            | `string`                                                             | -           |
| checked        | 是否选中，可用 `bind:checked` 双向绑定；在 RadioGroup 中使用时无效。`bind:checked={get, set}` 时完全受控；只传 `checked` 时作为初值，点击在组件内覆盖，父级再传新值时以父级为准。 | `boolean`                                                            | -           |
| children       | Radio 的文本内容 snippet，写在标签内的其余内容就是它。                                                                                                                            | `Snippet`                                                            | -           |
| disabled       | 是否禁用。                                                                                                                                                                        | `boolean`                                                            | -           |
| displayMode    | 设为 vertical 时 Radio 以块级元素独占一行。                                                                                                                                       | `RadioDisplayMode`                                                   | -           |
| extra          | 辅助文本的 snippet，aria-describedby 指向它；type 为 button 时不渲染。                                                                                                            | `Snippet`                                                            | -           |
| extraId        | extra 节点的 id，aria-describedby 指向这个 id；未设置时随机生成。                                                                                                                 | `string`                                                             | -           |
| mode           | 设为 advanced 时，已选中的 Radio 可以通过点击或空格取消选中；在 RadioGroup 中以组的 mode 为准。                                                                                   | `RadioMode`                                                          | `""`        |
| onChange       | 选中状态变化时的回调，参数的 `target` 为 `{ checked, value, name, disabled }`。                                                                                                   | <ApiType detail={"(event: RadioChangeEvent) => void"}>Type</ApiType> | -           |
| prefixCls      | CSS 类名前缀，未设置时依次取所在 RadioGroup 的值与全局默认值。                                                                                                                    | `string`                                                             | -           |
| preventScroll  | 聚焦时是否阻止浏览器滚动到该元素，作用于 focus 方法。                                                                                                                             | `boolean`                                                            | -           |
| type           | 样式类型，可选 default、button、card、pureCard；在 RadioGroup 中以组的 type 为准。                                                                                                | `RadioType`                                                          | `"default"` |
| value          | Radio 的值，RadioGroup 据此判断是否选中；同时作为原生 input 的 value 参与表单提交。                                                                                               | `RadioValue`                                                         | -           |

**Methods**

| 方法  | 说明                    | 类型                                          |
| ----- | ----------------------- | --------------------------------------------- |
| blur  | 使原生 input 失去焦点。 | <ApiType detail={"() => void"}>Type</ApiType> |
| focus | 使原生 input 获得焦点。 | <ApiType detail={"() => void"}>Type</ApiType> |
