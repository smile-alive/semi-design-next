### 前缀 / 后缀

<Framework only="react">

可以通过 `prefix` 传入输入框前缀，通过 `suffix` 传入输入框后缀，可以为文本或者 ReactNode。  
当 `prefix`、`suffix` 传入的内容为 string 或者 Icon 时，会自动带上左右间隔；若为自定义 ReactNode，则左右间隔为 0，如需可以在你传入的 ReactNode中自行设置。

</Framework>

<Framework only="vue">

可以通过 `#prefix` 插槽传入输入框前缀，通过 `#suffix` 插槽传入输入框后缀，可以为文本或者图标等节点。  
当插槽内容为纯文本或者 Icon 时，会自动带上左右间隔；若为自定义节点，则左右间隔为 0，如需可以在你传入的节点中自行设置。

</Framework>

<Framework only="solid">

可以通过 `prefix` 传入输入框前缀，通过 `suffix` 传入输入框后缀，可以为文本或者 JSX 元素。  
当 `prefix`、`suffix` 传入的内容为文本或者 Icon 时，会自动带上左右间隔；若为自定义 JSX 元素，则左右间隔为 0，如需可以在你传入的元素中自行设置。

</Framework>

<Framework only="svelte">

可以通过 `prefix` snippet 传入输入框前缀，通过 `suffix` snippet 传入输入框后缀，可以为文本或者图标等节点。  
当 snippet 内容为文本或者 Icon 时，会自动带上左右间隔；若为自定义节点，则左右间隔为 0，如需可以在你传入的节点中自行设置。

</Framework>

将 `draggable`设为 true，开启拖拽排序功能。拖拽功能开启后，聚焦 TagInput（点击或 Tab）后 Tag 可拖拽，焦点离开 TagInput 后 Tag 不可拖拽。拖拽句柄位于标签旁边，可用键盘操作，见下文「键盘和焦点」。值相同的标签也能分别拖拽排序。

## Accessibility

### ARIA

- TagInput 支持传入 `aria-label` 来表示该 TagInput 作用，它落在输入框上，根节点不带；
- 根节点的角色是 `group`，把输入框、标签和清除按钮作为一个整体；禁用时根节点带 `aria-disabled="true"`，未禁用时不带；
- 禁用时输入框是原生 `disabled`，标签是静态文本，不带 `aria-label`；`validateStatus` 为 `error` 时输入框带 `aria-invalid`，显式传入的 `aria-invalid` 优先；
- `showClear` 开启、有标签或输入内容且未禁用时，渲染清除按钮。它是原生 `button`，名称为语言包中的「清空标签输入」，在 hover 或焦点位于 TagInput 内时显示。从输入框按 `Tab` 移到清除按钮，`Enter` 或 `Space` 清空，效果与鼠标点击相同，清空后焦点回到输入框；也可在空输入框中按 `Backspace` 删除最后一个标签。

### 键盘和焦点

- 输入框中按 `Enter` 把输入内容添加为标签，空输入时不做任何事。`Enter` 一律阻止默认行为，TagInput 位于表单内时不会提交表单。
- 输入框为空时按 `Backspace` 删除最后一个标签。
- 可关闭的标签是 `role="button"` 的 Tab 停靠点，位于输入框之前；聚焦标签后按 `Backspace` 或 `Delete` 关闭它，标签被移除后焦点回到输入框。禁用时标签是静态文本，不可聚焦。
- 开启 `showClear` 且有内容时，清除按钮在输入框之后：`Tab` 到达，`Enter` 或 `Space` 清空，焦点回到输入框。
- 激活状态跟随焦点：焦点从组件外进入（点击、`Tab` 或 `focus()`）即激活，焦点离开整个组件即退出。焦点在输入框、标签与清除按钮之间移动不算离开组件，不触发 `focus`、`blur`，也不会触发 `addOnBlur`。激活时，被 `maxTagCount` 折叠的标签会展开（`expandRestTagsOnClick` 为 `false` 时不展开）。
- 开启 `draggable` 并激活后，每个标签前出现拖拽句柄，句柄是独立的 Tab 停靠点，位于它所属的标签之前。聚焦句柄后按 `Space` 拿起，方向键移动，`Space` 放下，读屏会播报拿起、移动与放下。
