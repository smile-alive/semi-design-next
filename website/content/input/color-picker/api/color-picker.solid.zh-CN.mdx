**Props**

| 属性 | 说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| alpha | 是否开启透明度选择。 | `boolean` | `true` |
| bottomSlot | 底部渲染额外元素。 | `JSX.Element` | - |
| children | usePopover 时的触发器，默认是一个色块按钮；不使用 usePopover 时不渲染。使用函数（声明参数）时参数为 `getTriggerProps`，展开到取得焦点的元素上。 | `PopoverProps['children']` | - |
| classNames | 内部各部位的类名，键为 `area`（选色区）、`hue`（色相滑条）、`alpha`（透明度滑条）、`handle`（三处共用的圆形手柄）、`preview`（颜色预览块）、`input`（颜色值输入框）、`format`（格式选择器）、`trigger`（默认触发按钮）、`dropdown`（usePopover 时的弹出层），与组件自带的类名合并。 | <ApiType detail={"Partial\u003cRecord\u003cColorPickerPart, string>>"}>Type</ApiType> | - |
| defaultFormat | 手动输入时默认使用的颜色格式，可选 `rgba`、`hex`、`hsva`。 | `ColorFormat` | `"hex"` |
| defaultValue | 非受控的初始值，是同时包含 hsva、hex、rgba 三种格式的对象，默认对应 `#39c5bb`。 | `ColorValue` | <ApiType detail={"{\n hsva: { h: 176, s: 71, v: 77, a: 1 },\n rgba: { r: 57, g: 197, b: 187, a: 1 },\n hex: '#39c5bb',\n}"}>Type</ApiType> |
| eyeDropper | 是否开启滴管拾色器。 | `boolean` | `true` |
| height | 高度，单位为像素，未设置时为 280。 | `number` | - |
| onChange | 用户选中颜色时的回调，参数为 ColorValue，包含 hsva、hex、rgba 三种格式。 | <ApiType detail={"(value: ColorValue) => void"}>Type</ApiType> | - |
| popoverProps | 放入 Popover 时传给 Popover 的属性，如 `trigger`、`aria-label`、`aria-labelledby`。弹层默认以点击触发、role 为 `dialog`，名称默认取语言包；`aria-label` 或 `aria-labelledby` 优先。 | `PopoverProps` | - |
| styles | 内部各部位的样式，键同 `classNames`，值可传对象（键为 CSS 属性名）或字符串。 | <ApiType detail={"Partial\u003cRecord\u003cColorPickerPart, JSX.CSSProperties \u007c string>>"}>Type</ApiType> | - |
| topSlot | 顶部渲染额外元素。 | `JSX.Element` | - |
| usePopover | 是否放入 Popover 渲染，触发器使用 `children`，默认 false。 | `boolean` | - |
| value | 受控值，形态同 defaultValue。传 `undefined` 视为非受控，从受控变回 `undefined` 时显示回到 defaultValue；传 `null` 是受控的空值，显示 defaultValue 且只报告变化。ColorValue 按不可变值对待，更新时整体替换。 | `ColorValue \| null` | - |
| width | 宽度，单位为像素，未设置时为 280。 | `number` | - |
