### 键盘和焦点

- 使用 `usePopover` 时，默认触发器是一个带名称的按钮，`Enter`、空格打开弹层；弹层是 `dialog`，默认以点击触发，`Esc` 关闭。弹层的名称默认取内置文案，传入 `popoverProps` 的 `aria-label` 或 `aria-labelledby`（Vue 中为 `ariaLabel`、`ariaLabelledby`）优先。
- 选色区、色相条、透明度条的手柄都可以用键盘操作。选色区有饱和度与明度两个滑块，色相条、透明度条各有一个。
- 方向键步进 1，`PageUp`、`PageDown` 步进 10，`Home`、`End` 跳到两端。在选色区内无论聚焦哪个滑块，左右键都改饱和度，上下键与 `PageUp`、`PageDown` 都改明度，`Home`、`End` 作用于聚焦的那一个。同时按下 `Alt`、`Ctrl`、`Meta` 时不处理，留给浏览器和辅助技术。
- 聚焦手柄时显示主题焦点环；颜色输入框、透明度输入框和格式选择器都有可访问名称。

#### 属性落点

`className`、`style`、`ref` 与其他原生属性和事件落在 picker 根元素上；使用 `usePopover` 时落在弹层内的 picker 元素上，不落在触发器与对话框上。使用方传入 `aria-label` 或 `aria-labelledby` 且未传 `role` 时，picker 根元素加 `role="group"`。

#### ColorValue

`value`、`defaultValue` 与 `onChange` 的参数都是同一种对象：

| 字段 | 说明                                                  | 类型                                             |
| ---- | ----------------------------------------------------- | ------------------------------------------------ |
| hsva | HSV 色值与透明度，h 为 0-360，s、v 为 0-100，a 为 0-1 | `{ h: number; s: number; v: number; a: number }` |
| rgba | RGB 色值与透明度，r、g、b 为 0-255，a 为 0-1          | `{ r: number; g: number; b: number; a: number }` |
| hex  | 十六进制色值，`#rrggbb` 或带透明度的 `#rrggbbaa`      | `string`                                         |

</Framework>
