### Keyboard and Focus

- With `usePopover`, the default trigger is a named button, and `Enter` or `Space` opens the popup. The popup is a `dialog` that opens on click by default and closes with `Esc`. Its name defaults to the built-in text; an `aria-label` or `aria-labelledby` passed in `popoverProps` (`ariaLabel`, `ariaLabelledby` in Vue) takes precedence.
- The handles of the color area, the hue slider and the alpha slider can all be operated with the keyboard. The color area has two sliders, saturation and brightness; the hue slider and the alpha slider have one each.
- Arrow keys step by 1, `PageUp` and `PageDown` step by 10, and `Home` and `End` jump to the ends. In the color area, whichever slider has focus, Left and Right change saturation, while Up, Down, `PageUp` and `PageDown` change brightness; `Home` and `End` act on the focused slider. Keys pressed with `Alt`, `Ctrl` or `Meta` are not handled, so the browser and assistive technology keep them.
- A focused handle shows the theme focus ring; the color input, the alpha input and the format selector all have accessible names.

### API Table

<Framework only="react">

#### ColorPicker

<ColorPickerReactApi />

#### Attribute placement

`className`, `style`, `ref` and other native attributes and events land on the picker root element; with `usePopover` they land on the picker element inside the popup, not on the trigger or the dialog. When the caller passes `aria-label` or `aria-labelledby` without a `role`, the picker root gets `role="group"`.

#### ColorValue

The `value`, `defaultValue` and `onChange` payload are all the same kind of object:

| Field | Description                                                    | Type                                             |
| ----- | -------------------------------------------------------------- | ------------------------------------------------ |
| hsva  | HSV color and opacity; h is 0-360, s and v are 0-100, a is 0-1 | `{ h: number; s: number; v: number; a: number }` |
| rgba  | RGB color and opacity; r, g and b are 0-255, a is 0-1          | `{ r: number; g: number; b: number; a: number }` |
| hex   | Hexadecimal color, `#rrggbb`, or `#rrggbbaa` with opacity      | `string`                                         |

</Framework>
