| --- | --- | --- | --- |
| allowEmpty | 值变为空的字段是否在 values 中保留 key。字段上的同名属性优先。 | `boolean` | - |
| autoScrollToError | 提交或调用 formApi.validate 校验失败时，是否自动滚动到出错的字段；传对象时作为 scroll-into-view-if-needed 的选项。 | `boolean \| ScrollOptions` | - |

| disabled | 统一应用在每个字段上的 disabled，字段自身的 disabled 优先。 | `boolean` | - |
| extraTextPosition | 统一应用在每个字段上的 extraText 位置，middle 在 Label 与控件之间，bottom 在控件之后。字段上的同名属性优先。 | `'bottom' \| 'middle'` | - |
| form | useForm 返回的 formApi，用于在 Form 外部控制表单。 | <ApiType detail={"FormApi\u003cValues, Output>"}>Type</ApiType> | - |

| id | form 元素的 id，同时写入 x-form-id；不传时自动生成。 | `string` | - |
| initValues | 表单的初始值，仅在 Form 创建时复制一次。 | `Values` | - |
| jsonSchema | 要渲染的 JSON Schema，优先于从 Form 的 `schema` 导出的结果；两者都没有时不渲染字段，开发模式下警告。 | `JsonSchema` | - |
| keepState | 字段卸载后是否保留它的值、错误和 touched，重新挂载时按路径恢复。字段、ArrayField 未设置时取这里的值。 | `boolean` | - |
| labelAlign | 统一应用在每个字段上的 label 文本对齐方式，字段上的同名属性优先。 | `'left' \| 'right'` | - |
| labelCol | 统一应用在每个字段上的 label 栅格布局，同 Col 的 span、offset 等属性，需与 wrapperCol 一起设置。 | `ColProps` | - |
| labelPosition | 统一应用在每个字段上的 label 位置，inset 仅部分字段支持，其余字段按 top 布局。字段上的同名属性优先。 | `'inset' \| 'left' \| 'top'` | - |
| labelWidth | 统一应用在每个字段上的 label 宽度，数字单位为 px。 | `number \| string` | - |
| layout | 字段的排列方向，可选 vertical 或 horizontal。 | `'horizontal' \| 'vertical'` | - |
| onChange | 表单状态更新时的回调，包括字段挂载、卸载、值变更、blur、校验状态与错误信息变更，参数为 formState。 | <ApiType detail={"(formState: FormState\u003cValues>) => void"}>Type</ApiType> | - |
| onErrorChange | 校验状态更新时的回调，参数为全部错误和本次变化的字段错误。validate、submit、reset 等批量操作只触发一次，静默校验不触发。 | <ApiType detail={"(errors: AllErrors\u003cValues>, changedError?: Partial\u003cRecord\u003cFieldPath\u003cValues>, FieldError>>) => void"}>Type</ApiType> | - |
| onReset | 点击重置按钮或调用 formApi.reset 时的回调。 | <ApiType detail={"() => void"}>Type</ApiType> | - |
| onSubmit | 点击提交按钮或调用 formApi.submitForm 且校验通过后的回调，参数为 values 与提交事件；配置了 `schema` 时 values 是 schema 的输出。 | <ApiType detail={"(values: Output, e?: SubmitEvent) => void"}>Type</ApiType> | - |
| onSubmitFail | 点击提交按钮或调用 formApi.submitForm 且校验失败后的回调，参数为 errors、values 与提交事件。errors 的每个错误是字符串数组；校验函数抛出的异常原样传入。 | <ApiType detail={"(errors: Partial\u003cAllErrors\u003cValues>> \u007c unknown, values: Partial\u003cValues>, e?: SubmitEvent) => void"}>Type</ApiType> | - |
| onValueChange | 字段的值变化时的回调，参数为全部 values 与本次变化的字段值。 | <ApiType detail={"(values: Values, changedValues: Partial\u003cValues>) => void"}>Type</ApiType> | - |
| renderField | 按字段路径接管渲染的 snippet，数组的行写作 `[]`（如 `contacts[].email`），参数为 `{ node, field }`；命中时由它渲染这个节点和它的子节点。 | <ApiType detail={"Record\u003cstring, Snippet\u003c[SchemaFieldRenderProps]>>"}>Type</ApiType> | - |
| schema | 实现了 Standard Schema 的校验对象（如 Zod、Valibot、ArkType），与字段的 validator、rules 互斥，设置后它们不再运行。校验全部字段通过后，`onSubmit` 与 formApi.validate 拿到 schema 的输出。同时传 `validator` 时只用 `validator`。 | <ApiType detail={"StandardSchema\u003cValues, Output>"}>Type</ApiType> | - |
| schemaDebounce | 配置了 `schema` 时，值变化触发的校验在输入停顿多少毫秒后才运行；submit、formApi.validate 与 blur 触发的校验不等待。 | `number` | - |
| showValidateIcon | 校验信息前是否显示对应状态的图标。 | `boolean` | - |
| stopPropagation | 是否阻止 submit、reset 事件冒泡，用于嵌套 Form 时避免触发外层 Form 的事件。 | `{ submit?: boolean; reset?: boolean }` | - |
| stopValidateWithError | 使用 rules 校验时，遇到第一条不通过的规则后是否不再校验后续规则。字段上的同名属性优先。 | `boolean` | - |
| trigger | 统一应用在每个字段上的校验时机，可选 change、blur、mount、custom 或其数组。字段上的同名属性优先。 | `FieldValidateTriggerType` | - |
| validator | Form 级别的校验函数，submit 与 formApi.validate 时调用，支持返回 Promise，与 `schema` 互斥。设置后字段自身的 validator 与 rules 不再生效。返回空值或空对象表示通过，失败时返回与 values 结构相同的错误对象，每个错误是字符串或字符串数组。 | <ApiType detail={"FormValidator\u003cValues>"}>Type</ApiType> | - |
| widgets | 替换控件的字段组件，键是 JSON Schema 的 `format`（如 `uri`）或控件种类（`input`、`textarea`、`number`、`switch`、`select`），先按 `format` 查找。 | <ApiType detail={"Record\u003cstring, Component\u003cany, any, any>>"}>Type</ApiType> | - |
| wrapperCol | 统一应用在每个字段上的控件栅格布局，同 Col 的 span、offset 等属性，需与 labelCol 一起设置。 | `ColProps` | - |
