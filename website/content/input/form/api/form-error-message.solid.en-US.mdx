**Props**

| Property         | Description                                                                                                                                                                                                      | Type          | Default |
| ---------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------- | ------- |
| error            | The error, a string array whose messages are joined with commas. helpText is hidden while there is an error; `['']` means failed without text and renders nothing; an empty array or empty value means no error. | `FieldError`  | -       |
| errorMessageId   | The id of the error text element, referenced by aria-errormessage.                                                                                                                                               | `string`      | -       |
| helpText         | The help text. It shares the block with the error, and the error is shown when both are set.                                                                                                                     | `JSX.Element` | -       |
| helpTextId       | The id of the help text element, referenced by aria-describedby.                                                                                                                                                 | `string`      | -       |
| isInInputGroup   | Whether it is inside an InputGroup. When it and showValidateIcon are true, the error icon shows whatever validateStatus is.                                                                                      | `boolean`     | -       |
| showValidateIcon | Whether to show the icon of validateStatus.                                                                                                                                                                      | `boolean`     | -       |
| validateStatus   | Validation status of the message: default, error, warning or success.                                                                                                                                            | `string`      | -       |
