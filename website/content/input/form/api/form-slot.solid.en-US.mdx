**Props**

| Property      | Description                                                                                                                                   | Type                               | Default |
| ------------- | --------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------- | ------- |
| error         | The error, rendered after the content: an object is the props of ErrorMessage and any other content is the error. Nothing shows when omitted. | `ErrorMessageProps \| JSX.Element` | -       |
| label         | The text of the label, or a label configuration such as text, extra, align, width, required and optional.                                     | `LabelProps \| JSX.Element`        | -       |
| labelPosition | Label position. Defaults to the Form's, and can be top or left.                                                                               | `'top' \| 'left'`                  | -       |
| noLabel       | Whether to render no label. When the Form sets both labelCol and wrapperCol, the label column is still kept.                                  | `boolean`                          | -       |
