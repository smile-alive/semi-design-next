**Props**

| 属性 | 说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| allowEmpty | 值变为空的字段是否在 values 中保留 key。字段上的同名属性优先。 | `boolean` | `false` |
| autoScrollToError | 提交或调用 formApi.validate 校验失败时，是否自动滚动到出错的字段；传对象时作为 scroll-into-view-if-needed 的选项。 | `boolean \| Options` | `false` |
| disabled | 统一应用在每个字段上的 disabled，字段自身的 disabled 优先。 | `boolean` | `semiGlobalDefault("Form", "disabled")` |
| extraTextPosition | 统一应用在每个字段上的 extraText 位置，middle 在 Label 与控件之间，bottom 在控件之后。字段上的同名属性优先。 | `"bottom" \| "middle"` | `semiGlobalDefault("Form", "extraTextPosition")` |
| form | useForm 返回的 formApi，用于在 Form 外部控制表单。 | <ApiType detail={"FormApi\u003cValues, Output>"}>Type</ApiType> | `undefined` |
| id | form 元素的 id，同时写入 x-form-id；不传时自动生成。 | `string` | `undefined` |
| initValues | 表单的初始值，仅在 Form 创建时复制一次。 | <ApiType detail={"DeepPartial\u003cValues>"}>Type</ApiType> | `undefined` |
| keepState | 字段卸载后是否保留它的值、错误和 touched，重新挂载时按路径恢复。字段、ArrayField 未设置时取这里的值。 | `boolean` | `true` |
| labelAlign | 统一应用在每个字段上的 label 文本对齐方式，字段上的同名属性优先。 | `"left" \| "right"` | `semiGlobalDefault("Form", "labelAlign")` |
| labelCol | 统一应用在每个字段上的 label 栅格布局，同 Col 的 span、offset 等属性，需与 wrapperCol 一起设置。 | `ColProps` | `semiGlobalDefault("Form", "labelCol")` |
| labelPosition | 统一应用在每个字段上的 label 位置，inset 仅部分字段支持，其余字段按 top 布局。字段上的同名属性优先。 | `"inset" \| "left" \| "top"` | `"top"` |
| labelWidth | 统一应用在每个字段上的 label 宽度，数字单位为 px。 | `string \| number` | `semiGlobalDefault("Form", "labelWidth")` |
| layout | 字段的排列方向，可选 vertical 或 horizontal。 | `"horizontal" \| "vertical"` | `"vertical"` |
| schema | 实现了 Standard Schema 的校验对象（如 Zod、Valibot、ArkType），与字段的 validator、rules 互斥，设置后它们不再运行。校验全部字段通过后，`submit` 事件与 formApi.validate 拿到 schema 的输出。同时传 `validator` 时只用 `validator`。 | <ApiType detail={"FormSchema\u003cValues, Output>"}>Type</ApiType> | `undefined` |
| schemaDebounce | 配置了 `schema` 时，值变化触发的校验在输入停顿多少毫秒后才运行；submit、formApi.validate 与 blur 触发的校验不等待。 | `number` | `semiGlobalDefault("Form", "schemaDebounce")` |
| showValidateIcon | 校验信息前是否显示对应状态的图标。 | `boolean` | `true` |
| stopPropagation | 是否阻止 submit、reset 事件冒泡，用于嵌套 Form 时避免触发外层 Form 的事件。 | `{ submit?: boolean \| undefined; reset?: boolean \| undefined; }` | `semiGlobalDefault("Form", "stopPropagation")` |
| stopValidateWithError | 使用 rules 校验时，遇到第一条不通过的规则后是否不再校验后续规则。字段上的同名属性优先。 | `boolean` | `semiGlobalDefault("Form", "stopValidateWithError")` |
| trigger | 统一应用在每个字段上的校验时机，可选 change、blur、mount、custom 或其数组。字段上的同名属性优先。 | `FieldValidateTriggerType` | `semiGlobalDefault("Form", "trigger")` |
| validator | Form 级别的校验函数，submit 与 formApi.validate 时调用，支持返回 Promise，与 `schema` 互斥。设置后字段自身的 validator 与 rules 不再生效。返回空值或空对象表示通过，失败时返回与 values 结构相同的错误对象，每个错误是字符串或字符串数组。 | <ApiType detail={"FormValidator\u003cValues>"}>Type</ApiType> | `undefined` |
| wrapperCol | 统一应用在每个字段上的控件栅格布局，同 Col 的 span、offset 等属性，需与 labelCol 一起设置。 | `ColProps` | `semiGlobalDefault("Form", "wrapperCol")` |

**Events**

| 事件 | 说明 | 回调参数 |
| --- | --- | --- |
| change | 表单状态更新时触发，包括字段挂载、卸载、值变更、blur、校验状态与错误信息变更，参数为 formState。与原生 change 事件同名，会遮住原生事件。 | <ApiType detail={"[formState: FormState\u003cValues>]"}>Type</ApiType> |
| errorChange | 校验状态更新时触发，参数为全部错误和本次变化的字段错误，每个错误是字符串数组。validate、submit、reset 等批量操作只触发一次，静默校验与内容相同的重复校验不触发。 | <ApiType detail={"[errors: AllErrors\u003cValues>, changedError?: Partial\u003cRecord\u003cFieldPath\u003cValues, 5>, FieldError \u007c undefined>> \u007c undefined]"}>Type</ApiType> |
| getFormApi | Form 挂载后触发，参数为 formApi。 | <ApiType detail={"[formApi: FormApi\u003cValues, Output>]"}>Type</ApiType> |
| reset | 点击重置按钮或调用 formApi.reset 时触发。与原生 reset 事件同名，会遮住原生事件。 | `[]` |
| submit | 点击提交按钮或调用 formApi.submitForm 且校验通过后触发，参数为 values 与提交事件；配置了 `schema` 时 values 是 schema 的输出。与原生 submit 事件同名，会遮住原生事件。 | `[values: Output, e?: SubmitEvent \| undefined]` |
| submitFail | 点击提交按钮或调用 formApi.submitForm 且校验失败后触发，参数为 errors、values 与提交事件。errors 的每个错误是字符串数组；校验函数抛出的异常原样传入。 | <ApiType detail={"[errors: Partial\u003cAllErrors\u003cValues>>, values: Partial\u003cValues>, e?: SubmitEvent \u007c undefined]"}>Type</ApiType> |
| valueChange | 字段的值变化时触发，参数为全部 values 与本次变化的字段值。 | <ApiType detail={"[values: Values, changedValues: Partial\u003cValues>]"}>Type</ApiType> |
