**Props**

| 属性 | 说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| children | 每一行的渲染函数，必填，只调用一次，参数为 `{ arrayFields, add, addWithInitValue, move }`，需在返回的 JSX 中读取 `arrayFields` 才会随行增删更新。`move(from, to)` 把一行连同它的值、错误和 touched 移到目标位置，越界的下标按首尾处理。 | <ApiType detail={"(props: ArrayFieldChildrenProps) => JSX.Element"}>Type</ApiType> | - |

| keepState | 卸载时是否保留整组数据，也是行内字段未设置 keepState 时的默认值；未设置时取 Form 的 keepState。保留时重新挂载按保留的值渲染各行。 | `boolean` | - |
