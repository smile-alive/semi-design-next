**Props**

| Property         | Description                                                                                                                                                                                                    | Type                                                              | Default |
| ---------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------- | ------- |
| className        | Class name of the error message element.                                                                                                                                                                       | `string`                                                          | -       |
| error            | The error, a string array whose messages are joined with `, `. helpText is hidden while there is an error; `['']` means failed without text and renders nothing; an empty array or empty value means no error. | `FieldError`                                                      | -       |
| helpText         | The help text. It shares the block with the error, and the error is shown when both are set.                                                                                                                   | `React.ReactNode`                                                 | -       |
| ref              | Reference to the error message element.                                                                                                                                                                        | <ApiType detail={"React.Ref\u003cHTMLDivElement>"}>Type</ApiType> | -       |
| showValidateIcon | Whether to show the icon of `validateStatus`.                                                                                                                                                                  | `boolean`                                                         | -       |
| style            | Inline style of the error message element.                                                                                                                                                                     | `React.CSSProperties`                                             | -       |
| validateStatus   | Validation status of the message: `default`, `error`, `warning` or `success`.                                                                                                                                  | `string`                                                          | -       |
