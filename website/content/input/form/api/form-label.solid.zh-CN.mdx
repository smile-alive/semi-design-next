**Props**

| 属性     | 说明                                                                    | 类型               | 默认值 |
| -------- | ----------------------------------------------------------------------- | ------------------ | ------ |
| align    | Label 文本的对齐方式，可选 left 或 right。                              | `string`           | -      |
| disabled | 是否为禁用样式。                                                        | `boolean`          | -      |
| extra    | 跟随在 label 文本后的内容。                                             | `JSX.Element`      | -      |
| name     | 所标注控件的 id，写入 label 的 for 属性；不传时使用 `for`。             | `string`           | -      |
| optional | 是否在文本后追加语言包中的可选标识。为 true 时不再显示 required 的 \*。 | `boolean`          | -      |
| required | 是否显示必填的 \* 号。                                                  | `boolean`          | -      |
| text     | Label 文本；不传时使用 children。                                       | `JSX.Element`      | -      |
| width    | Label 宽度，数字单位为 px。                                             | `number \| string` | -      |
