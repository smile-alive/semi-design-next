**Props**

| 属性 | 说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| field | 要渲染的节点路径，默认为根；根对象不包 Section，其他对象渲染为以 title 为标题的 Section。 | `string` | `""` |
| jsonSchema | 要渲染的 JSON Schema，优先于从 Form 的 `schema` 导出的 JSON Schema；两者都没有时不渲染，开发模式下警告。 | `JsonSchema` | - |
| renderers | 各种类节点的渲染函数 `{ object, array, field }`，SchemaField 自身不渲染任何界面；传 `semiRenderers` 得到 Semi 表单控件的默认界面。缺少 `object` 时直接渲染对象的属性，缺少 `array`、`field` 时对应节点不渲染，开发模式下警告。渲染函数只调用一次，参数 `context` 的字段都是 getter，要在 JSX 或 effect 里读取；`render(field)` 渲染 `field` 处的节点，数组的行传 `() => item.field`，行移动时原地更新；对象的 `content` 每次读取都新建节点，只读一次。 | `SchemaFieldRenderers` | - |
| renderField | 按节点路径替换 `renderers` 里对应种类的渲染函数，数组的行写作 `[]`（如 `contacts[].email`），参数与该种类的渲染函数相同。 | <ApiType detail={"Record\u003cstring, (context: SchemaFieldContext) => JSX.Element>"}>Type</ApiType> | - |
