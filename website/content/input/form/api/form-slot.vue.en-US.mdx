**Props**

| Property      | Description                                                                                                                                | Type                             | Default     |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------- | ----------- |
| label         | The text of the label, or a label configuration such as text, extra, align, width, required and optional. The label slot takes precedence. | `string \| number \| FieldLabel` | `undefined` |
| labelPosition | Label position. Defaults to the Form's, and can be top or left.                                                                            | `"top" \| "left"`                | `undefined` |
| noLabel       | Whether to render no label. When the Form sets both labelCol and wrapperCol, the label column is still kept.                               | `boolean`                        | `undefined` |
| error         | The error, rendered after the content. Nothing shows when omitted.                                                                         | `FieldError`                     | `undefined` |

**Events**

| Event | Description | Callback parameters |
| ----- | ----------- | ------------------- |
| None  |             |                     |

**Slots**

| Slot       | Description                                                                    | Scope parameters         |
| ---------- | ------------------------------------------------------------------------------ | ------------------------ |
| default    | The custom content.                                                            | `any`                    |
| label      | Content of the label. It takes precedence over the text in the label property. | `any`                    |
| labelExtra | Content after the label text.                                                  | `any`                    |
| error      | Custom rendering of the error. The scope provides error.                       | `{ error: FieldError; }` |
