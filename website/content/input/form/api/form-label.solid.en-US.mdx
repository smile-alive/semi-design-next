**Props**

| Property | Description                                                                                    | Type               | Default |
| -------- | ---------------------------------------------------------------------------------------------- | ------------------ | ------- |
| align    | Text alignment of the label: left or right.                                                    | `string`           | -       |
| disabled | Whether the label looks disabled.                                                              | `boolean`          | -       |
| extra    | Content after the label text.                                                                  | `JSX.Element`      | -       |
| name     | The id of the labeled control, written to the for attribute. `for` is used when it is not set. | `string`           | -       |
| optional | Whether to append the optional text of the locale. When true, the \* of required is hidden.    | `boolean`          | -       |
| required | Whether to display the required \* symbol.                                                     | `boolean`          | -       |
| text     | Text of the label. children is used when it is not set.                                        | `JSX.Element`      | -       |
| width    | Width of the label. A number is in px.                                                         | `number \| string` | -       |
