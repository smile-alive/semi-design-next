**Props**

| Property   | Description                                                                                                                                                                           | Type                                                                                                         | Default |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------ | ------- |
| align      | Text alignment of the label: left or right.                                                                                                                                           | `string`                                                                                                     | -       |
| classNames | Class names of the inner parts, keyed by `text`, `extra` and `tooltip`; merged with the built-in classes.                                                                             | <ApiType detail={"Partial\u003cRecord\u003cFormLabelPart, string>>"}>Type</ApiType>                          | -       |
| disabled   | Whether the label looks disabled.                                                                                                                                                     | `boolean`                                                                                                    | -       |
| extra      | Content after the label text.                                                                                                                                                         | `JSX.Element`                                                                                                | -       |
| name       | The id of the labeled control, written to the for attribute. `for` is used when it is not set.                                                                                        | `string`                                                                                                     | -       |
| optional   | Whether to append the optional text of the locale. When true, the \* of required is hidden.                                                                                           | `boolean`                                                                                                    | -       |
| required   | Whether to display the required \* symbol.                                                                                                                                            | `boolean`                                                                                                    | -       |
| styles     | Inline styles of the inner parts, keyed like `classNames`.                                                                                                                            | <ApiType detail={"Partial\u003cRecord\u003cFormLabelPart, JSX.CSSProperties \u007c string>>"}>Type</ApiType> | -       |
| text       | Text of the label. children is used when it is not set.                                                                                                                               | `JSX.Element`                                                                                                | -       |
| tooltip    | Tooltip content of the help button beside the label. The button sits outside the label element, so it is not part of the field's accessible name, and its name comes from the locale. | `JSX.Element`                                                                                                | -       |
| width      | Width of the label. A number is in px.                                                                                                                                                | `number \| string`                                                                                           | -       |
