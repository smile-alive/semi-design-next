**Events**

| Event | Description | Callback parameters |
| --- | --- | --- |
| submit | Emitted when a submit button is clicked or formApi.submitForm is called and validation passes. Receives values and the submit event; with `schema`, values are the schema's output. It has the name of the native submit event and hides it. | `[values: Output, e?: SubmitEvent \| undefined]` |
| submitFail | Emitted when a submit button is clicked or formApi.submitForm is called and validation fails. Receives errors, values and the submit event. Each error in errors is a string array; an exception thrown by a validator is passed as is. | <ApiType detail={"[errors: Partial\u003cAllErrors\u003cValues>>, values: Partial\u003cValues>, e?: SubmitEvent \u007c undefined]"}>Type</ApiType> |
| reset | Emitted when a reset button is clicked or formApi.reset is called. It has the name of the native reset event and hides it. | `[]` |
| change | Emitted when the form state changes: a field mounts, unmounts, changes its value, blurs, or changes its validation state or error. Receives formState. It has the name of the native change event and hides it. | <ApiType detail={"[formState: FormState\u003cValues>]"}>Type</ApiType> |
| valueChange | Emitted when a field value changes. Receives all values and the values that changed. | <ApiType detail={"[values: Values, changedValues: Partial\u003cValues>]"}>Type</ApiType> |
| errorChange | Emitted when validation state changes. Receives all errors and the errors that changed, each error a string array. Batch operations such as validate, submit and reset emit once; silent validation and a repeated validation with the same errors do not emit. | <ApiType detail={"[errors: AllErrors\u003cValues>, changedError?: Partial\u003cRecord\u003cFieldPath\u003cValues, 5>, FieldError \u007c undefined>> \u007c undefined]"}>Type</ApiType> |
| getFormApi | Emitted after the Form mounts. Receives formApi. | <ApiType detail={"[formApi: FormApi\u003cValues, Output>]"}>Type</ApiType> |
