**Props**

| Property  | Description                                                                                               | Type      | Default |
| --------- | --------------------------------------------------------------------------------------------------------- | --------- | ------- |
| children  | The fields in the section.                                                                                | `Snippet` | -       |
| extraText | A description snippet below the title, also the accessible description of the group (`aria-describedby`). | `Snippet` | -       |
