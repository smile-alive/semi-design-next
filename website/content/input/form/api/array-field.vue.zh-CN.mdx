**Props**

| 属性      | 说明                                                                                                                                                | 类型        | 默认值                                         |
| --------- | --------------------------------------------------------------------------------------------------------------------------------------------------- | ----------- | ---------------------------------------------- |
| field     | 数组在 formState.values 中的路径，必填。例如各行字段为 a[0].name、a[1].name 时应传 a。                                                              | `string`    | `undefined`                                    |
| initValue | 数组的初始值，必须是数组；与 Form 的 initValues 同时配置时优先。                                                                                    | `unknown[]` | `semiGlobalDefault("ArrayField", "initValue")` |
| keepState | 卸载时是否保留整组数据，也是行内字段未设置 keepState 时的默认值；未设置时取外层 ArrayField 或 Form 的 keepState。保留时重新挂载按保留的值渲染各行。 | `boolean`   | `semiGlobalDefault("ArrayField", "keepState")` |
