**Props**

| Property | Description | Type | Default |
| --- | --- | --- | --- |
| field | Path of the node to render, the root by default. The root object renders without a Section; other objects render as a Section titled by their title. | `string` | `semiGlobalDefault("SchemaField", "field")` |
| jsonSchema | The JSON Schema to render. It takes precedence over the JSON Schema exported from the Form's `schema`; with neither, nothing renders and a warning is logged in development. | `JsonSchema` | `semiGlobalDefault("SchemaField", "jsonSchema")` |
| renderers | Render functions by node kind, `{ object, array, field }`, returning VNodes; SchemaField itself renders no UI. Pass `semiRenderers` for the default UI built from Semi Form controls. Without `object` an object renders its properties as they are; without `array` or `field` those nodes render nothing and a warning is logged in development. Each function receives a `context` with `node` and `render(field)`; an object also has `content` (the VNode of its properties), an array also has `items`, `add`, `move`, `error`, `fieldProps` and so on. | `SchemaFieldRenderers` | `semiGlobalDefault("SchemaField", "renderers")` |
| renderField | Replaces the `renderers` function of a node by its path, with array rows written as `[]` (such as `contacts[].email`). It receives what the function of that node's kind receives and returns VNodes. | <ApiType detail={"Record\u003cstring, (context: SchemaFieldContext) => VNodeChild>"}>Type</ApiType> | `semiGlobalDefault("SchemaField", "renderField")` |
