**Props**

| 属性      | 说明                                                                           | 类型      | 默认值 |
| --------- | ------------------------------------------------------------------------------ | --------- | ------ |
| children  | 分组内的字段。                                                                 | `Snippet` | -      |
| extraText | 显示在标题下方的说明 snippet，同时作为分组的无障碍描述（`aria-describedby`）。 | `Snippet` | -      |
| text      | 分组标题，没有内容时不渲染标题元素。                                           | `Snippet` | -      |
