**Props**

| Property | Description | Type | Default |
| --- | --- | --- | --- |
| allowEmpty | Whether a field whose value becomes empty keeps its key in values. Setting it to true on either the Form or the field takes effect. | `boolean` | - |
| autoScrollToError | Whether to scroll to the first invalid field when submit or formApi.validate fails. An object is passed to scroll-into-view-if-needed as its options. | `boolean \| ScrollOptions` | - |
| children | Content rendered after the fields, such as a submit button. | `JSX.Element` | - |
| disabled | The disabled state applied to every field. A field's own disabled takes precedence. | `boolean` | - |
| extraTextPosition | Position of the extra text of every field: middle puts it between the label and the control, bottom after the control. The same property on a field takes precedence. | `'bottom' \| 'middle'` | - |
| form | The formApi returned by `useForm()`, used to control the form from outside. | <ApiType detail={"FormApi\u003cValues, Output>"}>Type</ApiType> | - |
| getFormApi | Called once the Form has mounted, with the formApi. | <ApiType detail={"(formApi: FormApi\u003cValues, Output>) => void"}>Type</ApiType> | - |
| id | The id of the form element, also written to x-form-id. Generated when omitted. | `string` | - |
| initValues | Initial values of the form, copied once when the Form is created. | `Values` | - |
| jsonSchema | The JSON Schema to render. It takes precedence over the JSON Schema exported from `schema`. | `JsonSchema` | - |
| keepState | Whether an unmounted field keeps its value, error and touched state, restored by path when it mounts again. Fields and ArrayFields without their own setting use this value. | `boolean` | - |
| labelAlign | Text alignment of the label of every field. The same property on a field takes precedence. | `'left' \| 'right'` | - |
| labelCol | Grid layout of the label of every field, with the properties of Col such as span and offset. Set it together with wrapperCol. | `ColProps` | - |
| labelPosition | Label position of every field. inset is supported by some fields only; the others are laid out as top. The same property on a field takes precedence. | `'inset' \| 'left' \| 'top'` | - |
| labelWidth | Label width of every field. A number is in px. | `number \| string` | - |
| layout | Direction in which the fields are arranged: vertical or horizontal. | `'horizontal' \| 'vertical'` | - |
| onChange | Called when the form state changes: a field mounts, unmounts, changes its value, blurs, or changes its validation state or error. Receives formState. | <ApiType detail={"(formState: FormState\u003cValues>) => void"}>Type</ApiType> | - |
| onErrorChange | Called when validation state changes, with all errors and the errors that changed. Batch operations such as validate, submit and reset call it once; silent validation does not. | <ApiType detail={"(errors: AllErrors\u003cValues>, changedError?: Partial\u003cRecord\u003cFieldPath\u003cValues>, FieldError>>) => void"}>Type</ApiType> | - |
| onReset | Called when a reset button is clicked or formApi.reset is called. | <ApiType detail={"() => void"}>Type</ApiType> | - |
| onSubmit | Called when a submit button is clicked or formApi.submitForm is called and validation passes, with values and the submit event. With `schema`, values are the schema's output. | <ApiType detail={"(values: Output, e?: SubmitEvent) => void"}>Type</ApiType> | - |
| onSubmitFail | Called when a submit button is clicked or formApi.submitForm is called and validation fails, with errors, values and the submit event. Each error in errors is a string array; an exception thrown by a validator is passed as is. | <ApiType detail={"(errors: Partial\u003cAllErrors\u003cValues>>, values: Partial\u003cValues>, e?: SubmitEvent) => void"}>Type</ApiType> | - |
| onValueChange | Called when a field value changes, with all values and the values that changed. | <ApiType detail={"(values: Values, changedValue: Partial\u003cValues>) => void"}>Type</ApiType> | - |
| ref | Receives the form element, which carries the formApi. | <ApiType detail={"(element: FormElement\u003cValues, Output>) => void"}>Type</ApiType> | - |
| renderField | The renderField of SchemaField. | <ApiType detail={"Record\u003cstring, (context: SchemaFieldRenderContext) => JSX.Element>"}>Type</ApiType> | - |
| schema | A Standard Schema object (Zod, Valibot, ArkType and so on) that validates the form and, when it implements Standard JSON Schema, gives the JSON Schema to render. Once all fields pass, `onSubmit` receives the schema's output. | <ApiType detail={"StandardSchema\u003cValues, Output>"}>Type</ApiType> | - |
| schemaDebounce | With `schema`, how many milliseconds of pause in input a change-triggered validation waits for. Validation on submit, formApi.validate and blur does not wait. | `number` | - |
| showValidateIcon | Whether the validation message is preceded by an icon of its status. | `boolean` | - |
| stopPropagation | Whether to stop the submit and reset events from bubbling, so that a nested Form does not trigger the events of the outer one. | `{ submit?: boolean; reset?: boolean; }` | - |
| stopValidateWithError | Whether to skip the remaining rules after the first rule fails. The same property on a field takes precedence. | `boolean` | - |
| trigger | When every field validates: change, blur, mount, custom, or an array of them. The same property on a field takes precedence. | `FieldValidateTriggerType` | - |
| validator | Form-level validation, exclusive with `schema`; works as the validator of Form. | <ApiType detail={"FormValidator\u003cValues>"}>Type</ApiType> | - |
| widgets | The widgets of SchemaField. | <ApiType detail={"Record\u003cstring, Component\u003cany>>"}>Type</ApiType> | - |
| wrapperCol | Grid layout of the control of every field, with the properties of Col such as span and offset. Set it together with labelCol. | `ColProps` | - |
