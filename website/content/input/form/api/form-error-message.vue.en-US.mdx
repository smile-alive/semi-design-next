**Props**

| Property         | Description                                                                                                                                                                                                      | Type                                             | Default     |
| ---------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------ | ----------- |
| error            | The error, a string array whose messages are joined with commas. helpText is hidden while there is an error; `['']` means failed without text and renders nothing; an empty array or empty value means no error. | `FieldError`                                     | `undefined` |
| errorMessageId   | The id of the error text element, referenced by aria-errormessage.                                                                                                                                               | `string`                                         | `undefined` |
| helpTextId       | The id of the help text element, referenced by aria-describedby.                                                                                                                                                 | `string`                                         | `undefined` |
| isInInputGroup   | Whether it is inside an InputGroup. When it and showValidateIcon are true, the error icon shows whatever validateStatus is.                                                                                      | `boolean`                                        | `undefined` |
| showValidateIcon | Whether to show the icon of validateStatus.                                                                                                                                                                      | `boolean`                                        | `undefined` |
| validateStatus   | Validation status of the message: default, error, warning or success.                                                                                                                                            | `"default" \| "error" \| "success" \| "warning"` | `undefined` |

**Events**

| Event | Description | Callback parameters |

**Slots**

| Slot     | Description                                                                    | Scope parameters         |
| -------- | ------------------------------------------------------------------------------ | ------------------------ |
| error    | Custom rendering of the error. The scope provides error.                       | `{ error: FieldError; }` |
| helpText | Help text, shown while there is no error and sharing the block with the error. | `any`                    |
