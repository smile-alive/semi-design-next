| Property  | Description                                                                                                                                                                                               | Type                                                                      | Default |

| children  | Content of the rows, with `{ arrayFields, onAdd, onAddWithInitValue, onMove }`. `onMove(from, to)` moves a row with its values, errors and touched state, clamping indexes out of range.                  | <ApiType detail={"Snippet\u003c[ArrayFieldSnippetProps]>"}>Type</ApiType> | -       |
| field     | Path of the array in formState.values, required. | initValue | Initial value of the array, which must be an array; it takes precedence over the initValues of the Form.                                                                                                  | `unknown[]`                                                               | -       |
| keepState | Whether the whole array keeps its data when unmounted, and the default keepState of the fields in its rows. Defaults to the Form's keepState. When kept, the rows render from the kept values on remount. | `boolean`                                                                 | -       |
