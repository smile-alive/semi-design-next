**Props**

| Property | Description | Type | Default |
| --- | --- | --- | --- |
| field | Path of the node to render, the root by default. | `string` | `""` |
| jsonSchema | The JSON Schema to render. It takes precedence over the JSON Schema exported from the Form's `schema`; with neither, nothing renders and a warning is logged in development. | `JsonSchema` | - |
| renderers | Render functions by node kind, `{ object, array, field }`; SchemaField itself renders no UI. Pass `semiRenderers` for the default UI built from Semi Form controls. Without `object` an object renders its properties as they are; without `array` or `field` those nodes render nothing and a warning is logged in development. See Render a form from a Schema for what each function receives. | `SchemaFieldRenderers` | - |
| renderField | Replaces the `renderers` function of a node by its path, with array rows written as `[]` (such as `contacts[].email`). It receives what the function of that node's kind receives. | <ApiType detail={"Record\u003cstring, (context: SchemaFieldContext) => React.ReactNode>"}>Type</ApiType> | - |
