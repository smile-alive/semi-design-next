**Props**

| Property | Description                                                                               | Type               | Default  |
| -------- | ----------------------------------------------------------------------------------------- | ------------------ | -------- |
| align    | Alignment of the Label text.                                                              | `string`           | `"left"` |
| children | Label content, which takes precedence over text.                                          | `Snippet`          | -        |
| disabled | Whether it has the disabled style.                                                        | `boolean`          | -        |
| extra    | Content that follows the label text.                                                      | `Snippet`          | -        |
| name     | The id of the labeled control, written to the for attribute of the label.                 | `string`           | -        |
| optional | Whether the optional text of the locale follows the text. The required \* is then hidden. | `boolean`          | `false`  |
| required | Whether to show the required \* mark.                                                     | `boolean`          | `false`  |
| text     | Label text; the `children` snippet takes precedence.                                      | `string \| number` | -        |
| width    | Label width; a number is in px.                                                           | `number \| string` | -        |
