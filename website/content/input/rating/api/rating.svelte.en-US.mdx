import ApiType from '#/components/ApiType.astro';

**Props**

| Property      | Description                                                                                                                                                                    | Type                                                                                               | Default         |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------- | --------------- |
| allowClear    | Whether clicking the selected star again clears the value.                                                                                                                     | `boolean`                                                                                          | `true`          |
| allowHalf     | Whether half stars can be selected.                                                                                                                                            | `boolean`                                                                                          | `false`         |
| autofocus     | Whether to focus on mount.                                                                                                                                                     | `boolean \| null`                                                                                  | -               |
| character     | Character drawn in every star, a string or a snippet. A string is also the unit in each star's accessible name and the group summary; for a snippet the locale's unit is used. | `string \| Snippet`                                                                                | -               |
| count         | Total number of stars.                                                                                                                                                         | `number`                                                                                           | `5`             |
| disabled      | Read-only: no interaction and no focus.                                                                                                                                        | `boolean`                                                                                          | `false`         |
| onBlur        | Called when focus leaves the rating.                                                                                                                                           | <ApiType detail={"(event: FocusEvent) => void"}>Type</ApiType>                                     | -               |
| onChange      | Called when the selection changes, with the new value.                                                                                                                         | <ApiType detail={"(value: number) => void"}>Type</ApiType>                                         | -               |
| onClick       | Called when a star is clicked or selected with Enter or Space, with the event and the star index. It shadows a native click listener on the root element.                      | <ApiType detail={"(event: MouseEvent \u007c KeyboardEvent, index: number) => void"}>Type</ApiType> | -               |
| onFocus       | Called when focus enters the rating; moving between stars does not call it.                                                                                                    | <ApiType detail={"(event: FocusEvent) => void"}>Type</ApiType>                                     | -               |
| onHoverChange | Called when the hovered value changes; receives undefined when the pointer leaves or a click clears the value.                                                                 | <ApiType detail={"(value?: number) => void"}>Type</ApiType>                                        | -               |
| onKeyDown     | Called only for an arrow key that moved the value.                                                                                                                             | <ApiType detail={"(event: KeyboardEvent) => void"}>Type</ApiType>                                  | -               |
| prefixCls     | Class name prefix of the component.                                                                                                                                            | `string`                                                                                           | `"semi-rating"` |
| preventScroll | Whether the browser should avoid scrolling the document to show the newly focused element, for focus inside the component.                                                     | `boolean`                                                                                          | -               |
| size          | Size: default or small, or a number for a custom size.                                                                                                                         | `'small' \| 'default' \| number`                                                                   | `"default"`     |
| tooltips      | Prompt text for each item.                                                                                                                                                     | `string[]`                                                                                         | -               |
| value         | Current value; bind it with `bind:value`. `bind:value={get, set}` makes it fully controlled; a plain `value` is the initial value and user interaction changes it afterwards.  | `number`                                                                                           | -               |

**Methods**

| Method | Description                                                                                                  | Type                                          |
| ------ | ------------------------------------------------------------------------------------------------------------ | --------------------------------------------- |
| blur   | Blurs the focused element inside the rating. Does nothing when focus is elsewhere or the rating is disabled. | <ApiType detail={"() => void"}>Type</ApiType> |
| focus  | Focuses the radio that Tab reaches, the same one autofocus uses. Does nothing when disabled.                 | <ApiType detail={"() => void"}>Type</ApiType> |
