import ApiType from '#/components/ApiType.astro';

**Props**

| Property      | Description                                                                                                                                            | Type                             | Default                                        |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------- | ---------------------------------------------- |
| allowClear    | Whether clicking the selected star again clears the value.                                                                                             | `boolean`                        | `true`                                         |
| allowHalf     | Whether half stars can be selected.                                                                                                                    | `boolean`                        | `false`                                        |
| ariaLabel     | Accessible name of the radiogroup; without it the name summarizes the value.                                                                           | `string`                         | `semiGlobalDefault("Rating", "ariaLabel")`     |
| autofocus     | Whether to focus on mount.                                                                                                                             | `boolean`                        | `semiGlobalDefault("Rating", "autofocus")`     |
| count         | Total number of stars.                                                                                                                                 | `number`                         | `5`                                            |
| defaultValue  | Initial value when uncontrolled.                                                                                                                       | `number`                         | `0`                                            |
| disabled      | Read-only: no interaction and no focus.                                                                                                                | `boolean`                        | `false`                                        |
| modelValue    | Current value, used with v-model. When given, this value decides what is shown; back to undefined it returns to defaultValue and becomes uncontrolled. | `number`                         | `undefined`                                    |
| preventScroll | Whether the browser should avoid scrolling the document to show the newly focused element, for focus inside the component.                             | `boolean`                        | `semiGlobalDefault("Rating", "preventScroll")` |
| size          | Size: default or small, or a number for a custom size.                                                                                                 | `number \| "default" \| "small"` | `"default"`                                    |
| tooltips      | Prompt text for each item.                                                                                                                             | `string[]`                       | `semiGlobalDefault("Rating", "tooltips")`      |

**Events**

| Event             | Description                                                                                                                                                | Callback parameters                                   |
| ----------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------- |
| blur              | Emitted when focus leaves the rating.                                                                                                                      | `[event: FocusEvent]`                                 |
| change            | Emitted when the selection changes, with the new value.                                                                                                    | `[value: number]`                                     |
| click             | Emitted when a star is clicked or selected with Enter or Space, with the event and the star index. It shadows a native click listener on the root element. | `[event: KeyboardEvent \| MouseEvent, index: number]` |
| focus             | Emitted when focus enters the rating; moving between stars does not emit it.                                                                               | `[event: FocusEvent]`                                 |
| hoverChange       | Emitted when the hovered value changes; receives undefined when the pointer leaves or a click clears the value.                                            | `[value: number \| undefined]`                        |
| keydown           | Emitted only for an arrow key that moved the value.                                                                                                        | `[event: KeyboardEvent]`                              |
| update:modelValue | Emitted when the selection changes, for v-model to write back.                                                                                             | `[value: number]`                                     |

**Slots**

| Slot      | Description                                                                                                                                                            | Scope parameters |
| --------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------- |
| character | Character drawn in every star. When it is plain text, that text is the unit in each star's accessible name and the group summary; otherwise the locale's unit is used. | `any`            |

**Exposes**

| Name  | Description                                                                                                  | Type                                          |
| ----- | ------------------------------------------------------------------------------------------------------------ | --------------------------------------------- |
| blur  | Blurs the focused element inside the rating. Does nothing when focus is elsewhere or the rating is disabled. | <ApiType detail={"() => void"}>Type</ApiType> |
| focus | Focuses the radio that Tab reaches, the same one autofocus uses. Does nothing when disabled.                 | <ApiType detail={"() => void"}>Type</ApiType> |
