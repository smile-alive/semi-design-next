### 限制验证码格式

#### 设置位数

通过 count 设置位数，默认 6 位，下方 Demo 设置为 4 位

<Demo id="count" />

#### 设置字符范围

使用 format 控制可输入的字符范围

- 传入 "number" 只允许设置数字
- 传入 "mixed" 允许数字和字母
- 传入正则表达式，只允许输入可通过正则判定的字符
- 传入函数，验证码会在输入的时候以字符为单位被依次作为参数分别单独传入进行校验，当函数返回 true 时，允许该字符被输入进 PinCode

<Framework only="solid">

## API 参考

<Framework only="react">

<PinCodeReactApi />

## Accessibility

### ARIA

- 根元素为 `role="group"`，名称通过 `aria-label` 或 `aria-labelledby` 提供；没有可见标签时请传 `aria-label`，否则分组没有名称。
- 每格输入框的可访问名称来自语言包，形如「第 1 位，共 6 位」，随 `count` 与格子序号变化，无需手动设置。
- `aria-describedby`、`aria-errormessage`、`aria-invalid`、`aria-required` 落在每个输入框上；`validateStatus` 传给每个输入框。
- `format` 为 `"number"` 时输入框使用数字软键盘（`inputmode="numeric"`），其余为文本键盘。

### 键盘和焦点

- 每个格子是独立的输入框，输入一个合法字符后焦点移到下一格，在最后一格输入后失焦；已填内容总是从第一格起连续，在空格子之后输入的字符落在第一个空格子上。`Tab` 与 `Shift` + `Tab` 在格子之间切换。
- `左箭头`、`右箭头` 在格子之间移动焦点；`Backspace` 与 `Delete` 都删除当前格字符，后面的字符依次前移，`Backspace` 还会把焦点移到上一格。
- 粘贴整段验证码时，从当前格起按字符依次填入各格，遇到不合法字符即停止。
- `autoFocus`（Vue 为 `autofocus`）只在用户明确进入验证码输入步骤时开启，页面加载时自动聚焦会让读屏跳过之前的内容。

<Framework only="solid">

属性名写作 `autofocus`，行为同上。

</Framework>
