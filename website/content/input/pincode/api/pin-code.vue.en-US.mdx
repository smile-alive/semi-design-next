**Props**

| Property       | Description                                                                                                                                                                         | Type                                             | Default                                          |
| -------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------ | ------------------------------------------------ |
| autofocus      | Whether to focus the first input on mount. Turn it on only when the user has just entered the code step: focus moving at page load makes screen readers skip the content before it. | `boolean`                                        | `false`                                          |
| count          | Number of digits.                                                                                                                                                                   | `number`                                         | `6`                                              |
| defaultValue   | Initial content when uncontrolled.                                                                                                                                                  | `string`                                         | `semiGlobalDefault("PinCode", "defaultValue")`   |
| disabled       | Whether the input is disabled.                                                                                                                                                      | `boolean`                                        | `semiGlobalDefault("PinCode", "disabled")`       |
| format         | Format limit for a single character: number allows digits only, mixed allows digits and letters, and a regular expression or function judges each character.                        | `PinCodeFormat`                                  | `undefined`                                      |
| modelModifiers | The v-model modifiers, passed by Vue for v-model.trim and the like; declaring them keeps the modifiers off the root element.                                                        | `ModelModifiers`                                 | `undefined`                                      |
| modelValue     | Input content, used with v-model.                                                                                                                                                   | `string`                                         | `undefined`                                      |
| size           | Input size: large, default or small.                                                                                                                                                | `Size`                                           | `semiGlobalDefault("PinCode", "size")`           |
| validateStatus | Validation status, passed to every input; error shows the error style.                                                                                                              | `"default" \| "error" \| "success" \| "warning"` | `semiGlobalDefault("PinCode", "validateStatus")` |

**Events**

| Event             | Description                                                                                  | Callback parameters   |
| ----------------- | -------------------------------------------------------------------------------------------- | --------------------- |
| blur              | Emitted when focus leaves the whole code.                                                    | `[event: FocusEvent]` |
| change            | Emitted when the content changes, with the current content.                                  | `[value: string]`     |
| complete          | Emitted once all digits are entered, with the current content.                               | `[value: string]`     |
| focus             | Emitted when focus enters the code from outside; moving between the inputs does not emit it. | `[event: FocusEvent]` |
| update:modelValue | Emitted when the content changes, for v-model to write back.                                 | `[value: string]`     |

**Slots**

| Slot | Description | Scope parameters |
| ---- | ----------- | ---------------- |
| None |             |                  |

**Exposes**

| Name  | Description                                                                                                   | Type                                                       |
| ----- | ------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------- |
| blur  | Blurs the input at index, counted from 0 and ignored when out of range.                                       | <ApiType detail={"(index: number) => void"}>Type</ApiType> |
| focus | Focuses the input at index, counted from 0 and ignored when out of range, with the caret after its character. | <ApiType detail={"(index: number) => void"}>Type</ApiType> |
