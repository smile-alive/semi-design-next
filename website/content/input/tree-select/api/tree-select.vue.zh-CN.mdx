**Events**

| 事件 | 说明 | 回调参数 |
| --- | --- | --- |
| update:modelValue | 选中值变化时触发，v-model 使用；清空时载荷为 undefined。 | <ApiType detail={"[value: ByMultiple\u003cMultiple, T \u007c undefined, T[]>]"}>Type</ApiType> |
| change | 选中值变化时触发，载荷依次为值、节点和触发事件，值与 update:modelValue 相同。清空和多选时分别为 undefined 与数组；通过关闭标签触发时事件为 null；开启 changeWithObject 后值与节点是同一个节点对象。会遮住根元素上同名的原生事件。 | <ApiType detail={"[value: ByMultiple\u003cMultiple, T \u007c undefined, T[]>, node: ByMultiple\u003cMultiple, TreeNodeData \u007c undefined, TreeNodeData[]>, event: TreeSelectChangeEvent]"}>Type</ApiType> |
| update:expandedKeys | 展开的节点变化时触发，v-model:expandedKeys 使用。 | `[expandedKeys: string[]]` |
| expand | 展开或收起节点时触发，info 含 expanded 与 node。 | <ApiType detail={"[expandedKeys: string[], info: { expanded: boolean; node: TreeNodeData; }]"}>Type</ApiType> |
| update:loadedKeys | 已加载的节点变化时触发，v-model:loadedKeys 使用。 | `[loadedKeys: string[]]` |
| load | 节点加载完毕时触发，loadedKeys 为已加载节点 key 的 Set。 | <ApiType detail={"[loadedKeys: Set\u003cstring>, node: TreeNodeData]"}>Type</ApiType> |
| select | 节点被选中或取消选中时触发，载荷为该节点的 key、是否选中和节点数据。会遮住根元素上同名的原生事件。 | `[selectedKey: string, selected: boolean, node: TreeNodeData]` |
| search | 搜索框的值变化时触发；filteredExpandedKeys 是因搜索或 modelValue、defaultValue 而展开的节点，可在展开受控时用来展开搜索结果；filteredNodes 是搜索命中的节点。 | <ApiType detail={"[input: string, filteredExpandedKeys: string[], filteredNodes: TreeNodeData[]]"}>Type</ApiType> |
| dropdownVisibleChange | 下拉面板显示或隐藏时触发。组件在 KeepAlive 中停用时会关闭面板并发出 false，不发出 blur。 | `[visible: boolean]` |
| focus | 焦点从外部进入选择框（含其中的搜索框、清除按钮）或下拉面板时触发，载荷是 FocusEvent；焦点在它们之间移动不重复触发。选中节点并关闭面板后再次点击或按键打开时也会触发，载荷为该次点击或按键的事件；searchAutoFocus 挂载时自动聚焦的载荷为 null。禁用时不触发。会遮住根元素上同名的原生事件。 | `[event: MouseEvent \| KeyboardEvent \| FocusEvent \| null]` |
| blur | 每次 focus 之后只触发一次：焦点离开选择框和下拉面板时载荷是 FocusEvent，点击外部时是 MouseEvent，选中节点并关闭面板时是该次点击或按键的事件。会遮住根元素上同名的原生事件。 | `[event: MouseEvent \| KeyboardEvent \| FocusEvent]` |
| clear | 点击或用键盘触发清除按钮时触发，载荷是触发清除的事件，通过插槽函数清除且没有事件时为 null。 | `[event: TreeSelectChangeEvent]` |
| keydown | 按键事件，先于 TreeSelect 自身的按键处理触发。会遮住根元素上同名的原生事件。 | `[event: KeyboardEvent]` |
