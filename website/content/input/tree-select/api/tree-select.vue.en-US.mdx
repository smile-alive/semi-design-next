**Events**

| Event | Description | Callback parameters |
| --- | --- | --- |
| update:modelValue | Emitted when the selection changes; used by v-model. The payload is undefined once cleared. | <ApiType detail={"[value: ByMultiple\u003cMultiple, T \u007c undefined, T[]>]"}>Type</ApiType> |
| change | Emitted when the selection changes, with the value, the node and the triggering event; the value equals that of update:modelValue. It is undefined once cleared and arrays in multiple mode; the event is null for a closed tag; with changeWithObject the value and the node are the same node object. It shadows the native event of the same name on the root element. | <ApiType detail={"[value: ByMultiple\u003cMultiple, T \u007c undefined, T[]>, node: ByMultiple\u003cMultiple, TreeNodeData \u007c undefined, TreeNodeData[]>, event: TreeSelectChangeEvent]"}>Type</ApiType> |
| update:expandedKeys | Emitted when the expanded nodes change; used by v-model:expandedKeys. | `[expandedKeys: string[]]` |
| expand | Emitted when a node expands or collapses; info holds expanded and node. | <ApiType detail={"[expandedKeys: string[], info: { expanded: boolean; node: TreeNodeData; }]"}>Type</ApiType> |
| update:loadedKeys | Emitted when the loaded nodes change; used by v-model:loadedKeys. | `[loadedKeys: string[]]` |
| load | Emitted when a node has loaded; loadedKeys is the Set of keys of loaded nodes. | <ApiType detail={"[loadedKeys: Set\u003cstring>, node: TreeNodeData]"}>Type</ApiType> |
| select | Emitted when a node is selected or deselected, with its key, whether it is selected and its data. It shadows the native event of the same name on the root element. | `[selectedKey: string, selected: boolean, node: TreeNodeData]` |
| search | Emitted when the search input changes; filteredExpandedKeys are the nodes expanded by the search or by modelValue and defaultValue, which controlled expansion can use to show the results; filteredNodes are the nodes that matched. | <ApiType detail={"[input: string, filteredExpandedKeys: string[], filteredNodes: TreeNodeData[]]"}>Type</ApiType> |
| dropdownVisibleChange | Emitted when the dropdown opens or closes. Deactivating the component inside KeepAlive closes it and emits false, without a blur. | `[visible: boolean]` |
| focus | Emitted when focus enters the select box (including its search box and clear button) or the dropdown from outside, with a FocusEvent; moving between them does not emit again. It also fires when a click or key reopens the dropdown after a selection closed it, with that click or key event, and null for searchAutoFocus on mount. It is not emitted while disabled. It shadows the native event of the same name on the root element. | `[event: MouseEvent \| KeyboardEvent \| FocusEvent \| null]` |
| blur | Emitted once after each focus: a FocusEvent when focus leaves the select box and the dropdown, a MouseEvent for a click outside, and the click or key event when a selection closes the dropdown. It shadows the native event of the same name on the root element. | `[event: MouseEvent \| KeyboardEvent \| FocusEvent]` |
| clear | Emitted when the clear button is used by click or keyboard; the payload is the triggering event, null when cleared through a slot function without an event. | `[event: TreeSelectChangeEvent]` |
| keydown | A key press, emitted before the TreeSelect handles the key. It shadows the native event of the same name on the root element. | `[event: KeyboardEvent]` |
