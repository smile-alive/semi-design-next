**Methods**

| Method | Description                                                                              | Type                                                       |
| ------ | ---------------------------------------------------------------------------------------- | ---------------------------------------------------------- |
| close  | Closes the dropdown.                                                                     | <ApiType detail={"() => void"}>Type</ApiType>              |
