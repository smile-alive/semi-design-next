**Events**

| Event | Description | Callback parameters |
| --- | --- | --- |
| update:modelValue | Emitted when the selection changes; the update event of v-model, with the same payload as change. | <ApiType detail={"[value: ByMultiple\u003cMultiple, CascaderSimpleValue[], CascaderSimpleValue[][]>]"}>Type</ApiType> |
| change | Emitted when the selection changes. In single mode the selected path, in multiple mode an array of the selected paths; node data with changeWithObject. It shares its name with the native change and hides the native one that bubbles from inside the root. | <ApiType detail={"[value: ByMultiple\u003cMultiple, CascaderSimpleValue[], CascaderSimpleValue[][]>]"}>Type</ApiType> |
| select | Emitted when a node is selected, with the value of the node. In multiple mode, one checked node gives its value and more give an array. | <ApiType detail={"[value: ByMultiple\u003cMultiple, string \u007c number, string \u007c number \u007c (string \u007c number)[]>]"}>Type</ApiType> |
| search | Emitted when the search input changes, with the text. | `[value: string]` |
| focus | Emitted when a click or a key opens the dropdown, with that MouseEvent or KeyboardEvent. It is not a DOM focus event and Tabbing in or out does not emit it. | `[event: MouseEvent \| KeyboardEvent \| FocusEvent]` |
| blur | Emitted when the dropdown closes: a MouseEvent for a click outside, a KeyboardEvent for Esc, undefined when the close method closes it. It is not a DOM blur event. | `[event?: MouseEvent \| KeyboardEvent \| FocusEvent \| undefined]` |
| dropdownVisibleChange | Emitted when the dropdown opens or closes, with whether it is open. | `[visible: boolean]` |
| clear | Emitted when the clear button clears the selection. | `[]` |
| exceed | Emitted in multiple mode when the selection goes past max, with the Entity array of the checked nodes. | `[checkedItem: CascaderEntity[]]` |
| load | Emitted when a node has loaded, with the set of loaded keys and the node data. | <ApiType detail={"[newLoadedKeys: Set\u003cstring>, data: CascaderData]"}>Type</ApiType> |
| listScroll | Emitted when a column of the tree scrolls, with the scroll event and the column. Scrolling the search results does not emit it. | `[event: Event, panel: CascaderScrollPanelProps]` |
| keydown | Emitted once per key press before the Cascader handles it; calling preventDefault there does not stop the Cascader. Except for a key on the clear button or a control inside a custom trigger, it is emitted in the capture phase on the trigger, so stopPropagation there keeps the key from the search input and skips the trigger's handling of it (opening the dropdown, closing it on Esc); the options still take it. It shares its name with the native keydown and hides the native one that bubbles from inside the root. | `[event: KeyboardEvent]` |
