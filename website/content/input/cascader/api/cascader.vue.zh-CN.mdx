**Events**

| 事件 | 说明 | 回调参数 |
| --- | --- | --- |
| blur | 关闭下拉时触发：点击外部时载荷为 MouseEvent，Esc 为 KeyboardEvent，通过方法 close 关闭时为 undefined。不是 DOM 失焦事件。 | `[event?: FocusEvent \| KeyboardEvent \| MouseEvent \| undefined]` |
| change | 选中值变化时触发。单选为所选路径，多选为各选中路径的数组；开启 changeWithObject 时为节点数据。与原生 change 同名，声明后会遮住根元素上冒泡的同名原生事件。 | <ApiType detail={"[value: ByMultiple\u003cMultiple, CascaderSimpleValue[], CascaderSimpleValue[][]>]"}>Type</ApiType> |
| clear | 点击清除按钮清空选中值时触发。 | `[]` |
| dropdownVisibleChange | 下拉展开或收起时触发，载荷是是否展开。 | `[visible: boolean]` |
| exceed | 多选时选中数量超出 max 时触发，载荷是已选节点的 Entity 数组。 | `[checkedItem: CascaderEntity[]]` |
| focus | 点击或按键打开下拉时触发，载荷是那次 MouseEvent 或 KeyboardEvent。不是 DOM 焦点事件，Tab 进出不会触发。 | `[event: FocusEvent \| KeyboardEvent \| MouseEvent]` |
| keydown | 在 Cascader 处理按键之前触发，每次按键只触发一次；在其中调用 preventDefault 不会阻止 Cascader 的处理。除清除按钮与自定义触发器内控件上的按键外，事件在触发器的捕获阶段发出，此时调用 stopPropagation 会让搜索框收不到该键，并跳过触发器对它的处理（打开下拉、Esc 关闭），选项仍会处理该键。与原生 keydown 同名，会遮住根元素上冒泡的原生事件。 | `[event: KeyboardEvent]` |
| listScroll | 滚动列视图中的某一列时触发，载荷是滚动事件与该列的信息。搜索结果的滚动不触发。 | `[event: Event, panel: CascaderScrollPanelProps]` |
| load | 节点加载完毕时触发，载荷是已加载的 key 集合与该节点的数据。 | <ApiType detail={"[newLoadedKeys: Set\u003cstring>, data: CascaderData]"}>Type</ApiType> |
| search | 搜索输入变化时触发，载荷是输入的文本。 | `[value: string]` |
| select | 选中某个节点时触发，载荷是该节点的 value；多选时只勾选了一个节点时是它的 value，勾选多个时是 value 数组。 | <ApiType detail={"[value: ByMultiple\u003cMultiple, string \u007c number, string \u007c number \u007c (string \u007c number)[]>]"}>Type</ApiType> |
| update:modelValue | 选中值变化时触发，是 v-model 的更新事件，载荷与 change 相同。 | <ApiType detail={"[value: ByMultiple\u003cMultiple, CascaderSimpleValue[], CascaderSimpleValue[][]>]"}>Type</ApiType> |
