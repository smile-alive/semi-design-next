**Events**

| Event             | Description                                                                                                                                                       | Callback parameters                                                                                                             |
| ----------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| update:modelValue | Emitted when the time changes, for v-model to write back. Cleared, it is undefined (single) or an empty array (range); the unpicked side of a range is undefined. | `[value: Date \| (Date \| undefined)[] \| undefined]`                                                                           |
| change            | Emitted when the time changes, with (Date value, formatted string); both are arrays in range mode.                                                                | <ApiType detail={"[value: Date \u007c (Date \u007c undefined)[] \u007c undefined, str: string \u007c string[]]"}>Type</ApiType> |
| update:open       | Emitted when the panel opens or closes, for v-model:open to write back.                                                                                           | `[open: boolean]`                                                                                                               |
| openChange        | Emitted when the panel opens or closes.                                                                                                                           | `[open: boolean]`                                                                                                               |
| focus             | Emitted when the input's root element gains focus; moving focus between the input and the clear button does not emit it.                                          | `[event: FocusEvent]`                                                                                                           |
| blur              | Emitted when a click outside closes the panel, with the native event of that mousedown; leaving the input does not emit it.                                       | `[event: MouseEvent]`                                                                                                           |

**Slots**

| Slot        | Description                                                                                                                                                                                                                                     | Scope parameters             |
| ----------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------- |
| trigger     | Custom trigger that replaces the default input; a click anywhere in it opens the panel. Receives value (the unpicked side undefined), inputValue, placeholder, disabled, componentProps and onChange (updates the input text, as typing would). | `TimePickerTriggerSlotProps` |
| panelHeader | Content above the panel; index is the panel's position (0 for time, 0 or 1 for timeRange). Without it, a range shows the locale's start and end text.                                                                                           | `TimePickerPanelSlotProps`   |
| panelFooter | Content below the panel; index is the panel's position.                                                                                                                                                                                         | `TimePickerPanelSlotProps`   |
| panel       | Range mode only: used as both the header and the footer of panel index, taking precedence over panelHeader and panelFooter while it has content.                                                                                                | `TimePickerPanelSlotProps`   |
| prefix      | Prefix content of the input.                                                                                                                                                                                                                    | `any`                        |
| insetLabel  | Inset label of the input.                                                                                                                                                                                                                       | `any`                        |
| clearIcon   | Custom clear icon; effective when showClear is true.                                                                                                                                                                                            | `any`                        |

**Exposes**

| Name  | Description                                                                   | Type                                          |
| ----- | ----------------------------------------------------------------------------- | --------------------------------------------- |
| focus | Focuses the input, which opens the panel; does nothing with a custom trigger. | <ApiType detail={"() => void"}>Type</ApiType> |
| blur  | Removes focus from the input; does nothing with a custom trigger.             | <ApiType detail={"() => void"}>Type</ApiType> |
