**Events**

| 事件              | 说明                                                                                                  | 回调参数                                                                                                                        |
| ----------------- | ----------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| blur              | 点击外部关闭面板时触发，参数为该次 mousedown 的原生事件；离开输入框不触发。                           | `[event: MouseEvent]`                                                                                                           |
| change            | 时间变化时触发，参数为 (Date 值, 格式化字符串)，范围模式下两者都是数组。                              | <ApiType detail={"[value: (Date \u007c undefined)[] \u007c Date \u007c undefined, str: string \u007c string[]]"}>Type</ApiType> |
| focus             | 输入框根元素获得焦点时触发；焦点在输入框与清除按钮之间移动不触发。                                    | `[event: FocusEvent]`                                                                                                           |
| openChange        | 面板打开或关闭时触发。                                                                                | `[open: boolean]`                                                                                                               |
| update:modelValue | 时间变化时触发，供 v-model 回写；清除后单选为 undefined，范围为空数组，范围中未选的一侧为 undefined。 | `[value: (Date \| undefined)[] \| Date \| undefined]`                                                                           |
| update:open       | 面板打开或关闭时触发，供 v-model:open 回写。                                                          | `[open: boolean]`                                                                                                               |
