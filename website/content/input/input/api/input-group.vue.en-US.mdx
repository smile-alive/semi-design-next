**Props**

| Property      | Description                                                                                                                                                                 | Type              | Default                                            |
| ------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------- | -------------------------------------------------- |
| size          | Input size: large, default or small; controls at any depth in the group that set no size of their own take it.                                                              | `Size`            | `semiGlobalDefault("InputGroup", "size")`          |
| disabled      | Whether the group is disabled; controls at any depth in the group take it, and a disabled a control sets itself takes precedence.                                           | `boolean`         | `semiGlobalDefault("InputGroup", "disabled")`      |
| label         | Label configuration of the group (Form.Label props, plus id, class and style); text and extra accept only strings or numbers, use the label and labelExtra slots for nodes. | `InputGroupLabel` | `semiGlobalDefault("InputGroup", "label")`         |
| labelPosition | Label position: top or left.                                                                                                                                                | `string`          | `semiGlobalDefault("InputGroup", "labelPosition")` |

**Events**

| Event | Description                                                                                                                                 | Callback parameters   |
| ----- | ------------------------------------------------------------------------------------------------------------------------------------------- | --------------------- |
| focus | Emitted when an element in the group gains focus (focusin), including when focus moves between children; it is not passed to the children.  | `[event: FocusEvent]` |
| blur  | Emitted when an element in the group loses focus (focusout), including when focus moves between children; it is not passed to the children. | `[event: FocusEvent]` |

**Slots**

| Slot       | Description                                                                                                               | Scope parameters |
| ---------- | ------------------------------------------------------------------------------------------------------------------------- | ---------------- |
| default    | The input components in the group, such as Input, InputNumber, Select, AutoComplete, TreeSelect, Cascader and DatePicker. | `any`            |
| label      | Node content of the label.                                                                                                | `any`            |
| labelExtra | Extra content of the label.                                                                                               | `any`            |
