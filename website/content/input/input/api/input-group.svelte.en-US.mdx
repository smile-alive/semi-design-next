**Props**

| Property      | Description                                                                                                                                                                                               | Type                                                           | Default |
| ------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------- | ------- |
| children      | The input components in the group, such as Input, InputNumber, Select, AutoComplete, TreeSelect, Cascader and DatePicker.                                                                                 | `Snippet`                                                      | -       |
| disabled      | Whether the group is disabled; controls at any depth in the group take it, and a disabled a control sets itself takes precedence.                                                                         | `boolean`                                                      | -       |
| fieldLabel    | Node content of the label, in place of `label.text`.                                                                                                                                                      | `Snippet`                                                      | -       |
| label         | Renders a FormLabel that names the group, configured with the Form.Label props plus id, class and style; `name` becomes the id of the group. Use the fieldLabel and labelExtra snippets for node content. | `InputGroupLabel`                                              | -       |
| labelExtra    | Extra content of the label.                                                                                                                                                                               | `Snippet`                                                      | -       |
| labelPosition | Label position: top or left.                                                                                                                                                                              | `'top' \| 'left'`                                              | -       |
| onBlur        | Called when an element in the group loses focus (focusout), including when focus moves between children; it is not passed to the children.                                                                | <ApiType detail={"(event: FocusEvent) => void"}>Type</ApiType> | -       |
| onFocus       | Called when an element in the group gains focus (focusin), including when focus moves between children; it is not passed to the children.                                                                 | <ApiType detail={"(event: FocusEvent) => void"}>Type</ApiType> | -       |
| size          | Input size: large, default or small; controls at any depth in the group that set no size of their own take it.                                                                                            | `InputSize`                                                    | -       |
