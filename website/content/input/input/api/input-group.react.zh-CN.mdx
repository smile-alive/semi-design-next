**Props**

| 属性          | 说明                                                                                                 | 类型                                                                                   | 默认值      |
| ------------- | ---------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------- | ----------- |
| children      | 组内的控件，如 `Input`、`InputNumber`、`Select` 等。                                                 | `React.ReactNode`                                                                      | -           |
| className     | `role="group"` 元素的类名。                                                                          | `string`                                                                               | `""`        |
| disabled      | 是否禁用，下发给组内未自行设置 `disabled` 的控件。                                                   | `boolean`                                                                              | -           |
| label         | 组的标签，对象形式，属性同 `Form.Label`，如 `text`、`required`、`extra`；`text` 可以是 `ReactNode`。 | `LabelProps`                                                                           | -           |
| labelPosition | 标签位置，可选 `top` 或 `left`。                                                                     | `string`                                                                               | -           |
| onBlur        | 组内任一控件失去焦点时的回调，组内控件之间移动焦点也会触发。                                         | <ApiType detail={"(e: React.FocusEvent\u003cHTMLSpanElement>) => void"}>Type</ApiType> | -           |
| onFocus       | 组内任一控件获得焦点时的回调，组内控件之间移动焦点也会触发。                                         | <ApiType detail={"(e: React.FocusEvent\u003cHTMLSpanElement>) => void"}>Type</ApiType> | -           |
| ref           | `role="group"` 元素的引用。带 `label` 时仍指向该元素，而不是外层容器。                               | <ApiType detail={"React.Ref\u003cHTMLSpanElement>"}>Type</ApiType>                     | -           |
| size          | 输入框大小，可选 `large`、`default` 或 `small`；下发给组内每个控件，替代控件自身的 `size`。          | `InputSize`                                                                            | `"default"` |
| style         | `role="group"` 元素的内联样式。                                                                      | <ApiType detail={"Record\u003cstring, any>"}>Type</ApiType>                            | -           |
