**Props**

| Property      | Description                                                                                                             | Type                                                       | Default |
| ------------- | ----------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------- | ------- |
| disabled      | Whether the group is disabled; controls at any depth in the group that set no disabled of their own take it.            | `boolean`                                                  | -       |
| label         | Label of the group, as an object with the Form.Label props such as text, required and extra; text can be a JSX element. | `LabelProps`                                               | -       |
| labelPosition | Label position: top or left.                                                                                            | `'top' \| 'left' \| (string & {})`                         | -       |
| onBlur        | Called when any control in the group loses focus, including a move to another control in it.                            | <ApiType detail={"(e: FocusEvent) => void"}>Type</ApiType> | -       |
| onFocus       | Called when any control in the group gets focus, including a move from another control in it.                           | <ApiType detail={"(e: FocusEvent) => void"}>Type</ApiType> | -       |
| size          | Input size: large, default or small; controls at any depth in the group that set no size of their own take it.          | `InputSize`                                                | -       |
