**Props**

| Property                | Description                                                                                                                                                                  | Type                                                                                  | Default     |
| ----------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------- | ----------- |
| addonAfter              | Addon after the input: text, a Semi icon or any JSX element.                                                                                                                 | `JSX.Element`                                                                         | -           |
| addonBefore             | Addon before the input: text, a Semi icon or any JSX element.                                                                                                                | `JSX.Element`                                                                         | -           |
| borderless              | Borderless mode.                                                                                                                                                             | `boolean`                                                                             | `false`     |
| clearIcon               | Custom icon of the clear button, effective when showClear is true.                                                                                                           | `JSX.Element`                                                                         | -           |
| composition             | Whether to enable IME mode; onChange does not fire during a composition and fires once after it ends.                                                                        | `boolean`                                                                             | `false`     |
| defaultValue            | Initial content when the input is uncontrolled.                                                                                                                              | `string \| number`                                                                    | -           |
| disabled                | Whether the input is disabled. When not set, the disabled of the InputGroup it is in applies.                                                                                | `boolean`                                                                             | -           |
| getValueLength          | Custom string length calculation, used with maxLength and minLength.                                                                                                         | <ApiType detail={"(value: string) => number"}>Type</ApiType>                          | -           |
| hideSuffix              | Hides the suffix while the clear button is shown; by default the two sit side by side.                                                                                       | `boolean`                                                                             | `false`     |
| inputRef                | Receives the native input element.                                                                                                                                           | <ApiType detail={"(element: HTMLInputElement) => void"}>Type</ApiType>                | -           |
| inputStyle              | Style of the native input element; object keys are kebab-case and numbers need a unit.                                                                                       | `JSX.CSSProperties \| string`                                                         | -           |
| insetLabel              | Inset label rendered in the prefix position when no prefix is set; then, if neither aria-label nor aria-labelledby is set, the input is named by it through aria-labelledby. | `JSX.Element`                                                                         | -           |
| insetLabelId            | The id of the element around insetLabel, for aria-labelledby to reference.                                                                                                   | `string`                                                                              | -           |
| maxLength               | Maximum length. With getValueLength the length is measured and truncated by it; otherwise the native attribute applies.                                                      | `number`                                                                              | -           |
| minLength               | Minimum length. With getValueLength it is converted accordingly; otherwise the native attribute applies.                                                                     | `number`                                                                              | -           |
| mode                    | Input mode; password shows a button that reveals or hides the text.                                                                                                          | `InputMode`                                                                           | -           |
| onBlur                  | Called when focus leaves the input. It listens on the wrapper, so focus moving between the input and the buttons inside the component does not fire it.                      | <ApiType detail={"(e: FocusEvent) => void"}>Type</ApiType>                            | -           |
| onChange                | Called when the value changes, with the new value and the event.                                                                                                             | <ApiType detail={"(value: string, e: InputChangeEvent) => void"}>Type</ApiType>       | -           |
| onClear                 | Called when the clear button is clicked.                                                                                                                                     | <ApiType detail={"(e: MouseEvent) => void"}>Type</ApiType>                            | -           |
| onEnterPress            | Called on Enter keydown; the Enter that commits an IME composition does not fire it.                                                                                         | <ApiType detail={"(e: InputElementEvent\u003cKeyboardEvent>) => void"}>Type</ApiType> | -           |
| onFocus                 | Called when the input gets focus. It listens on the wrapper, so focus moving inside the component does not fire it again.                                                    | <ApiType detail={"(e: FocusEvent) => void"}>Type</ApiType>                            | -           |
| onlyBorder              | The border width of the wrapper, in px.                                                                                                                                      | `number`                                                                              | -           |
| placeholder             | Hint text shown while the input is empty.                                                                                                                                    | `string \| number`                                                                    | -           |
| prefix                  | Prefix: text, a Semi icon or any JSX element.                                                                                                                                | `JSX.Element`                                                                         | -           |
| preventScroll           | Whether the browser should avoid scrolling the document to show the newly focused element, for focus calls inside the component.                                             | `boolean`                                                                             | -           |
| readonly                | Read-only: blocks typing and hides the clear button. The native readOnly only blocks typing.                                                                                 | `boolean`                                                                             | `false`     |
| ref                     | Receives the wrapper div element; its `focus()` and `blur()` act on the input.                                                                                               | <ApiType detail={"Ref\u003cHTMLDivElement>"}>Type</ApiType>                           | -           |
| showClear               | Shows a clear button when the input has content and the pointer or focus is inside the component.                                                                            | `boolean`                                                                             | `false`     |
| showClearIgnoreDisabled | Internal property used by DatePicker: the clear button stays available while disabled.                                                                                       | `boolean`                                                                             | -           |
| size                    | Input size: large, default or small. In an InputGroup, the size of the group replaces it.                                                                                    | `InputSize`                                                                           | -           |
| suffix                  | Suffix: text, a Semi icon or any JSX element.                                                                                                                                | `JSX.Element`                                                                         | -           |
| type                    | The type of the native input.                                                                                                                                                | `string`                                                                              | `"text"`    |
| validateStatus          | Validation status: default, error or warning; error outputs aria-invalid.                                                                                                    | `ValidateStatus`                                                                      | `"default"` |
| value                   | Content of the input, used as a controlled value together with onChange.                                                                                                     | `string \| number`                                                                    | -           |
