**Props**

| Property                | Description                                                                                                                                                                        | Type                                                                                | Default     |
| ----------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------- | ----------- |
| addonAfter              | Addon after the input. Text or a Semi icon alone gets horizontal spacing automatically.                                                                                            | `Snippet`                                                                           | -           |
| addonBefore             | Addon before the input. Text or a Semi icon alone gets horizontal spacing automatically.                                                                                           | `Snippet`                                                                           | -           |
| autofocus               | Focuses the input on mount, using preventScroll.                                                                                                                                   | `boolean`                                                                           | -           |
| borderless              | Borderless mode.                                                                                                                                                                   | `boolean`                                                                           | `false`     |
| clearIcon               | Custom icon of the clear button, effective when showClear is true.                                                                                                                 | `Snippet`                                                                           | -           |
| composition             | Whether to enable IME mode; onChange is not called during a composition and is called once after it ends.                                                                          | `boolean`                                                                           | `false`     |
| disabled                | Whether the input is disabled.                                                                                                                                                     | `boolean`                                                                           | -           |
| getValueLength          | Custom string length calculation, used with maxlength and minlength.                                                                                                               | <ApiType detail={"(value: string) => number"}>Type</ApiType>                        | -           |
| hideSuffix              | Hides the suffix while the clear button is shown; by default the two sit side by side.                                                                                             | `boolean`                                                                           | `false`     |
| inputStyle              | Style string of the native input element.                                                                                                                                          | `string`                                                                            | -           |
| insetLabel              | Label inside the input.                                                                                                                                                            | `Snippet`                                                                           | -           |
| insetLabelId            | The id of the element around the insetLabel snippet, for aria-labelledby to point at.                                                                                              | `string`                                                                            | -           |
| maxlength               | Maximum length. With getValueLength the length is measured and truncated by it; otherwise the native attribute applies.                                                            | `number`                                                                            | -           |
| minlength               | Minimum length. With getValueLength it is converted accordingly; otherwise the native attribute applies.                                                                           | `number`                                                                            | -           |
| mode                    | Input mode; password shows a button that reveals or hides the text.                                                                                                                | `InputMode`                                                                         | -           |
| onBlur                  | Called when focus leaves the component. The event is the focusout of the wrapper.                                                                                                  | <ApiType detail={"(event: FocusEvent) => void"}>Type</ApiType>                      | -           |
| onChange                | Called when the content changes, with the new value and the event; in IME mode it is called once after the composition ends. This is the callback of Input, not the native change. | <ApiType detail={"(value: string, event: InputChangeEvent) => void"}>Type</ApiType> | -           |
| onClear                 | Called when the clear button is activated.                                                                                                                                         | <ApiType detail={"(event: MouseEvent) => void"}>Type</ApiType>                      | -           |
| onCompositionEnd        | Called when an IME composition ends.                                                                                                                                               | <ApiType detail={"(event: CompositionEvent) => void"}>Type</ApiType>                | -           |
| onCompositionStart      | Called when an IME composition starts.                                                                                                                                             | <ApiType detail={"(event: CompositionEvent) => void"}>Type</ApiType>                | -           |
| onCompositionUpdate     | Called when an IME composition updates.                                                                                                                                            | <ApiType detail={"(event: CompositionEvent) => void"}>Type</ApiType>                | -           |
| onEnterPress            | Called when Enter is pressed (keydown); the Enter that commits an IME composition does not call it.                                                                                | <ApiType detail={"(event: KeyboardEvent) => void"}>Type</ApiType>                   | -           |
| onFocus                 | Called when focus enters the component; moving focus between the input and its buttons does not call it. The event is the focusin of the wrapper.                                  | <ApiType detail={"(event: FocusEvent) => void"}>Type</ApiType>                      | -           |
| onInput                 | The native input event.                                                                                                                                                            | <ApiType detail={"(event: Event) => void"}>Type</ApiType>                           | -           |
| onKeyDown               | The native keydown event.                                                                                                                                                          | <ApiType detail={"(event: KeyboardEvent) => void"}>Type</ApiType>                   | -           |
| onKeyUp                 | The native keyup event.                                                                                                                                                            | <ApiType detail={"(event: KeyboardEvent) => void"}>Type</ApiType>                   | -           |
| placeholder             | Hint text shown while the input is empty.                                                                                                                                          | `string \| number`                                                                  | -           |
| prefix                  | Prefix. Text or a Semi icon alone gets horizontal spacing automatically.                                                                                                           | `Snippet`                                                                           | -           |
| preventScroll           | Whether the browser should avoid scrolling the document to show the newly focused element, for focus inside the component.                                                         | `boolean`                                                                           | -           |
| readonly                | Whether the input is read-only; it also hides the clear button.                                                                                                                    | `boolean`                                                                           | `false`     |
| readOnly                | Whether the input is read-only, locking typing only; the clear button stays (pickers rely on it).                                                                                  | `boolean`                                                                           | -           |
| showClear               | Shows a clear button when the input has content and the pointer or focus is inside the component.                                                                                  | `boolean`                                                                           | `false`     |
| showClearIgnoreDisabled | Internal property used by DatePicker: the clear button stays available while disabled.                                                                                             | `boolean`                                                                           | -           |
| size                    | Input size: large, default or small.                                                                                                                                               | `InputSize`                                                                         | -           |
| suffix                  | Suffix. Text or a Semi icon alone gets horizontal spacing automatically.                                                                                                           | `Snippet`                                                                           | -           |
| type                    | The type of the native input.                                                                                                                                                      | `string`                                                                            | `"text"`    |
| validateStatus          | Validation status: default, error or warning; error outputs aria-invalid.                                                                                                          | `ValidateStatus`                                                                    | `"default"` |
| value                   | Content of the input; bind it with `bind:value`. A plain value is the initial content, which the input then maintains itself; `bind:value={get, set}` makes it fully controlled.   | `string \| number`                                                                  | -           |

| Method            | Description                                                                            | Type                                                                                                                                                   |
| ----------------- | -------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| blur              | Removes focus.                                                                         | <ApiType detail={"() => void"}>Type</ApiType>                                                                                                          |

| select            | Selects all the text in the input.                                                     | <ApiType detail={"() => void"}>Type</ApiType>                                                                                                          |
| setSelectionRange | Sets the selection, with the parameters of the native setSelectionRange.               | <ApiType detail={"(start: number \u007c null, end: number \u007c null, direction?: 'forward' \u007c 'backward' \u007c 'none') => void"}>Type</ApiType> |
