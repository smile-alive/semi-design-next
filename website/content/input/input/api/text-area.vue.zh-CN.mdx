**Props**

| 属性 | 说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| modelValue | 文本内容，用于 v-model。 | `string` | `undefined` |
| modelModifiers | v-model 修饰符 trim、number 与 lazy，由 Vue 在使用对应修饰符时传入。lazy 时输入过程中不更新绑定值，原生 change（失焦）时才发出 update:modelValue；change 事件仍在每次输入时触发。 | `InputModelModifiers` | `undefined` |
| defaultValue | 非受控时的初始内容。 | `string` | `semiGlobalDefault("TextArea", "defaultValue")` |
| autosize | 高度是否随内容自适应，可传 `{ minRows, maxRows }` 限制行数。 | `boolean \| AutosizeRow` | `semiDefault("TextArea", "autosize", false)` |
| borderless | 无边框模式。 | `boolean` | `semiDefault("TextArea", "borderless", false)` |
| rows | 默认行数。 | `number` | `semiDefault("TextArea", "rows", 4)` |
| cols | 默认列数。 | `number` | `semiDefault("TextArea", "cols", 20)` |
| placeholder | 输入框为空时显示的提示文字。 | `string` | `semiGlobalDefault("TextArea", "placeholder")` |
| maxCount | 字数上限，设置后显示字数统计；超出时计数器标红，不截断输入。 | `number` | `semiGlobalDefault("TextArea", "maxCount")` |
| showCounter | 是否显示字数统计；设置 maxCount 时总是显示。 | `boolean` | `semiDefault("TextArea", "showCounter", false)` |
| showClear | 有内容且悬停或焦点位于组件内时展示清除按钮。 | `boolean` | `semiDefault("TextArea", "showClear", false)` |
| disabled | 是否禁用。 | `boolean` | `undefined` |
| readonly | 是否只读。 | `boolean` | `semiGlobalDefault("TextArea", "readonly")` |
| autofocus | 挂载时自动获取焦点。 | `boolean` | `semiGlobalDefault("TextArea", "autofocus")` |
| validateStatus | 校验状态，可选 default、error、warning；error 时输出 aria-invalid。 | `"default" \| "error" \| "warning" \| "success"` | `semiGlobalDefault("TextArea", "validateStatus")` |
| composition | 是否开启输入法模式，开启后输入法组合期间不触发 change，组合结束后触发一次。 | `boolean` | `semiDefault("TextArea", "composition", false)` |
| disabledEnterStartNewLine | 内部属性，供 Chat 使用：Enter 不换行，Shift + Enter 换行。 | `boolean` | `semiGlobalDefault("TextArea", "disabledEnterStartNewLine")` |
| showLineNumber | 是否展示行号。 | `boolean` | `semiDefault("TextArea", "showLineNumber", false)` |
| lineNumberStart | 行号起始值。 | `number` | `semiDefault("TextArea", "lineNumberStart", 1)` |
| lineNumberClassName | 行号区域的类名。 | `string` | `semiGlobalDefault("TextArea", "lineNumberClassName")` |
| lineNumberStyle | 行号区域的样式，数字需带单位。 | `StyleValue` | `semiGlobalDefault("TextArea", "lineNumberStyle")` |
| textareaStyle | 内部 textarea 元素的样式，可设置高度等，数字需带单位。 | `StyleValue` | `semiGlobalDefault("TextArea", "textareaStyle")` |
| resize | 是否允许拖拽调整尺寸及方向，可选 none、both、horizontal、vertical、block、inline；仅在显式传入时生效，autosize 开启时忽略。 | `"vertical" \| "block" \| "none" \| "both" \| "horizontal" \| "inline"` | `semiGlobalDefault("TextArea", "resize")` |
| maxlength | 最大长度。传入 getValueLength 时按它计算长度并截断，否则使用原生属性。 | `number` | `undefined` |
| minlength | 最小长度。传入 getValueLength 时按它换算，否则使用原生属性。 | `number` | `undefined` |
| getValueLength | 自定义计算字符串长度，搭配 maxlength、minlength、maxCount 使用。 | <ApiType detail={"((value: string) => number)"}>Type</ApiType> | `undefined` |

**Events**

| 事件              | 说明                                                                                                      | 回调参数                                                   |
| ----------------- | --------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------- |
| resize            | 尺寸变化时触发：autosize 导致高度变化时参数为 border-box 高度；拖拽调整尺寸时为内容区的 height 与 width。 | `[size: { height: number; width?: number \| undefined; }]` |
| update:modelValue | 内容变化时触发，供 v-model 回写。                                                                         | `[value: string]`                                          |
| change            | 内容变化时触发，参数为新值与事件；输入法模式下组合结束后触发一次。                                        | `[value: string, event: TextAreaChangeEvent]`              |
| clear             | 点击清除按钮时触发。                                                                                      | `[event: MouseEvent]`                                      |
| focus             | 焦点进入组件时触发。                                                                                      | `[event: FocusEvent]`                                      |
| blur              | 焦点离开组件时触发。                                                                                      | `[event: FocusEvent]`                                      |
| input             | 原生 input 事件。                                                                                         | `[event: Event]`                                           |
| keydown           | 原生 keydown 事件。                                                                                       | `[event: KeyboardEvent]`                                   |
| keyup             | 原生 keyup 事件。                                                                                         | `[event: KeyboardEvent]`                                   |
| enterPress        | 按下回车时触发（keydown），输入法组合中的回车不触发。                                                     | `[event: KeyboardEvent]`                                   |
| compositionstart  | 输入法组合开始时触发。                                                                                    | `[event: CompositionEvent]`                                |
| compositionupdate | 输入法组合更新时触发。                                                                                    | `[event: CompositionEvent]`                                |
| compositionend    | 输入法组合结束时触发。                                                                                    | `[event: CompositionEvent]`                                |
